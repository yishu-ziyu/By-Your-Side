# Raycast（闭源，只有截图）
- source: manual.raycast.com/settings, /ai/bring-your-own-key, /ai/bring-your-own-subscription, /ai/custom-providers（2026-10 抓取）
- screenshots: real-ui-subscriptions(-crop).png, real-ui-custom-providers(-crop).png, real-ui-manage-models.png
1. 结构：Settings → AI → Models & Providers，按「接入方式」分段：默认模型 / 本地订阅（账号登录）/ API Keys / Custom Providers / Local Models。
2. 状态：每段是一个圆角分组框，行间细线；账号行第二行 = 绿点 + 账号邮箱；API Key 行 = 图标 + 名称 + 删除 + ↗（去控制台）+ 开关；段标题右侧「+」加 key。
3. 默认模型行右侧直接显示当前模型 + ⌄（就地换）；自定义服务商行右侧写「N models」。
