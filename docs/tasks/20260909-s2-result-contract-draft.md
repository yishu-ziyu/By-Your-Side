# S2结果与纠正执行边界：主代理设计记录

已冻结可观察标准在docs/evals/20260909-s2-lifecycle.md。本记录只细化实现，不放宽标准。

- 通用结果登记是意图，不能由模型直接设置完成。每个结果有稳定id、描述、执行工具、目标约束；观察和写操作分开。
- 执行事件需关联run/member/toolCallId/工具名/目标。只有对应真实成功回执推进匹配结果；结果缺失/失败/取消/旧版本不能完成。
- TaskProgress仍是对外进度投影，不能新造与它平行的任务真相；Pi工具结果/会话记录承载恢复证据。TaskReceipt继续负责请求幂等。
- 改对象保留原任务和已完成项，待执行目标需要重新核对。接受纠正到模型消费最新输入之间，不能放行旧计划的页面写入。优先复用现有控制epoch与执行闸门，不能只写提示词。
- 恢复不自动执行unknown；若不能确认工具结果，查询或让用户决策。结果投影可恢复为未知，不能声称动作未发生。
- 新增普通能力通过工具注册/执行与验证接入，不增加语音关键词分类。
