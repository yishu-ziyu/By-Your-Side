# 任务调度与请求结果

文字与语音共用任务调度。语音接入和播放见[语音架构](voice-architecture.md)。

## 身份与入口

- 程序按任务自己的身份识别请求，不用当前可见会话替换原请求的归属。
- 上一个任务没做完、用户正在回答助手的问题时，文字新消息按插话续接原任务。见[记忆、过往任务与任务跨轮](memory-and-tasks.md)。
- 只有「终止任务」由任务宿主直接中止，见[语音架构](voice-architecture.md#停声不等于中止任务)。其他中止说法仍由模型转达。
- 读页不启动网页写任务，也不切换标签页。用户要切换标签页时，选没选对工具取决于语音模型，工具名或提示词不能保证。

## 请求结果

本节是请求结果语义的唯一说明。

- 请求结果只说明请求的去向，不说明网页目标已经完成。
- 已接收不证明网页结果成立。失败可能已部分完成，要读请求结果的内容。
- 程序不自动重做结果未知的一步。助手重读页面后可以重做。
- 执行前，程序先登记持久记录；出现异常时，记录保留不确定性。
- 结果交付和播放另有生命周期。不能从「已接收」或空闲推出「完成」。

## 页面、排队与恢复

- 恢复需要新的页面观察和原任务身份。断连或超时不代表已停手，也不代表已完成。
- 多个独立要求的准入与结果关联见[多要求设计](voice-multi-request-design.md)。容量是策略配置，不是服务承载量实测。
