By-Your-Side · Motion Language

一套动效语法：3 个时长 + 3 条曲线，配 6 个动作动词。目标不是"多加动画"，而是让控件像有物理性的东西——按下去有反馈，状态之间是变成而不是消失又出现。每张卡都能点，卡里可切"现在 / 改后"。

按钮类要按住才看得到按压；其余点一下播放。
01

press

所有可点控件

按下去要有"按到了实心东西"的反馈，松手回弹。力度必须一致，否则整个产品的手感是散的。

现在 scale(.86) / 180ms / spring-bounce
另一个按钮是 .95，第三个没有反馈

改后 统一 scale(.94) · 压下 120ms swift，回弹 240ms spring

问题：0.86 在 30px 的圆上像被捏扁；三个控件三种力度，用户说不出哪里怪，只觉得不精致。

收益：所有按钮同一种手感，像同一台机器上的按键。

02

morph

发送 ↔ 停止

同一个按钮，两个身份之间连续变化。这是产品里唯一已经做对的动作，我把它定成范式。

已是 圆→圆角方 / 黑→红 / ↑ 转 90° 退出、■ 反向转入 · morph 350ms spring

形状、颜色、图标同时在变，用户读到的是"它变成了停止键"，而不是"图标换了"。这一条不需要改动。

03

reveal

模型选择器

面板要从触发它的那颗按钮"长出来"，而不是在别处淡入。用户的眼睛在按钮上，动效得接住它。

DeepSeek V4 Flash
GPT-5.6 Luna
MiniMax M2.7

现在 缩放 .94 + 上移 6px 淡入 · 260ms spring-bounce（9.7% 回弹）
origin 固定在左下角

改后 从按钮中点长出 · 240ms swift · 列表项 20/45/70ms 依次落位

问题：回弹曲线用在"展开面板"上太活泼，像弹窗；origin 和按钮的实际位置无关。

收益：面板和被点的东西有空间关系，眼睛不用重新找。

04

settle

工具步骤完成

步骤跑完时，图标不该"啪"地换一个，而是从"正在跑"收束成"完成了"。

读取页面结构 1.2s

现在 replaceChildren(icon(List)) —— 一帧内直接替换，没有任何过渡

改后 转动的点先收束退出（240ms），勾从同一点旋转展开（延迟 90ms，360ms），耗时数字随后推入

问题：动作完成是用户唯一会"被奖励"的时刻，现在这里是最生硬的一帧。

收益：完成有交代，用户能感到这一步真的结束了。

05

breathe

Agent 正在工作

持续进行中的状态（不是一瞬间的动作）。已定稿的方案 B：三件事各有自己的球。

映射 思考 → composing（飘带）· 调用工具 → solving（色带归位）· 记忆 → connecting（星座接线）
尺寸 20px 行内档，深色自动换 ink

收益：跑起来的时候，面板里一直有个活着的东西在转，用户不用读文字就知道 Agent 没死。

06

trace

网页元素被定位

Agent 在页面上找到目标、点它、收起标记。三个阶段各自该多快，现在没有规定。

展开 5 小时用量详情

现在 出现 160ms ease，再加一段 500ms 呼吸
另一处涟漪用 480ms cubic-bezier(.22,1,.36,1)

改后 出现 120ms swift → 保持原位 → 点击涟漪 240ms → 消退 240ms swift

问题：出现、停留、消失三段的时长各写各的，页面上看到的节奏和侧栏对不上。

收益：页面上发生的事和侧栏里发生的事，是同一个节奏。
