记忆方案（草案，等你拍板）

依据：你说的"范围 × 有效期"；项目 9/08 以来七次记忆决定；ChatGPT、Claude、Zep、Mem0、Browser Use 等的做法与公开研究（10-01 调研）。

一、你的框架：每条记忆都回答两个问题

长期有效有时间或条件
到处都适用邮箱、生日、爱吃辣、坐飞机要靠过道、"回复我用中文""10 月 3 日飞成都" —— 行程结束前订酒店、叫车都用得上，结束后退场
"这周在上海出差"
只在某处适用"在这个客户系统导出要选全部"
"12306 改签点'改签'，别走退票"		"这次报销要附发票" —— 只对这一件事

现在的产品只有"到处 / 某个网站"这一个维度，没有有效期。所以"3 号的航班"没地方放。

二、四种记忆（业界通行的分法，换成大白话）

① 这件事的要求

只活在这次任务里
"不对，我要的是 3 号的航班"
"只看京东自营"
谁记：自动　存哪：这次对话
怎么用：每一步都带着
多久：任务结束就清，内容转进 ②

② 做过的事

你的经历，带日期
"10/3 在携程订了北京→成都，东航"
"上次翻这篇论文，你把 attention 改成了'注意力'"
谁记：自动　存哪：本机
怎么用：日期没到前主动带上；过了就只在你问起时查
多久：带有效期，过期改成"过去时"

③ 关于你

跨任务成立、会改变以后结果
邮箱、生日、爱吃辣
"坐飞机都要靠过道"
谁记：你明说→直接记+可撤销；它猜出来的→先问你
怎么用：每次都带（条数少）
多久：长期；被新的替换时旧的留历史

④ 做事的方法

某网站怎么做成、你对它做法的纠正
"这个客户系统导出要选全部"
"别每次下单前都让我确认"
谁记：它总结→你点"记住"
怎么用：打开对应网站时带上；关于它做法的，到处带
多久：在该网站上反复失败就提示可能过时

三、你说一句话，它怎么判断记成哪种（按顺序，先中先停）

  1. 来自网页的文字 → 一律不记 不记 （网页注入：2024 ChatGPT、2025 Gemini、2025 Atlas 都出过事；研究中注入成功率 98%）
  2. 密码、验证码、证件号、银行卡 → 一律不记 不记
  3. 你明说"记住 / 以后都 / 忘掉" → 照办，并告诉你记在了哪个范围 直接记
  4. 改这次任务的参数（"我要 3 号"）→ 只改 ①，任务结束后进 ②（带日期） 自动
  5. 你原话里说出的长期事实或偏好（"我邮箱是…""我吃不了辣"）→ ③ 直接记+撤销
  6. 它从你的行为里猜出来的规律（连续三次选靠过道）→ 先问你一次 问你 （2026 审计：ChatGPT 超过 95% 的记忆是它自己推断的，用户普遍感到意外）
  7. 你纠正它的做法（"不对，导出要选全部"）→ 它总结成一条 ④，出卡片，你点"记住" 你确认
  8. 其余 → 只在 ② 里留一笔 自动

统一的原则一句话：记忆内容就是你的原话 → 直接记，给撤销；需要它归纳或猜 → 先问你。
这一条同时解释了项目过去看似矛盾的两次决定：资料自动记（是你原话），纠正规则要确认（是它归纳的）。

四、默认范围怎么定（回答之前"用中文回复"那个问题）

哪种默认范围例子
③ 关于你到处邮箱、生日、爱吃什么
④ 关于它做事方式的纠正到处"回复我用中文""别每次都让我确认"
④ 关于某个网站操作的纠正这个网站"这个客户系统导出要选全部"
② 做过的事按日期或那件事"10/3 飞成都"只在行程结束前主动带

卡片上都能改。研究（BenchPreS 2026）提醒：模型容易把偏好当成到处都要照做，所以网站相关的默认收窄。

五、每次干活前带哪些（分三层，不全塞）

层带什么为什么
总是带③ 关于你 + 到处适用的 ④ + 有效期内的 ②（如这周的行程）少而关键，设上限
按网站带当前网站的 ④ + 这个网站最近几次 ②按网址精确匹配，说得清为什么带
需要才查更早的 ② 和别的网站的 ④它用"查记忆"去找，侧栏显示"查了记忆"

各家的共同做法："一小份常驻 + 其余按需查"（Claude Code、ChatGPT、Letta）。

六、怎么知道记忆真的好用

看什么怎么量
记得对不对从你真实记录里抽样，人工标"该记成哪种/不该记"，看它判对多少；重点数"一次性的事被记成长期"
用得对不对该用时用上、不该用时不乱用（照 BenchPreS 的两个比率）；过了有效期的不再主动出现
你的感受同一句纠正你要说几遍；你删掉记忆的次数；"它记住了"的时刻

七、和现在比，要补什么

要补现状
每条带"种类、范围、有效期、原话、用过几次、状态"只有内容和范围
② 做过的事带日期和有效期只有最近 200 条摘要，没有有效期
④ 做事的方法（纠正卡片）代码写好了，没接进扩展
"它猜的先问你"没有
"查记忆"工具没有
检查方法（上面第六节）只有零散的测试
