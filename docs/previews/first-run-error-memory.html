二、出错：不管什么错，都只有「继续原任务」

现状：401 点继续也没用 · 429 文案说「在下方换模型」但下方没有入口 · 测试失败露出原始 JSON

原则：错误卡的按钮要指向病因。key 无效 → 去换 key；额度满 → 换模型或等；断网 → 重试 + 网络恢复自动重试。原始报错收进「技术详情」，默认不示人（Nielsen #9；ChatGPT/Claude 都是 Retry + Switch model 双按钮）。

现状

一个按钮应付所有错

401 的「继续原任务」点了还是 401；429 文案承诺的「下方换模型」不存在。

三、记忆：能看、能忘，但不能改、不能找

更正一个事实：记忆抽屉已经存在（顶栏数据库图标），问题是发现性 + 缺编辑/搜索

代码事实：main.ts:193 的 memory-drawer 已能列记忆、忘掉、恢复旧任务。缺的是：①入口太隐蔽（顶栏一个数据库图标，没有名字）②不能改内容，记错了只能整条忘掉 ③不能搜索筛选。对照 ChatGPT「Manage memories」：列表 + 逐条删除 + 总开关；Claude 还支持编辑。

推荐方案 A

抽屉补强：编辑 + 搜索

不加新界面，把现有抽屉补完整：顶部搜索框、每条可「改」（内联编辑）、忘掉后可撤销。分组按范围（全局 / 本站）。都可以点：试试搜索「马拉松」，或点「改」。
