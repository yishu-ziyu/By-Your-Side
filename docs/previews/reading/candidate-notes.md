# 回答正文宋体候选 — 说明

- 正文 15px / 行高 1.72：比现网 14px/1.85 略大、行距略紧，重心从松弛转向密排，压掉整页留白。
- 宋体栈优先 Songti SC，退化到 STSong / Songti TC / SimSun / serif；不含内嵌字体、不引 CDN。
- 标题沿用宋体，仅按字号（19 / 15.5）与字重分层；段距 8/12、列表 6/12，控制在中文字体常见比例。
- 表格降到 13.5px 并保留横向滚动；长链接用 overflow-wrap 兜底，未在真机 320px 逐条取样。
- 未验：无 Songti 环境（Windows/Linux）退化为 serif 的观感、宋体合成粗体在深色主题下的对比、与光球/状态区的实际并置。
