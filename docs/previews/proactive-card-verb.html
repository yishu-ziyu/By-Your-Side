主动卡：动词即按钮，按下原位接着说

从 Hark Pro 4:40–5:40 学来的理念，嫁接到我们侧栏。基准是我们的产品：奶油纸面、同一组圆角和字号、助手回复仍是纸面上的文字而不是气泡，并保留我们的特质——每个动作有名字、耗时和结果态，卡片写明出处。

要判断 1：第一个词当按钮，读完句子就等于看完后果吗要判断 2：按下后原位变成助手的话，比跳到别处找结果好吗要判断 3：出处行和步骤 chip 留着，是否已经够克制

方案 · 侧栏对话流（点动词试试，或按「自动演示」）

这段视频里学到的，以及这里怎么用

  • 一张卡 = 一句话，第一个词是按钮。 金额、日期、商家在句子里，没有标题/正文/CTA 三段。这里照搬，但加了一行出处（我们的「可依赖」）。
  • 按下后卡片原位变成助手的话。 Hark 变成气泡；我们的助手回复本来就是纸面文字，所以壳淡掉、文字长出来，不换容器。
  • 结果固定三段： 在做什么 / 一个具体细节证明理解了 / 接下来或兜底。付款类写明「用你存的凭据」。
  • 两个退路： 对卡提问（这里是放进输入框）、取消（×）。「取消后以后不再出」Hark 只说未来会有，这里不承诺。
  • 视频没展示的： 一按付款没有二次确认、没有失败态。本预览按你的决定一按即执行；失败态另排。
