# 结果未知的边界

「结果未知」指一个可能造成后果的动作出错或超时，程序不知道它做成了没有。

- 程序把这一步记成「结果未知」，不记成「失败」。这只是如实记账：程序不暂停写入，也不拦重做。助手先重读页面，再决定是否重做。
- 以前有一把结果未知锁，挡住可能重复造成后果的调用。用户决定去掉它。代码里仍有带「lock」字样的名字，但它们只决定这一步怎么记账，不拦调用。
- 去掉锁的代价：助手可能重复一个已经生效的动作。付款不受影响，因为助手永远不点付款按钮（见[网页操作不再逐次确认](browser-confirmation.md)）。
- 扩展后台重启后，有结果未知步骤的任务不自己接着做，等用户点「继续原任务」。接管、中止和重启都不重放原动作。
