# 网页操作不再逐次确认

助手在网页上的操作直接执行，不弹批准卡（产品负责人决定，见[验收](evals/20261004-remove-approvals.md)）。删除、发送、支付、提交类按钮也不再拿住等确认；没有受信任网站名单。

仍然保留：

- 结果未知锁：写入结果未知时，程序不重复执行。助手停下来如实告诉用户；用户在会话里决定是否继续（见[结果未知](unknown-results.md)）。
- 用户接管、交还与中止；派发前仍检查任务身份与控制轮次。
- 无进展、重复失败自动停下，以及目标核对。
- 凭据脱敏、隔离环境读取页面。
- 记忆照常作为上下文交给模型，纠正后的“要我记住吗”照常询问。

已知后果：网页里注入的恶意指令可能让助手在已登录的网站上点击、发送或提交，不再有逐步确认来拦。

原生弹窗：点击或按键弹出 alert/confirm/prompt 时，回执说明弹窗内容；助手按用户意思确认或关闭。
