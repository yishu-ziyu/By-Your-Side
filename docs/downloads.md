# 文件下载

[协议](protocol.md) · [使用说明](guides/usage.md#下载文件) · [验收入口](testing/acceptance.md)

本页是下载行为的唯一说明。

## 页面下载

- 助手先订阅下载事件，再点页面的下载入口。Chrome 把文件存进用户的下载文件夹。
- 是否下完只看 Chrome 的下载状态。中断算失败。
- 不用调试通道的 `Page.setDownloadBehavior`，因为扩展调试通道拒绝这个浏览器级命令（[09-23 记录](evals/20260923-ci-gate-failures.md)）。

## 点击期间开始的下载

- 助手没先订阅就点了下载入口时，点击回执也写出这次点击期间开始的同网站下载，以及 Chrome 报告的结果。
- 这样做是因为以前这种下载不进任何回执，助手和目标核对都以为没导出，于是一再重导（[10-08 验收](evals/20261008-download-result.md)）。
- Chrome 的下载没有标签页归属，所以回执只说下载「在这期间开始」，不断言下载由这次点击产生。

## 按链接下载

- 按链接下载用于链接只打开 PDF 阅读器的情况。
- 按链接下载沿用页面控制和控制闸门，不增加权限。
- 只有 Chrome 报完成才算存好。没下完时返回下载编号；助手不为查询再下一次。
- 危险下载留给用户在 Chrome 里决定。
- 程序按 Chrome 返回的编号登记并检查会话归属，不按 URL 匹配，免得串到别的下载。
- 登记只在扩展后台内存里。扩展后台重启后，旧编号查不到。

验收见 [PDF 下载](evals/20261002-pdf-download.md)。
