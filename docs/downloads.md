# 文件下载

本页是下载行为的唯一说明。

## 页面下载

- 是否下完只看 Chrome 的下载状态。中断算失败。
- 不用调试通道的 `Page.setDownloadBehavior`，因为扩展调试通道拒绝这个浏览器级命令。

## 点击期间开始的下载

- 助手没先订阅就点了下载入口时，点击的工具结果也写出这次点击期间开始的同网站下载。因为以前这种下载不进任何工具结果，助手和目标核对都以为没导出，于是一再重导。
- Chrome 的下载没有标签页归属，所以工具结果只说下载「在这期间开始」，不断言下载由这次点击产生。

## 按链接下载

- 按链接下载用于链接只打开 PDF 阅读器的情况。它沿用页面控制和控制闸门，不增加权限。
- 危险下载留给用户在 Chrome 里决定。
- 程序按 Chrome 返回的编号登记下载，不按 URL 匹配，免得串到别的下载。
- 登记只在扩展后台内存里。扩展后台重启后，旧编号查不到。
