# SideAgent 桥接协议

本页写扩展后台与任务宿主之间协议的语义与边界。消息与字段以 [`shared/protocol.ts`](../shared/protocol.ts) 为准。任务身份、请求结果与语音见[语音架构与调度](voice-architecture.md#任务调度多要求与请求结果)。

## 连接

- 只有一个客户端：新连接握手成功，就顶替旧连接。
- 配置完成前，只读查询不报任务失败；真正的任务输入返回明确的拒绝结果。

## 会话身份

- 会话 ID 标识用户会话，执行成员 ID 标识会话里的执行者。现在执行成员只有 Lead。
- 状态、工具调用、结果和控制确认始终按原会话路由。切换侧栏不改变事件归属。
- 每个会话有自己的循环、页面控制、上下文、控制闸门和历史。新建会话 B 不中止会话 A。

## 任务与页面控制

- 页面控制归用户时，任务既不是空闲，也不是中止。
- 插话附带当前页锚点，免得助手在插话后丢失工作标签页。
- 侧栏文字插话到达时，如果模型还在写正文：已写部分保留，同一轮立刻按插话重写。语音插话和工具阶段仍等这一步结束。
- 接管时，程序先挡住目标页的新写入，等在途短动作到达安全停止点，再暂停。其他会话的独立页继续运行。
- 交还时，程序读取绑定页的新快照。页面已关闭或读取失败时，保持暂停，不用当前活动页顶替。部分失败时，不写成全部已恢复。
- 晚到或重复的结果只关联任务账本，不画新卡片。
- 程序拦下重复已成功的写入时，这次写入没执行，不算失败，也不留待办。
- 点击效果证据只说明页面有反应，不说明业务成功。

## 工具调用

- 工具执行不经过侧栏。关闭侧栏不中止任务。
- 扩展侧出现任何异常，都回失败和一行人能读懂的错误，不挂断不回。
- 发出前就被拒绝的调用记为没执行，错误里说明可行的替代做法。
- 点「发送」按钮前，扩展在网页上等用户确认；教学的一步也在调用里等用户自己点。等的时候，宿主放宽这次调用的期限，所以等用户不会被记成结果未知，而卡住的普通点击仍按原期限超时。
- 用户没让发（点「不发」、停下、接管、离开网页、等确认超时）时，结果记为没执行，不算工具出错，也不算失败的一步。教学的一步没完成也这样记。
- 整页翻译按落页进度决定何时停止，不受单次工具时限约束，见[整页翻译](artifacts.md#整页翻译)。

## fetch 读取

- 扩展内 `fetch` 不写本机文件。响应隐去凭据、加不可信包装后内联。
- 截断时明确说明。

## 工作标签页

- 标签页一律独占。执行成员绑定工作标签页，不取代标签页的资源归属检查。
- 会话第一次认领页面时，才建该会话的 Chrome 标签组。纯聊天不建空组。标签组只用于展示。
- Lead 可跨会话只读页面，不认领页面。
- 操作其他会话的页面前，先接手：停下原会话，等扩展的旧调用结束，再继续。读取不需要接手。
- 接手时，程序用检查到的会话身份防止覆盖并发的归属变更。
- 查活动页只读，不自动认领。用户可以把没有归属的活动页明确借入当前会话。
- 未显示的会话不抢标签页焦点。

## 读元素与定位

- 读元素不滚动、不聚焦、不改页面，也不接受任意脚本。
- 读数或批量输出超过安全上限时，程序明确报错，不返回截断值或部分命中。所以原值核验不会拿截断值去比。
- 条件检查匹配只说明该目标的该条件成立，不能单独推出整项任务成功。
- 定位串失效、找不到或匹配多个元素时，明确报错，不猜另一个目标。
- 按文字定位的目标在点击、填写那一刻再核对一次文字。文字不在了，或同样的文字渲染到别的元素上，程序就停下，记为没执行。
- 页面刷新或跳转后，只拒绝指向旧快照的元素编号。
- 悬停和点击只确认事件已派发，不证明编辑器已打开或任务已完成。
- 截断文字与数字框范围见[页面读数](web-actions.md#页面读数截断文字与输入范围)。

## 侧栏恢复与持久化

接受任务和发送浏览器 RPC 前，程序等待存储提交；提交失败就不执行。恢复规则见[扩展会话恢复](memory-model.md#存储与扩展会话恢复)。

记忆与跨轮见[记忆、过往任务与任务跨轮](memory-model.md)和[目标核对](goal-check.md)。文件卡片见[文件、下载与页面阅读](artifacts.md)。

## 安全

- 网页操作不弹批准卡，见[网页操作不再逐次确认](web-actions.md#网页操作不再逐次确认)。
- 双击或按键遇到原生弹窗时，程序中断后续输入。

## 本机诊断记录

- 诊断记录写入失败不改变任务结果。诊断记录只是证据，不用来自动停止任务或判定业务成功。
- 本机记录保留哪些原文、导出时遮住什么，见[使用说明](guides/usage.md#数据和权限)。图片只留元数据。任务和页面文本仍属本机私密数据。

## 划词转入与页面微交互

这些消息走扩展内部的界面通道，不进模型任务消息。

- 划词转入：网站、标题与标签页身份取自 Chrome 的发送方信息，不信任页面传来的值。这条中继不发任务、不调模型。
- 来源回查用发送时固定的页面身份，回查时再比对原文。程序不凭当前活动页给历史回答补来源。
- 拖入材料：扩展后台按原文重新比对，侧栏不相信拖拽数据。拖入不扩大任务权限。
- 快捷动作不进任务、不调模型。内容脚本只认扩展页发来的消息。
- 边注：AI 解释不进任务、不做网页操作，也不写记忆。导航后，旧文档不能清空新文档的边注。
- 主动建议：引文逐字出现在页面里才出卡；卡上的对象名也要在页面里出现过。失败只回空，不进会话。
  侧栏关着时，建议只填进输入框，由用户改过再发。侧栏开着时，用户按句首动词，就交给助手执行，不再问。
