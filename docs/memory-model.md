# 记忆、过往任务与任务跨轮

本页只写代码里看不出的理由。

## 记什么、不记什么

原则：**记下的内容就是用户原话 → 直接记，可撤销；需要助手归纳或推断 → 先问用户。**

- 网页、附件和工具结果里的文字一律不记；密码、验证码、证件号和银行卡一律不记。
- **对回答方式的反馈不用关键词初筛**：10-21 的「解释太干巴了」「你从来没用卡片」「现在就清晰多了」都被初筛漏掉；用 10-06 至 10-21 的 169 句真实原话离线评测（考卷原话不进提示词），5 句沟通反馈全部判出，其余 161 句零误报，中位 1.8 秒。

## 过往任务

- 平时只带「做成了什么」，不带当时的回答：防止助手不看当前页而照抄旧价格。

## 备份

- 卸载扩展时 Chrome 会删掉它的全部存储，所以记忆要另存到下载文件夹。
- 备份是明文文件，所以浏览记录、习惯计数和还没判完的原话不进备份：这些由网页内容生成，可能带网址里的 token。
