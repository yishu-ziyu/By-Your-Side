# 记忆模型

2026-10-01 用户定稿（[路线图](ROADMAP.md)第 10 条）。本页定义记什么、记成哪种、用到哪里、到什么时候；已实现的接口与存储以[记忆与任务跨轮](memory-and-tasks.md)为准。每条标注现状：**已有** / **待做（第 N 块）**，块的进度见[当前状态](STATUS.md)。调研依据与方案页见 [10-01 记忆方案](previews/20261001-memory-model.html)。

## 每条记忆回答两个问题

| | 长期有效 | 有时间或条件 |
|---|---|---|
| 到处适用 | 邮箱、生日、爱吃辣、「回复我用中文」 | 「10 月 3 日飞成都」：行程结束前订酒店、叫车都用得上，结束后不再主动带 |
| 只在某处适用 | 「这个客户系统导出要选全部」 | 「这次报销要附发票」：只对这一件事 |

现状：「到处 / 某网站」范围与有效期都**已有**（有效期第一块做完，2026-10-01）；「这次报销要附发票」这类只对一件事的要求仍只留在对话里。

## 四种记忆

| 种类 | 例子 | 谁记 | 存哪 | 怎么带给助手 | 到什么时候 | 现状 |
|---|---|---|---|---|---|---|
| ① 这件事的要求 | 「不对，我要的是 3 号的航班」「只看京东自营」 | 自动 | 这次对话 | 这次任务每一步都在 | 任务结束；内容转进 ② | 已有（对话上下文与任务账本） |
| ② 做过的事 | 「10/3 在携程订了北京→成都，东航」 | 自动，任务结束时 | 本机扩展数据库 | 有效期内主动带（当前网站最近几条 + 有效期内的行程类）；过期后只在用户问起或助手查时出现 | 带日期与有效期，过期改为过去时，仍可查 | 已有：摘要（最多 200 条，当前网站最近 3 条）、用户说的带日子的事、任务结束时立即记下、日期与有效期稍后补上（任务没被删、没被同一任务的新记录覆盖才补）；同一任务再次记录时沿用用过几次与原日期，带给助手的任务也算用过 |
| ③ 关于你 | 邮箱、生日、「坐飞机要靠过道」 | 用户原话说出 → 直接记，给「撤销」；助手推断的 → 先问用户 | 本机扩展数据库 | 每次都带（有上限） | 长期；被新值替换时旧的标为「被替换」留历史，可来回撤销、始终只有一个生效；「忘掉」生效的值连同全部旧值一起删，只忘某条旧值则只删那一条，前后的历史接上；被替换或失效的旧值可点「撤销」恢复成唯一生效的值，原来生效的变为失效；忘记或撤销后列表马上刷新 | 原话自动记、「被替换」留历史与撤销已有；「推断先问」待做 |
| ④ 做事的方法 | 「这个客户系统导出要选全部」「别每次下单前都让我确认」 | 用户纠正后助手总结 → 出卡片，用户点「记住」才生效 | 本机扩展数据库 | 网站操作类在该网站带；关于助手做事方式的到处带 | 长期；在该网站反复失败时提示可能过时 | 纠正后开口问、点「记住」才存、在该网站总是带已有（第二块，2026-10-01）；「改一下」、反复失败提示过时待做 |

## 一句话记成哪种（按顺序，先命中先停）

1. 来自网页、附件、工具输出的文字 → 不记。
2. 密码、验证码、证件号、银行卡 → 不记，原话也不进任何记录。
3. 用户明说「记住 / 以后都 / 忘掉」→ 照办，并告诉用户记在哪个范围。
4. 改这次任务的参数 → 只改 ①；任务结束后进 ②，带日期。
   用户此刻让助手去做的事（订票、买东西）带的日期就是任务本身，这时还没做完，不记；任务结束时记成「做过的事」，带那天的日期。
5. 用户原话说出的长期事实或偏好 → ③，直接记，给「撤销」。
6. 助手从行为里推断的规律（如连续几次选靠过道）→ 先问用户一次再记 ③。
7. 用户纠正助手的做法 → 助手总结成一条 ④，出卡片，用户确认。
8. 其余 → 只进 ②。

现状：1–5、7、8 **已有**（模型只答窄问题，代码按此顺序落位；带日子的事记成 ②、有效期到那天结束；7 是纠正后开口问，用户点「记住」才存）；6 待做。

保存或更新时，模型必须明确回答「长期事实」和「只对这次任务」；缺失或畸形会拒绝写入，再由已有有界补判处理。纠正消息的候选个人记忆还要经过现有做法判断：可复用做法不直接写入，留给确认卡片；靠过道、邮箱等个人资料仍可自动记。混合消息中，纠正判断也指出独立个人资料原话、该原话包含候选资料依据，且与做法原话唯一并互不重叠时，分别处理：资料自动记，做法仍需确认；无法分开时不自动写入。模型调用改记忆工具遇到做法时，会收到确认卡片的操作说明，而不是宣称不能跨会话保存。同一句做法判断与卡片复用，卡片出现前仍重新核对范围和替换目标。此边界依赖模型正确理解内容，格式拒绝由代码执行。

原则：**记下的内容就是用户原话 → 直接记并可撤销；需要助手归纳或推断 → 先问用户。** 这解释了已有两个决定为何不同：资料自动记（原话），纠正规则要确认（归纳）。

## 默认范围

| 种类 | 默认 | 例子 |
|---|---|---|
| ③ 关于你 | 到处 | 邮箱、生日 |
| ④ 关于助手做事方式的纠正 | 到处 | 「回复我用中文」 |
| ④ 关于某网站操作的纠正 | 该网站 | 「这个客户系统导出要选全部」 |
| ② 做过的事 | 按有效期 | 「10/3 飞成都」行程结束前主动带 |

只有 http(s) 网页算一个网站：扩展页、浏览器自己的页面是「没有当前网站」，不对上任何网站的记忆；纠正发生在这类页面上时，用助手最近操作过的网站，没有就不问关于网站的做法。

卡片上都可改。网站相关默认收窄，因为模型容易把某处的偏好当成到处都要照做（BenchPreS，2026-03）。

## 已确认方法如何影响提交

对已确认且有效的方法，宿主只把明确“填/填写/填上「字段」”的肯定规则变成提交前检查；带未解释条件或否定的不编译，不把自动经历当强制规则。每次真实操作重读，删除和替换不沿用旧缓存。字段、主机名和实际表单必须匹配。

字段空、缺失、多个候选或不可读时，点击和提交Enter不执行。没有内容先问用户。模型不能用“无备注”等占位话代填；填写值须逐字来自当前任务用户输入，或有效个人资料的内容和来源原话，原文复制也可用既有核验通过的材料；不从过往任务、方法或助手推断中恢复值；未核对的生成草稿需用户明确提供内容。允许后续确认沿用本任务已提供的值，网站限定资料的来源证明仍绑定该网站。当前用户明确“这次备注留空”只取消本任务要求，长期规则不变。只实现确定形态，不能代替任意自然语言方法理解。

受约束网站不能改用脚本、直接POST或低层输入绕过；普通读页、GET、导航和其他字段照常。参数和控件范围见[协议](protocol.md)，验收见[提交前执行](evals/20261003-method-form-enforcement.md)。

## 每次干活前带哪些

1. **总是带**：③、到处适用的 ④、有效期内的 ②；各设上限（**已有**）。
2. **按网站带**：当前网址精确匹配的 ④ 与该网站最近几条 ②（**已有**）；用户确认过的 ④ 在该网站总是带，自动总结的仍要对得上这件事。
3. **需要才查**：更早的 ② 与其他网站的 ④，由助手用「查记忆」查，侧栏显示「查了记忆」（待做）；过期的 ② 现已能经过往任务查询查到。

每轮带了哪些、为什么带，与每句话判成哪种，各写一条决定记录进诊断记录（**已有**）。

暂不用语义向量检索：几百条规模下网址精确匹配更准、说得清为什么带。

## 每条记忆存什么

种类、内容、范围、有效期（开始、结束或「随这件事」）、来源原话、创建与修改时间、用过几次与上次用上、状态（生效 / 被替换 / 失效）、格式版本号。现状：全部**已有**（第一块，格式版本 3，旧数据读入时升级并补默认值；字段名见[记忆与任务跨轮](memory-and-tasks.md#个人记忆)）。扩展已申请「不限存储」权限（**已有**）；导出 / 导入在纠正卡片之后紧接着做。

## 怎么检查

| 看什么 | 检查 |
|---|---|
| 记成哪种判得对不对 | 从用户真实记录抽样，人工标「该记成哪种 / 不记」，数判对多少；重点数「一次性的事被记成长期」 |
| 用得对不对 | 该用时用上、不该用时不用；过了有效期不再主动出现；每次多带多少字 |
| 用户感受 | 同一句纠正要说几遍；用户删掉记忆的次数 |

具体场景：底座见 [20261001 记忆底座](evals/20261001-memory-foundation.md)；纠正卡片见 [20261001 记住我的纠正](evals/20261001-remember-corrections.md)。

## 10-01 架构与交互调研后的决定

依据：[调研页](previews/20261001-memory-design.html)（DDIA 对照现有实现；Mem0、Zep、Letta、Claude、ChatGPT、Copilot、Cursor；CHI 2025/2026 记忆研究）。

- **先加固底座，再做纠正询问**（**已有**，2026-10-01 加固块；纠正询问随后做完，见上文规则 7）：同一件事一个编号、写入前自动检查「只有一个生效值」，不满足就拒绝写；过往任务读到看不懂或损坏的数据时只读、绝不覆盖；「要不要记」失败留记录，任务结束后补判，用消息编号防重复；整份记忆带递增版本号，面板发现变了就重读；记忆写入用严格持久模式；诊断记录只存编号、不存原话。不上同步引擎、不以操作日志为唯一数据源、不拆分存储。
- **回答下方显示用了哪些记忆**（待做）：用到记忆就有一行「用了 N 条记忆 ›」，默认折起；某条记忆改变了助手的做法时自动展开，写明「因为你之前说过……」。
- **「这里别用」**（待做）：只在当前网站不再用这条，记忆保留；记忆面板里写明「在某网站不用」，不装作已删除。
- **过期的安排**：留在原处变灰、写「已过期」，不再主动用，问起仍可查（与现状一致）。
