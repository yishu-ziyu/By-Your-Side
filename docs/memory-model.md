# 记忆、过往任务与任务跨轮

[文档导航](README.md) · [当前状态](STATUS.md)

本页写记忆、浏览习惯、过往任务、任务跨轮与会话恢复的设计理由和边界。

## 四种记忆与两个维度

每条记忆按「到处适用 / 只在某网站适用」与「长期有效 / 有时间或条件」切分（只管当前这一件事的要求留在对话里）：

| 种类 | 例子 | 谁记 | 到什么时候 | 默认范围 |
|---|---|---|---|---|
| ① 这件事的要求 | 「不对，我要的是 3 号的航班」 | 自动 | 任务结束转进 ② | 当前任务 |
| ② 做过的事（过往任务） | 「10/3 在携程订了北京→成都」 | 自动，任务结束时 | 过期后改为过去时，不再主动带，问起仍可查 | 按有效期 |
| ③ 关于你 | 邮箱、「坐飞机要靠过道」 | 用户原话说出 → 直接记，可撤销；助手推断的 → 先问 | 长期；新值替换旧值，始终只有一个生效 | 到处 |
| ④ 做法（「做事的方法」） | 「这个客户系统导出要选全部」 | 明确的网站操作纠正 → 自动记、可删除；其他归纳 → 点「记住」才生效 | 长期 | 网站操作归该网站，做事方式归到处 |

## 记什么、不记什么

原则：**记下的内容就是用户原话 → 直接记，可撤销；需要助手归纳或推断 → 先问用户。**

- 网页、附件和工具结果里的文字一律不记；密码、验证码、证件号和银行卡一律不记。
- **网站操作纠正**：只依据用户直接发的那句原话判断，不用历史补全含糊指代；明确可复用才自动保存（只留规则与会话来源，不复制同句里的个人资料），涉及某网站的纠正默认收窄到该网站。如果归纳出的做法里出现了原话没有的邮箱、网址或长数字，助手不问也不存。
- **浏览习惯归纳**：开关默认打开。用户自己在 http/https 网页上的打开、点击、搜索和填写（密码与卡号除外；助手执行任务的操作不计入）保存在本机，在「记忆 → 看到的操作」中可逐条删除或清空。同一件事出现在 **2 个不同日子**里，侧栏才问一次「你好像每次都这样做：…。要我记住吗？」，点「记住」才成为做法；天数直接按送检记录现算，删掉记录就不再计入。
- **对回答方式的反馈**：每轮答完后，快速模型在后台复盘用户刚说的那句话是不是在评价沟通方式（图示与卡片、长短、深浅、带入情境、语气、主动性），只判这一类，不判任务内容。一句抱怨不成规则：用户明说「以后都 / 从来没」、「抱怨 → 改了 → 认可」成对出现，或同一方面在两个回合被抱怨，侧栏才问一次「…，要我记住吗？」并折叠列出用户说过的原话；问过的方面不再问。点「记住」存成到处适用的做法，每轮单列为「用户要你怎样工作」交给模型，优先于默认的格式与卡片规则。自动记忆不收这类话，免得同一句被记成两条。为什么不用关键词初筛：10-21 的「解释太干巴了」「你从来没用卡片」「现在就清晰多了」都被初筛漏掉；用 10-06 至 10-21 的 169 句真实原话离线评测（考卷原话不进提示词），5 句沟通反馈全部判出，其余 161 句零误报，中位 1.8 秒。`npm run memory:report` 按周看抱怨、认可、提问卡被点或没理，以及「记住后同类又抱怨」（应为 0）。
- **说一句话就打开记住的网址**：用户原话教过「以后我说 X，就打开这几个网址」时，再说 X，任务宿主开工即并行打开原话里的网址，模型只回一句，本轮不动网页、不做目标核对；原话含「不要、别、除了」或插话后照常交给模型与核对。
- 中止、接管或新任务会取消在途的旧学习；删除、编辑或替换规则后，在途旧判断不再写回。重开侧栏按当前保存状态显示。

## 过往任务与任务跨轮

- **过往任务**：只记做成了事（会产生外部效果）或未做完的任务，只读查询不记。平时带给助手的只有「做成了什么」，不带当时的回答（防止助手不看当前页而照抄旧价格）；用户主动问起过往时，查过往工具才附上当时的回答并标明可能过期。写入前只隐去密码、验证码、卡号等敏感值。
- **任务跨轮**：上一个任务部分完成时，程序按本地规则判断下一句是否算接着做，不调用模型；接着做时保留原任务身份与目标。

## 每次干活前带哪些、回答里怎么显示

每一轮带哪些记忆由代码决定，不调用模型（网址精确匹配加共同词，不用语义向量检索）：

- 本网站的过往任务要和用户这句话有共同实词才带（只比用户原话，不比任务摘要，且排除「帮我查一下」「打开」「点击」「网站」等口头词和浏览词）。
- 回答上方的记忆引用行：本网站记忆照常列出；到处适用的「关于你」、做法及有效期内的过往任务，只在与本句有共同实词或用户明确提及「上次 / 那天」时才点名列出，避免无关旧任务挂在每个回答下。
- 点「这里别用」只让当前网站不再使用该条记忆，记忆面板写明「在某网站不用」，不装作已删除。

## 存储与扩展会话恢复

- **备份与重装**：卸载扩展时 Chrome 会删掉它的全部存储，所以记忆、过往任务和站点笔记每次变化后，都自动另存到下载文件夹的 `By-Your-Side/记忆备份-<安装时间>.json`（不含模型密钥，不上传）。备份是明文文件，所以浏览记录、习惯计数和还没判完的原话不进备份，这些由网页内容生成、可能带网址里的 token；重装后习惯重新从浏览里学。文件名带安装时间，重装后的新安装不会覆盖旧安装的备份；写的时候不弹下载气泡，也不留在下载列表里。重装后在设置 → 数据与诊断 →「从备份恢复记忆」选那份文件；当前已有记忆时先说明会替换多少条，再点一次才恢复。
- **存储底线**：一件事只有一个生效值；程序读不懂或版本更新的记忆与过往任务只读不写，绝不当作空数据覆盖（只有「全部清空」才一并清除）。诊断记录不写用户原话和记忆原文。
- **会话恢复**：扩展内的循环使用 `pi-durable`，每一轮、每次工具调用与插话都先通过专用 Worker 原地追加写入 OPFS（`/pi-durable/<会话 id>`）。扩展重载或浏览器重启后，重开侧栏从存储接着做，已做完的写操作不会重复执行；带有结果未知步骤或需要重读页面的中断任务，先读取当前页面，用户说继续前不自动重放写入。
