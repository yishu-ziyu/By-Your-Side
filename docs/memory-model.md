# 记忆模型

本页写记忆的设计：记什么、记成哪种、用在哪里、用到什么时候，以及为什么这样定。边界见[记忆、过往任务与任务跨轮](memory-and-tasks.md)。

## 每条记忆回答两个问题

| | 长期有效 | 有时间或条件 |
|---|---|---|
| 到处适用 | 邮箱、生日、「回复我用中文」 | 「10 月 3 日飞成都」：行程结束前订酒店、叫车都用得上，结束后不再主动带 |
| 只在某处适用 | 「这个客户系统导出要选全部」 | 「这次报销要附发票」：只对这一件事 |

「这次报销要附发票」这类只对一件事的要求，现在只留在对话里。

## 四种记忆

| 种类 | 例子 | 谁记 | 到什么时候 |
|---|---|---|---|
| ① 这件事的要求 | 「不对，我要的是 3 号的航班」 | 自动 | 任务结束；内容转进 ② |
| ② 做过的事 | 「10/3 在携程订了北京→成都」 | 自动，任务结束时 | 过期后改为过去时，不再主动带，问起仍可查 |
| ③ 关于你 | 邮箱、「坐飞机要靠过道」 | 用户原话说出 → 直接记，可撤销；助手推断的 → 先问 | 长期；新值替换旧值时，始终只有一个生效 |
| ④ 做法（面板里叫「做事的方法」） | 「这个客户系统导出要选全部」 | 明确的网站操作纠正 → 自动记、可删除；助手说话方式的归纳 → 点「记住」才生效 | 长期 |

待做：做法在某网站反复失败时，提示它可能过时。

## 一句话记成哪种

原则：**记下的内容就是用户原话 → 直接记，可撤销；需要助手归纳或推断 → 先问用户。** 个人资料沿用原话自动记；明确可复用的网站操作规则自动记，含糊指代或一次性参数不推广成规则。其他归纳仍要用户确认。

- 网页、附件和工具输出里的文字一律不记。密码、验证码、证件号和银行卡不记。
- 例外：用户自己的浏览记录（打开的页面、点的按钮、搜索词、填写的内容）存在本机，交给快速模型归纳反复做的事；归纳出的习惯仍要用户点「记住」才成为做法。见[浏览习惯](evals/20261018-browsing-habits.md)。
- 用户明说「记住 / 以后都 / 忘掉」时，助手照办。待做：告诉用户记在哪个范围；现在用户要在「记忆」面板里看范围。
- 用户此刻让助手做的事所带的日期属于任务本身，所以任务没做完时不记这个日期。
- 助手从行为里推断的规律不自动记。同一偏好在不同对话里反复出现后，侧栏才问「要我记住吗」。
- 一句话里个人资料和做法分不开时，两者都不自动写入。这条边界依赖模型正确理解内容。

## 默认范围

| 种类 | 默认 |
|---|---|
| ③ 关于你 | 到处 |
| ④ 关于助手做事方式的纠正 | 到处 |
| ④ 关于某网站操作的纠正 | 该网站 |
| ② 做过的事 | 按有效期 |

涉及网站操作的纠正默认收窄到该网站，因为模型容易把某处的偏好当成到处都要照做（BenchPreS，2026-03）。用户可以在卡片上改范围。

只有 http(s) 网页算一个网站。纠正发生在扩展页或浏览器自己的页面上时，用助手最近操作过的网站；没有就不问关于网站的做法。

## 说一句话就打开记住的网址

用户原话教过「以后我说 X，就打开这几个网址」时，再说 X（只多「听说、好像」这类口头词），宿主开工就并行打开原话里的网址，模型只回一句，这一轮不动网页、不做目标核对。因为模型会把「打开渠道」理解成「去查新闻」，读页面写总结要几十秒。网址只取用户原话；原话里有「不要、别、除了」时不自动打开，交给模型。插话后这一轮照常核对。

## 已确认的做法如何影响提交

已保存的做法只作为上下文交给模型。任务宿主不把做法编译成提交前的字段检查，因为网页操作已不再逐次确认（见[网页操作不再逐次确认](browser-confirmation.md)）。结果由目标核对判断。

## 每次干活前带哪些

每一轮带哪些记忆，由代码决定，不调用模型。

- 该网站的 ② 要和用户这句话有共同的词才带。程序只比用户的原话，不比任务摘要，因为摘要会抄网页原文。不比时，同一网站上无关的旧任务会挂在每个新回答下面。
- 暂不用语义向量检索：几百条规模下，网址精确匹配更准，也说得清为什么带。
- 待做：更早的 ② 与其他网站的 ④，由助手用「查记忆」查，侧栏显示「查了记忆」。

## 回答里显示用了哪些记忆

- 每轮都带的「关于你」、到处适用的做法、有效期内的 ② 做过的事和本网站的 ② 过往任务，只在和这句话有共同的词时才列出。用户为本网站存的记忆照常列出。有效期内的 ② 不论在哪个网站、哪个会话都带给助手；全部列出时，别处订的事会挂在无关的回答下面（#287）。用户明确提到以前那件事（「上次」「那天」）时，有效期内的事照常列出。
- 这一行不把「帮我查一下」「看一下这个」这类口头词和「打开」「点击」「网站」这类浏览词算作共同的词（否则同一网站上无关的旧任务，只因两句话都有「打开」，就挂在回答下面），「上次」也只认指回以前那件事的说法，不认「付款之前」这类时间先后。这两条只管这一行；带给助手的记忆不变，因为改它要用真模型评测。
- 没有共同的词、只用「那个会」指代时，助手照常拿到有效期内的事，但这一行不点名。
- 「这里别用」只让当前网站不再用这条，记忆保留。记忆面板写明「在某网站不用」，不装作已删除。
- 待做：助手在首句写明「因为你之前说过……」、改了做法时自动展开。
- 待做：记忆的导出和导入。

## 放弃了什么

记忆底座只保证两件事：一件事只有一个生效值；看不懂或损坏的数据只读、绝不覆盖。同时，底座不上同步引擎、不以操作日志为唯一数据源、不拆分存储。

网站纠正的当前验收见[网站纠正规则](evals/20261016-site-correction-rules.md)。自动保存只留规则与会话来源，不复制整句纠正中的个人资料；删除规则不清除对话、过往任务或站点笔记，也不撤回已执行的网页操作。

## 怎么检查

| 看什么 | 检查 |
|---|---|
| 记成哪种判得对不对 | 从用户真实记录抽样，人工标「该记成哪种 / 不记」；重点数「一次性的事被记成长期」 |
| 用得对不对 | 该用时用上、不该用时不用；过了有效期不再主动出现；每次多带多少字 |
| 用户感受 | 同一句纠正要说几遍；用户删掉记忆的次数 |
