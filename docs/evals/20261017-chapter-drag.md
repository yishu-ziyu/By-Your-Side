# 任务: 用鼠标拖动章节导航

## 规则
- 章节放不下时，鼠标拖动能露出后面的章节，松手不跳章；普通点击仍跳到对应章节。主代理用隔离真实扩展的章节用例检查，并保留拖动前后截图。
- 重开侧栏后仍可拖动；键盘和触控板沿用原有操作。

## 技术前提
项目已有原生指针拖动。对照预览证明了这种入口可以操作；正式实现只增加章节拖动，不引入 Blossom 的页面级滚动改写，也不增加依赖。

## 边界与不做
不增加惯性滑动或轮播，不改回答卡片。它是鼠标操作便利性改进，不宣称提高查找速度。隔离用例使用脚本模型，不评价模型能力。

## 证据
隔离真实扩展通过拖动、反向拖回、松手不跳章、点击与重开。旧版在拖动判据失败；故意在松手时打开第一章的故障包在不跳章判据失败。截图与结果归档在主目录 `out/release-20261017-chapter-drag/`。尚未把此结果当作日常用户体验验收。
