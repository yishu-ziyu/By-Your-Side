## 规则

- R1（#234 R1、R2）没有已连接的服务商时，打开设置页，服务商列表已经展开，标题不写「其余」。用户收起列表后，列表保持收起。有已连接的服务商时，保持「已连接 · N」和「其余服务商 · N」，其余默认折起。

  - 例子(反)：用户收起列表后，存储变化让页面重绘，列表又自己打开 — 谁检查：同上第 2 步
  - 例子(反)：去掉首次展开的代码，用例必须失败 — 谁检查：故意弄坏产品复跑（10-11 做过，失败）
- R2（#234 R3）一家都没连时，主模型一行显示「去选服务商」按钮，不显示只有「还没有选择」一项的下拉。点按钮后列表展开，焦点在搜索框。主模型下拉仍然只列已连接的服务商。
  - 例子(正)：点「去选服务商」，列表展开，焦点在搜索框 — 谁检查：用例第 2 步
  - 例子(正)：按钮的位置和文字是否合适 — 谁检查：人看 `1-first-screen.png`

## 技术前提

- 前提：扩展的设置页能直接调用 `chrome.commands.getAll()`，读到的快捷键已是本系统的写法。结果：通过。macOS 无头 Chrome 读到「⌘J」，所以 Linux 的「Ctrl+J」这一条在本机没有跑。
- 前提：TypeSafe 只有分类模型。结果：通过。pi-ai 目录里 TypeSafe 的对话模型是 0 个，分类模型只有 `jev-latest`。
- 前提：@lobehub/icons-static-svg 有小米在 18px 下看得清的单色图标。结果：不成立。最新版 1.95.1 只有 `xiaomimimo`，它是「Xiaomi MiMo」两行文字，18px 下看不清。所以小米保留首字。Azure 和 Meta 的图标在 18px 下看得清。
