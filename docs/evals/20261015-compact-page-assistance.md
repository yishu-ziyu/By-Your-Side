# 任务：页面助手更轻，细节仍能完整查看

## 规则
- R1 光标保留原圆角气泡，缩小并去掉装饰光球；圈画用细线与轻标签，不遮住目标。
  - 主会话检查真实扩展截图、点击结果与圈画位置。
- R2 阅读卡先显示有内容的摘要，不把标题或分隔线当答案；长段落和后续段落可完整展开。
  - 主会话检查划词、展开、收起以及键盘焦点。
- R3 追问、生成中改口、停止和完整复制不能因收起而丢失。
  - 主会话检查真实扩展输入与模型收到的请求。
- R4 卡片仍避让网站侧栏，窄窗口和滚动时不脱离原文。
  - 主会话检查真实扩展位置与截图。

无。

## 技术前提
沿用现有阅读对话和元素锚定圈画，不增加模型调用或权限。摘要只是原文开头的显示，不冒充模型总结。

## 边界与不做
不实现自由生成图解，不加入示意图里的硬编码三角形；不更新日常扩展。脚本模型和练习页只验证界面与操作，不能证明真实网站与模型的体验。

- 通过：开发检查；真实扩展的气泡、圈画、摘要展开、长段落、快慢模型切换、窄屏、避让侧栏、滚动和生成中改口。
- 反例：相同检查加载旧版扩展，气泡大小、装饰光球、标签底色、默认摘要与展开入口均失败；没有为新实现放宽判定。
