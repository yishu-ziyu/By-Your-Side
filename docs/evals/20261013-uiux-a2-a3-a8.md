# 任务: 发问时能拉进别的标签页；写页或跨站先看三行计划；结果只留一个主动作

来源：用户指定的 A2 / A3 / A8 幻灯规格。Chrome 的 Ctrl/⌘K 会抢去地址栏，动作列表改用 Ctrl/⌘+Shift+K，和已有的 `/` 技能菜单分开。

## 规则
- R1 输入 `@` 列出打开的标签页（站点图标、标题、域名，当前页排第一）。选中后 `@` 从输入框消失，变成一枚页面胶囊：待读是描边，已读是实心加 ✓（扩展后台真读到正文才变），读不到是划线加原因。
  - 例子(正)：两个本机页打开时打 `@`，弹层有两行；回车后输入区出现页面胶囊 — 谁检查：脚本模型演示
  - 例子(反)：`@` 只是普通字符、没有弹层 — 谁检查：同一演示的改前录屏
- R2 任务要写页面或跨站时，发送先出现三行：会去、会做、不会做，按钮是「开始 ↵」和「改一下」。只读且同一站不出这张卡。点开始后，计划收成任务条上的一行目标。
  - 例子(正)：说「填进对照表，不要提交」时先出计划，不会做是「提交、付款」；点开始后才发任务 — 谁检查：脚本模型演示
  - 例子(正)：说「填好并提交」时不会做只剩「付款」。助手把原话里的提交、报名、下单当授权，卡片不能承诺它不做 — 谁检查：脚本模型演示
  - 例子(正)：出卡后用户改了输入，旧卡收掉，回车按新话出卡，发出去的是新话 — 谁检查：脚本模型演示
  - 例子(反)：写页任务一按发送就开工，没有计划 — 谁检查：同一演示的改前录屏
- R3 每条结果只留一个主动作：有表格是「复制为表格」，有「切过去看」是「在页面上查看」，否则是「复制」。其余收进动作列表。`Ctrl+K` 不打开动作列表；`Ctrl+Shift+K` 打开，可以筛选，Esc 关掉。`/` 仍只打开技能菜单。
  - 例子(正)：表格回答的主动作是「复制为表格」；Ctrl+Shift+K 列出复制为 Markdown、作为新会话继续、存成技能 — 谁检查：脚本模型演示
  - 例子(反)：Ctrl+K 打开动作列表，或动作列表和 `/` 技能是同一个菜单 — 谁检查：同一演示

## 还没答上的问题
- 无。快捷键已按 Chrome 默认键位核对：Ctrl/⌘K 是地址栏搜索，Ctrl/⌘+Shift+K 不是 Chrome 默认快捷键。

## 技术前提
- 前提：拉进来的标签页由扩展后台用 `page_text` 真读正文，侧栏不在选中当下冒充已读。小实验：演示里胶囊先待读，读到后才 ✓。结果：见演示录屏。
- 前提：动作列表挂在结果上，不改发送路径，也不占用 `/`。小实验：空输入时 `/` 仍出技能；有结果时 Ctrl+Shift+K 出动作列表。结果：见演示录屏。

## 边界与不做
- 不接真实模型。演示用脚本模型，只证明侧栏这一层。
- 计划的「会做」从用户原话截出，不另请模型写计划。
- 页面胶囊最多 6 个；浏览器内部页（chrome、devtools）不出现在列表里。
- @ 页面随开新任务、运行中插话、暂停后交还、续做送到模型。任务已中断时只登记的修订、排队任务的修订、发送被退回后放回输入框，这几处还不带 @ 页面。

## 结果
- 脚本模型演示：`@` 弹出两行标签页；选中后输入区出现页面胶囊；发出后消息下的页面胶囊在读到正文后打 ✓。
- 表格回答的主动作是「复制为表格」。Ctrl+K 不打开动作列表；Ctrl+Shift+K 打开，和 `/` 技能菜单不是同一个。
- 写页任务先出三行计划（不会做：提交、付款），点「开始」后才发任务；说了「并提交」时不会做只剩付款。
- 任务运行中 @ 另一页再插话，模型读到那一页，这条消息下的胶囊打 ✓。
