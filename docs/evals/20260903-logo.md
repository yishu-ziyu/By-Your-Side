# 任务: 把新图设为扩展 logo

## 验收标准
- [ ] 1. `extension/icons/` 下有 16/48/128 三档 PNG，源自下载文件夹新图 — evaluator: 人工查看文件存在且可读
- [ ] 2. `manifest.json` 声明 `icons` 与 `action.default_icon` — evaluator: `npm run build` 后 `extension/dist/manifest.json` 含 icons 字段
- [ ] 3. 构建产物包含图标文件 — evaluator: `ls extension/dist/icons/` 非空，且 `npm run typecheck` / `npm run build` 通过
- [ ] 4. 加载扩展后工具栏与扩展管理页显示新图标 — evaluator: 人评

## 边界与不做
- 不改 side panel 页面内的 UI 展示（如 header 加 logo）
- 不改动图内容本身（不抠图、不改色）
