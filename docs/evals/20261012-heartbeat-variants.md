## 规则
- R1 默认 v3：思考时四个墨点呼吸，第一行轮换真实思考动词，第二行仍是步数。
  - 例子(正)：想的时候出现「想想怎么说」或「理一理」或「看看下一步」，行首 4 个点 — 谁检查：`thinking-heartbeat.mts` a、b
- R2 `inproc_heartbeat` / `sideagent.heartbeat` 为 v1 时只动墨点、标题仍是「正在思考」；为 v2 时只换动词、没有墨点。
  - 例子(正)：录屏并排能看出三种差别 — 谁检查：人看 `heartbeat-variants.mp4`
- R3 后一组在画时，先折好的组先藏起来，五路不被 176px 裁掉；死路写人话原因；本机 IP 不进标题。
  - 例子(正)：B1 五路都看得见；死路写「接口没回（HTTP 0）」或「连不上这个地址」；标题没有 `127.0.0.1` — 谁检查：`process-graph.mts` a、c、d / 人看 fan.mp4、lanes.mp4
