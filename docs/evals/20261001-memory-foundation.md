# 任务: 记忆底座——每条记忆知道自己是哪种、用在哪、到什么时候；带日期的事过期后不再主动带

依据：[记忆模型](../memory-model.md)（2026-10-01 用户定稿）第一块；用户定「先打底座，再做纠正卡片」、加「不限存储」权限。本块同时是第一个「决定点」样板（见末节），做完单独给用户看。

## 用户能看到的变化

1. 你说「我 10 月 3 日飞成都」或让它订了一张 10/3 去成都的票 → 行程结束前，你在任何网站说「帮我订那天成都的酒店」，它知道是 10/3、成都。
2. 10/3 之后 → 它不再主动提这趟行程；你问「我上次去成都是什么时候」，它仍答得出。
3. 你说「我邮箱换成 b@example.com」→ 之后只用新邮箱；「记忆」面板里旧邮箱标「已被替换」，留作历史，不再带给助手。
4. 「记忆」面板（侧栏右上角「⋯」→「记忆」）每条显示：哪种、用在哪（所有网站 / 某网站 / 到某天为止）、来源原话、用过几次。
5. 升级后，你已有的记忆和过往任务一条不少、照常能用。

## 决定点样板（本块要做成的样子，做完给用户看）

- **决定点 A：这句话记成哪种、带不带有效期。** 模型只答窄问题（这是用户原话里的长期事实吗？这件事关联哪一天？只对这一次有效吗？）；代码按[记忆模型](../memory-model.md)的判断顺序落位；诊断记录写一条「判为哪种、依据哪句原话」；检查场景 D1–D4、D12。
- **决定点 B：这一轮带哪些记忆。** 纯代码规则（总是带 / 按网站 / 有效期内，各有上限）；诊断记录写「带了哪几条、各因为哪条规则」；检查场景 D5、D6、D11。

## 边界与不做

- 不做纠正卡片（第二块）、「查记忆」工具、导出导入、推断后先问用户。
- 不改变已有的「用户原话自动记 + 撤销」行为，只补字段与有效期。
- 不做跨设备同步。
- 真实模型按提供方分线串行，跑完报告用量。
