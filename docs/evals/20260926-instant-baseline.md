# 任务: 测出三种即时动作从用户动手到页面第一块可见变化的时间（基线）

来源：2026-09-26 用户认可的判断——即时感是主卖点，也是当前最明显的短板（翻译约 20 秒到一分多钟、圈画 13–51 秒，见 [ROADMAP](../ROADMAP.md) 第 7 条）。先量基线，再改路线并前后对比；本文件只管基线，改动另立验收。

## 用户能观察到的结果

一份可重复的计时：「读不懂」「找东西」两个场景里，用户动手之后页面上多久出现第一块变化、多久完成，每轮都有截图。

## 完成标准

- [x] 1. 三个动作都走用户入口：划一句 → 页内「解释」；侧栏输入「把这页翻译成中文」；侧栏输入「价格在哪？」 — 谁检查: `scripts/acceptance/real-path/instant-baseline.mts`
- [x] 2. 真实扩展（只装扩展、扩展内 agent）、真实模型 `stepfun/step-3.7-flash`，文字请求只走 Step Plan 地址 — 谁检查: 脚本记录的请求地址
- [x] 3. 每个动作 5 轮，每轮记下：动手时刻、第一块可见变化（解释卡出现文字 / 当前一屏第一段变中文 / 页面滚到价格或出现圈画）、完成时刻，并在第一块变化时截图 — 谁检查: `out/acceptance/real-path/<时间>-instant-baseline/results.json`
- [x] 4. 跑基线时机器上没有其他批量验收在跑，避免负载拉长计时 — 谁检查: 结果里的负载记录
- [x] 5. 「多快算即时」的目标值看完基线再由用户定 — 谁检查: 人。2026-09-26 用户定为 **2 秒内**：从动手到页面出现第一块变化（解释出字、当前一屏变中文、价格被指出）。

## 边界与不做

- 不改产品代码；不测语音入口（语音多一层识别，另测）；不测多步代办。
- 计时从外部看页面（CDP 穿透读取），不以产品自己的诊断记录代替可见变化。
- 无头隔离 Chrome 的计时可能与日常 Chrome 有差异，结果注明。

## 证据

2026-09-26，`main`（`c13cf60`）的干净工作树，`npx tsx scripts/acceptance/real-path/instant-baseline.mts --headless --rounds=5`。每个动作 5 轮、0 错误；文字请求全部走 `api.stepfun.com/step_plan/v1`（离开 Step Plan 的请求 0 次）。机器上没有其他验收在跑，但日常程序使 1 分钟负载在 12–70 之间；每轮负载记在 [results.json](assets/20260926-instant-baseline/results.json)。

| 动作 | 第一块可见变化（中位 / 最慢） | 完成（中位） | 每轮第一块可见变化 |
|---|---|---|---|
| 划一句 → 「解释」 | 12.6 s / 13.4 s（扣除测试环境的点击延迟，见下） | 14.3 s | 12.6、13.4、11.8、13.3、6.3 s |
| 「把这页翻译成中文」 | 24.7 s / 31.9 s（当前一屏第一段变中文） | 31.7 s | 24.7、24.3、29.9、31.9、18.5 s |
| 「价格在哪？」 | 5 轮里 4 轮页面没有任何变化，只在侧栏用文字回答（6.6–14.2 s）；1 轮滚到价格并圈出，11.6 s | 12.2 s | —、—、—、—、11.6 s |

- **点击延迟：** 无头 Chrome 里工作页在后台，「解释」这一下鼠标事件 5 轮中 4 轮要约 5 s 才送达（`clickDispatchMs`），解释卡随后 0.2 s 内出现；5 轮中送达正常的那一轮，从点击到发出模型请求只用 0.23 s。上表已扣除这段测试环境延迟，未扣除的原始值是 19.1、18.4、11.8、18.3、11.3 s。
- **时间花在哪（每轮的模型请求时刻见 results.json）：**
  1. 模型先思考再回答。`step-3.7-flash` 从发出请求到第一个字节 2.7–7.5 s，思考流完才出现正文；解释卡里第一行字出现时请求已接近结束。
  2. 翻译要先等主模型决定「要翻译」，这一轮第一个字节 5–12 s，页面在此期间没有变化；之后 3 批并行翻译，每批 6–24 s；最后主模型再写一句总结约 3 s。
  3. 翻译不优先当前一屏：第 4 轮别处的段落 12.0 s 就变成中文，当前一屏等到 31.9 s（`firstAnyCjkMs` 与 `firstVisibleMs`）。
  4. 「找东西」的回答大多只落在侧栏：主模型一次请求就用文字答完，没有调用滚动或圈画。
