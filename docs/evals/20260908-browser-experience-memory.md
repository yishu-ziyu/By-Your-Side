日期：2026-09-08。实现前固定，由主代理先承担校验职责。用户已授权第一轮实现。

## 完成标准
- [x] 1. 生产运行记录任务目标、所属会话/网站、关键工具结果、用户纠正和结束状态。结束不自动等于成功；中止和接管不能被整理成成功经验。— 机器：新增 experience 专项测试

- [x] 6. 在合成导出网页走真实路径：第一次产生仅当前页的结果→用户纠正→整理经验→新会话换数据后检查全部范围及最终数量。改版场景重新观察，无关任务和忘记后为反例。不用硬编码回复或注入经验替代生产链路。— 机器：正式扩展、真实模型、网页动作与结果证据
- [x] 7. 全量 typecheck/test/build 与现有记忆/会话关键回归通过，最终 diff 检查通过。命令和用户路径分别报告。— 机器

## 边界与不做
- 本轮复用当前模型进行普通后台结构化整理，不启动子代理，不接开发者 wiki/hooks。
- 第一轮针对同网站的任务经验；不自动升级为跨网站技能，不自动执行生成代码，不推断长期人格偏好。
- EverOS 独立服务与语义检索接入不作为本轮前置；先完成上述可替换的记录/整理/使用链路，不能声称本轮已经接入 EverOS。
- 不改 Pi，不把 assistant 自称成功当作结果证据；未核实的做法明确标为候选。
- 用户历史和现有偏好保留；只用合成材料验收。

### 失败与修正

1. 模型把分开的观察拼成一条引用，来源校验拒绝。改用短连续引用，并让模型区分用户澄清和助手失误；不能通过放宽引用断言掩盖失败。
2. A占用的页面不能作为B的上下文，初次B虽然完成347条但没有使用经验；不算记忆通过。改为独立页面，并支持用户显式给出的目标网址。
3. 一次模型返回无可提炼做法；现在明确显示“未形成做法”，不静默显示成功。
4. 当前活动页变化、模型请求重试、截图等待动画和读取未操作的原始标签使早期跑道失败。跑道改为明确网址、独立正式面板、按本轮页面真实导出结果取证，失败任务结束时中止。

早期失败保存在同目录 attempt1–attempt6.json。最终通过未覆盖这些失败，也不把它们计为产品通过次数。
