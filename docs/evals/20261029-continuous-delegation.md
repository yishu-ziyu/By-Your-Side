# 持续委托：候选实现与发布判定

本轮范围是首个“等待结果 → 自动筛选、标注 → 核对”闭环，以及同一机制的控制和恢复。基线为 `37b32570`。候选在 `feat/continuous-delegation`，功能默认关闭，尚未合并或安装日常扩展。

**发布判定：否决本轮启用发布。** 受控闭环通过，但真实维基百科搜索建议场景未稳定登记等待。24 个冻结场景、三个站点、A/B 人工催促及 B/C 成本门槛未完成，不能用本机练习页或事件数量换算。

## 需求覆盖

| 需求 | 已取得的证据 | 限制 |
|---|---|---|
| R1 持续推进 | 受控真实扩展一次交代后自动读取、标注并核对；真实 `gpt-6-luna` 练习页闭环通过 | 实站搜索建议仍会提前交付部分结果，未稳定转入等待 |
| R2 持续关注 | 两批结果分别处理；保留旧标注、不重复唤醒；稳定等待窗口零模型请求 | 只验证了本机可控页面；不保证任意网站 |
| R3 保留上下文 | 原 runId、目标、修订和观察/处理位置保留；关闭离屏宿主后同文档恢复、旧版记录升级后明确续做均通过 | 浏览器重启后新格式委托的资源重新绑定、长期会话及跨会话完整体验无法判断 |
| R4 可控 | 真实暂停/继续按钮、修改阈值、停止、关开关、换资源、重载及到期反例通过 | 用户批准问题的全部过期回答场景未扩大验证 |
| R5 可信交付 | 等待、核对、完成、暂停、到期与预算分别投影；只有核对成功才推进处理位置 | 真网站成功率和整体交付可靠性未达到发布证据要求 |

## 技术前提

依赖浏览器保持打开、原目标文档仍有效，以及现有离屏宿主、原生任务日志和浏览器执行器。后台或设备休眠期间不保证精确定时，也不保证捕获短暂页面事件。浏览器重启或文档身份变化不直接重放动作。

真实模型验收使用现有 ChatGPT 登录，仅写入隔离测试配置；测试配置与日常扩展分离，测试结束关闭并清理自己的浏览器。候选包不包含测试登录数据。

## 规则

- `shared/task-continuation.ts` 定义有界外部条件、委托版本、生命周期、期限和累计预算；作为原任务检查点的一部分保存。
- `TaskProgress` 维护唯一事实，`TaskProgressSnapshot` / `TaskView` 只读投影；`decideTaskNextStep()` 继续是决策入口。
- `TaskContinuationObserver` 只做定向读取、复核和唤醒；模型执行仍经 `TaskDispatcher`。请求编号绑定委托、目标版本和观察版本。
- 等待不占执行片段；主动耗时、模型次数和观察次数跨片段累计。观察位置、处理中的位置、核对完成位置分离。
- 停止/修改使旧异步结果失效；保存失败暂停自动续做，不能提前推进已处理位置。已发出的动作不声称可撤回。
- 自动续做仅允许原文档的读取、分析和标注；浏览器执行边界再次核对 URL、文档和控制轮次。
- 快照编号只有在宿主能解析为唯一稳定 ID 或测试属性时才可登记；持久化不保存快照编号。整页文字变化不能充当明确的完成条件。
- 完整来源尚未就绪时，开启实验功能仅允许同页读取和登记等待，不能标注或交付最终结果；唤醒前重新取得完整来源并接回原核对链。未开启功能仍保留原全文门禁。
- 设置页提供“持续关注网页”，默认关闭。关闭后中止观察和自动续做，保留原记录。`chrome.alarms` 只作非精确唤醒提示。

保留浏览器 RPC、Agent 循环、任务分发器、结果账本、技能普通执行、权限体系与目标核对。未接入 Pomerado 运行时，未增加第二个任务数据库或模型调度器。
