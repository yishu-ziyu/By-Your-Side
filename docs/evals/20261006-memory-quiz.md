# 任务: 用日常记录和 20 道小考量出记忆现在会不会记、记得对不对、会不会乱用

背景：用户认为「用久了越来越喜欢」靠的是记住使用习惯，这一块他最想要也最没底，要靠调研加快速迭代验证（2026-10-06）。本任务只量现状，不改记忆。

## 规则

- R1 纠正重放：从用户日常 Chrome 导出诊断记录（只读），逐条对照用户说的话和记忆系统当时的判断，列出「该记没记」「记了乱用」两类。
  - 例子(正)：用户明说「记住这是我常用邮箱」，记忆库没有 — 记为该记没记 — 谁检查：人（本文件证据）
  - 例子(反)：把助手的回答当成用户纠正 — 谁检查：人
- R2 记忆小考 20 题（BYS-151–170），分 6 类：记住并跨会话用、更新、只在本站、没记过要说不知道、纠正后照做、不该记的。最终问题都在新会话里问，只能靠记忆；判分同时看回答和事后的记忆库。
  - 例子(正)：BYS-159 记住邮箱 → 新会话「忘掉」→ 再问，回答不知道且记忆库为空 — 谁检查：judge
  - 例子(反)：回答说「不知道」，但记忆库里还留着邮箱 — 谁检查：judge 看 `<题号>.memory.json`
- R3 小考用同一把尺子跑 3 次：`node eval/harness/ladder.mjs --tag <名> --levels MEM`，和阶梯同一张表。

## 技术前提

- 多轮对话与记忆库导出：框架按 `before_turns` 逐轮发送、每轮跑完再发下一轮，可开新会话；结束后从扩展 IndexedDB 读出生效的记忆条目交给 judge。冒烟 BYS-151、BYS-159 各 1 次，judge 都通过，记忆库内容与回答一致（`eval/runs/mem-smoke-1`）。

## 边界与不做

- 不改记忆代码；看到的问题留给后续任务。
- 日常记录只在本机分析，原始文件留在被 git 忽略的 `tmp/daily-export/`；本文件只写结论，不抄用户原话里的个人信息。

## 证据

### R1 纠正重放（日常 Chrome，10-01 至 10-06，只读导出）

5 天里用户在侧栏发了 55 句话（`run_start` 47、插话 8）。记忆库里只有 1 条生效记忆。

| 用户说的 | 记忆系统当时 | 结果 |
|---|---|---|
| 明说「记住这是我常用邮箱，下次登录就用它」（10-06） | 这一轮没有任何记忆判断记录 | 该记没记。推断：这一轮被下一句打断，记忆只在一轮完整结束后判断 |
| 「翻译字体改为宋体，高频词用紫色」（10-06） | 只记成过往任务 | 偏好没记，下次翻译还要再说 |
| 「当前页面明明是 ChatGPT」「他们只是名字像，其实不是一个人」「直接定位到他的推特页面就行」 | 3 句都判为「不是纠正」（正则没命中） | 纠正没被识别，没问「要我记住吗」 |
| 「转成 Markdown 后存到我的 Google Drive」（10-01） | 第一次判断超时，补判后记成「关于你」 | 记住了，但之后 44 轮每轮都带上它，大多和当时的任务无关 |
| 重复出现的做法：「关注这个博主」4 次（YouTube、播客）；「提取字幕并保存」3 次（B 站）；「找这个人在其他平台的账号」3 次 | 只记成过往任务 | 习惯没被总结成做法 |

小结：50 次纠正判断里 0 次识别为纠正；用户明说「记住」的 2 次里只记住 1 次；唯一的记忆被无差别带了 44 轮；反复做的事没有变成做法。

### R2、R3 小考

- 20 题 × 3 次：59/59 通过，1 次环境失败（站点连不上）。表：`eval/runs/ladder-before-1006/ladder.md` 的 MEM 行。
- 结论：用户明说「记住 / 更新 / 忘掉 / 只这一次」时，现在的记忆做得对。R1 的问题都出在用户没明说的地方：没说「记住」的纠正、反复做的事、记忆每轮都带。这套题测不到这些，下一版要加。
- 顺带发现的产品问题：
  - 用户只说「记住…」时，记忆存上了，但模型没说话，侧栏随后显示「模型返回了空响应：可能触发了限流」。75 次铺垫对话里出现 5 次；BYS-153、157 几乎每次都这样。R1 里「记住常用邮箱」那一轮很可能是同一原因。
  - 新会话还在建立时打字，字会被清掉，消息发不出去。

### 修复（2026-10-07）

- 「记住」后的假报错：原因是记忆工具回给模型「本轮仅修改记忆；不要操作当前网页」，模型照做不说话，宿主把没有正文当成空响应。现在这一轮记忆改成功时不再报空响应，侧栏只留「已记住」与撤销、查看。提示语也改成让模型用一句话确认，但 gpt-6-luna 仍常常不说话。真模型复测：BYS-153、157、158、167、168 共 13 次全部通过（`eval/runs/remember-fix-1007`）。前 10 次框架没区分「已记住」和空响应提示；最后 3 次记下了结束方式，BYS-153 的「记住」一轮以「已记住」结束，没有空响应提示。
- 新会话丢字：点「新会话」后、切过去之前打的字跟着用户走。验收 `npx tsx scripts/acceptance/real-path/new-conversation-draft.mts --headless`，修复前失败、修复后通过。
