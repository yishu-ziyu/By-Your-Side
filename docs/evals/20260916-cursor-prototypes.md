# 任务：通过可操作原型选择光标与角色反馈的位置

## 完成标准
- [x] 同一模拟网页对比跟随名牌、目标旁注、边缘角色栏；原Kima图形和光球保留。主代理：应用内浏览器逐版截图观察。
- [x] 操作、等待、确认/取消、失败重试、结果核对、跨页返回和停止可操作。主代理：浏览器点击并检查结果，错误/警告日志为空。
- [x] 支持减少动态、URL选项、切换键与重播；页面窄时上下排布。主代理已观察窄布局及减少动态；未做全设备适配验证。
- [x] 用户选定统一右上角状态，目标旁只显示确认；已接入正式版，见[接入验收](20260916-unified-cursor.md)。

## 资源与边界
- Excalidraw的身份/指针分离，assistant-ui的消息/过程分层用于设计判断；没有引入这两个框架。
- Kima图形和光球从现有项目代码打包，品牌SVG沿用现有资产。
- 仅新增prototypes/cursor-study，正式光标、状态协议和日常扩展均未在本轮修改或重载。
- 原型内的评论、请求结果和跨页均为模拟。等待语义、计时及终态保护的后端建议尚未实施，不能用此原型算生产验收。
- 预览：http://127.0.0.1:54067/?v=1；启动：python3 -m http.server 54067 --bind 127.0.0.1 --directory prototypes/cursor-study。

## 用户修订

用户确认头像用于跨页入口，光标提示不带头像。三版原型均已调整：光标保留名字与操作文字，跨页入口复用Kima头像。此选择尚不代表选定三种布局中的某一种。

用户进一步收敛：一般状态统一到右上角，角色头像保留；目标旁只在确需用户授权时出现简短确认/取消，去除重复名字和头像。选择器已移除，现为单一方向原型；正式状态链路仍未在此轮变更。
