# 任务: 网页右边只有一个边缘胶囊，说清助手在这一页做什么、结果怎样、何时归你

以前右上角的停止条、跨页入口、多位助手列表、执行反馈，加上右边缘中间的边缘药丸，五样东西说同一件事，还会叠在一起。现在合成一个边缘胶囊：侧栏开着时从侧栏边长出来，关着时贴在窗口右边。形状、动效和文案照 `out/xpage-capsule/edge4.html`、`states.html` 做。

## 规则
- R1 没有任务时不显示；助手在这一页动手时伸出「动词 + 对象」和停止键，连续多步不缩回，只换变了的字；做成变绿圈约 2 秒后收回，任务结束淡出。
  - 例子(正)：加入购物车任务里，从第一下到最后一下，胶囊一直在，最窄也没缩回一小截 — 谁检查：`npx tsx scripts/acceptance/real-path/edge-tab.mts --headless`
  - 例子(反)：两步之间胶囊收回再伸出 — 谁检查：同上
- R2 结果不确定、没做成不自动收起，等下一步或用户点一下；「现在归你」压过其他一切，带「继续」，点它交还；页面上同时只有一个胶囊。
  - 例子(正)：页面挂着「没做成」时用户接管，胶囊换成「现在归你」，点「继续」后助手接着做 — 谁检查：同上；`handoff.mts`、`takeover-handback.mts`
  - 例子(反)：「现在归你」下面还叠着「没做成」或另一个小圆泡 — 谁检查：同上
- R3 别的标签页还有助手：只有别页助手时写「在 〈那页标题〉 ↗」，点它切过去；这一页也有动作时，那页的助手收进下方小圆泡，点开是列表。侧栏关着时点胶囊打开侧栏。
  - 例子(正)：用户看资料页、助手在后台页加购物车，资料页胶囊写「在 京东 · 降噪耳机 ↗」，点了切过去 — 谁检查：`edge-tab.mts`
- R4 底色等于侧栏底色，深浅跟系统；减少动态效果时只淡入淡出不伸缩；新状态从当前形状接着变；只有胶囊接鼠标。
  - 例子(正)：深色时胶囊底色和侧栏 `--wallpaper` 一样；减少动态效果时第一帧就是整句宽度 — 谁检查：`edge-tab.mts`

## 技术前提
- 前提：页面视口右边缘就是侧栏边，不用判断侧栏开没开。小实验：`edge-tab.mts` 关侧栏后量胶囊右边和视口右边 结果：通过
- 前提：无头 Chrome 画不出贴边的真侧栏，「从侧栏长出来」的观感只能在日常 Chrome 里看。

## 边界与不做
- 光标旁「我在点「…」」那句保留，不在这次删。
- 别页头像只用标题首字，不用站点图标：图标地址放进这一页，这一页的网站就能看到用户还开着哪一页。
- 等页面响应、结果不确定、没做成的真实触发不在这个用例里，验收直接调页面脚本的同一个入口。
