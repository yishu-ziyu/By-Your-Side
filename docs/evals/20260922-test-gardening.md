# 任务: 测试只保护真实行为，不再冻结实现形状

## 目标

清理已经失去生产价值的测试与一次性验收脚本，同时保留会阻止真实失败的契约：安全边界、幂等、恢复、真实结果核验与 Golden Tasks。

本轮只改测试、验收脚本和本文档，不改产品源码，不构建或重载日常扩展。

## 完成标准

- [x] 1. 删除读取产品源码后用字符串/正则检查实现写法的测试；同一用户行为已有运行时测试或真实 Chromium 验收入口。— 谁检查: `rg` + 定点测试
- [x] 2. 工具面测试只检查生产装配一致性、角色权限和必需工具，不再锁死工具总数或整份名字快照。— 谁检查: `agent/test/tool-surface.test.ts`
- [x] 3. Reviewer 临时契约若已被正式测试覆盖，则合并独有反例并删除重复文件。— 谁检查: 定点测试
- [x] 4. 删除没有 package 入口、没有脚本依赖、没有非历史文档引用的一次性验收脚本；候选 fixture 必须再按 TypeScript 的 `.js` 导入解析复核。— 谁检查: 引用扫描 + 全量测试加载
- [ ] 5. 本轮不新增全量测试失败；当前工作树既有失败逐项保留，不通过删有效测试消红。— **BLOCKED：共享产品源码在本轮中途继续变化，全量失败集合不可与起始快照直接比较；本轮触及的 13 个测试文件 216/216 通过，且全量报告没有本轮文件失败。**

## 优化指标

- 活跃测试与验收代码净减少至少 2,000 行。
- 测试文件数下降，但独特生产失败契约不下降。
- 全量单测耗时不高于本轮开始时约 65 秒；既有失败基线为 18 项。

## 保留边界

- 保留 `read_element`、任务恢复矩阵、未知写入、重复执行、接管/中止、安全沙箱等当前失败或高风险契约。
- 保留独立 Oracle、真实浏览器验收驱动和发布质量门禁。
- 不删除原始评测证据目录；证据仓库瘦身另开任务，避免与测试语义清理混在一起。
