# 任务: 比价这类卡片里，来自别的标签页的那一行，点它就切到那一页并把那个数圈出来

用户 10-18 看过对照页（左边比价卡要自己切页找数，右边点一行切过去圈出那个数）后认可。沿用回答正文“数字回原页定位”的做法（`sonar-citations.ts`），从“只认提问那一页”扩到卡片每一行自己的标签页。

## 规则

- R1 卡片里的一行（数字格、选项、表格行）写了 `tab` 时，侧栏到那一页找这一行的数；页面上恰好找到一处，这一行才变成可点（右边一个小箭头）。找不到、找到不止一处、那一页已关，都不变，不猜。
  - 例子(正)：京东页、天猫页各开一个标签，卡片两行分别写 `tab="京东页编号"`、`tab="天猫页编号"`，两行都可点 — 谁检查：`scripts/acceptance/real-path/card-row-source.mts`
  - 例子(反)：第三行写的数在那一页上出现两处，这一行不可点 — 谁检查：同上
- R2 点可点的一行：切到那一页，那个数被圈出来；那一页在另一个窗口时，那个窗口提到前面。
  - 例子(正)：现在在京东页，点天猫那一行，前台变成天猫页，页面上圈住 ¥2,459 — 谁检查：同上
  - 例子(反)：故意让侧栏不去找，用例报“天猫那一行不可点” — 谁检查：同上（弄坏一次）
- R3 价格写在普通文字块里（不是段落、列表、表格）时也找得到，仍要求整页只有一处。
  - 例子(正)：价格在 `<span class="price">` 里，照样能圈 — 谁检查：同上
- R4 真模型会写 `tab`：比较几个标签页里的东西时，每行写上它来自哪个标签页。
  - 例子(正)：gpt-6-luna 比三家价格，三行各有 tab — 谁检查：`tmp/genui/run.mts` 小实验

## 还没答上的问题

- 无

## 技术前提

- 前提：到另一个标签页找数用现成的 `PINPOINT_DOM_TARGET`（identity → resolve → reveal），不需要新权限。小实验：用例 R2。结果：通过
- 前提：真模型在产品提示词里会给比较的每一行写 tab。小实验：`tmp/genui/run.mts`（本机，不进仓库），gpt-6-luna，3 道跨标签页比较 + 1 道单页题，各 3 次。结果：第一版失败，9 次里只有 4 次写了 tab，酒店题 3 次都没写；而且比价最要紧的那一行多半是“标价 + 运费”的算式，按“只认原样的数”的规则连不上。改成算式圈第一个数、每轮提醒里加一句后：画出来的 19 行跨标签页的行全部带对 tab（1 次没画卡片）；单页题模型也给行写了当前页的 tab，只是指回当前页，不出错。

## 边界与不做

- 算式那一行圈算式里的第一个数（“标价 + 运费”圈标价）；没写 tab 的合计、差价不可点。
- 页面后来变了（刷新、跳走），点了提示“原文已变化”，不再找。
- 找数时段落、列表、表格里没有，才看整页文字；整页文字最多看 2 万个文字节点，太大的页面找不到就不连。
