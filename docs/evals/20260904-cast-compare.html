Claude Code
好玩的是「还活着」这句话本身。词表写死，不让模型编。结束必须立刻停——有人被残留的 Perambulating 骗得以为还在跑。
tldraw
彩色箭头 + 白边名牌。我们已经在用这个形状。缺的是名，不是再画一个光标。
ChatGPT Atlas / Operator
并行标签是真的，人设是一个 ChatGPT。不适合我们这种「两个人同时在两个站点」。
X 上的方向
