# 任务：划词后在原文旁阅读、追问，并带完整上下文进入侧栏

用户于本会话确认交互方向，随后指定本轮由主代理独立实现，不使用 DeepSeek。

## 完成标准

- [x] 统一工具条 → 输入 → 回答容器；原文高亮保留，正文可读，流式生成不抢滚动 — 谁检查：主代理浏览器截图与交互；最终观感由用户判断。
- [x] 解释、自由提问、连续追问、复制、停止、关闭重开、错误重试真实可用 — 谁检查：主代理隔离扩展。
- [x] 阅读请求独立于主执行任务；请求身份阻止重选、切页、取消后的旧结果串入 — 谁检查：定点测试及隔离扩展。
- [x] 保留换行与有限相邻段落；超限明确显示；编辑区不触发；中文输入法、键盘、边缘定位可用 — 谁检查：定点测试及浏览器。
- [x] 侧栏承接原文、来源、全部问答，模型可接着回答；不自动启动新执行 — 谁检查：真实模型及隔离扩展。
- [x] 断线与部分失败保留已生成内容和问题；真实状态驱动，无伪搜索与伪等待 — 谁检查：受控传输及真实模型。
- [x] 相关类型、单测、模块边界、构建通过，实际 diff 复核 — 谁检查：主代理。

## 设计与实现决定

- 参考 Kobra AI Editor 的容器连续性，Chat Input 的紧凑输入，Streaming Text 的正文层次；不复制付费源码。
- 选区旁「问 AI / 解释」；展开后顶部来源与选区摘要，中部问答，底部追问与次要操作。
- 关闭仅收起，当前文档可重开；停止取消本阅读请求；文档离开停止请求。
- 阅读使用当前所选模型的无工具流式调用及独立上下文，不注入正在运行的任务。
- 「在侧栏继续」建立独立普通会话，持久化阅读上下文，并回放真实问答；不自动调用模型。
- 复用现有传输、模型配置、Markdown 消毒与图标；无新增 UI 框架。有限保存当前文档阅读记录。

## 边界

- 不新增编辑器、翻译套件、搜索能力；不修改其他项目或无关语音/团队行为。
- 隔离无头扩展验证；不自动重载用户日常扩展，不提交或发布。
- 不以截图/测试替代真人最终观感。真实模型、受控传输、原生扩展分别留证。

## 实测结果

- 真正运行的是隔离、无头 Chrome 中的生产扩展、真实 background/Port/WS 和本地模型运行时。`--live` 使用现有配置的 DeepSeek V4.1 Flash (Go) 作为产品模型；不是向 DeepSeek 委派开发任务。
- [真实模型记录](20260916-selection-reading/live-report.json)：解释选区、从有限相邻段落识别“蓝桉四十七”、浮层追问、复制、关闭重开、侧栏完整交接和真实追问通过。侧栏模型正确复述浮层里上一条问题。只有用户在侧栏发送新问题之后才出现普通侧栏的页面快照请求；划词阅读期间没有浏览器工具调用。
- [受控传输记录](20260916-selection-reading/controlled-report.json)：同一个生产扩展，替换后端回答用于确定性验证停止、迟到结果、部分失败重试、中文输入法、键盘选区、编辑区排除、换行与窄窗口。该记录不是答案质量或模型速度证据。
- [定点测试](20260916-selection-reading/focused-tests.txt)：6 个文件、98 项通过；覆盖协议、后端取消隔离、主任务不被改动、交接幂等、首次侧栏回复前重启恢复、跨文档拒绝、离开 SPA 取消、离线重试保留部分答案、已存在选区间切换。
- [普通回归](20260916-selection-reading/unit-regression.txt)：195 文件、1790 项通过。此后新增的交接持久化与界面收尾按受影响范围定点复验，没有机械重跑全套。
- [类型](20260916-selection-reading/typecheck.txt)、[模块边界](20260916-selection-reading/boundaries.txt)、[构建](20260916-selection-reading/build.txt)和差异空白检查通过。未运行规模测试与发布评测。
- 实时模型快照后仅修正失败草稿直接重发的复用、焦点归还、交接提示和默认解释的显示文案；请求/模型/持久化路径未变。最终界面经受控路径复验，最终构建指纹见[记录](20260916-selection-reading/source-hashes.json)。

### 原失败与修正依据

1. 新侧栏启动后，普通“打开新会话”策略会切走刚导入的阅读。增加阅读交接的启动意图，并将选区存储限制到目标会话；检查等待面板启动完成后仍显示问答，而不是只捕捉中间瞬间。
2. Pi 在首次助手消息前延迟创建会话文件，只有 custom context 的交接无法跨重启保留。新增有界、原子写入的 `reading.json` 作为该阶段的明确交接种子；已有 Pi 文件仍优先，从不拿 UI 历史重新编造模型上下文。恢复测试不伪造助手回答。
3. 长回答会超过选区上方空间并覆盖原文。按上/下可用空间约束实际容器高度，正文独立滚动；1200×900 的正常选区检查确保浮层与原文不相交，360px 窄窗检查确保不越界。
4. 验收脚本曾因原轮次 done、原生点击回执尚未完成、重复声明页面变量、或只收 `text_delta` 漏掉正式 `user_delivery` 而报告错误。均保留了失败记录，在修正测量后重跑；未将这些直接记成产品故障。
5. 原始本地失败位于 `out/acceptance/selection-reading-*`；该目录包含受控页面及模型事件，保持本地，不复制完整事件到报告。默认测试端口遇到并行任务占用后，验收改用独立临时端口，仅在隔离实例中替换 WebSocket 端点，不修改生产连接或终止其他服务。

## 改动与复杂度

- 阅读 UI、文档/请求归属、无工具模型调用各有单独边界；从原 background 主文件移除了共享输出 tab 和划词作为 steer 的整段逻辑。
- 浮层约 250 行，样式单独约 55 行；新增后台阅读记录模块约 146 行、后端请求生命周期约 42 行、共享协议约 68 行。增长对应多轮对话、停止、恢复、交接和边界校验；没有引入新框架、依赖或第二套 provider。
- Markdown 原实现移到扩展 shared，侧栏保留原入口再导出；既有渲染测试复用。其他并发的语音、团队、整页翻译改动保留，不归入本轮成果。
