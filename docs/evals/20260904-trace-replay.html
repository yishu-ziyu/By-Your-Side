操作轨迹回放 · 做好了长这样

任务结束后，你能看见它刚才点过哪里。世界做得最好的是 Playwright Trace Viewer：时间轴胶片 + 每次点击落在页面哪一点。我们要的不是它的调试器，是同一件事用我们已经有的浅弧光标演一遍。

对照 Will’s S：Apple Motion — 动效有目的、短、可跳过。NNGroup 动效 — 空间隐喻（光标还在它点过的地方飞），周边视野对运动敏感，所以不要常驻拖尾。Live Activity — 一眼能扫：三步、一个播放，不要做成控制台。

做好了任务跑完，点「回放」，光标按刚才的浅弧再飞一遍：搜索 → 那条笔记 → 删除。你能指给别人看「它点的是这个」。

没做好只有侧栏步骤列表；或整页永远画着一条线；或打开一个像 DevTools 的胶片工作台。
