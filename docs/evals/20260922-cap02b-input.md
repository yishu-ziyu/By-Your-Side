## 合并票要接的函数名与参数形状（短列表）

| 函数 | 参数形状（要点） |
|------|------------------|
| `click` / `doubleClick`（扩展） | 增 `button?: "left"\|"middle"\|"right"`, `position?: {x,y}`, `clickCount?: number`, `force?: boolean` |
| `wheel` | `{ deltaX?, deltaY?, point?, target?, position?, tabId? }` → `{ wheeled, point }` |
| `mouseDown` / `mouseUp` | `{ button?, clickCount?, point?, target?, position?, tabId? }` |
| `keyDown` / `keyUp` | `{ key, tabId? }`（`key` 支持 `ControlOrMeta+…`、独立 `Shift`/`Meta`/`Control`） |
| `releaseHeldInputs` | `(sessionId?)` → `{ releasedKeys, releasedButtons }` |
| `paste` | `{ content: string \| { text, html? }, tabId? }`；需先 `setClipboardBridge` |
| `html5DragAndDrop` | `{ from, to, tabId?, syntheticData? }` → `{ dragged:true, path }` 或 `{ dragged:false, gap }` |
| `setClipboardBridge` | 注入 macOS pasteboard 桥（对照 EGO `withTemporaryClipboardText` + changeCount） |

纯类型：`shared/pointer-input.ts`（`MouseButton`、`ElementPosition`、`PasteContent`、`ClipboardBridge`、`pointInElementRect`、`createIsolatedClipboardBridge`）。
