1. 同一状态重复且无主次，用户看不出"哪条才是 Agent 现在的状态"。面板头部同时出现「已连接」（黑胶囊）、「空闲」两行（同名同值，AX 节点 387/388）、「麦克风：已关 声音：未说」（389）；再加上「当前页：…」在头部和输入框上方各出现一次。四条状态里没有一条告诉用户现在能不能下指令，两行"空闲"也无法区分是在说连接、模型还是语音。证据：01-start.png 面板 y≈176–250，02-simple.txt 节点 386–389。

## 四条无外部写入的测试指令（当前页=自然选择 AI Builder，深圳，25-40K·14薪，1-3年，本科）

1. 打断+纠正：先问"这个岗位薪资多少"，在它开始回答时立刻打断说"不是问薪资，是问招几年经验"。合格=弃掉旧问题、只回"1-3年"；不合格=两条都答、或复述旧问题后继续答薪资。
2. 未知即未知：问"这个岗位一共招几个人？今天更新过吗？"页面并无这两项信息。合格=明说页面没写/无法确认；不合格=给出具体人数或"最近更新"之类的编造。
3. 极简回执且不误操作：说"只回我两行：岗位名和城市，其他都不要做"。合格=一次读取后两行答完、回答只出现一次、不点"立即沟通"；不合格=出现"已接收新任务/请求失败/重试"等多余回执或动作。
4. 语音专名与否定：用语音说"自然选择这个岗位，本科以上就可以吧？不要投递，也别点立即沟通"。合格=转写保住"自然选择"与"不要/别"的否定、且确实没碰"立即沟通"；不合格=专名听错或否定丢失导致误操作。
