用户已试听现有音色的流式样本并授权正式产品接入和真人试用。Pi及网页控制继续复用；不提交推送。

## 完成标准（实现前冻结）
- [ ] 1. 只对显式正式回答/正式回答生成过程输出音频；thinking、普通内部text_delta、工具参数及原始回执不朗读。— 机器：定点流式出口测试；隔离真实侧栏与模型路径。
- [ ] 2. 正式回答持续产生时，第一短句已进入合成并有音频返回，不等待整个正式回答结束；正式文字在同一消息中增量显示，结束不重复生成消息或重播。完整回答fallback仍沿原来源约束处理，不假称所有路径都已经模型增量。— 机器：分段屏障检查及真实模型时间记录；人：跟手感。
- [ ] 3. 使用当前Step Plan和已试听音色的纯TTS流式接口；正常超过20秒的回答完整返回并可播放，不走原整段一致性/20秒拒绝分支，不再调用实时对话模型重组固定正文。— 机器：实际流式服务和生产播放器路径；人：长回答可听。
- [ ] 4. 插话先停播并取消该次合成；晚到旧音频/未完成旧正文不能恢复旧播放。普通插话不新增网页暂停，明确停手/修改仍走原控制。— 机器：播放器/语音生命周期定点检查；人：实际插话。
- [ ] 5. 合成错误清楚显示，不卡在准备回答；不因重试声音重做网页动作。语音关闭/会话切换清理待播放内容；纯文字和原历史不退化。— 机器：故障及身份测试。
- [ ] 6. 定点通过后一次typecheck/test/build/diff；复核正式扩展加载本轮构建，用户原页面可试用。— 机器：主代理；人：最终听感与交互。

- 旧整段播报验收中要求等待全文一致才播放的断言被本次用户明确认可的流式目标取代；保留“不改写用户回答、不念工具、可打断”的目的，记录必要测试修订理由。
