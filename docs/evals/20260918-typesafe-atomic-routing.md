# 拆分Jev路由判断

用户同意继续改进路由，随后明确取消子Agent；已停止该子Agent，本轮后续由主代理独立完成。

## 预定标准与范围

- 旧路由和旧证据保持，实验模块不接入生产。
- 同一版本jev-1.13.0，一次请求并行判断：当前委托、额外任务、局部范围、字体是否有正向要求、模式是否有正向要求，以及两个参数选择。
- 新方案仍按0.8/0.2界线处理明确/不明确，不靠整体降阈值提高数字。未请求的维度不消费其参数选择置信；有正向要求才消费对应Choice。
- 用旧24条做开发回归；新24条在运行前写入并固定。主代理既设计方案也出题，因此新题只是前瞻合成评测，不声称独立盲测。
- 新集同输入对照旧/新路由，交替调用顺序；最多开发24次+新集48次Jev调用，5秒单次超时、不重试、并发2。
- 通过要求：新集正确直达多于旧方案，且无错误参数、错误放行或服务失败；同时报告延迟和成本。样本通过只支持进一步验证，不等于生产接入。

## 首次结果与一次有限修正

旧24条开发回归：2/13→4/13，未误放行。但新24条前瞻集：旧5/12、新4/12；新方案挡住旧方案一次局部范围误放行，但没有达到直达率提升，退出码1。见[原始结果](../../out/experiments/typesafe-atomic-holdout-1789704168254/summary.json)，不改标签或追认通过。

诊断发现字体/模式的正向存在性Noul与参数Choice重复设门槛。用已记录相同响应离线重组，取消这两个重复存在性门槛、保留direct/extra/partial及实际选中参数0.8界线，旧开发与新集均可10条正确直达、无错参/误放行。这只是开发诊断，不能算新方案通过。

因此仅做一次有限修正：新composeReduced消费已有参数Choice，unspecified不修改该维度，不再以另一道存在性Noul否决同一参数；仍保留三个独立意图/范围判断。沿用相同7问题请求（其中2个存在性问题暂只留诊断、不参与执行），避免同时改提问和组合无法定位原因。未来移除未消费问题需另查，当前不以此宣称最低成本。

主代理另固定12条新前瞻合成样本（6正/6负），旧/新同输入交替调用，最多追加24次请求；先前48题都已成为开发材料。新样本仍非独立出题，失败一律保留。阈值未下降。

## 有限修正后的新样本结果

[原始结果](../../out/experiments/typesafe-atomic-holdout-1789704306366/summary.json)与[冻结输入/源文件hash](../../out/experiments/typesafe-atomic-holdout-1789704306366/frozen.json)。同12条输入，两路真实调用，交替先后顺序：

| 指标 | 旧路由 | 修正后路由 |
|---|---:|---:|
| 正确直达（6条可执行） | 2 | 4 |
| 错误参数 | 0 | 0 |
| 可执行但回退 | 4 | 2 |
| 错误放行（6条应回退） | 1 | 0 |
| 请求p50 | 289ms | 312ms |
| 请求p95 | 747ms | 795ms |

旧方案将“只调整第二段译文为宋体，其余保持”放行成全页字体操作，新方案识别partial并回退。两条网站原字体请求仍因extra判断不够确定而回退，保留原结果，不降阈值追分。

新集满足预定的“直达增加、无错参/错误放行/服务失败”条件，退出码0。这个小样本不能证明生产错误率；所有新题由主代理编写，未做独立出题或真实用户流量抽样。参数选择与意图/范围模型判断全部有误差可能。

本轮真实调用：开发23次，新24题对照46次，修正后新12题对照22次，共91次（无译文样本在代码层跳过）；旧开发基线从已存响应读取，未重复计作新调用。修正后新路由输入11769 tokens，旧路由6720 tokens；保留7问题作可比性验证，成本更高，未声称最低成本。

## 最终判断与验证边界

拆开不同职责确实改善了局部范围识别；给同一参数再加一个存在性判断则制造了额外回退。最终保留当前委托、额外任务、局部范围三项控制判断，实际参数只消费一次；未请求的维度不因为其选择概率不足而挡住其他明确操作。

严格本地快捷命令及所有生产路径保持。新增实验文件不自动接入会话、任务账本或扩展；没有修改日常模型、重载扩展或操作用户页面。下一步可用此候选进入隔离执行链检查页面身份、取消、混合指令与回执一致性，尚不能直接接入日常产品。

已验证组合逻辑：局部范围/额外任务拒绝、低概率实际参数回退、不合法答案拒绝、无译文不执行，以及低确定性的未请求维度不误挡明确字体。所有输入和原始响应已保存；差异检查通过。未跑全仓产品测试或构建（未改生产代码）。
