# 任务: 用户能找到、看懂、改掉、删掉自己的记忆，每次写入都有回执（预览原型）

预览原型：`docs/previews/memory-management.html`（浏览器直接打开；R 键复位可反复演示）。
状态：预览已经用户目测认可（2026-10-06「还行的不错」）；2026-10-07 已实现，证据见文末「实现」。

已核实的事实：记忆抽屉已存在（`extension/src/sidepanel/main.ts:193` memory-drawer，顶栏数据库图标进入，能看、能忘、能恢复旧任务）。本任务的缺口是：入口没有名字（只是图标）、不能改、不能搜、写入没有回执。方案是补强而非新造。

## 规则

- R1 入口有名字：顶栏图标变为「记忆」文字入口；回答里的「用了 N 条记忆 ›」可展开看到具体用了哪几条
  - 例子(正)：点「用了 2 条记忆 ›」弹簧展开，列出本条回答实际引用的记忆及来源 — 谁检查：Playwright 断言展开后条数与 toggle 计数一致（预览已跑通）
  - 例子(反)：用户看完「用了 2 条记忆」后找不到这 2 条是什么（现状） — 谁检查：人
- R2 每条记忆可「改」：内联编辑，存后立即生效并给反馈
  - 例子(正)：点「改」→ 文本变输入框 → 点「存」→ 条目高亮 + toast「已更新，下次回复生效」 — 谁检查：Playwright 断言文本更新且 toast 出现（预览已跑通）
  - 例子(反)：想改一条记错的记忆，只能先忘掉再想办法让它重记 — 谁检查：人
- R3 每条记忆可「忘掉」，且可撤销
  - 例子(正)：点「忘掉」→ 条目弹簧收拢消失 → toast「已忘掉，不再用于新回复 · 撤销」，点撤销条目恢复 — 谁检查：Playwright 断言收拢后计数减 1、撤销后恢复（预览已跑通）
  - 例子(反)：忘掉是不可逆弹窗确认，或忘掉后才发现记错了没法找回 — 谁检查：人
- R4 单条记忆可只在当前对话停用（「这里别用」），不影响其他对话
  - 例子(正)：点「这里别用」→ 条目标灰并标注「此对话不再使用」，可随时「恢复」 — 谁检查：Playwright（预览已跑通）
  - 例子(反)：为了让这次不用某条记忆，只能整条忘掉 — 谁检查：人
- R5 抽屉可搜索，空组自动隐藏，组头计数跟着搜索结果走
  - 例子(正)：搜索「马拉松」→ 只剩匹配条目，组头显示「全局 · 1 条」 — 谁检查：Playwright 断言可见条目数与组头计数（预览已跑通）
  - 例子(反)：搜索后组头还写着过滤前的总数 — 谁检查：Playwright
- R6 每次纠正写入记忆都有回执，且能直达新条目
  - 例子(正)：用户纠正后对话里出现回执（定格小光球 +「已整理这次纠正 · 查看」），点「查看」自动开抽屉并高亮新条目 — 谁检查：Playwright（预览已跑通）
  - 例子(反)：纠正完没有任何痕迹，用户不知道助手记没记住、记成了什么 — 谁检查：人
