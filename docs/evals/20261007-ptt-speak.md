# 任务: 按住说话交代的事做完，念出结果和「留给你的」

来源：#125 第 3 步（念结果，总览 #106）。10-07 用户定：念结果用 MiniMax `speech-2.8-hd`，只用订阅 Key（「只有 Realtime 3 走 API 计费」）。胶囊（第 2 步，[验收](20261007-ptt-capsule.md)）已经显示结果，本任务让它同时念出来。

## 规则

- R1 按住说话交代的任务做完时，念出回答的第一句；目标核对说还差时，接着念「留给你的：…」。停下来等你时，念「需要你：…」。已停下、出错时不念。侧栏关着也念
  - 例子(正)：说「把这三家整理成一张表」，做完听到「已经按营收排好了表，Lumen 最高。」 — 谁检查：`ptt-capsule.mts`（离屏文档真的放完了声音，时长对得上）
  - 例子(反)：按 Esc 停下的任务不念 — 谁检查：`ptt-capsule.mts`（第 2 轮没有念结果的请求）
- R2 只用 MiniMax 订阅 Key（`sk-cp-` 开头）。设置页拒绝其他 key；请求只发 `https://api.minimaxi.com/v1/t2a_v2`，模型 `speech-2.8-hd`。没填 key 或关了「做完念出来」时，不念，也不报错
  - 谁检查：`ptt-capsule.mts`（设置页填按量格式的 key 被拒；离屏文档的请求地址与模型）
- R3 念的时候，光球是「在说」的样子。按 Esc、点 ✕ 或再按住右 ⌥，马上停下。念完以后，胶囊才开始倒计时收起
  - 谁检查：`ptt-capsule.mts`（第 3 轮念到一半按 Esc，声音停下，胶囊还在）
- R4 念失败（网络断了、key 失效）时，胶囊照常显示结果，对话里写一行原因
  - 谁检查：代码审阅

## 技术前提

- 前提：MiniMax 订阅 Key 能流式返回 24kHz 16 位 PCM，边收边放。小实验：用 Python 直接请求 `t2a_v2`，`format: pcm`、`stream: true`。结果：通过（10-07）。
  - 0.94 秒收到第一段声音，一句 4.9 秒的话分 6 段送完。
  - 声音在 `status: 1` 的段里，用十六进制编码；`status: 2` 是收尾段。
  - 字节序是小端：按小端读，相邻样本差值与振幅之比是 0.17；按大端读是 1.0，也就是噪声。
- 前提：离屏文档能直接放声音，不需要用户先点一下。由验收脚本检查：无头 Chrome 没有打开自动播放的参数，离屏文档的 `AudioContext` 要真的走完这段时长才算通过。

## 边界与不做

- 侧栏的免按键模式（Realtime 3）照旧，用它自己的声音。
- 不念整段回答，只念第一句；细节在胶囊和侧栏里。
- 音色先固定一个（`female-shaonv`）。要不要可选，等听过再定。

## 实测

- 真实路径 `ptt-capsule.mts`（10-07）：跑了 3 次，后 2 次通过。条件：无头 Chrome，侧栏关着；听写连真实的 Step Plan 套餐，念结果连真实的 MiniMax 订阅 Key，助手用脚本模型。
  - 设置页拒绝了按量格式的 key，提示「只接受 MiniMax Token Plan 的订阅 Key」，存储里没有写入。
  - 第 1 轮：结果一出现就开始念，0 毫秒延迟。离屏文档放完 2.8 秒的声音，胶囊才去掉「在说」。只念了第一句，回答的第二句没念。
  - 第 2 轮：按 Esc 停下的任务没有发出念结果的请求。
  - 第 3 轮：念到一半按 Esc，0–0.25 秒后声音停下，胶囊留着。
  - 只有两个念结果请求，都发往 `https://api.minimaxi.com/v1/t2a_v2`，模型都是 `speech-2.8-hd`。
  - 无头 Chrome 没开自动播放，离屏文档的 `AudioContext` 也走完了全部时长。所以离屏文档放声音不需要用户先点一下。
- 代码审阅（另一个审阅代理）没有发现计费问题，指出 4 个缺陷，都已修，修后真实路径重跑通过（第 4 次）：
  - 念完的回调会把过期的胶囊盖回去（比如已停下又被换成「等你」）。现在每句话带编号，过期的回调不改胶囊；任务再跑、停下、出错时，正在念的那句作废。
  - 「留给你的」晚到时不会念。现在按念的内容判断：内容变了就重念，同一句不念第二遍。
  - 连接半开时会一直显示「在说」。现在 45 秒超时。
  - Key 被拒时，MiniMax 回的是不带 `data:` 的 JSON，原因被吞成「没有收到声音」。现在读出原因。
- 第 1 次失败：第 1 轮松开后，胶囊直接显示「没成」，失败出在听写这一步。后两次没有再出现。原因不明：当时没截图，胶囊上写的原因没留下来。之后验收失败时会自动截图。
- 只靠代码审阅、没有跑到的：念「留给你的」和「等你」；念失败时对话里的说明（R4）；关掉「做完念出来」后不念。
- 没测：真实扬声器的音量和音色观感。示例音频由同一接口生成，放在本次会话的 scratchpad 里（`ptt-probe/speak-sample.wav`），给人试听。
