# 任务：输入或说翻译命令，在当前网页逐段显示译文并继续调整

用户确认：主代理独立实现；默认双语，明确要求仅译文时直接切换，用户决定显示方式。

> 后续真实用户长文试用曾失败；短页通过不足以证明长文可用。原因、修复和原页面最终结果见[故障验收](20260916-page-translation-failure.md)。以下保留早期证据。

## 完成标准

- [x] 侧栏输入“翻译这个页面”，当前网页逐批显示中文译文，默认双语；明确仅译文请求直接采用该模式 — 谁检查：主代理，隔离无头真实扩展及真实模型。
- [x] “只要译文 / 恢复双语 / 恢复原文”实际改变网页；模式切换不重新翻译，链接与原 DOM 保留 — 谁检查：主代理，真实模型命令和浏览器断言。
- [x] 译文可调整字号；重复翻译复用已有结果，动态改文不套用旧译文 — 谁检查：主代理，浏览器边界测试。
- [x] 停止/纠正、文档导航、部分失败不追加迟到译文、不串页；已完成结果保留 — 谁检查：主代理，定点自动检查。
- [x] 语音转写后的命令进入现有任务链路；真人麦克风与听感单独记录 — 谁检查：自动分类/派发验证；真人最终验收。
- [x] 相关类型、契约、权限闸门、单测、构建通过，检查本轮差异 — 谁检查：主代理。

## 实现边界

- 普通网页的可读 DOM 文字；编辑区、代码、隐藏内容、图片文字、PDF、跨域框架不纳入正文翻译。
- 复用当前会话模型及既有控制权/请求身份；不增加供应商或凭据。
- 翻译时分批处理当前文档，包含运行中新增的正文；完成后新增内容可用“继续翻译”处理，不启动无期限后台任务。
- 页面显示保留在当前文档内；刷新或导航后恢复网站原文。
- 不提交/发布，不自动重载日常扩展；保留其他正在进行的修改。

## 证据

### 通过

- 真实隔离扩展 + 当前会话模型 `opencode-go/deepseek-flash`：5 条侧栏文字指令通过（默认双语、仅译文、切回双语并改字号、恢复原文、首次直接要求仅译文）；2 条语音转写经过生产 `routeVoiceInput` 派发，网页模式/字号实际变化。见 [完整路径结果](20260916-page-translation/live/results.json)。这里只是产品原有模型调用，没有委派开发子 Agent。
- 4 条语音分类检查通过，完整原话保留；空闲跟进允许分类为 start 或 steer，由真实派发结果判定成功。见 [分类证据](20260916-page-translation/voice-results.json)。
- 9 项真实无头浏览器检查：段落逐批插入、代码/编辑区/隐藏文字排除、链接和原节点/监听器保留、模式与字号切换、原始 HTML 完整恢复、迟到结果拒绝、源文变化保护、新增正文收集、文档导航隔离。最终恢复样式修改连续两次通过。见 [浏览器结果](20260916-page-translation/browser-results.json)。
- 定点测试验证模型输出缺项/错位、空白分隔、取消、真实工具轮次闸门拒绝旧批次、部分失败保留结果。普通单测最终 195 文件 / 1793 项通过；Agent 与扩展类型检查、模块边界、构建及差异空白检查通过。未运行规模及正式发布评测。
- 人工查看了真实模型双语截图，原文字号层次继承网站、译文可读且保留链接；最终观感和真人麦克风仍由用户验收。[双语截图](20260916-page-translation/live/bilingual.png) · [仅译文截图](20260916-page-translation/live/translated.png)。

### 延迟与限制

- 同一短文页面最新一轮：默认翻译约 **6.47 秒**收到第一批已写入回执，整轮 **9.32 秒**；仅译文切换约 **2.02 秒**写入、整轮 **4.08 秒**；恢复双语和字号约 **2.55 秒**写入、整轮 **5.01 秒**。时间从侧栏发送开始，第一批时间取浏览器回执，非逐帧视觉计时。
- 早一轮默认翻译整轮约 37 秒，说明供应商/会话延迟波动明显；不以最新短文成绩承诺所有网页即时完成。
- 语音转写派发两例整轮约 9–10 秒，不包含麦克风、ASR 停句、TTS 播放；真人完整语音体验未跑。
- 首版翻译当前已加载的 DOM 正文（含运行期间新增文字）；完成后新增内容需“继续翻译”。单段超过 12000 字符或 64 个文本节点会计入 unsupported 并保留原文，模型输出失败也保留之前的译文。每次执行最多 128 批、4 分钟。
- 图片、PDF、嵌入框架和封闭 Shadow DOM 不覆盖；网页刷新后不保留译文。不扩展成无限后台翻译服务。
- 本轮未提交、未发布、未重载日常扩展。

### 失败与修正依据

- 初次连接检查漏发重连消息，隔离扩展未连接；补齐既有验收入口的 retry 后通过。此前复用了同一运行记录，现已改为每轮独立运行目录。
- 首轮单测暴露模型工具预算增加 1 项和提示词长度超限。整页翻译合并为一个工具，团队工具预算 27→28、无团队仍为 23；没有放宽提示词长度，删除本轮重复说明，继续满足 15000 字符原门槛。
- 原语音分类测试把空闲时的 steer 直接判成故障，但生产 manager 已会将它转成 start。本轮临时提示词修改已撤回，改为验证完整派发及网页结果；没有修改语音生产规则。
- 真实模型首条指令有一次页面归属工具拒绝，随后正常恢复并完成翻译；最终结果保留该错误，不把所有工具零错误作为用户路径的替代标准。page_translation 无失败。未在本任务修改归属机制。
- 字号恢复曾留下空 style 属性；现在核对实际属性后移除本功能增加的样式，保留网站其他样式。最终按原始 HTML 比对通过。
- 并行阅读任务曾临时引入类型错误；未改其测试，最终整体类型检查已恢复通过。

### 维护取舍

新增生产代码约 250 行，主要集中在文档内的段落识别、译文状态和恢复；另有模型调用、工具接线与权限/页面身份登记。模式切换和重复翻译复用同一批段落记录，模型仅返回文本，不写 HTML；每次落页仍经过原执行闸门。没有新增依赖或另建供应商通道。相对 HEAD 的其他大量改动属于既有/并行工作，不计入本任务。
