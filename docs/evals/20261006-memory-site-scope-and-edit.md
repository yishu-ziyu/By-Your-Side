# 任务：「只在这个站用」能按网站记住；「要我记住吗」卡片可以先改一下再记

[issue #28](https://github.com/yishu-ziyu/By-Your-Side/issues/28)（BYS-123）· [记忆模型](../memory-model.md)

## 规则

- R1 用户在某个网站说出关于自己的资料，同时说「只在这个站用」或意思相同的话：这条按该网站范围记住，并给「撤销」，不能判成只用这一次。
  - 正：在 demoqa.com 说「我在这个网站的地址填上海市浦东新区，只在这个站用」，记成 demoqa.com 范围的资料。机器检查：定点测试，加上真实快速模型探针（gpt-6-luna，5 次至少 4 次对）。
  - 反：「这次地址填上海市浦东新区」仍然只用于这一次，不记。机器检查：同上。
- R2 「要我记住吗」卡片多一个「改一下」：点开后可以改规则文字，再点「记住」，存下的是改后的文字，范围按卡片当时的选择。
  - 正：把「导出时选全部」改成「导出时选全部并勾选附件」再点记住，记忆面板里显示的是改后的文字。机器检查：`scripts/acceptance/real-path/remember-corrections.mts --headless --scripted` 新增的场景。
  - 反：改成空白，或者改成密码、验证码一类的内容，不能存下，卡片上给出原因。机器检查：同上。

## 证据

- 原因（R1）：快速模型把「只在这个站用」当成「只用这一次」（`about.onlyThisTask=true`），代码据此判为一次性，不记。改法：判断提示里写明网站限定说的是在哪里用、不是用多久，并给出「值 + 只在这个站用」应按网站范围保存的例子（`agent/src/memory-decision.ts`）。
- 真实模型探针（gpt-6-luna，ChatGPT 登录，在 demoqa.com，2026-10-06）：
  - 改前：「我在这个网站的地址填…，只在这个站用」自动判断 1/5、明说记住时 0/5 按网站记住；「这个网站以后地址都用…」5/5；「这次地址填…」5/5 不记。
  - 改后：上述正例自动 5/5、明说 5/5；反例 5/5 不记。补测「我的邮箱是…」3/3 记成所有网站，「这次在这个网站地址填…」3/3 不记。
- R2：卡片多「改一下」，点开是输入框，「记住」存改后的文字，范围用卡片当时的范围；空白、过长、像密码的被拒，原因显示在卡片上，草稿保留，可以改好再点；被拒的原文不进诊断记录。
- 端到端：`npx tsx scripts/acceptance/real-path/remember-corrections.mts --headless --scripted` 全部通过，含新场景 23edit（改后存「导出时选全部并勾选附件」，范围 crm.test；空白与密码各被拒且不写入）。
- 定点测试：`agent/test/memory-correction-ask.test.ts`、`extension/test/memory-ask.test.ts` 新增用例先写；`npm run test:unit` 254 个文件 2409 项通过；`npm run typecheck`、`npm run build` 通过。
- 收尾：执行者中途停止，主代理核对改动与探针记录后补跑检查并提交。
