# 任务: 界面上同一件事只用一个词，看不到内部名（#247）

依据：10-11 文案审校报告（`assets` 分支的 `20261011-copy-pass/`，不合并）。用词以[术语表](../glossary.md)为准。

## 规则
- R1 「中止」在侧栏、页面上的按钮、语音胶囊里同名，状态写「已中止」。
  - 例子(正)：页面右上角按钮写「中止」，点了写「正在中止」 — 谁检查：`npm run check:copy`（拦「停下」「已停止」「收手」）
- R2 界面上不出现 Agent、AI、成员、检查点、基线、伴随进程、控制权、工件、凭据、令牌、忘掉、截屏、key — 谁检查：`npm run check:copy`，CI 的 Quality 也跑
- R3 自动记住的记忆写成不带主语的短句。
  - 例子(正)：说「我坐飞机都要靠过道」，存下「坐飞机要靠过道」，不是「用户…」或「我…」 — 谁检查：工程师用真实模型跑，结果见下
- R4 文案读起来自然，没有公文腔 — 谁检查：人（用户）

## 还没答上的问题
- 无。Q1（按钮名）用户 10-11 定：保留「接管」「交还」，改术语表。Q2（语音的「需对应服务可用」）：说不清要用户做什么，所以删掉，只写「下次开启语音时生效」。Q3（「交付」）：保留。

## 技术前提
- 前提：界面字符串能从源码里机器取出。仓库的 typescript 7 没有 JS 解析器，所以检查脚本自己扫字符串字面量。小实验：直接跑检查，修改前报 69 处，人工看过都是界面文字或给模型看的工具结果（后者按标记跳过）。结果：通过

## 边界与不做
- 只改文案和记忆提示词，不改交互和样式。
- 给模型看的工具结果不按界面用词改；动作卡展开后的「技术详情」（报告 2.44）没做，要改动作卡的结构，另开任务。
- 语音胶囊「交给助手了」在确认收到前就显示（报告 7.7）是行为问题，没改。
- 开发面板（报告 8.3、8.14）的文字没改。

## 结果（2026-10-11）

- R3 真实模型（阶跃 step-5-preview，低档）：新提示词下「我坐飞机都要靠过道」3 次都存成「坐飞机要靠过道」，「我不吃香菜」存成「不吃香菜」。旧提示词同样输入存成「坐飞机时要靠过道的座位（长期偏好）」「我不吃香菜」。
- 按住说话没听到声音的提示：macOS 写「右 ⌥」，其他系统写「右 Alt」。麦克风授权页按系统给设置路径。只读了代码，没在 Linux 上跑。
