# 任务: 用当前默认模型重测三个即时动作，替换 STATUS 里 9 月底的速度数字

来源：10-11 用户要求。STATUS 里的速度数字是 09-24 到 09-27 用阶跃和智谱测的，之后默认模型换成了 gpt-6-luna，没有重测。

## 规则

- R1 用 09-26 的同一个脚本、同一张测试页，把主模型换成 gpt-6-luna，三个动作各跑 5 轮，记录页面第一处变化的时刻 — 谁检查：`npx tsx scripts/acceptance/real-path/instant-baseline.mts --headless --rounds=5 --model=openai-codex/gpt-6-luna`
  - 例子(反)：页面没有变化时，脚本记为「无可见变化」，不记成 0 秒 — 谁检查：同一命令（本次「价格在哪」5 轮都记成了无变化）

## 技术前提

- 前提：脚本仍能在当前主干上跑通。结果：通过，15 轮 0 报错。

## 边界与不做

- 没有设快速模型：测试用的 Kimi 登录已过期。用户日常扩展里设的快速模型可能更快，本次没有测。
- 每个动作只跑 5 轮，数字只说明量级。

## 结果（10-11，主干 b887259，机器负载约 4.6–5.6）

| 动作 | 09-26（阶跃主模型 + 智谱快速模型） | 10-11（gpt-6-luna，无快速模型） |
|---|---|---|
| 划词解释，第一行字 | 中位 2.04 秒 | 中位 3.2 秒；1.6、1.7、3.2、6.4、6.6 秒 |
| 当前一屏第一段变中文 | 6.1–11.3 秒，回退时约 27 秒 | 中位 4.5 秒，4.3–6.5 秒；一屏译完 11.3–14.7 秒 |
| 「价格在哪」页面变化 | 4/5 轮 2.8–7.0 秒滚到并圈出 | 0/5 轮；文字回答都对，2.4–7.9 秒 |

- 解释的耗时几乎全是 ChatGPT 接口的首字：点击送达后约 0.07 秒就发出请求。
- 「价格在哪」不再滚动、不再圈出，原因是快速模型的找东西捷径（`find-intent`）于 10-04 在「砍掉半成品与预判」里删除；现在由主模型回答，它只回文字。要不要恢复这个页面变化，由用户决定。
