# 任务: FIX-02 等待语义与证据必须真实

版本日期：2026-09-22。网站仍有请求未完成时不能说 network-idle 已就绪；等待中取消/权限/连接故障按类型传出，不吞成「目标尚未出现」。

## 完成标准

- [x] 1. 有一个请求未结束超过 idleMs 时 helper 不提前返回 idle；结束后静默窗口满足才返回 — 谁检查: `npx vitest run agent/test/fix02-wait.test.ts`
- [x] 2. 覆盖失败、重定向、ring 满、clear 展示、detach/重启/晚接入；证据不全 → 不完整/超时 — 谁检查: 同上 + `extension/test/network.test.ts` 既有 ring 语义
- [x] 3. 等待期间 abort/权限拒绝立即停，不吞成目标尚未出现 — 谁检查: `fix02-wait.test.ts`
- [x] 4. document 替换与 tab 切换不返回混合身份或旧文档就绪 — 谁检查: 同上
- [x] 5. 新增等待状态逐项验收；可见且启用不冒充 hidden/detached — 谁检查: 同上
- [ ] 6. `browser_run` 真实入口等待后动作 + 宿主账本顺序 — 谁检查: 隔离浏览器 — **未跑**（本票无隔离浏览器授权/未启动）

## 边界与不做

- 不改上传授权、CDP 允许集、点击/悬停测试装载、选择链、`docs/STATUS.md`、用户本地文件 UI。
- 不取消既有 15 秒空闲 detach，不永久 attach。
- 不重建恢复协议；不把 network-idle 当作页面业务完成。
- 不 commit / push / 重载日常扩展 / 新建 worktree。

## 实现要点

1. `shared/network.ts`：有界在途集合 + 捕获代次/完整性；`NETWORK_IDLE_EXCLUDED_TYPES = websocket|eventsource` 显式可测；展示 ring 丢弃/clear 不抹在途。
2. `network-log.ts` / `exec/network.ts`：复用同一监听器；回执含 `inFlight`/`integrity`/`generation`/`lastActivityAt`。
3. `debugger.ts`：detach 同步捕获完整性；默认晚接入为 late；Document 请求可提升为 ok；保留 15s idle detach。
4. `browser-program.ts`：`waitForNetworkIdle` 按在途+静默+完整捕获判定；`pageInfo`/`waitForLoad` 防身份串扰；子调用可区分 ID；错误按码分支（仅 NOT_FOUND/NOT_READY 可重试）。
5. `read-element.ts`：对外错误加稳定码前缀，供等待 helper 分类。
