# 任务：跨页工作以角色轻量入口呈现，不重复显示旧页等待状态

## 完成标准
- [x] 单角色显示身份与页面短标题，完整标题可查看；点击或键盘进入正确标签页。
- [x] 多角色聚合且可分别跳转；状态结束、停止和迟到回执不复活入口。
- [x] 工作页切换清除旧状态，同角色跨页入口不与旧光标提示重复。
- [x] 原光球、角色资产、侧栏阅读优先与任务调度保持；窄屏与减少动态可用。

主代理以生产 content bundle 的无头浏览器和后台状态测试检查；视觉由用户最终判断。不将页面标题推断为未经证实的动作。

## 实现与维护

复用角色名册和现有角色图形；跨页数据由已有后台成员表生成，沿用队列与迟到绘制保护，不另设状态源。新增成员列表与键盘交互，单角色仍直接跳转。仅公开角色PNG资源供网页显示；内容脚本因复用现有角色图形数据增加约80KB，不增加运行依赖。角色图形静止，不新增循环动效。

初次浏览器测试的模拟runtime缺getURL，Omar图片角色路径报错；补齐实际图片资源映射后通过。正式manifest同步公开cast图片，避免只在侧栏可见而网页不可见。
