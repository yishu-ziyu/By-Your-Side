# 任务: 侧栏回答按稳的节拍一段段淡入，不再跟着模型一阵一阵跳

用户在 claude.ai 对照过流式手感，#262 写了节拍和淡入参数。这一条只改侧栏怎么把已经到的字放出来。

## 规则

- R1 字按段出来：一段大约十几个到二十几个字，约 0.2 秒放一段；模型一阵给很多字时，大约 1.5 秒内追平，答完后不再多等。
  - 例子(正)：模型一阵 2 个字、一阵 28 个字，中间卡约 1 秒，侧栏仍一段段往外放，卡的时候不闪光标 — 谁检查：人看左右同播录像；机器：`scripts/acceptance/real-path/plain-text-streaming.mts`
  - 例子(反)：积压空了就硬停、速度跟着模型忽快忽慢 — 谁检查：同上
- R2 每段 400ms 只改透明度淡入，淡完字留在正文里；减弱动态或打开旧会话时整段直接出现。
  - 例子(正)：新到的一段从透明到清楚，流结束后没有淡入外壳；系统开了「减少动态」时没有淡入 — 谁检查：`plain-text-streaming.mts`（流完后淡入 span 为 0）；减弱动态由 `revealText` 直接整段显示
  - 例子(反)：每个字带模糊闪一下，或答完还留着淡入外壳 — 谁检查：同上

## 技术前提

- 前提：只改侧栏显示层就能换手感，宿主仍然把每个增量原样转过来。小实验：#262 原型 `20261011-stream-proto`（资产分支）。结果：通过（同一条到达时间表，改后约 20 段，整段重渲染 0 次）

## 边界与不做

- 不改默认正文字体，衬线仍由「字体字号 → 宋体」提供。
- 不在宿主端缓冲模型增量。
- 思考行换字交叉淡入不在这一条。
- 回答里的卡片不按节拍放：卡片标记一到就放，空位和组件淡入由卡片自己负责（`card-placeholder.mts`）。按节拍切在组件中间时，写得快的组件也会闪出占位条。
