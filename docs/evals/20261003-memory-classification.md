## 边界与不做

- 沿用现有纠正判断、确认卡片和存储，不新增服务、模型、向量库或全局配置。
- 复用模型判断只能验证已测场景，不承诺语义分类绝不会错；格式缺失的拒绝由代码确定。
- 先在隔离Chrome验收；日常升级前核对空闲状态并保护原数据。

## 实施前列出的失败方式

- 缺失 about 或畸形关键布尔值触发 longTerm=true 回退。
- about 合法但网站步骤被模型误答为个人偏好，压掉纠正询问。
- 自动路径被拦，工具兜底或补判重新写入。
- 新检查把靠过道等个人偏好也拦住；忘记被无用字段拒绝。
- 新检查重复问同一句或失败后偷偷写入；用户停止后晚到结果仍落盘。
