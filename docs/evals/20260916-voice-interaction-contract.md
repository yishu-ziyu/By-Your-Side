# 任务：语音能连续交流、修改当前任务并可靠停住

## 用户要求与范围

2026-09-16：用户要求先清晰定义功能标准、验收现象和指标，由主代理直接推进，不派发子 Agent。主代理持续提供下一步操作，不把制定计划当完成。先验收既有语音路径，再依据失败修复；本轮不改变诊断界面、不重载日常扩展、不提交发布。

## 完成标准

以下是本轮检查清单，未勾选不等于已发现产品失败。

- [ ] 自然修改：网页翻译运行时，连续说“只保留译文”“字体改成宋体”；原页落实两项要求，不强制逐句读回、不重复派发、不被旧结果覆盖。冲突要求以最新要求为准，非冲突要求保留。— 谁检查：机器核对派发身份及最终 DOM，人确认说话过程。
- [ ] 打断播报：旧回答正在有声播放时开口，旧声音停下，迟到音频不续播；随后新话完整识别并正常回应。— 谁检查：生产音频图测量、人耳确认；至少一次正常新轮完成。
- [ ] 暂停任务：分别在生成中、动作排队、动作执行中说“暂停”；暂停生效后不启动新写入，旧代次写入被拒绝，回执与页面状态一致。记录已经发出的在途动作及结果，不声称撤销已发生动作。— 谁检查：真实浏览器动作时间线、页面结果、人确认回执。
- [ ] 暂停后继续：暂停期间人工改一个页面值，再说“继续”；使用最新页面状态，保留修改要求，不重复已完成动作。— 谁检查：真实页面前后值、任务身份和操作计数。
- [ ] 故障恢复：分别覆盖权限拒绝、断连、空转写及音频失败；提示与实际失败阶段一致，可再次发起有效语音；未知执行结果不自动重放网页动作。— 谁检查：定点故障注入、恢复后的完整新轮。
- [ ] 首声：普通问答沿用 ≤4 秒、页面问答沿用 ≤5 秒的既有目标；计时为最后一个字结束到实际可听见的有效回答。占位反馈另列，不能算答案首声。— 谁检查：声学记录与人确认有效回答。
- [ ] 日常入口：以上关键路径在用户实际加载的扩展、普通语音模式下通过。— 谁检查：人；记录构建/会话身份，不以当前源码等同已加载版本。

## 测量与判定

- 同一类别至少 20 次固定用例尝试，报告样本数、P50、P90、P95、最大值、超时/无回应数及目标内次数；nearest-rank 分位数。失败样本不得静默剔除或重试替换。
- 4/5 秒目标历史上存在不同统计口径。本轮先逐次判断是否达到并报告分布，不擅自把目标改为“中位数达标即可”。整体分位数门槛若需改变，交用户裁决。
- 插话分别记录：开口→检测、检测→音频图静音、开口→实际停声。既有内部门槛为检测后 P95≤200ms；它不是真人全程停声门槛。真人总延迟尚无获认可数值，先实测并由人判断自然程度。
- 停止播报与暂停网页操作是两个动作，分别测量。网页静止观察窗口必须覆盖测试动作的排队/执行周期，并用旧代次写入探针核对，不能只截一张静态截图。
- 函数被调用、回执 accepted、首帧收到均是中间证据，分别不能替代网页改变、页面停住和耳朵听见。

## 第一条真人操作

1. 日常侧栏开启普通语音，不开启诊断录音。
2. 说“你好，请简单介绍一下你能帮我做什么”。
3. 正在播报时插话“先别说了”。
4. 待停声后说“十加七等于多少”。
5. 记录是否停声、有无旧句续播、最后是否正常回答17，以及测试的大致时间。人的“立即”判断不换算成未经测量的毫秒数。

下一步根据该轮现象定位收音、转写、意图还是播放层；若通过，继续运行中修改与暂停恢复。诊断标记只提供日志定位，不执行纠错。
