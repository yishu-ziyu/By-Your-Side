# 任务：读 MDN 不因响应落盘失败锁住后续阅读

## 完成标准（实现前）

- [x] 扩展内成功读取超过 4,000 字符响应，不调用本机文件系统，给出有界且标记不可信的正文 — 机器：扩展运行时契约测试
- [x] 扩展不支持的保存/批量落盘参数在请求发出前拒绝 — 机器：工具入口测试
- [x] 已取得 GET 执行回执后的本地处理失败不变成未知写入；无回执 GET 与 POST 的保护保留 — 机器：生产 TaskProgress 测试
- [x] 历史未知请求不阻塞当前页滚动/圈画，但不清除旧账、不解锁真实写入，不绕过接管/取消 — 机器：任务执行闸门测试
- [ ] 原 MDN 三轮要求实际读页、滚到 5 秒示例并圈出，不重复要求确认，不误报全部完成 — 人与已安装扩展的允许环境复验；本云环境不能执行

## 原始失败与边界

2026-09-30 用户实际纯扩展路径，模型 opencode-go/mimo-v2.6-flash，页面 MDN AbortSignal。第一轮正确解释与示例已出现，但回执报“发送网络请求（结果待确认）”。第二轮明确不执行示例、只滚动圈画，第三轮明确继续，仍未恢复；过程显示已完成而正文说暂停。只有 UI 证据，无后台调用/响应日志。不能把模型关于宿主的解释当成后端诊断。

首轮隔离修复在云端进行，不使用本机、不安装扩展、不发真实模型请求。隔离测试只复现代码路径，不能冒充该次真人失败的最终归因。

## 失败模式（先于实现）

1. 超过 4,000 字符的成功 GET 在格式化时强制 mkdir/write；扩展 node:fs shim 抛错，读页失败。
2. 小响应带 savePath、批量 pages 可以先发请求再发现无文件系统；不能用请求后的错误掩盖已发生操作。
3. GET 的 executed 回执被格式化异常转成 unknown，制造无写入前基线的永久阻塞。
4. 真正未知 GET、POST、点击/输入不能因阅读修复而获得重复执行权限。
5. scroll/mark 是本地阅读展示，不能与业务写入共用未知结果闸门；但用户接管、取消、重启检查点仍须拦截，已有未知圈画也不能盲重放。
6. 过程结束不能等同用户目标完成；内部字段不应作为面向用户的回答。

## 证据

先写扩展无文件系统和 TaskProgress/执行闸门回归，得到 6 失败 / 34 通过。修复后最初 40 项全通过；扩展安全反例后，相关 11 文件 149 项全通过。

- 实际浏览器构建使用的 `config`、`node:fs/path/os/crypto` shim 与修复前/后的 `fetch-result.ts` 分别打成浏览器 bundle，以同一个 30 KB 合成 MDN 响应执行：旧版确定抛“扩展里没有本机文件”；新版返回 16,289 字符的有界回执，包含不可信包装、截断说明且不声称已保存文件。此复现不访问 MDN、不调用模型。
- 生产工具 + ToolRpc + TaskProgress 契约测试：大响应取得 executed 回执并返回正文，不产生 unknown；不支持参数不发请求。安全测试保留未知 GET、POST、取消、接管、重启、同一未知圈画（含 worker）的重放阻断。
- 全单元测试：286 文件、3,114 项通过；规模测试 1 文件、2 项通过；类型检查（extension 与 agent）、架构检查、文档检查及 `--base HEAD` 同步检查通过。
- 原 `npm run build` 仍遇已知云环境 tsx CLI IPC 限制；使用上一轮已验证的临时 `node --import tsx` helper 调用适配后构建通过。生产 build.mjs 未改。
- 过程结束图标文案改为“本轮结束”，不再静态宣称“已完成”；新增不向用户回显内部字段的模型指令。没有用合成模型/静态文案检查冒充真实侧栏和模型已通过。

## 结论与未验证项

已确认代码缺陷链：扩展大响应误走 Node 文件落盘 → 工具在成功 RPC 后失败 → GET 处理失败被登记成未知写入 → 未知写入闸门同时拦截滚动/圈画。修复分别消除前两处错误并拆开阅读展示与业务写入的阻断范围。现有未知记录不删除、不改成成功；未知业务动作仍不可重做。

该链与真人现象吻合，但原会话缺少调用参数、RPC 回执和异常日志，不能宣称已经证明是那一轮的唯一触发原因。模型是否选择已恢复的阅读工具、是否不再重复确认/复述已答内容/泄漏字段，以及实际滚动与圈画位置、耗时仍需原 MDN 三轮真路径复验。云浏览器不能安装扩展，本轮没有绕过该限制。真实路径耗时与发布验收未跑。

## 复验步骤

在允许且已经安装该扩展的环境加载本次构建，在 MDN AbortSignal 页面用原模型执行报告里的三轮原话；核对实际滚到 timeout 章节、圈中 5 秒示例，既不执行示例也不切其他标签。另保留一次未知写入反例，确认继续阅读不能重发请求、点击提交或清除未决账目。导出不含密钥的工具事件，才能把历史真人失败归因闭环。
