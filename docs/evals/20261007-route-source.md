# 任务: 照着走的回答下面写照的是哪一次，点开看每一步，能说「下次别照旧」（YIS-97，走老路第 5 步）

预览：[走老路](../previews/route-replay/index.html) 第二次、页面改了两个场景回答下面那一行。上一步见 [20261007-route-check](20261007-route-check.md)。

## 规则
- R1 照上次的做法走完的任务，回答下面一行写「照 10 月 2 日那次的做法 · 上次 28 秒」（当天的写「今天」）；中途对不上、后面一步步做完的，写「页面和上次不一样，已按这次的做法更新」。一步步做的照旧写「记下了这次的做法，下次照着走」。
  - 例子(正)：真实路径第二次订会议室，回答下面是「照今天那次的做法 · 上次 N 秒」；改版页那次是「页面和上次不一样…」 — 谁检查：`scripts/acceptance/real-path/route-replay.mts`
- R2 点开列出每一步：换成这次说的值加粗；页面变了之后这次重新想的步骤编号标橙色，并写「前 N 步照旧，第 N+1 步起是这次重新想的」。
  - 例子(正)：改版页那次点开，第 3 步起标出来 — 谁检查：同上（数标出来的行）；样子对照预览 — 人
- R3 照着走完、存下这次的做法时，替掉照的那一次的做法：一类事只留最新的一份，下次不会照到旧的。
  - 例子(反)：照走后旧做法还在，下次模型挑了旧的那份 — 谁检查：同上（每次之后只剩一份做法）
- R4 「下次别照旧」删掉这份做法，可撤销；删后下次这类事一步步来。
  - 例子(正)：点「下次别照旧」后过往任务里没有做法；点「撤销」后回来 — 谁检查：同上

## 还没答上的问题
- 无。「下次别照旧」只管下一次：下次一步步做完，会再记一份新做法。用户要一直不照，再点一次。

## 技术前提
- 前提：照走时知道照的是哪条过往任务、那次的开始时间和用时，中途停下时知道这次做法从第几步起是重新想的。全在本进程内已有的数据里（过往任务记录、这次记下的步骤），不需要新的外部能力，不另做小实验。

## 边界与不做
- 不在过往任务列表里加照走标记。
- 照走一步都没做成（第 1 步就对不上）不算照着走，回答下面照旧写「记下了这次的做法」。
- 去留看对照实验（YIS-98）。
