# 任务：语音时光球居中表达状态，字幕卡里当前句墨色

[#55](https://github.com/yishu-ziyu/By-Your-Side/issues/55) · 设计稿：Claude Design 画板「#55 语音状态」方向 A（用户 2026-10-06 选定）

## 规则

- R1 听、想、说由光球自己的动法表达；球下只留一个灰字「在听」「在想」（有具体说明时写说明，如「在读这个页面」）；在说时不写字（只给读屏）。不再有琥珀、青绿胶囊。
  - 正：三种状态下 `.voice-state` 文字为在听 / 在想 / 在说，颜色都是提示灰；在说时视觉上隐藏。机器检查：`scripts/probes/design-check/55/voice-capsule.mts --headless`（本地探针；它按旧胶囊设计写的颜色、文案判据现在应判失败）。
- R2 回答放在白色字幕卡里，说过的句子退成静默色，当前句墨色、常规字重、不加底色。
  - 正：当前句 `color: rgb(20,20,19)`、`font-weight: 400`、无底色。机器检查：同上 A2。
- R3 来源写成一行署名「读了 a、b 等 N 个网站」（同一网站只算一次）；没有来源不显示。停声、结束放在底部居中。
  - 正：注入 3 个同站来源时显示「读了 example.com」；0 个时隐藏；两个按钮不与状态字重叠。机器检查：同上 A3、A4。
- R4 减少动态效果时，光球定格，界面没有其他动画。机器检查：同上 A5（胶囊已删，无动画可查）。
