# 任务: 没连模型的新用户打开侧栏就看到「连一个模型」，连好后刚才的话自动发出

来源：10-11 新用户走查，[#233](https://github.com/yishu-ziyu/By-Your-Side/issues/233) 与 [#236](https://github.com/yishu-ziyu/By-Your-Side/issues/236) 的 P1、P3（侧栏部分）、P4。用户 10-11 裁决：连好模型后直接自动发送，不再问一次。

## 规则

- R1（#233）没连模型时打开侧栏，在用户输入之前，空侧栏显示「先连一个模型」和「连一个模型」按钮，网页建议收起。
  - 例子(正)：全新配置打开侧栏，2 秒内出现这个入口 — 谁检查：`npx tsx scripts/acceptance/real-path/first-run-sidepanel.mts --headless`
  - 例子(反)：侧栏除顶栏和输入框外是空白 — 谁检查：同一命令。故意让后台在没有记录时不回 history，这一项失败（20 秒都没出现）。
- R2（#233）已连模型时，起点引导照常出现，没有连模型入口 — 谁检查：同一命令（连好模型后点新会话）。
- R3（#233）没连模型时发过的话，连好模型后自动发一次，只发一次，问的仍是原来那页。
  - 例子(正)：发「这页讲了什么？」→ 从设置页连好模型 → 模型只收到一次这句话，会话里只有一个用户气泡，连模型期间打的草稿不动 — 谁检查：同一命令看脚本模型收到的请求和侧栏
  - 例子(反)：打开设置页、没连模型就关掉，什么都不发 — 谁检查：同一命令
- R4（#233，F01 修订）卡片先写「连好以后，这句话会自动发出。」，连好后变成「已连上 <模型>」，不再留「还没有连接模型」或「已用…重新发送」 — 谁检查：同一命令与 `connect-first-minute.mts`；措辞好不好由人看截图裁决。
- P1（#236）输入框没字、也没附件、不在运行时，发送键是禁用的灰色；打一个字恢复；运行中仍是中止键 — 谁检查：`first-run-sidepanel.mts` 读 `aria-disabled` 和底色
- P3（#236 侧栏部分）「圈出来问」的按键按系统写：Mac 写 ⌘⇧S，其他系统写 Ctrl+Shift+S — 谁检查：同一命令，本机一次、模拟 Linux 一次
- P4（#236）设置页和侧栏声明不翻译 — 谁检查：人，在英文界面的真实 Chrome 里打开设置页，看不到翻译栏（本次没查）

## 还没答上的问题

- 无。#233 的 Q1 由用户裁决为自动发送；Q2（连模型期间又打了新的话）按「重发原话，新草稿留在输入框不动」处理。

## 技术前提

- 前提：脚本模型能在无头 Chrome 里经设置页真实连上（`configureViaSettings` 填自定义地址）。结果：通过，`welcome-context` 已在用。
- 前提：侧栏能分辨「确知没连模型」。没连时宿主回 `hello_ok` 不带模型、目录为空；连上后目录不空。只看 `model` 不够：后台给非默认会话回放的 `hello_ok` 可能不带 `model`。结果：通过，用例里两种状态都分对了。
- 前提：发送键的 `disabled` 不能改含义，因为很多用例用它判断「会话就绪」。所以禁用样子只用 `aria-disabled`。

## 做法与取舍

- 根因：后台只在有记录时回 history；全新安装没有记录，侧栏一直等不到「回放完」，起点引导永远不出现。改为总是回一条。
- 没连模型时，宿主不建会话，侧栏原来要等两段兜底时限（约 10 秒）才定下会话。现在侧栏确知没连模型时直接用后台选中的会话，入口约 0.3 秒出现。
- 重发用原来那页：连模型时开着的是设置页，按当时的活动标签页重发会问错页（第一次实测就问成了设置页）。现在记下原话发出时的那页，重发时照它发。
- 只有本面板刚发出、收到没连模型回执的那句会自动重发。重开侧栏后回放出来的旧卡片，以及不是本面板发的话，卡片写「连好以后，把刚才的话再发一次。」，不自动发。
- 重发不画第二个用户气泡：沿用原来的气泡。

## 边界与不做

- 重开侧栏后：历史里有两条同样的用户消息，回放时会画两个气泡，旧卡片写「把刚才的话再发一次」。只在实时那次合并成一个。
- 原话带的图片不随重发带上：回执里只有文字。
- 用户在等待期间自己又发了话时，之前记下的那句作废；没连模型时连发两句，只重发最后一句。这两点只读代码确认，用例没有覆盖。
- 设置页的问题（#234、#235、#236 P2、设置页的 ⌘J 写法）不在本次。设置页里的按键写法由另一项任务改。
