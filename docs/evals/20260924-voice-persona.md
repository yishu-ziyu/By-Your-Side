# 任务: 用户能在设置页给语音选人设（默认、罗宾式、自定义），语气随之改变，功能不受影响

方向见[语音交互原则](../voice-interaction.md)。用户 2026-09-24 决定：只作用于语音；选项只有默认、罗宾式、自定义；音色单独选择，不联动。

## 完成标准

- [x] 1. 设置页能选预设、能写并保存自定义内容，存入 `voice_persona` — 谁检查: `inproc-voice --persona=robin|custom|default`（`personaSavedInSettings`，点击设置页真实控件）
- [x] 2. 选中的人设出现在发给 StepFun 的 `session.update` 里；选默认时不附加任何人设 — 谁检查: 同上 `providerGotPersona`（抓取扩展内 agent 的 WebSocket 帧）
- [x] 3. 罗宾式下，问答和终止的真实路径照常通过 — 谁检查: `--case=question`、`--case=stop-task` 加 `--persona=robin`
- [ ] 4. 罗宾式下圈画稳定通过 — 未满足：服务端断句偶尔把“帮我把保存按钮圈出来，不要点它”切成两段，默认人设和不带人设的原路径也会复现（见下方证据），属于既有的断句拼接问题，另行处理
- [ ] 5. 口吻像“罗宾式”：沉静、有见解、偶尔冷幽默 — 谁检查: 人（用户试听）

## 过程中推翻的做法

| 做法 | 结果 |
|---|---|
| 人设附在全部规则之后 | 与默认几乎无差别；模型在自我介绍时复述人设原文 |
| 挪到身份句后，但仍用“人设：用下面的……”旁白写法 | 自定义偶有体现（“靠港歇会儿”），罗宾式仍与默认相同 |
| 改为第二人称写进身份，并给出口吻示例 | 模型照搬了示例句。示例恰好与测试题一样，结论无效，已作废 |
| 示例改为与测试无关的句子，并加入示例之外的留出题 `opinion` | 罗宾式与默认可以区分，见下表 |

StepFun 文档说明，实时模型的人设只能通过 `instructions` 配置，没有专门字段。

## 证据（留出题，产物在 `out/acceptance/real-path/2026-09-24T10-2*`）

| 题目 | 默认 | 罗宾式 |
|---|---|---|
| 我今天有点累，陪我聊两句吧。 | 好呀，今天怎么这么累？是工作太忙了，还是没休息好？想聊点什么放松一下？ | 累就先歇会儿，不急着做事。今天是怎么了，忙了一天还是心里有点沉？ |
| 你觉得这个页面做得怎么样？ | ……看不出整体设计水平。你想让我具体评价哪方面，还是帮你操作这个备注？ | ……功能聚焦，没有多余的东西，这种克制的设计在工具型页面里是加分项。 |

罗宾式下问答通过（“备注写的是：周五前发货。”），终止通过（abort `applied`，回执前没有宣称已停）。圈画：`10-29-05`（默认人设）与 `10-30-20`（不带人设）都复现了断句切两段，`10-30-50`（不带人设）通过。

定点测试：语音相关的 agent 测试 399/399 通过；扩展测试中 `resume-entry` 有 2 条失败，在干净 HEAD 上同样失败。

## 边界与不做

- 冷幽默在样本中没有出现；罗宾式的整体气质需要用户试听后再调整描述。
- 文字回复不使用人设；音色不随人设切换。
- 自适应习惯不在本任务内。
