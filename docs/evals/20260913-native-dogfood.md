# By Your Side 原生电脑控制试用

2026-09-13，用户明确要求以 Codex 原生电脑控制亲自试用，含简单/困难问题、纠正与控制。用户已加载扩展。宿主为真实 ChromeMain，侧栏模型显示 DeepSeek V4.1 Flash (Go)。UI 操作全部使用 cua_repl 的原生应用控制；没有以 CDP、Playwright、注入 RPC 替代。

## 标准与范围

- 读取事实应正确，不编造页面未给出的信息。
- 用户更改要求后按新要求答；区分运行中插话与任务结束后的追问。
- 接管、恢复、中止要有一致且可信的可见状态。
- 多页面动作遵守新标签和不修改原页约束。
- 记录原始失败，电脑控制本身的错误不能直接归因给插件。
- 不联系招聘者、不投递、不写真实外部业务数据。麦克风语音未测。

## 已执行

1. 打开插件：已连接，空会话。证据 01-start.png。
2. 简单读页：“岗位叫什么、在哪个城市、只回答两项”。事实正确，但给了额外地址和免责声明；面板执行耗时 27s，答案后报空响应/重试。证据 02-simple.png/txt。
3. 多条件题：按14薪算年薪、列5要求、是否支持远程。35–56万元计算正确，提取要求正确，明确远程没有写明。执行显示11s；回答后仍报空响应。
4. 纠正：“不要列要求，只要年薪与远程，两句话内”。发送时上一轮已经结束，因此实际是追问，不冒充运行中插话通过。按新要求去掉清单，但输出3句，并再次空响应/重试。执行9.9s。证据03-correction.png/txt。
5. 新会话多页面任务，在开始后点接管：出现“现在归你”“1个Agent已暂停”；未见新网页打开。暂停后改成只开example.com，收到“修改已保存，继续后生效”。证据04-paused.png。
6. 交还与中止：原生点击出现无即时反馈，后续读到任务已中止；页面仍有“现在归你/1个已暂停/交还”，侧栏却显示空闲、已中止。证据05-handback.png、06-aborted.png/txt。交还未完成，不标通过；点击延迟有电脑控制焦点干扰，不能宣称是产品造成。
7. 单步新标签打开 example.com：真实新标签已打开，原招聘页保留；执行显示9.6s。仍出现有效答案后空响应错误。回复中链接实际地址为 example.xn--com,-8k0i458g7d8b31b/，把中文标点和后文“页面显示”当进了URL；未点击该错误域名。证据07-open-page.png/txt。
8. 跨来源比较 Example Domain 和 IANA：真实第二个新标签已打开，3项结论与页面相符，各项来源正确，保留原招聘页和example.com；执行显示23s。仍在有效答案后显示空响应。证据08-multi-source.png/txt。

## 目前发现

- P1：五轮已有有效答案，随后显示“模型空响应/请求失败”。成功与失败同时出现，会诱导重试。只能确认用户可见矛盾，尚未确定是 provider、重试逻辑还是交付终态处理的根因。
- P1：纯文本网址自动链接误吞中文尾文，实际链接目的地偏离用户要求。原网页操作已正确打开example.com，但回执链接指向另一个域名；这项是呈现层可见缺陷，不是模型打不开网页。
- P2：顶部同时显示重复空闲、当前页、会话长标题，答案还在顶部摘要与正文各出现一次。普通两字段问题产生多条橙色通知，阅读负担明显。首次27s只代表本次样本，不推为p95。
- P2：短回答约束执行不严，追加“只读了这页…”等第三句，纠正后仍未严格两句。
- 控制状态问题待定：终止后页面仍说“1个已暂停”，需进一步复现和检查语义；交还效果尚未可靠验证。

## 电脑控制边界

遇到原生点击不聚焦、坐标 noWindowsAvailable、AX/截图不同步。按用户授权重新连接，核对进程后仅重启一次 SkyComputerUseService，未重启 Chrome。原生 setValue 与按钮操作可完成实际提交；遇到无反馈时使用原生窗口菜单、Finder 激活和新快照继续。没有修改系统权限、写授权白名单或换控制技术。此前“计算器与Chrome单次通过”不能视作整个电脑控制已稳定。

独立 DeepSeek 只读复核 01/02 的截图与AX，在约102秒返回。其建议中“页面没有更新时间”与实际页面有2026-09-11冲突，主代理未采用；Chrome自身调试横幅也不直接算插件UI缺陷。完整报告见20260913-native-dogfood/independent-review.md。

## 收尾状态

本轮完成真实文字路径的首轮审查，未修改产品源码、未提交推送。没有向招聘者发消息、投递或写业务数据。新增的两个公开资料标签保留便于复核；测试任务已空闲，暂停实验的任务已中止。语音输入、音频打断、交还后继续的行为未通过实测，不由本轮结论替代。

| 指令 | 内容/动作结果 | 收尾表现 |
|---|---|---|
| 岗位名+城市 | 正确，27s | 答案后空响应/重试 |
| 年薪+5要求+远程 | 正确，11s | 答案后空响应 |
| 改成两句 | 主题已纠正，9.9s；实际3句 | 答案后空响应/重试 |
| 接管后保存修改 | 暂停与排队回执成立 | 恢复未确认；最终中止已确认 |
| 只打开example.com | 新标签打开，9.6s | 答案后空响应，回执网址误吞中文 |
| 两页比较并附来源 | 正确，23s | 答案后空响应 |

时间来自面板执行耗时，只是本轮样本，不是严格端到端计时或性能分位数。

建议先做两个最小修复：1）区分已有有效交付后的空尾响应和真正失败，让最终状态唯一；2）中文相邻网址解析保留正确目的地。重复状态与简短回答约束放在下一轮减负中处理。恢复按钮的无即时响应仍需排除原生控制焦点影响。
