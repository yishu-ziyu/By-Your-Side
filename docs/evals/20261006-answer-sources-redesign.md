# 任务：回答前一行署名写出读了哪些网站，正文数字角标能点回原页

[#49](https://github.com/yishu-ziyu/By-Your-Side/issues/49) · 设计稿：Claude Design 画板「#49 回答出处」方向 A（用户 2026-10-06 选定）

## 规则

- R1 回答读过网页时，回答前一行灰色署名「读了 a、b 等 N 个网站 ⌄」（写出网站名，同一网站只算一次）；这一轮没读网页就不画。不论模型有没有列目标计划都要出现。
  - 正：真实模型读三页比价，署名列出的网站与服务器记下的这一轮访问完全一致。机器检查：`scripts/probes/design-check/49/answer-sources.mts --headless --ports`（gpt-6-luna；本地探针，它的 A1 仍按旧「读了 N 个网站」文案比对，判失败属预期，看 listedHosts 与 serverFetchedHostsThisRun）。
  - 反：下一问「一年有几个月」没读网页，却带上上一轮的署名。机器检查：同上 A4a。
- R2 展开后每个来源一行：编号、网站单字图标、页面标题、域名；指着时域名换成「在旁边打开」。没有标题时只写地址，不左右重复。
  - 正：人看截图。
- R3 正文里指向已读页面的链接后有小号灰色上标数字；点数字或点链接都打开出处（同一件事），输入框旁只留「当前页」一个标签。
  - 正：点角标后主窗口切到该页，输入框上只有一个标签。机器检查：同 R1 探针 A2 与截图 `04-sidepanel-after-click.png`。

## 技术前提

- 前提：读过的页面原本就记在任务进度里，只是装在「完成情况」里、没列目标计划就不发。拆成交付上的独立 `sources`，按「这一轮」清零（宿主催的续做不清）。结果：通过（R1 正反例）。

## 边界与不做

- 段落高亮仍常常定位不到（主张里的数字常是模型算出来的、原页没有），本任务不改。
- 模型用批量脚本读页时拿不到页面标题；界面只能从还开着的标签页补标题，补不到就显示地址。
- 旧记录没有 `sources` 时退回事实链里的 `sources`，不改旧记录。
