# 任务: 助手在网页上直接动手，不再弹批准卡，也不再硬拦回车和拖放

起因：10-04 产品负责人决定，网页任务直接做，不要批准卡，也不要硬禁令；删代码，不留开关。说明见[网页操作不再逐次确认](../browser-confirmation.md)。

## 规则

- R1 读页、打开网页、点击、填写、回车、请求都不弹卡。
  - 例子(正)：在北极星 N1 查一个词并写进 Flomo 时，那么侧栏全程零张批准卡，Flomo 恰好收到一条、正文一致。 — 谁检查：`north-star-research.mts --only=N1`
  - 例子(反)：在侧栏出现任何卡片元素或原生 `consent_*` 消息时，判定 FAIL。 — 谁检查：同脚本 `--self-test-judges`
- R2 回车不再被拦：在输入框按 Enter 会提交表单。
  - 例子(正)：在维基首页搜索框填词后按 Enter，那么 press_key 回执为已执行，服务器收到 `GET /search?q=…`。 — 谁检查：N1 `enterSubmitsForm`
  - 例子(反)：服务器没收到搜索请求时判 FAIL。 — 谁检查：`--self-test-judges`
- R3 结果未知锁、停止/接管、无进展与重复失败自停照旧；慢保存不重复保存，回答不说反。
  - 例子(正)：在 N2 第二条保存慢 40 秒、模型再点一次时，那么服务器每个词只收到一条，回答不含“有一步没做成”。 — 谁检查：`--only=N2`
