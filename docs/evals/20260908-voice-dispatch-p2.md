# P2：说出任务即可启动，追加要求与进度闲聊正确分流

## 完成标准（实现前冻结）
- [ ] 结构化路由只接受规定动作、明确目标名称、原始转写中的指令片段；非法输出、添加的指令、超时不执行。— 协议与路由测试
- [ ] 空闲语音任务请求经共享调度启动一次；运行中要求修改经同一steer；已在运行时无关新任务先询问，不覆盖原任务。— manager测试与真实Chrome
- [ ] 查询和闲聊不会写页面；引用、假设、询问能否修改不能当修改执行；“停止”对象不清先澄清。— 冻结48句分类集，真实模型每句3遍全部匹配
- [ ] 识别出的控制动作在P3未接通时明确拒绝，不能口头承诺；P3接通后保留原分类标准。
- [ ] 文字启动同样有requestId/runId与回执；P0修改DOM断言保持通过；真人耳麦不作为本阶段前置。
- [ ] 无任务合成语音“筛选测试页”启动真实执行任务、页面结果可读；进度/闲聊反例无新任务。
- [ ] typecheck、test、build、diff检查通过。

## 边界
- 不让语音模型直接调用网页工具；只依据应用回执回答。
- 分类输入仅用户本轮转写和运行状态，不含网页正文或任务事实中的潜在指令。
- 48句覆盖后续P3/P5分类合同；控制和跨会话执行尚需对应阶段验收，分类通过不代表执行通过。
