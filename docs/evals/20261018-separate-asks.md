# 任务：做一件事时打一句另一件事，两件各做各的，各交各的结果

## 规则

- R1 任务进行中打的话由快速模型判断是补充还是另一件事；判断不了当补充，和以前一样插进当前任务。
  - 例子（正）：整理清单时说“顺便查一下明天北京的天气”，这句下面写“另开一件”，清单照常做完。谁检查：`separate-asks` a、b，真模型试用。
  - 例子（反）：说“也加上每位作者的单位”仍是“接在当前任务里处理”，不出卡片。谁检查：`separate-asks` d。
- R2 另一件事在自己的会话和后台标签页里做；只有说到“这页”时才带上当前页面，并排在占着这页的任务后面。
  - 例子（正）：天气在新标签页里查，清单那页不被抢。谁检查：真模型试用。
- R3 另开那件结束后，“任务名 + 回答”出现在当前会话；没做成就写原因；重开侧栏后照样在，不出顶部条。
  - 例子（正）：重开侧栏后天气卡片和清单回答都在，各一份。谁检查：`separate-asks` c。
- R4 “改成补充上一件”由宿主停掉另开那件，把原话插进上一件；不多出气泡，卡片写“已并回上一件”。
  - 例子（正）：并回后上一件的模型收到这句话，另开那件不再交回答。谁检查：`separate-asks` e。

## 边界与不做

- 扩展后台重启后，另开那件能安全接着做就自动做完；页面变了不能接着做时，卡片写明原因并给「继续」，按它自己的那页接着做。
- 侧栏顶部“进行中 N 件”和分别停止，留到后面。
- 判断要多等 1–3 秒才决定插进还是另开；这期间插话还没送到当前任务。
- 语音路径不变。
