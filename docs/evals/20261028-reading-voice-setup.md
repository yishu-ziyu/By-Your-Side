# 网页语音配置与返回

## 规则

读网页时按右 ⌥，缺配置可补齐、试说并返回原页，选区和草稿保留；试说不发送给助手。引用失效有反馈，发送按钮可用键盘确认。

## 技术前提

已安装日常 Chrome；设置界面和四项资源哈希与验证包一致。代码检查、阅读卡与发送确认用例通过。真实 Realtime 3 用合成音频识别，原页选区和草稿返回断言通过；真人麦克风由用户明确暂缓。

已复现并修正一类卡在听写中的原因：后台拒绝开始录音后，网页仍在松键时进入听写。现在先核对开始结果，失败不提交；取消或新一轮后，旧回应不更新界面。`ptt-start-rejection` 用真实扩展、真实按键和受控失败验证，改前断言失败、改后通过。缺配置入口及返回选区、草稿也通过。早期首次运行没有足够日志，不能断言历史失败一定由同一原因引起。
