# 网页语音配置与返回

## 规则

读网页时按右 ⌥，缺配置可补齐、试说并返回原页，选区和草稿保留；试说不发送给助手。引用失效有反馈，发送按钮可用键盘确认。

## 技术前提

已安装日常 Chrome；设置界面和四项资源哈希与验证包一致。代码检查、阅读卡与发送确认用例通过。真实 Realtime 3 用合成音频识别，原页选区和草稿返回断言通过；未验真人麦克风。
