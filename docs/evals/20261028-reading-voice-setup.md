# 网页语音配置与返回

## 规则

读网页时按右 ⌥，缺配置可补齐、试说并返回原页，选区和草稿保留；试说不发送给助手。引用失效有反馈，发送按钮可用键盘确认。

## 技术前提

已安装日常 Chrome；设置界面和四项资源哈希与验证包一致。代码检查、阅读卡与发送确认用例通过。真实 Realtime 3 用合成音频识别，原页选区和草稿返回断言通过；真人麦克风已在日常 Chrome 试说通过：用户说“我想继续阅读刚才这段文章”，识别结果一致，页面显示“试说成功，文字未发送”；用户截图与页面读回一致。此次真人操作从设置页直接进入；返回原文仍以之前的独立浏览器验证为证。

已复现并修正一类卡在听写中的原因：后台拒绝开始录音后，网页仍在松键时进入听写。现在先核对开始结果，失败不提交；取消或新一轮后，旧回应不更新界面。`ptt-start-rejection` 用真实扩展、真实按键和受控失败验证，改前断言失败、改后通过。缺配置入口及返回选区、草稿也通过。早期首次运行没有足够日志，不能断言历史失败一定由同一原因引起。

证据在 `out/reading-voice-delivery/evidence`，上一版在 `out/reading-voice-delivery/previous-dist`。已同步远端；最终版本与 CI 结果见 GitHub Quality。
