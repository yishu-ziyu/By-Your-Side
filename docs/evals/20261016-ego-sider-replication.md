# 评测: 照着 EGO 和 Sider 官网的 21 个例子做，扩展做成了几个

来源：2026-10-15 夜间到 10-16 中午的一次自动测试和研究（Proto Bot 跑、QA 判分）。原始材料在已删除的分支 `proto/overnight-research`（最后提交 `68b2b8e5`），只保留这里的结论。

## 规则

- R1 每个例子照官网原文的任务在测试页上跑，运行前写好评分标准。判定只看最终页面状态（服务器记录）和回答文字，不看扩展自己的回执。
  - 例子(正)：选笔记本填采购单，服务器记录里品名 FeatherX 13、数量 2、没有提交 — 谁检查：QA 对照评分标准
  - 例子(反)：回答说「CSV 已经生成」，运行目录里没有文件，判为做错 — 谁检查：QA

## 技术前提

- 版本 main `ba3d11a8`，模型 MiniMax-M3.1-Flash-Preview。
- 例子取自 EGO 和 Sider 官网的宣传，能力是官网宣称，不是我们测出来的。网站是自己搭的测试页，不是真实网站。
- 每个例子跑 1 次（乘客票价、整理联系方式各 3 次），所以结果不是成功率。

## 结果

21 个里通过 12，做错 3，缺功能 5，整理联系方式 3 次全没过。

## 用户会遇到的问题（设计评审，按严重程度）

阻断：

- 说做了，其实没做。例子：「CSV 已经生成（侧栏可下载）」，实际没有文件；「以后每次都会去掉」Shorts，刷新后就回来了。
- 只到了付款页，回答却说「已提交，收不回」，读起来像已经付了钱。
- 暂停时侧栏只显示「已暂停」「助手在旁边等」，不说在等什么、用户下一步做什么。

值得修：

- 价格合计由模型自己算。应该从页面抄下合计，并写明出处。
- 还不能导出文件的时候，收集到的数据至少列在侧栏里，不能什么都不给。
- 回答说「见下方卡片」，不直接写价格。
- 地址照原文抄，不翻译；来源链接显示成能点的网址，不显示成代码。
- 填写回执的数字对不上（回执「已填 4 项」，回答「五个字段」，读回来 3 个值）；同名字段要写明位置，例如「首篇文章 › 标题」。
- 已保存的内容撤销不了，按钮却叫「撤销」。
