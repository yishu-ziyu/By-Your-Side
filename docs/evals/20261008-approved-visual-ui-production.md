用户已在本机预览里认可常驻光标、交互结果卡，并从三个动效里选定 C「柔和彩边」。历史的追踪流光和扫页光束不再采用。

## 规则
- R1 光标出现过后退到角落，保持低存在感，不挡网页点击；明确停止仍能隐藏。
  - 正例：在真实内容脚本里调用光标停靠，箭头在角落可见且不挡网页按钮。谁检查：隔离 Chrome + 真人。
  - 反例：停靠态透明或依然持续刷新动画；显式停止仍留箭头。谁检查：隔离 Chrome。
- R2 正在工作的页面显示 C 柔和彩边，完成、停止、切页后熄灭。减少动效时保留静态边框。
  - 正例：触发已有页面 glow，细边框缓慢变化、可穿透点击；关闭后动画为 none。谁检查：隔离 Chrome + 真人。
  - 反例：页面出现扫光、运动亮点；没有任务时持续运行；延迟点亮覆盖已熄灭的页面。谁检查：隔离 Chrome / 现有任务验收。
- R3 模型提供的 HTML 可从对话里的文件卡主动展开为可操作组件，默认不执行；选择内容只准备草稿，经用户点击后才进入输入区。
  - 正例：点击「交互预览」后沙箱呈现按钮；沙箱按钮回传短文本，侧栏点「填入输入框」后可自行发送。谁检查：隔离 Chrome。
  - 反例：组件能读取扩展 DOM/存储或操作网页；关闭/删除后仍运行；普通文件下载受损。谁检查：隔离 Chrome。
