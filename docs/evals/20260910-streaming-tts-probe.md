# 固定文字流式语音小验证

用户批准5—10分钟小验证，不改正式产品。使用现有Step Plan凭据、现有音色`voice-tone-T3kZb9MwL2`，纯合成模型`stepaudio-2.5-tts`，WebSocket流式接口。未读取私人网页，未改Pi/扩展。

- 首句送出后732ms收到第一段音频；最后一段文字在建联后4009ms才送完，首段音频在1005ms已到。第一次短句显式flush，其余文字每250ms送18字。是分段输入、未等全文的真实接口检查，不是模型生成时延测试。
- 服务正常完成，返回2,292,480字节PCM，24kHz单声道16位，合计47.76秒。非空音频，首个明显信号在音频时间0.329625秒处；732ms是首数据时延，不等同于用户实际听到声音的时延。
- 第二次首数据538ms。在首包后关闭连接并禁止输出，另有9个在途包被本地丢弃。接口取消路径可行；本次没有启动正式插件播放器，因此不能称真人插话停播已验收。
- 当前音色ID被服务接受。音色一致性、自然度、全文朗读准确性待用户听样本；不以ID相同或audio.done代替听感验收。

脚本、完整事件报告及音频在`/tmp/ego-stream-tts-probe/`。样本`sample.mp3`，原始`stepaudio-2.5-tts-full.wav`；报告分别为`stepaudio-2.5-tts-full.json`与`stepaudio-2.5-tts-cancel.json`。仅固定测试文本，凭据没有写入文件或输出。

结论：现有服务/音色可用于下一步流式接入候选。不是正式产品流式输出完成；Pi正式回答的增量交付、现有VoicePlayer接入及真人插话仍待实现/验收。官方特别提示2.5-TTS流式音质可能弱于非流式，实际样本由用户判断，不擅自换音色。
