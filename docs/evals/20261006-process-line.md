# 任务: 一轮任务只留一行过程灰字

来源：issue #58 C。用户 2026-10-06 认可形式，否掉过程行里的紫色光球，选「只有流光」（预览 `out/design-check/58/preview-c.html`、`preview-c2.html`）。

## 规则
- R1 进行中，对话里只有一行「正在 动词 对象」：动词墨色、对象浅灰、无图标无光球，一道光扫过整行；每句至少停 1.1 秒。模型只想不做时也有「正在思考」。
  - 例子(正)：填表任务进行中显示「正在填 「出发日期」」 — 谁检查：`scripts/probes/shell/process-line.mts`
  - 例子(正)：模型想 45 秒才回话，期间显示「正在思考 N 秒」 — 谁检查：`scripts/acceptance/real-path/sidebar-header.mts`
  - 例子(反)：进行中还有厚任务卡、输入框上方任务条、「执行失败 7.5s」块同时在讲 — 谁检查：同上两项
- R2 结束后收成一行小灰字「做了 N 件事 · 9 秒 ›」；有失败写「有一件没成功」。点开是左边细线下一步一行，失败那步后写「· 没成功」。
  - 例子(正)：做完的任务展开看到 定位当前页 / 读取页面结构 / 填 「出发日期」 / 填 「乘客」 / 点 「查询车票」 — 谁检查：`process-line.mts`
- R3 没做完时，回答之后一行「没做成：…」加描边按钮「继续原任务」；做完时没有这一行。重复用户原话的目标行、灰底勾选列表、页面药丸都不再出现。
  - 例子(正)：最后一步点空 → 回答下面是「继续原任务」 — 谁检查：`process-line.mts`
- R4 任务条只在有它独有的事时出现：页面归你、停止/接管回执、任务页不是当前看的页、还没送入的附件。
  - 例子(正)：点页面「停下」后任务条写「已暂停 · 页面归你」 — 谁检查：`scripts/probes/cursor-narration/page-stop.mts`、`takeover-handback.mts`
  - 例子(正)：任务在跑、你切到别的页 → 任务条写「任务在 forms.example」 — 谁检查：`extension/test/task-view-ui.test.ts`（撤掉修复时失败）
  - 修订（10-06 用户裁决）：删掉「任务页不是当前看的页」这一条，已送入的附件也不再让任务条出来。原因：你切去别的页时，那张卡把同一页说三遍；补一句话时代码已附上你在看的页，过程行与回答也说明在哪做。检查：`task-view-ui.test.ts`「附件已送入：任务条让位」（改回旧条件时失败）；真实路径切页截图无任务条；`takeover-handback.mts` 全过。
- R5 好不好看由用户在真实扩展里裁决 — 谁检查：人
