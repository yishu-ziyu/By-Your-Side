# 任务: 语音光球可以在设置里换三种，默认是暮色

来源：#124（总览 #106）。10-07 用户对照 Incredible 的光球挑选：实时着色器版都不行；自己用流体模拟渲染的暮色、晨光与现在的粒子球可以，三种都保留，由用户自己选，默认暮色。

## 规则

- R1 新装扩展、没改过设置时，欢迎页中央的光球和语音光球都是暮色
  - 例子(正)：新资料目录打开侧栏，欢迎页光球的像素以暮色的蓝/杏色为主 — 谁检查：`orb-style.mts`
  - 例子(反)：存储里是不认识的值，按暮色显示，不报错 — 谁检查：`voice-orb-style.test.ts`
- R2 在设置页点「晨光」或「粒子」，已打开的侧栏光球立即换，不用重开侧栏
  - 例子(正)：设置页点晨光后，侧栏欢迎页光球的颜色变成晨光的杏色 — 谁检查：`orb-style.mts`
- R3 视频光球（暮色、晨光）不低于 1 倍速播放；待机、在听、在想、在说靠亮度、轻微起伏和不超过 1.45 倍的速度区分
  - 谁检查：`voice-orb-style.test.ts`（状态到播放参数的对应）；观感由人看
- R4 系统开了「减少动态」时，视频光球定格不播放
  - 谁检查：`orb-style.mts`（模拟 prefers-reduced-motion，视频处于暂停）

## 还没答上的问题

- 无

## 技术前提

- 前提：Chrome 扩展页里静音 mp4 能自动播放，并能逐帧画进 canvas（现有光球是 canvas，换样式不改外层结构）。小实验：预览页用同样做法，无头 Chrome 截图三处尺寸都有画面。结果：通过（`scratchpad/orb` 预览，10-07）。

## 边界与不做

- 视频素材用仓库里的渲染脚本生成（`scripts/orb/render_fluid.py`），不使用 Incredible 的任何素材。
- 过程行里的小墨色球（执行面板的 thinking-orbs）不在本次范围。
- 页面底部胶囊里的光球属于 #125，到时复用同一个挂载函数。

## 实测

- 单元：`voice-orb-style.test.ts` 3 项（先写，改前因模块不存在失败）：默认暮色、不认识的值按暮色；四种状态的播放参数各不相同，倍速都在 1–1.45。
- 真实路径 `orb-style.mts`（只装扩展的无头 Chrome）通过：新装默认暮色并在播放（画面平均色蓝 171 > 红 165）；设置页点晨光，侧栏欢迎页光球立即变暖（红 244 > 蓝 174）；点粒子换回粒子球、再点暮色换回；减少动态时重开侧栏，视频光球定格不播放。
- 素材：`scripts/orb/render_fluid.py` 生成 320px、60 帧、12 秒循环；暮色约 640KB，晨光约 240KB。
- 语音界面的两组旧测试（语音文字、诊断）原来不经过扩展存储；改为提供一个只选粒子球的最小扩展环境（`test/fixtures/orb-storage.ts`），它们测的内容不变。
