# 任务: 任务结束时，同一件事只说一次，而且不说错

来源：#103（总览 #106）。10-07 体验走查看到 4 处重复或说错的收尾信息。

## 规则

- R1 模型在回答里自己交代了没做完的部分、又没有「继续」可点时，回答下面不再另弹一张「没做成」卡
  - 例子(正)：圈「升级套餐」按钮做不到，回答写「这页当前没有显示『升级套餐』按钮」，下面没有卡 — 谁检查：`unfinished-turn.mts`；`resume-entry.test.ts`
  - 例子(反)：账本里还有回答没说到的事，卡照旧出现 — 谁检查：`resume-entry.test.ts`
- R2 停下时那一步做到一半（结果未知），写「停在中途」，不写「还没做」；本会话停止成功不再另起一条「任务已终止」
  - 例子(正)：长页翻译 30 秒时按停止，那一行是「已停止，翻译网页停在中途，不会自动继续」，消息流里没有「任务已终止」 — 谁检查：`everyday-baseline.mts --only=translate-long-stop`；`resume-entry.test.ts`、`receipt-copy.test.ts`
  - 例子(反)：停止失败照旧露出 — 谁检查：`receipt-copy.test.ts`
- R3 「Chrome 顶部的正在调试此浏览器」说明只在那一轮进行中出现在过程行下方，结束后收起
  - 例子(正)：调研任务第 2–8 秒说明在最近几步下方，结束后侧栏里没有它 — 谁检查：`everyday-baseline.mts --suite=sitegeist --only=research` 的侧栏结构
  - 例子(反)：说明出现在第二个任务，或结束后仍在 — 谁检查：`readonly-script.mts`（#19 的「只说一次」一并检查）
- R4 别的对话结束后，当前对话顶部的条写「另一个对话结束了：标题 ↗」，看过那个对话后收起
  - 谁检查：`panel-selectors.test.ts`；看过即收起是原有行为（`completedConversations`）

## 技术前提

- 前提：「没做成」卡来自模型交付时自带的 unfinished，而不是目标核对。查 10-07 第一次长文翻译的诊断记录：交付 outcome=partial、unfinished=「把这个页面翻译成中文。」，正文已写「仍有 319 段未翻译」。结果：通过。
- 前提：交付工具的约定要求 outcome=partial 的正文说明做不到的部分（`agent/src/user-delivery.ts` 的 outcome 描述）。结果：通过；本次两次真实运行的正文都说了。

## 修订依据

- 取代 [09-25 没做完的一行](20260925-unfinished-line-and-answer-reveal.md) 标准 1「侧栏那一行写没做成的事」：当时回答常不提这件事；现在正文已说，单独一行变成重复。用户 10-07 认可 #103 的对照预览。

## 边界与不做

- 顶部条不写结果（「没做完，剩 N 段」）：侧栏拿不到别的对话的结果，要改协议，另议。
- 「接着翻剩下的」按钮不做：模型自己交代的没做完本来就不给「继续」（直接在输入框回复）。
- 回答后目标核对在后台又开一轮（侧栏回答下面再出现「正在思考」）归 #105。

## 实测

- 单元：新增 6 项，改前 5 项失败（另 1 项是防误伤的反例，改前改后都过）；扩展全量与 `npm run check` 结果见提交说明。
- 真实路径（gpt-6-luna，只装扩展的无头 Chrome）：
  - R1：`unfinished-turn.mts` 通过，回答说出「升级套餐」，没有卡。评估脚本改为只读看得见的步骤：收尾后隐藏的准备步骤，读 innerText 时会带出耗时，造成假失败。
  - R2：translate-long-stop 那一行为「已停止，翻译网页停在中途，不会自动继续」，没有「任务已终止」。
  - R3：research 第 2/4/6/8 秒说明在过程行下方，结束后没有；`readonly-script.mts` 中说明只在第一个任务出现、结束后不在（该脚本另有 read_script 未实现的两项失败，见[验收入口](../testing/acceptance.md)，与本项无关）。
  - 实现中踩到一次：新会话第一轮经补放历史到达，起初「补放时不显示」把说明整个吞掉，改为只要有在跑的一轮就挂上。
