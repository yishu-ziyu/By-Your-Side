# 任务: 等待时秒数贴在动词后面，没有扫光，也不造百分比

## 规则
- R1 首字还没出来时，过程行写「正在思考」加这段已经过了多久，例如「正在思考 1 分 29 秒」。不要「已等」，秒数前不要间隔点，标题不要扫光。
  - 例子(正)：发出去 3 秒还没有第一个字，第一行是「正在思考 3 秒」，计算样式里标题动画名不是 `runShine` — 谁检查：`wait-inline-timer.mts` b
  - 例子(反)：仍写「已等 3 秒」，或秒数前有「·」，或标题还在扫光 — 谁检查：同上
- R2 首字前满 15 秒还没有回音，只把标题换成「还没有回音」。秒数继续数，四个墨点的节奏和颜色不变。
  - 例子(正)：等到 15 秒，标题是「还没有回音」，时间仍是「15 秒」或更长 — 谁检查：`wait-inline-timer.mts` c
  - 例子(反)：标题仍是「正在思考」，或墨点变色、放慢 — 谁检查：同上
- R3 已经动手、某一步还在进行时，只报这一段已经过了多久。不写百分号，不画进度条。
  - 例子(正)：点完一步之后模型又想 5 秒，第一行是「正在… N 秒」，全文没有 `%` — 谁检查：`wait-inline-timer.mts` d
  - 例子(反)：写出「37%」或出现进度条 — 谁检查：同上
- R4 空会话仍是起点建议；模型出错仍是错误卡。这两种状态不因为等待行改动而消失。
  - 例子(正)：还没发过话时看得到起点；回 500 时看得到错误卡 — 谁检查：`wait-inline-timer.mts` a、e
  - 例子(反)：空会话只剩空白，或出错只剩一行灰字 — 谁检查：同上
