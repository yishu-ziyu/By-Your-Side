# 任务：空会话光球下一张清单，每行写短主题和一个具体的下一步

[#53](https://github.com/yishu-ziyu/By-Your-Side/issues/53) · 设计稿：Claude Design 画板「#53 继续上次的事」方向 B（用户 2026-10-06 选定）

## 规则

- R1 空会话时，光球、问候和「继续上次的事」作为一组，在空白区里上下居中。
  - 正：开启设置、有可续记录时，光球在上，清单在下，不挤在输入框上方。机器检查：截图，人看。
- R2 清单无框：每行网站单字图标、短主题、时间，下一行是下一步；整行可点，× 只在指着时出现。
  - 正：没做完的任务显示模型起的短主题（如「周末行程登记」）和下一步（如「接着填第 3 页」）。机器检查：`scripts/probes/design-check/53/open-threads.mts --headless=new`（gpt-6-luna 真跑两个填表任务并中途停下）。
  - 反：起不出主题时空白，或标题露出用户原话截断。机器检查：起不出时沿用原话目标（代码路径），真跑时两条都有主题。
- R3 短主题与下一步只在任务没做完时由快速模型起一次，只依据目标和没做完的事；过长、像密码的不用。
  - 反：做完的任务也多花一次模型调用。机器检查：`labelPastTask` 遇 `outcome === "complete"` 直接返回。
- R4 原有行为不变：默认关闭、最多 3 条、按钮只回原会话或原标签页、× 隐藏 7 天、关设置即消失。机器检查：同 R2 的探针 A1–A4b。

## 边界与不做

- 阅读记录的行仍写「打开上次页面」：按钮只是切回那一页，不替用户追问。
- 起始区的说明文字和快捷按钮保留，只改成居中。
- 「边注」下拉框悬在输入框上方的问题不在本任务。
