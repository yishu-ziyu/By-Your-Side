Sider 实际怎么做 原件

对照官方《上下文菜单》：划词出现阅读菜单；输入框里划自己的字出现写作菜单；⌘/Ctrl+J 打开「问 AI」。答案生成在选区旁边，可复制、朗读、固定、拖动；要追问点「在侧栏继续对话」。可按站点关掉。下面这一段可以划。

nature.com · Methods · 可划字

Spatial transcriptomics of the tumor margin

We performed visium HD profiling on FFPE sections spanning the invasive front. Spots with mixed epithelial–stromal barcodes were discarded if the contamination fraction exceeded 0.18, a threshold chosen to keep clonal CNV calls stable across serial sections.

This is the sentence a Sider user actually highlights: not a dictionary word, a dense claim they need unpacked without leaving the paper.

阅读菜单　问 AI · 解释 · 复制 · 高亮 · 更多（翻译 / 总结 / 固定提示）

写作菜单　Gmail / Docs 输入框里划自己的字：改写、语法、更短。第一刀建议 SideAgent 不做。

为什么好用　不离开正在读的那段。追问才进侧栏。快捷键是「问」，不是「发出去」。

做完之后 SideAgent 大概长什么样（同一段论文，三案）

从 Sider 偷什么，不偷什么

偷：答案先贴在选区旁；「问」是一个输入框（⌘J），不是默默发出「解释这段」；追问才进侧栏；可按站点关掉浮层。
不偷：翻译插件、写作改写、朗读、多模型切换、提示市场。那些是 Sider 的阅读/写作产品。SideAgent 是会操作浏览器的 Agent——解释完可以接着点、填、归档。

真实用例（替换上一版的词典查询）

  • 读论文　Nature 方法段划一句门槛条件，点解释。答案贴在旁边。再「在侧栏继续」问「我们的数据也能这么滤吗」。
  • 看 CI 红了　GitHub Actions 划一段 error log，问 AI「这是什么错」。SideAgent 特有的下一步：可以接着去翻文件、改配置。
  • 危险操作前　ChatGPT 设置划「Archive this chat」，问「点了会怎样」。可以接到已经在做的就地确认，而不是只聊天。
  • 读条款　结账页划「non-refundable after 24 hours」，问「我现在取消能退吗」。
  • 不做（交给 Sider）　Gmail 草稿划「Please find attached」点改写；整页翻译；PDF 对照翻译。

第一刀边界（按 Sider 对照改过）

做不做
对象网页正文划出来的句子/段落（2–2000 字）图片、视频、没划到字的链接
浮层问 AI + 解释；答案贴在选区旁翻译 / 总结 / 改写 / 语法 / 朗读作为主按钮
侧栏「在侧栏继续」才带上引用追问；Agent 在跑则当插话划完立刻跳侧栏空等；另开一条会话
写作—输入框、Docs、Gmail 里改自己的句子
站点普通 http(s)；可按站点关掉浮层chrome://、扩展页、PDF 阅读器浮层

怎么做（点头后才写代码）

和上一版相同的工程底座：contextMenus、storage.session 交接侧栏、content script 用 Range 包围盒贴浮层。
多出来的一层：解释/提问的第一段回答画在页面 overlay（跟光标 overlay 同一套隔离），不要先拆侧栏。侧栏只接「继续」。
协议仍是 PageContext.selection。⌘J 打开问 AI 输入框。
