# 任务: 重载扩展后已打开的网页不用刷新；侧栏每一步都有自己的图标

来源：10-07 用户在日常 Chrome 试按住说话：重载扩展后按右 ⌥ 没反应（要刷新网页）；侧栏「做了 N 件事」里有的步骤有图标、有的只有一个点，用户希望都有。

## 规则

- R1 扩展安装、更新、重载后，已经打开的普通网页不用刷新，按住右 ⌥ 就出现胶囊，而且只有一个
  - 例子(正)：网页先开着，重载扩展，不刷新，按住右 ⌥ → 一个「在听」胶囊 — 谁检查：`reinject.mts`
  - 例子(反)：去掉补装，同样操作没有胶囊（复现用户遇到的问题） — 谁检查：`reinject.mts`（临时注释 `installReinject()` 跑一次）
- R2 侧栏过程里每一步都有对应的图标；认不出的工具用扳手，不再用点
  - 谁检查：`step-icons.mts`（7 种动作，读出图标种类并截图）；观感由人看截图

## 还没答上的问题

- 无

## 技术前提

- 前提：Chrome 只在网页加载时注入 manifest 里的网页脚本，重载后已打开的网页要扩展自己用 `chrome.scripting.executeScript` 补装。重载后旧脚本留在网页里，`chrome.runtime.id` 变成 undefined。由 `reinject.mts` 的正反两次运行检查。
- 无头 Chrome 里 `chrome.runtime.reload()` 之后扩展不会回来；验收用 CDP `Extensions.loadUnpacked` 从同一目录重新加载，效果和扩展管理页点「重载」相同（新的后台起来）。

## 边界与不做

- 旧版本留下的脚本没有「断开就不接按键」这道检查。所以这一次更新时，用旧版本打开过的网页可能出现两个胶囊（一个卡在「在听」），刷新一次即可；以后的更新不会再这样。
- 划词条不用处理：新脚本启动时会删掉旧脚本的划词条。

## 实测

- `reinject.mts`（10-07）：通过。重载用了 1.8 秒，不刷新网页按住右 ⌥，出现一个「在听」胶囊。去掉补装再跑：没有胶囊（`[]`），与用户遇到的一致。
- `step-icons.mts`（10-07）：通过。7 步依次是 open、script、run、look、key、mark、click，没有一步落到「其他」。截图里每一行前面都有图标。
