# 任务: 过程块进行中只说「现在」，做完收成一行回执（#263）

## 规则
- R1 进行中两行：第一行只写现在在做什么，秒数只数这一段（在想就数这段思考，在跑一步就数这一步，≥3 秒才写）；第二行小字「已做 N 步 ›」，有没做成的步骤时跟「· N 步换了做法」。
  - 例子(正)：一步没做成、模型又想 8 秒，第一行「正在思考 5 秒」（和真实时间差 ≤1.2 秒），第二行「已做 2 步 · 1 步换了做法」 — 谁检查：`process-block.mts` a
  - 例子(反)：主干构建同一时刻第一行是「出错 9 秒」（数的是整轮），没有第二行 — 谁检查：同上
- R2 思考按段计时：一段从发送或上一步结束开始，到下一步开始、回答出字、等你确认或页面归你时结束；短于 0.1 秒的不算。等你和页面归你的时间不算「想了」。
- R3 做完收成一行回执「做了 N 步：短名 → … → 短名 · N 步换了做法 ›」，不写耗时；放不下时短名链从中间省略，「换了做法」不省略。只做一步时仍写那一步的完成说法；出错结束写「做了 N 步 · 有 1 步没做成」；中止写「已中止 · 做了 N 步：…」。
  - 例子(正)：380px 宽「做了 3 步：打开 Page B → … → 点作品 · 1 步换了做法」，300px 宽「做了 3 步：… → 点作品 · 1 步换了做法」，都是一行 — 谁检查：`process-block.mts` c、c2
- R4 展开是记录：每步一行，≥3 秒的写秒数；≥3 秒的思考单列「想了 N 秒」（模型写了思考过程的，就写在那块的标题上）；末行「共 N 秒，其中想了 M 秒」。历史回放没有时钟时不写秒数。
  - 例子(正)：记录是「想了 4 秒 / 打开页面 Page B / 读出标题 / 点「不存在的按钮」· 没做成 / 想了 8 秒 / 点「作品」/ 共 13 秒，其中想了 12 秒」，合计和真实时长差 ≤1.5 秒 — 谁检查：`process-block.mts` d
- R5 `js` 带一句用途（`purpose`），步骤名和短名用它；没带时写「在页面里运行代码」「运行代码」。侧栏不再出现「执行脚本」「0.0s」「+ 前面」「件事」。
  - 例子(正)：`purpose: "读出标题"` 的那步在记录和短名链里都叫「读出标题」 — 谁检查：`process-block.mts` b、d
- R6 一步没做成、模型接着想时，状态仍是在想，不显示「出错」；整轮出错（模型、连接）才马上显示出错。整轮结束时最后一步仍没做成，结论才是出错（和原来一样）。
  - 例子(反)：主干构建这时第一行是「出错」 — 谁检查：`process-block.mts` a 的反例

## 还没答上的问题

## 边界与不做

- 进行中不加胶囊（10-06 的决定）。
- 等首包和模型思考合在一起叫「想了」，没有拆开（#263 Q2）。
