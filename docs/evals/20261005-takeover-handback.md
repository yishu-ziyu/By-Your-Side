# 任务：任务做到一半，你点「我来」接手、改完点「你继续」，Agent 从你改过的页面接着做

[issue #44](https://github.com/yishu-ziyu/By-Your-Side/issues/44) · [Computer Use 复测](20260922-computer-use-product-path.md) · [使用说明](../guides/usage.md)

## 规则

- R1 任务运行中点侧栏「我来」：1 秒内侧栏显示「已暂停 · 页面归你」，页面上的条显示「现在归你」和「你继续」；暂停期间 Agent 的点击不落到页面上。
  - 正：本机计数页，Agent 每 1.5 秒点一次按钮；点「我来」后 3 秒内计数不变。机器检查：`scripts/acceptance/real-path/takeover-handback.mts`。
  - 反：侧栏同一位置的按钮变成「你继续」，不再是「我来」。机器检查：同上。
- R2 你在页面上改了东西后点页面条上的「你继续」：Agent 下一次请求带着你改后的页面和原目标，在同一轮里接着点，点击照常落到页面上。
  - 正：改后的输入框文字出现在交还后第一次模型请求里，计数继续增加，最后回答「点完了。」，侧栏只有一条用户消息。机器检查：同上。
  - 反：不出现「助手自己在页面上画的…」拒绝，也不出现「连续失败达到上限」。机器检查：同上。
- R3 交还以后页面条隐藏，原来条所在位置的网页内容能被用户点到。
  - 正：任务结束后用真实鼠标点左上角的按钮，计数加一。机器检查：同上。
- R4 暂停时直接点侧栏「你继续」，效果与页面条上的「你继续」相同。
  - 正：第二次任务中途点「我来」，再点侧栏「你继续」，计数继续增加，最后回答「点完了。」。机器检查：同上。

## 还没答上的问题

无。

## 技术前提

- 前提：无头真路径里能点到页面条（closed shadow）上的按钮，能读到交还后发给模型的请求。小实验：`scripts/probes/takeover-handback.mts`。结果：通过。
  - 同一实验复现了原问题：交还后页面条只是变透明，仍接住左上角的点击；Agent 点左上角按钮三次都被判成「点自己画的状态条」，任务停在「连续失败达到上限」。

## 边界与不做

- 不改权限确认卡，不在用户打字时自动接管。
- 不做「你改了什么」的强制填写。
- 接管请求失败、交还途中断线的提示沿用现有逻辑和单元测试（`extension/test/task-view-ui.test.ts`、`extension/test/team-p0p1.test.ts`），本轮不新增真路径。
- 暂停期间页面条显示在左上角，会盖住那里的网页内容；本轮不改位置。

## 证据

- 原因：页面条交还后只是变透明（去掉 `on`），条本身仍 `pointer-events: auto`、留在左上角。Agent 点那里的按钮时，落点检查 `elementFromPoint` 碰到我们自己的条，判成「助手自己在页面上画的…」不执行；连续三次后任务停在「连续失败达到上限」。用户点那里同样落空。
- 改法：条只在显示时接住点击（`extension/src/content/cursor.ts`）。按钮文案改成「我来」「你继续」；侧栏原「接管」按钮在页面归你时原位变成「你继续」，走已有的交还通路。
- 端到端：`npx tsx scripts/acceptance/real-path/takeover-handback.mts --headless --run=final`，12/12 通过。产物在 `out/acceptance/takeover-handback/final/`：result.json、payloads.json、paused-page.png、paused-panel.png、resumed-panel.png。
  - R1：点「我来」到显示已暂停 273ms；暂停 3 秒计数不变；侧栏与页面条都显示「你继续」。
  - R2：交还后第一次请求含用户在输入框改的文字和原目标；计数从 1 到 2；只有一条用户消息，回答「点完了。」；没有拒绝和连续失败。
  - R3：交还后页面条隐藏，用户点左上角按钮，计数加一。
  - R4：侧栏「你继续」后接着点并做完。
- 反证：把条的 `pointer-events` 改回 `auto` 重跑（run=mutant-no-fix），R2 交还后计数停在 1、回答「「点击」连续三次出同样的错」，R3 用户点击落空，R4 Agent 第一下就点不到。
- 稳定性：单跑与 3 个并行各跑多次，改为侧栏开机前写入模型配置后 7 次全过。
- 另外发现（不属本任务，未修）：新装、没配模型时，侧栏开机新建会话的请求被挂起；4 秒后侧栏退回默认会话。配好模型后挂起的请求才补发，侧栏被切到一条新的空会话。这时如果已经发了任务，任务在原会话里跑，侧栏只剩「后台运行中」一行，看不到「我来」。机器负载高时 3 次里出现 1 次。原因来自代码阅读，未逐步测时。验收脚本改为开机前写入配置来避开它。
- 交还后同一按钮重复点击被「已有成功回执，不重复执行」挡住，这是已有的防重复规则，不是本问题；验收只要求交还后至少落一次点击。
