# 任务: 按住说话时，网页底部的胶囊一直说清助手在干什么，Esc 能停

来源：#125 第 2 步（总览 #106）。设计见 #125 的预览图（按住时 / 做完没做完时）。另一会话整理的 Incredible 逐帧观察（#132 评论）定了两件事：状态只用一个词；页面上只留一个状态面。

## 规则

- R1 按住右 ⌥ 时，网页底部出现胶囊：光球（设置里选的样式）+ 随声音跳的声波 +「在听」。松开后变「听写中」。按住时按 Esc，胶囊直接消失
  - 例子(正)：按住说话，声波随假麦克风的声音起伏；松开后到听写结果出来前，显示「听写中」 — 谁检查：`ptt-capsule.mts`（截图 + 声波高度记录）
  - 例子(反)：没有听写完成的事件，就不离开「听写中」 — 谁检查：`ptt-capsule.mts`
- R2 听写出的那句话留在胶囊里，可以选中复制。任务在跑时，显示「在做」和当前步骤（与侧栏任务栏同一份数据）；助手停下等你时显示「等你」和原因
  - 谁检查：`ptt-capsule.mts`（脚本模型先调一个工具再回答，截「在做」时的胶囊）
- R3 做完显示「结果」、回答的第一句，以及「留给你的」（如果目标核对说还差）。胶囊 10 秒后收起，点 ✕ 也能收起；点「在侧栏看」打开侧栏。听写失败或没听到时显示原因；话没交给助手时，给「重发」
  - 谁检查：`ptt-capsule.mts`（结果截图、打开侧栏）；没听到、重发靠代码审阅
- R4 任务在跑时，按 Esc 或点「停」，任务停下（与侧栏「停止」同一条路），胶囊写「已停下」。胶囊显示期间，这一页右边缘的药丸收起
  - 谁检查：`ptt-capsule.mts`（第二轮：脚本模型挂起时按 Esc，等到任务停下）

## 技术前提

- 前提：胶囊放在网页里（内容脚本），不用 Document Picture-in-Picture 小窗。小实验：`scratchpad/ptt-probe/pip-probe.mts`，无头 Chrome。结果：PiP 不成立，所以用内容脚本。
  - 只按 ⌥ 不算用户动作，`requestWindow` 报 `Document PiP requires user activation`。按字母键就能打开。
  - 打开小窗的网页一跳转，小窗就关了。助手做事时经常跳转网页。
  - 侧栏关着时，侧栏也开不了小窗。
- 前提：离屏文档里的音量能传到网页，用来画声波。没有单独做小实验：走的是现有的消息通道（离屏文档 → 后台 → 网页），由验收脚本记录声波的高度来检查。

## 边界与不做

- 念出结果：第 3 步。
- 药丸增加「等你」「结果」两种状态：另开任务。
- 地址栏、Chrome 自带页面、PDF 查看页上没有胶囊（内容脚本不在这些页面上），只能去侧栏看。
- 按住时没有逐字字幕：套餐听写不支持流式（#125 实测）。松开后 0.85–2 秒出全文。
- 胶囊只在说话的那个标签页上显示。切到别的标签页时，那边显示的是药丸。

## 实测

- 真实路径 `ptt-capsule.mts` 通过（10-07）。条件：只装扩展的无头 Chrome，侧栏关着，假麦克风放 say 合成的一句话（5.4 秒），听写连真实的 Step Plan 套餐，助手用脚本模型。
  - 第 1 轮依次经过 在听 → 听写中 → 在做 → 结果。
    - 声波最高 23.5px（满格 24px）。
    - 松开后 1.3 秒显示「在做 · 查看标签页」，5.2 秒显示结果。结果只显示回答的第一句。
    - 胶囊显示期间，这一页没有药丸。
    - 点「在侧栏看」打开了侧栏，对话里有这句话。
  - 第 2 轮：脚本模型挂起，胶囊在做时按 Esc，0.8 秒后显示「已停下」。
  - 两轮听写都只连了 `step_plan/v1/realtime`。
  - 截图在 `out/acceptance/real-path/*-ptt-capsule/`：1-listening、2-doing、3-done、5-stopped。
- 只靠代码审阅、没有跑到的：「等你」「留给你的」两种显示，「重发」，没听到时的说明。
- 没测：真键盘的手感；在真实网站上，胶囊会不会挡住网页底部的按钮。
