# 任务: 输入框左下角写明当前模型和思考强度，用户点开在「快 / 深入」间切换（用户 10-07 选方向三）

预览：[思考强度三个方向](../previews/thinking-level/index.html)。默认档见 [20261007-effort-low](20261007-effort-low.md)。

## 规则
- R1 输入框左下角写「当前模型 · 快」；模型不能调思考（只有一档）时不显示。
  - 例子(正)：6 Luna 显示「GPT-6 Luna · 快」 — 谁检查：`scripts/acceptance/real-path/thinking-chip.mts`
- R2 点开列出「快 / 深入」，每项写明这个模型实际用哪一档（6 Luna：快=低档，深入=高档），另有「换模型…」。
- R3 选「深入」后，之后每次调用模型都用高档；选「快」用低档。对所有会话生效，关掉侧栏再开还记得。做的时候卡住仍会自动升一档。
  - 例子(正)：选深入后问一句，两次模型调用都是 high；选快后是 low；重开侧栏按钮仍写深入 — 谁检查：同上
- R4 没选过时不发选择，按模型登记的起始档。

## 技术前提
- 前提：每个模型能用哪些思考档，产品里已有一张表（`shared/model-capabilities.ts`），「快 / 深入」按它换算成不高于低档 / 高档的最近一档。不另做小实验。

## 边界与不做
- 不做三档以上；不按任务自动选档（升档信号照旧）。
