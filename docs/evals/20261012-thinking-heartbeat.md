# 任务: 思考时过程行有心跳，两行文案不变

## 规则
- R1 进行中仍是两行：第一行是当前真实动作的动词（思考时「想想怎么说 / 理一理 / 看看下一步」），秒数只数这一段；第二行「已做 N 步 ›」。行首是四个墨点在 4 点与十字之间收合，不是细环、不是别人的星号。
  - 例子(正)：一步没做成、模型又想 8 秒，第一行是思考动词加秒数，行首四个墨点在动，第二行「已做 2 步 · 1 步换了做法」 — 谁检查：`thinking-heartbeat.mts` a、b
  - 例子(反)：把两行收成一行、或把标题改成「出错」、或写和当前动作无关的动词 — 谁检查：同上
- R2 墨点盒子约等于 15px 标题的字身高度（14–16px），用主墨色。收合约 1.2 秒一拍，用产品的 `--e-glide` / `--e-swift`，能看出缩放和旋转，但不是转圈。等待行不再扫光，秒数怎么读见[行内计时](20261014-waiting-inline-timer.md)。减弱动态时墨点停在 4 点位置，动词不再轮换。
  - 例子(正)：墨点宽高 14–16px、主墨色、动画名含 markFold 与 markMorph、时长 1.2±0.05 秒，标题动画名不含 `runShine` — 谁检查：`thinking-heartbeat.mts` b、c
- R3 做完仍是一行回执，墨点不再显示。
  - 例子(正)：回执「做了 3 步：打开 Page B → … → 点作品 · 1 步换了做法」，墨点 `display: none` — 谁检查：`thinking-heartbeat.mts` d
