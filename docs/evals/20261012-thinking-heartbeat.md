# 任务: 思考时过程行有心跳，两行文案不变

## 规则
- R1 进行中仍是两行：第一行「正在思考」或「正在 + 动作」，秒数只数这一段；第二行「已做 N 步 ›」。心跳是行首一个 0.9 秒转一圈的细环，不是新皮肤、不是胶囊。
  - 例子(正)：一步没做成、模型又想 8 秒，第一行「正在思考 5 秒」，行首细环在转，第二行「已做 2 步 · 1 步换了做法」 — 谁检查：`thinking-heartbeat.mts` a、b
  - 例子(反)：把两行收成一行、或把标题改成「出错」 — 谁检查：同上
- R2 文字扫光仍是产品的 2.4 秒，不另做一套光。减弱动态时转圈和扫光都停。
  - 例子(正)：计算样式里标题动画 2.4±0.05 秒，细环 0.9±0.05 秒 — 谁检查：`thinking-heartbeat.mts` b、c
- R3 做完仍是一行回执，细环不再显示。
  - 例子(正)：回执「做了 3 步：打开 Page B → … → 点作品 · 1 步换了做法」，细环 `display: none` — 谁检查：`thinking-heartbeat.mts` d
