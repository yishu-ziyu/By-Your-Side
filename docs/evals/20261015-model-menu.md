# 任务: 输入框左下角一个菜单里选模型和思考强度，换模型两步到位

用户 10-15 看到原来的做法：点开关只能切“快 / 深入”，换模型要再点“换模型…”跳去另一个面板，而且那个面板点了没反应。改成和 Claude、ChatGPT 一样，发送键旁一个菜单里同时管模型和思考强度。用户看了可点的原型后定下这个方向。

## 规则
- R1 点开关，菜单在开关上方打开：上面是模型，当前的打勾；下面是“思考”滑块；目录大时最后一行是“更多模型”。
  - 例子(正)：当前 GPT-6 Luna，点开关 → 看到 Luna 打勾、另外至少一个模型、“快 | 深入”滑块。点另一个模型，菜单关上，开关在宿主确认后换成新名字。 — 谁检查：`scripts/acceptance/real-path/model-menu.mts`
  - 例子(反)：点开关后只有“快 / 深入”，换模型要再点一次别的入口。 — 谁检查：同上，旧版跑同一用例失败
- R2 切“快 / 深入”时菜单不关，开关上的字跟着变，选择对所有会话生效、重开侧栏还记得。
  - 例子(正)：点“深入”，菜单还开着，开关写“· 深入”，下一个任务用高档。 — 谁检查：`model-menu.mts`
  - 例子(反)：点了“深入”菜单就关，想接着换模型要重新打开。 — 谁检查：同上
- R3 “更多模型”在同一个菜单里往左滑进第二层：顶上返回和搜索框，按账号分组。Esc 先回第一层，再按一次才关上，焦点回到开关。
  - 例子(正)：点“更多模型”，搜索框有光标，打“sol”只剩名字带 Sol 的模型；Esc 回第一层，再 Esc 关上。 — 谁检查：`model-menu.mts`
  - 例子(反)：“更多模型”打开的是侧栏顶部的另一个面板。 — 谁检查：同上
- R4 输入框下面的工具行（加号、模型开关、话筒、语音、发送）一直显示，空着、没点进去时也在，不用先点输入框才能换模型。
  - 例子(正)：打开侧栏不点任何地方，就能看到并点开“GPT-6 Luna · 快”。 — 谁检查：`composer-expand.mts`
  - 例子(反)：空着时输入框只剩一行字和发送键，工具都藏起来（10-15 用户说“一片空白的设计不好”）。 — 谁检查：同上；右上角“…”菜单里也不再有“主模型”，换模型只有这一个入口 — 谁检查：`sidebar-interaction.mts`

## 还没答上的问题
- 无。每个模型下面一句“适合做什么”要等有实测数据再写；现在第一层的模型来自不同账号时才写账号名，同一个账号时不写。

## 技术前提
- 前提：开关在侧栏底部，菜单往上长，不会被侧栏顶部挡住；菜单放在输入框里面，打开时焦点在菜单里。 小实验：`out/probes/model-switch/menu-demo.mts` 结果：通过

## 边界与不做
- 第一层放当前模型、最近用过的、精选；都不够三个时用同一账号下的模型补。不按名字猜哪个更新、更强。
- 不在菜单里写能力标签（极速、推理等），原因同 `extension/src/sidepanel/models.ts` 里 `modelReasoningMeta` 的说明。
- 出错卡片上的“换一个模型”保持原样。
