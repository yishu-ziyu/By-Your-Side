# 任务: 操作网页时，用户能找到光标并看懂当前动作和目标

2026-09-10：用户批准优化方案，开始第一轮 P0 实施。实际宿主为当前 ChromeMain 的 By Your Side 扩展；用独立本地任务页验证正式 background → content script → 网页操作链，不改用户网站数据。

## 完成标准

- [ ] 1. 光标使用 44px 画布和双层轮廓；动作名优先、成员名次要；浅色、深色、密集背景下均可辨认 — 谁检查: 机器检查尺寸与截图，人判断可见性。
- [x] 2. 定位、填写、点击显示对应动作和实际目标名称，不展示输入值；名牌避开目标及视口边缘 — 谁检查: 定点测试与真实浏览器。
- [x] 3. 目标边框在操作期间持续显示，跟随同一元素的滚动和布局变化；失效元素不能换绑其他对象 — 谁检查: 真实浏览器及反例。
- [x] 4. 波纹仅在点击确已派发后播放；被阻止、失败和结果未知不能显示成功；退出、接管、隐藏清理动作提示 — 谁检查: 输入链定点测试与真实浏览器。
- [x] 5. 快速连续操作直接衔接新目标，动作提示的短暂保留不阻塞下一步；不新增动画固定等待，减少动态效果时保留静态信息 — 谁检查: 定点测试、浏览器计时与动态检查。
- [x] 6. 定点检查、typecheck、test、build 通过；正式扩展加载版本与最终构建一致，完整定位—填写—点击路径留证 — 谁检查: 主代理。
- [ ] 7. 用户扫一眼能指出当前光标、动作和目标，且不影响阅读 — 谁检查: 用户；机器通过不能代替。

## 边界与不做

- 第一轮只改光标、动作名牌、当前目标反馈及必要接线；P1 等待/阅读/结果状态条和 P2 跨页并行提示另轮推进。
- 保留现有侧栏、手绘标注和确认/接管行为，不改模型、语音、任务权限或执行成功定义。
- 点击提示只说明输入已派发，不代表网站业务结果成功；填写提示只在实际操作返回后结束。
- 不提交、推送。本轮不新增子代理。

## 基线与验证记录

- 源码基线：光标 SVG 36px；高亮动画 500ms 后消失；点击后 320ms 开始回角落；名牌仅成员名；真实点击前播放波纹且固定等待 150ms，目标高亮另固定等待 500ms。
- 前轮 chrome-devtools 默认 profile 发现失败；本轮直接核对 ChromeMain 的 9222 端口可达。不得把默认 profile 失败视为实际宿主不可用。

- 第一轮机器验证完成，正式 ChromeMain 扩展已重载。第 1 条的尺寸/截图部分通过，观感与第 7 条仍待用户判断；不宣称真人体验已接受。
- [26 项真实浏览器/渲染检查](20260910-cursor-visibility/result.json)全部通过。定位、CSS 填写/点击、AX ref 填写走正式工具链；深浅背景、长停留、旧回执、回放中断、嵌套滚动、节点替换、减少动态效果为同一已加载内容脚本的合成状态检查。
- 原有 `overlay-check.mjs` 通过，包含确认、标注、滚动及重注入检查。核心版本全量 131 文件 / 1058 项通过；最后名牌位置及回放中断调整后，6 文件 / 54 项定点、typecheck、build 通过。未为两个局部调整重复全量。
- [实际执行中的 background 与最终构建 SHA256](20260910-cursor-visibility/loaded-build.json)一致；cursor 资源 hash 与运行中的 44px / 动作 API 同时核对通过。
- [修改前默认浏览器验收](20260910-cursor-visibility/before-browser.json)、[修改后同一验收](20260910-cursor-visibility/after-browser.json)各 1/1 通过。click 步骤（包含下一次 snapshot）6970 → 5858ms，fill 1452 → 489ms；仅单次观察，不能当作普遍提速或模型任务时延结论。确定性变化是移除高亮 500ms 和点击预播放 150ms 固定等待。
- 名牌正文/深底对比 16.27:1，次要成员名 11.74:1。浅色、深色和三种条纹背景上，双轮廓中至少一层的对比最低 4.58:1；不宣称所有网站或完整无障碍合规。

### 中途失败与修订依据

- [第 1 次](20260910-cursor-visibility/attempt-1.json)：CSS 操作通过，测试误按 @N 格式读取 snapshot 输出。源码实际输出 `[ref=N]`；测试修正解析为 @N 输入，保留 AX 同一节点断言。
- [第 2 次](20260910-cursor-visibility/attempt-2.json)：SW 调试暂停超时，复用现有 inspector normalization 后恢复。
- [第 3 次](20260910-cursor-visibility/attempt-3.json)、[第 5 次](20260910-cursor-visibility/attempt-5.json)：正式 CSS/AX 操作通过，但合成动画等待超时；第 5 次记录 `visibility=hidden`，确认后台页 RAF 不推进。改成当前可见测试页再检查，不用固定坐标冒充运动。
- [第 4 次](20260910-cursor-visibility/attempt-4.json)：测试重用了 request id，收到已关闭旧标签的缓存回执。每轮改用唯一前缀，保留生产去重行为。
- [第 6 次](20260910-cursor-visibility/attempt-6.json)：24 项通过；截图人工复核发现宽字段名牌跨到相邻卡片。补充就近约束和反例，把目标下方/上方排在远处侧面之前，没有删除原遮挡断言。
- [第 7 次](20260910-cursor-visibility/attempt-7.json)：仅激活标签仍为 hidden，窗口未聚焦；最终检查使同一 ChromeMain 测试窗口可见并在结束恢复原前台应用。
- 正式链原来仅等待预计动画时长，低帧率时光标仍可能落后于真实输入。增加执行前落点同步；不追加固定等待，不改变目标重核对和点击未知处理。
- 旧点击安全测试中两个反例原依赖高亮 500ms 定时窗口；改为在实际光标移动的 300ms 窗口注入同样的目标移动/失效。原拒绝错点断言完整保留。
