# 任务: 首启引导预览——光球向导四步流，新用户装好扩展后 30 秒内连上模型并完成第一次对话

## 规则
- R1 未配置模型时打开侧栏，进入四步引导第 1 步：光球弹簧弹出（呼吸态）+ 自我介绍 +「开始」。
  - 例子(正)：无模型配置打开侧栏 → 看到光球与「我是 By Your Side。」 — 谁检查：人（首次体验）/ Playwright 截图 `docs/previews/first-run-guide/1-到来.png`
  - 例子(反)：打开侧栏整屏空白，或直接进入聊天 — 同上
- R2 任何一步都有可执行的前进路径，不存在死胡同。
  - 例子(正)：第 2 步无 key 时点「先跳过，随便看看 →」直达第 3 步；key 不足 8 位提示先粘贴或跳过；选「自定义」出现服务地址输入，缺地址有对应提示 — 谁检查：Playwright 走查脚本（跳过路径、空 URL、空 key 三条）
  - 例子(反)：没有 key 的用户停在第 2 步无法继续（本次预览初版的真实缺陷，已修） — 同上
- R3 第一次对话链路完整可走完：chip 飞入输入框 → 气泡 → 光球思考 → 流式回答 →「用了 1 条记忆 ›」→ 手绘圈画入圈出重点行。
  - 例子(正)：点 chip 后约 9 秒内走完上述序列，手绘圆角框圈住「② …」行 — 谁检查：Playwright 走查 + 截图 `4-第一次对话.png`/人
  - 例子(反)：链路中断、圈不出现的旧 bug（SVG 未撑满被裁切，已修） — 同上
- R4 动效语言统一：全部用欠阻尼弹簧（ζ≈0.72）与手绘描边画入，无线性渐变；prefers-reduced-motion 下全部定格。
  - 例子(正)：步骤切换时光球做共享元素弹簧迁移；交付步手绘环圈住光球；步骤切换清除上一步残留描边 — 谁检查：人
  - 例子(反)：第 3 步残留第 2 步的圈（已修）；任何 CSS transition 直动 — 同上
- R5 完成或跳过后落进日常空状态（光球 + 起点 chip + 输入框 pulsate），不重复进入引导；R 键/按钮可重播且状态完全复位。
  - 例子(正)：重播后手绘描边清空、表单复位、进度点复原 — 谁检查：Playwright 走查脚本
  - 例子(反)：重播后残留上轮的圈或对话 — 同上
