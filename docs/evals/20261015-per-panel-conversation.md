# 任务: 两个侧栏页面同时开着时，各看各的会话，互不改动

这是“把一个会话拿出来单独开一个窗口”的第一步。只开一个侧栏的用户看不出变化。

## 规则
- R1 在一个侧栏里切会话或新建会话，另一个侧栏还停在原来的会话。
  - 例子(正)：侧栏 A 在甲会话，侧栏 B 新建乙会话并提问；A 仍显示甲会话的问答 — 谁检查：`npx tsx scripts/acceptance/real-path/per-panel-conversation.mts --headless`
  - 例子(反)：B 新建会话后 A 也跳到空白新会话 — 谁检查：同上
- R2 一个会话正在写回答时，只有看着这个会话的侧栏显示这段字。
  - 例子(正)：A 的回答一段一段写出来时，B 一直只有乙会话的问答 — 谁检查：同上
- R3 刷新一个侧栏，它回到自己刚才看着的会话；关掉侧栏再打开（新页面），跟最近操作过的那个侧栏的会话。
  - 例子(正)：刷新 B，回放的是乙会话的问答，不是 A 正在看的甲会话 — 谁检查：同上
- R4 不是在某个侧栏里发起的动作（按住说话、右键菜单“问 By Your Side”、阅读转到侧栏、提示卡、前台切换）跟最近点进过的那个侧栏的会话；语音跟开始语音的那个侧栏。
  - 例子(正)：点进 B 后按住说话，这句话进乙会话 — 谁检查：人（还没有自动用例）

- 无

## 技术前提
- 前提：每个侧栏页面有自己的端口，后台按端口记它看着哪个会话；侧栏用页面级 sessionStorage 记住自己的会话，刷新后还在，关掉就没了。小实验：scripts/acceptance/real-path/per-panel-conversation.mts 结果：通过

## 边界与不做
- 不做单独窗口本身（第二步）。
- 不改任务排队（同时最多跑几个任务）。
- “最近点进过的侧栏”只靠侧栏页面的获得焦点和按下鼠标判断；后台重启后先重连上的那个侧栏算最近点进的。
