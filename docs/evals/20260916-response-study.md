# 任务：通过三个可操作原型选择回应区方向

## 完成标准

- [x] 三版可切换，同一内容、Logo、背景和原光球，差异集中在回应信息组织 — 检查者：主代理，应用内浏览器逐版操作及截图观察。
- [x] 本地设计资源有明确采用点与可打开的出处 — 检查者：主代理，源笔记与原型对照；详见阅读优先接入记录。
- [x] 生成、过程展开、引用预览、复制、追问与减少动态可操作 — 检查者：主代理，浏览器操作；无 error/warn 日志。
- [x] 用户选择阅读优先方向 — 检查者：用户。

## 边界与不做

- 本轮仅新增 `prototypes/response-study`，不将候选方案替换到正式扩展。
- 内容、生成时间、追问为模拟；光球复用实际项目代码。不能据此宣布真实模型或正式产品路径通过。
- 三版分别为阅读优先、过程优先、核对优先。选择后的接入与资源映射见 [阅读优先验收](20260916-reading-priority.md)。原型选择器已退役。
