## 用户可见变化

改前：目标、当前活动、控制权都堆在 `#task-strip` 里的一行文字，材料（页面/选区/附件）只在输入区瓷贴上可见；运行中用哪个页面、现在该谁动手、接管有没有生效都要靠日志推断。发出去之后界面立刻看起来「已完成」，没有「发送中／已接收」的分界。

改后：会话区上方多一条轻量任务条（`#task-bar-root`，独立组件）：
- 第一层：目标原文（视觉截断但 `title` 保留全文，+N 修订可悬停看原文）；
- 第二层：状态＋当前活动（`正在执行 · 读取页面 · 3.2s`、`已暂停 · 页面归你`、`已中断 · 可继续`、`已停止`），静默 ≥15 秒才补一句「距上次动作 X」；
- 材料入口：`已随任务送入 · N 项` / `材料 · N 项` / `待发送材料 · N 项`，逐项列出页面、选区原文、附件名；草稿态每项带「移除」按钮（真实 button，可 Tab/Enter），发送中写「发送中，尚未确认接收」，回执 accepted 才改口径，被拒绝写「未接收：原因」；
- 作用页：`作用于：<标题>（<host>）`，与当前活动标签页不一致时补一句「你现在看的是别的页，任务仍作用于上面这页」；
- 控制：点接管/停止后显示「已请求接管：正在让 Agent 停下手上动作…」「已请求停止：等 Agent 收手…」；10 秒没有权威结果就改说「接管请求还没得到确认，页面可能仍由 Agent 控制」并给「再试」按钮；权威状态到了（已暂停/已停止）控制行自行收掉。
- 面板重开：由 background 原样回放最近一次收到的权威视图，任务条不再空着等到下一次状态变化。
