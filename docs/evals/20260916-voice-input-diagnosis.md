# 任务：正常音量说一次停播即可生效，不必重复喊话

## 原始反馈与完成标准

2026-09-16 用户实际反馈：普通问答可以、插话最终可以停播，但收音糟糕，“别说了”需要提醒两三次。此前机器回归通过不能据此判定插话体验通过。

- [ ] 复现安静环境与助手播报期间同一句自然音量短句的差异，明确漏检、转写或重复播报所在环节。— 谁检查：真人输入、连续收音与检测时间线。
- [ ] 正常使用设备与距离下，“别说了”说一次就能停播，不要求先喊“你好”唤醒、不切掉开头、不继续漏播；随后问答正常。— 谁检查：人，机器辅助停声记录。
- [ ] 修复后保留安静时短句、轻声、噪声不误触及旧音频不续播的回归。— 谁检查：定点测试、真实声学路径。
