# 交互层级：内容先于标签

## 规则

- 发送确认等待用户时，过程行不声称正在执行发送；目标、网站、草稿和到期取消都可见。按钮批准与实际发送结果分开，双窗口和重开会话保持一致。
- 阅读卡以答案为主，来源和常用图标共用一行；重答和收起放在回答菜单。保留键盘名称、快速／深度、改口、引用定位、拖动缩放及多轮记录。
- 普通文字标记沿文本行显示，执行状态只在页边显示。教学和交接保留可读提示，不盖住目标控件。

## 设计依据

用户在查看当前扩展实拍、Notion 原件和可操作提案后要求实施。核心约束是减少不必要的次要标签与描述，用对齐、间距和视觉权重表达关系。不是删除目标身份、来源、错误或安全确认信息。

依据：[标签的使用](https://app.notion.com/p/226886bc60ff818b98d9c57d7cc13310)、[弱化次要内容](https://app.notion.com/p/226886bc60ff81bf97d8c7159b340719)、[Apple 反馈](https://app.notion.com/p/20f886bc60ff81b980f7f60210dfebea)、[连续性](https://app.notion.com/p/20f886bc60ff814999e2d750a3040b90)。保留现有浅纸色；不把参考作品的黑色皮肤或海报大字搬进扩展。

## 技术前提

确认状态由现有等待事件提供；阅读操作与来源绑定沿用现有消息。文字标记使用当前目标的 Range 矩形，换行后重排，未重写网页正文。已在隔离扩展中验证来源回跳、控件操作与重排结果。

## 验证与边界

`reading-card-gloss`、`panel-send-confirm`、`page-assistance-visual` 检查真实扩展在隔离 Chrome 中的操作与可见结果；模型和网站是本机固定材料，不代表真模型或真实网站的表现。截图、构建与检查日志封存在主工作区 `out/design-hierarchy-delivery/`。

未改版包能被新的页面验收判为失败：旧界面仍有重复状态与全页光晕，没有文本行标记。正式验收不得用旧截图替代当前画面。

教学全量检查曾为 28/29：可见停止行为通过，但模型收到通用 `Tool guide_step was aborted`，没有检查要求的具体停止原因；未改版包也未通过该项。旧答案提前满足等待的取证问题已修正，这条失败仍保留，不在本次视觉改动中改判通过。`guided-teaching --visual` 只覆盖正常三步、错点纠正、减少动态效果和无变化提示，结果明确标出范围。

本次未改发送授权或目标校验，不接入额外模型，不承诺任务提速。
