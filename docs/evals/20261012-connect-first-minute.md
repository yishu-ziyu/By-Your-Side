# 任务: 连好模型后，用户看得见「刚才那句话发出去了」

来源：用户认可的 F01 原型（未连接卡变形、暂存句飞成已发气泡、密钥无效不标红）。修订 #233 的 R4：连好后不再留「已用 <模型> 重新发送」，未连接卡变成「已连上」确认后离开。

## 规则
- R1 没连模型时发出的话，在未连接卡里显示成虚线小胶囊，并写「连好后自动发」。
  - 例子(正)：发「概括当前页」后，卡里能看到这句话和「连好后自动发」 — 谁检查：`connect-first-minute.mts`
  - 例子(反)：只有整块用户气泡、没有「连好后自动发」 — 谁检查：同一命令
  - 连模型前连发两句：只自动发最后一句；前一张卡改成「这句没有发出」，不留一句永远发不出的「连好后自动发」 — 谁检查：同一命令
- R2 连好以后，未连接卡变成「✓ 已连上 <模型>」，随后这张未连接卡不再出现。
  - 例子(正)：保存成功后，侧栏没有「还没有连接模型」 — 谁检查：同一命令，重复跑都要成立
  - 例子(反)：硬切回来后未连接卡还在 — 谁检查：同一命令
- R3 暂存句变成已发用户气泡，模型只收到这一次，回答照常出现。
  - 例子(正)：会话里只有一个用户气泡，脚本模型主任务请求数为 1 — 谁检查：同一命令
  - 例子(反)：重发两次或画出第二个用户气泡 — 谁检查：同一命令
- R4 默认动效：卡变形 240ms，暂存句 FLIP 320ms（测得的时长允许 -20/+50 ms，因为计时和调度只会让它变长）；`prefers-reduced-motion: reduce` 时跳过动效、直接到结束态。
  - 例子(正)：侧栏 `performance` 里 `f01-morph` / `f01-flip` 落在窗口内 — 谁检查：同一命令
  - 例子(正)：模拟减少动效后，没有这两段时长、已是「已连上」和已发气泡 — 谁检查：同一命令

## 还没答上的问题
- 无。密钥无效时的原因句沿用设置页已有的 401 说明，并补「密钥没有保存，侧栏里那句话还在等你」。
- 先试连再保存（用户 10-13 定）：只有服务商明确不接受（密钥被拒、模型不存在）才不保存；超时、限流、网络问题照样保存，并写「已保存，但刚才没连上：原因」，因为网络不稳时不该把人卡在设置页。

## 技术前提
- 前提：设置页「保存并使用」先探测再落盘，服务商明确拒绝时不会写入密钥。小实验：本验收脚本用本机 401 服务商。结果：见本文件「结果」。
- 前提：未连接卡被历史回放再次渲染时，必须沿用正在变形的那张卡，否则会冒出一张新的「还没有连接模型」。小实验：读 `renderReceipt` 对 `needs-model-card` 的复用。结果：通过。

## 边界与不做
- 不重做设置页结构，不改探测超时。
- 回放出来的旧卡片（侧栏不会自动重发的那句）仍写「把刚才的话再发一次。」
- 动效只用 transform / opacity，时长和曲线用已有 token（`--e-out`、240ms 走 `--m-move`）。

## 结果

- 10-12 原分支 8 项通过（变形 257 ms，FLIP 332 ms）。10-13 在新主分支上重接，补了连发两句和限流时保存两项，结果见 PR 描述。
- 未连接卡在历史回放时必须沿用同一张 DOM。新画一张会再露出「还没有连接模型」。
- 暂存句收进卡里以后，卡内第一个按钮是隐藏的「存成技能」。点连接必须点「连接模型」自己的类名。
- 设置页已经展开自定义表单时，再点一次「自定义地址」会收起表单。改密钥只改栏里的值。
