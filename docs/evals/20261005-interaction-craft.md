## 规则

- R1 可操作按钮按下缩至 0.96，嵌套圆角按容器内距计算；入场从 0.95 开始。
  - 正：鼠标按下更多按钮，计算样式为 0.96。机器检查。
  - 反：禁用按钮不缩放；减少动态效果时不播放入场。机器检查。
- R2 网页划词及 ⌘J 阅读卡可直接转入侧栏引用，不自动发任务。
  - 正：转入后原文、站点和输入焦点可见。真实扩展检查。
  - 反：去掉引用不清空正文；已有阅读回答仍沿原交接入口保留。真实扩展检查。
- R3 消息流任务卡显示真实目标、步骤状态和材料，支持折叠及原任务接续。
  - 正：真实任务视图更新卡片；恢复复用已有请求入口。机器检查。
  - 反：未知结果不显示完成；停止任务不提供恢复动作。机器检查。
- R4 工程检查和扩展构建成功，不改变共享协议与权限。
  - 正：`npm run check`、文档同步检查通过。机器检查。
  - 反：未跑的浏览器场景不能记为通过。

先在已有侧栏验收脚本加入按压、任务卡与折叠断言，再跑修改前构建。
不新增依赖、不更换浏览器基础设施；可见动效的主观手感留给用户。
