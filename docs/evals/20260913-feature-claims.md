# 产品承诺与真实用户路径

来源：README 使用章节、实际侧栏入口、20260913-native-dogfood 原生试用。主代理校正独立清单：本轮有多次新会话/重开，但未测并行隔离；教学与“看我做”在实际界面有入口，不能因README未写就当不存在。

| 能力 | 用户应完成的路径 | 真实成功标准 | 本轮修前证据 |
|---|---|---|---|
| 当前页面理解 | 打开侧栏→问当前岗位和城市 | 读对当前页，答对且只答所需 | 核心正确，收尾失败提示矛盾 |
| 数字与多条件提取 | 算14薪年薪、查远程要求 | 数字正确，没写明的说没写明 | 正确，35–56万；空响应尾态失败 |
| 新页面与来源 | 让Agent新开两页→比较→点来源 | 原页保留，事实和链接目的地正确 | 两页比较正确；裸URL中文尾文误入链接 |
| 执行中插话 | 任务运行时修订目标 | 原任务按新要求继续，不执行已撤回要求 | 未验；此前纠正发送时旧任务已结束 |
| 接管/交还/中止 | 执行中接管→修改→交还，另次中止 | 该页停手，新要求恢复后生效，终止后不继续 | 暂停及排队回执成立；交还未确认，中止已确认但状态呈现待查 |
| 多会话及标签归属 | A执行中切B并启动→中止B | A继续，B停止，各自页面/草稿/附件不串 | 新会话入口可用，隔离并行未验 |
| 关面板/重开/重连 | A运行时关面板再开；另测断线重连 | 关面板任务继续，重开新会话，重连不额外新建 | 空闲重开新会话已见；运行中续跑/重连未验 |
| 填表和成员协作 | 临时表单单字段→多字段分工→接管 | 原值/目标核对，完整动作串行，结果可见 | 本轮未验，不能以历史合成或单测代替 |
| 显式记忆/纠正经验 | 记住测试偏好→新会话使用→知识中改/忘记 | 按范围检索，编辑生效，忘记后不再注入 | 知识入口已见，完整闭环未验；测试需限定可清理数据 |
| 组合程序与授权 | 多步网页任务→触发POST等待→拒绝/允许一次 | 原参数一次授权，拒绝0请求，接管不越权 | 本轮原生未触发；上轮隔离机器证据单列 |
| 教学/看我做 | 开模式→一次无害页面动作→退出 | 教学只引导，看我做不抢操作；退出可继续 | 两个界面入口已见，完整闭环未验 |
| 语音/模型选择 | 打开麦克风→专名和否定→插话；另测切换模型 | 真实转写/声音/任务控制正确，模型选择路由正确 | 入口已见，真声学与切换路由未验 |

README路线图仍把“模型选择UI”列为未做，界面已有选择入口；记忆抽屉实际叫“知识”。这些是描述漂移，不能据入口存在就宣称切换/记忆全路径已验。

本次先修已证实的收尾、链接与重复呈现，再原生重跑受影响路径。未验项是后续验收工作，不等于未实现；也不能标成已验证。全部结果以STATUS及各轮证据为准。

## 全功能逐项验收续轮

已建立[固定用户用例与证据](20260913-feature-journeys.md)，覆盖执行中改意图、接管交还中止、双会话、关闭重开、无害填表、教学/示范及知识闭环。新增本地表单与延迟步骤设施，HTTP 200、脚本语法检查通过；这些均不是产品功能通过。

本轮发现的待实测冲突：教学按钮承诺“只标注引导”，agent提示规则却允许直接操作。看我做需区分“记录示范”和“编译后重用”，两段分别验。

原生电脑控制当前多次遭遇另一个Chrome窗口并发抢焦点，并出现标题可读但AX内容/截图不可用。重建控制会话、经Finder打开Chrome后恢复部分读取，但仍落在其他窗口；等待独占操作时段。未换用其他自动化工具，未把这些控制器结果计入产品失败，新增用例仍为未验。
