# 任务: mark/clear_marks 标注工具（修复"标注随滚动漂移"bug）

## 根因
Agent 用 js 工具在页面 main world 手写 `position:fixed` 覆盖层画标注，用户滚动后标注停在视口原位、脱离目标内容。且 main world 访问不到 ISOLATED world 的 overlay API，模型只能手写。

## 完成标准
- [ ] 1. 新增 `mark {target, label?}` 工具：在目标元素处画描边框+箭头+名牌，锚定文档坐标（absolute + scroll 偏移），用户滚动页面标注跟随内容不漂移 — evaluator: 人评（滚动测试）
- [ ] 2. 新增 `clear_marks` 工具清除全部标注 — evaluator: 人评
- [ ] 3. 系统提示词新增标注指引：标注用 mark，禁止手写 fixed 覆盖层 — evaluator: 代码审查 prompt.ts
- [ ] 4. mark 复用既有链路（domops rectOf 定位 + cursor overlay 渲染），target 定位串与 click 同语义；标注颜色跟随实例色（for(id).mark） — evaluator: 代码审查
- [ ] 5. `npm run typecheck` / `npm run build` / `npm test` 全绿 — evaluator: 机器
- [ ] 6. 标注样式无头截图自检 — evaluator: 机器

## 边界与不做
- 不做操作前自动高亮（已派 Gemini，见 20260903-element-highlight.md）
- 不做单个 mark 的删除（clear_marks 全清）
- 标注不做滚动跟随重算（absolute 文档坐标天然跟随）
