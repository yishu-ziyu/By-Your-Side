# 任务：四种页面伴读交互进入真实扩展

[规范](../tasks/20261005-killer-interactions-spec.md) · [使用说明](../guides/usage.md)

## 规则

- R1 仅译文使用可掀开的覆盖层，原 Text 节点、文字与监听器保留。
  - 正：真实页面翻译后按住，层偏移旋转；松开350ms内复位。机器检查。
  - 反：恢复、网页自行改写、移出与取消不留旧层；双语模式仍同时显示原译文。机器检查。
- R2 边注模式可选择关闭、原文或AI解释；当前页中心段落驱动导轨。
  - 正：滚动后段落、来源和导轨位置变化；AI模式实际调用模型。机器检查。
  - 反：关闭/原文不调用模型；切页、导航及旧段落回复不覆盖新边注。机器检查。
- R3 从页面拖入表格、代码或卡片，生成可移除材料及提问草稿。
  - 正：原生拖拽数据经过真实侧栏，出现磁吸槽、材料与模板；发送后模型收到正文材料。机器检查。
  - 反：取消、过期、外来拖拽不执行任务；不覆盖已有草稿；删除材料不删除正文。机器检查。
- R4 有唯一页面依据的数字引用可以定位并短暂声纳高亮。
  - 正：点引用，正确原段落居中，高亮1.2秒后清理。机器检查。
  - 反：重复、缺失或过期依据不能指向猜测的位置；减少动态效果关闭脉冲。机器检查。
