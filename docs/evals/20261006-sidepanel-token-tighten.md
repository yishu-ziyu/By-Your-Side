## 规则

- R1 浅色侧栏底是同一色相的奶油（hue 88），彩度比预览 wallpaper 的 `0.010` 低，看起来不那么黄。
  - 例子(正)：打开侧栏，纸底仍偏暖，但比预览截图更淡、更安静 — 谁检查：`npx tsx scripts/probes/sidepanel-token-tighten.mts` / 人
  - 例子(反)：wallpaper 仍是预览的 `oklch(… 0.010 88)`，或回到实心偏黄纸 — 谁检查：同上
- R2 对话里看得见的字号、圆角、间距走共用档，不再各写各的半像素。
  - 例子(正)：用户气泡和输入框同一套形状圆角；正文用阅读档；页胶囊和「用了 N 条记忆」用元信息档 — 谁检查：同上
  - 例子(反)：气泡 17px、输入框 17px、页胶囊 5px 仍各写死 — 谁检查：同上
- R3 强调色仍是墨蓝一家，不增加第二强调色。
  - 例子(正)：`--accent` 仍指向 `--apple-blue` — 谁检查：同上
  - 例子(反)：输入框聚焦再画一道亮蓝 ring，或引用条另起彩色 — 谁检查：同上 / 人
- R4 不新做记忆引用界面。已有「用了 N 条记忆」只改用共用字号和间距。
  - 例子(正)：生产里没有为 D+X1 预览新增的 `.x1` / `.inline-cite-link` — 谁检查：同上
  - 例子(反)：为了对齐预览 HTML 新写一套引用皮肤 — 谁检查：同上
