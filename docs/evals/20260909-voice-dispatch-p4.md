# P4：语音带上所选页面资料，并主动报告有依据的任务状态

## 完成标准（实现前冻结）
- [ ] 语音提交携带提交时的选区／当前页锚点和已选图片；与文字使用相同PageContext、Attachment验证及执行接口。— 协议/适配测试
- [ ] 异步补充页面锚点期间出现新语音轮、切换会话或断线，旧commit不得晚到触发旧指令；草稿正文不变成语音指令。— VoiceRelay竞态测试
- [ ] 真实合成语音引用唯一选区标记、图片中的唯一数字，执行模型能用这些资料完成受控页面动作；不以转写注入或mock执行结果替代。— 真实Step/M3/Chrome
- [ ] 查询与闲聊不把附件发进任务；未选图片／不可用页面如实反馈，不声称读到了资料。— 路由测试
- [ ] 有任务结束、失败、等待用户操作的真实事件时，只提醒一次；idle只报告结束，不宣称成功；旧会话／旧runId不播报，新说话可打断。— 事件和播放器测试
- [ ] typecheck、test、build、diff通过。真人听感另验。

## 边界
- 只对齐现有图片与页面引用能力，不宣称支持未实现的PDF/文档解析。
- 复用现有任务记录、语音状态和事实行；不新增需要选择的页面布局。
