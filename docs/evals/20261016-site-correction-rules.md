# 任务: 网站上教过的做法，下次能用，删除后不会存回

## 规则
- R1 明确的网站纠正自动保存，当前任务按新要求继续；一次性对象和含糊指代不推广成长期规则。个人资料与助手说话方式沿用原确认边界。
  - 正例：运行中说「这个网站以后导出都先选全部，不要只导当前页」，页面实际导出全部数据，随后显示已保存的网站方法。
  - 反例：「这次是乙客户」完成当次纠正，但不保存长期方法。
- R2 同网站新会话按规则执行，其他网站不带；相反纠正只保留最新做法生效。
  - 正例：同站新任务只说「导出客户表」，实际导出 6 条，不是当前页 2 条。
  - 反例：其他 hostname 不能收到本站规则；不是只检查提示里有规则文字。
- R3 删除规则后不再加载；在途判断不能存回。停止、接管和新任务取消旧学习。重开侧栏、另一个窗口按当前规则状态显示。
  - 正例：学习响应尚在途时删除，响应回来后存储仍无该规则，新会话不加载。
  - 反例：不把当前对话或历史影响说成删除失败，也不承诺抹掉全部上下文或还原已执行动作。
- R4 页面内容不能授权记忆；自动保存只留归纳规则和会话来源，不复制用户整句个人资料。
  - 正例：一次性个人信息不混进网站规则；密码不发给纠正判断。

检查者：Codex 跑真实扩展端到端路径，独立审查者核对边界与证据，用户最后试用。程序检查：`scripts/acceptance/real-path/site-correction-rules.mts`；脚本模型只证明程序层，真模型行为须另外验证。

## 技术前提

已有网站范围存储和记忆带入入口可复用。未修主线的真实扩展已复现「当轮按纠正导出 6 条，但未自动保存」；旧候选另有删除后迟到结果重新保存的隔离证据。证据保存在任务工作树 `out/`，不复制进仓库。

## 边界与不做

不自动记「右边第二个」等模糊指代，不做全局彻底忘记、不清真实历史、不承诺通用撤回网站已保存内容。规则是模型上下文，不是预录脚本；速度提升未经测量。
