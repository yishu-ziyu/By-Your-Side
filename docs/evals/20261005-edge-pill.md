# 任务：侧栏关着、任务还在跑时，网页右边缘留一颗小药丸；移上去看到在做什么，点一下回到侧栏

[issue #45](https://github.com/yishu-ziyu/By-Your-Side/issues/45) · [使用说明](../guides/usage.md)

## 规则

- R1 只在「侧栏关着」且「有进行中、暂停或出错的任务」时，当前标签页右边缘出现药丸；侧栏开着或没有任务时不出现。
  - 正：任务运行中关掉侧栏，1 秒内页面右边缘出现药丸。机器检查：`scripts/acceptance/real-path/edge-pill.mts`。
  - 反：侧栏开着时、任务做完后，页面上都没有药丸。机器检查：同上。
- R2 药丸能分出三种状态：进行中（呼吸光）、暂停等你（静止琥珀色）、出错（静止红色）；系统设了减少动态效果时不呼吸。
  - 正：运行中药丸有呼吸动画；接管后关侧栏，药丸是暂停色；模型出错后关侧栏，药丸是出错色。机器检查：同上。
  - 反：模拟减少动态效果时，运行中药丸没有动画。机器检查：同上。观感由人看截图。
- R3 鼠标移到药丸上展开，显示状态和目标原话、「打开侧栏」按钮；移开后 0.5 秒内收回；点「打开侧栏」回到侧栏，药丸消失。
  - 正：悬停后展开层含目标原话；移开 0.5 秒后收回；点按钮后侧栏出现，药丸消失。机器检查：同上。
  - 反：只是从药丸旁边掠过，不展开。机器检查：同上（鼠标停在药丸外侧 30px 处）。
- R4 药丸不挡网页：药丸以外的地方照常能点；侧栏关着时 Agent 照常操作页面。
  - 正：药丸显示时，真实鼠标点右边缘旁的网页按钮，计数加一；关掉侧栏期间 Agent 的点击继续落到页面上。机器检查：同上。

## 还没答上的问题

无。issue 里可选的「我来」快捷入口本轮不做：接手需要在侧栏里看任务状态，药丸只负责把人带回侧栏。

## 技术前提

- 前提：侧栏关掉后，页面内容脚本里的按钮被真实鼠标点击，后台能用 `sidePanel.open` 重新打开侧栏。小实验：`scripts/probes/edge-pill-open-panel.mts`。结果：通过，点击后 17ms 侧栏重新出现。
  - 同一实验里，在真实点击 2 秒后用脚本 `click()` 也打开了侧栏：页面刚有过用户点击时，浏览器仍认这是用户动作。不影响本任务。

## 边界与不做

- 不做系统级浮岛、常驻聊天窗，不在药丸里接手页面。
- 侧栏是否开着按「有没有任何侧栏连着」判断：多窗口时一个窗口开着侧栏，其他窗口也不显示药丸。
- 药丸放在右边缘正中，收起时连同可悬停的边距约 12px 宽、60px 高；Agent 要点的元素恰好在药丸下方时会被拒绝（与页面条同一条保护规则），本轮不处理。
- 扩展后台重启后，要等任务下一次状态变化才恢复药丸；和本机 Agent 断开时药丸收起。
- 侧栏关着、Agent 正在点页面时，它的每次点击会把浏览器的鼠标位置挪走，展开的卡片随之收起；手一微动就重新展开。本轮不处理。
- 会话被删除时不专门清掉它的旧状态。

## 证据

- 做法：后台记住每个会话最近一次任务视图，侧栏一个都没连着时，把「进行中 > 暂停 > 没看过的出错」里最近的一条推给当前激活的标签页（`extension/src/background/edge-pill.ts`）。页面一侧是 closed shadow 里的药丸和小卡（`extension/src/content/edge-pill.ts`），打开侧栏走点击时同步的 `sidePanel.open`。
- 端到端：`npx tsx scripts/acceptance/real-path/edge-pill.mts --headless --run=final`，16/16 通过。产物在 `out/acceptance/edge-pill/final/`：result.json、running-collapsed.png、running-open.png、paused-open.png、error-open.png。
  - R1：侧栏开着（有无任务）都没有药丸；关侧栏后约 0.4 秒出现；任务做完后关侧栏没有药丸。
  - R2：运行中蓝色、有呼吸动画；减少动态效果时没有动画；接管后是琥珀色、出错是红色，都不动；出错在侧栏看过后不再出现。
  - R3：悬停 0.3–0.6 秒展开（Agent 同时在点页面），显示「正在做」和目标原话、「打开侧栏」；停在药丸外 30px 不展开；移开约 0.35 秒收回；点按钮后侧栏出现、药丸消失。
  - R4：紧挨药丸的网页按钮真实点击生效；侧栏关着时 Agent 继续点页面（计数 1 → 2）；页面上的扩展浮层被清掉后药丸自己挂回。
- 反证（审查修改前的版本）：去掉「侧栏开着就不显示」（run=mutant-no-panel-gate），「任务运行中、侧栏开着时没有药丸」失败，悬停与打开侧栏也随之失败。
- 稳定性：final 与 stable-2、stable-3 共多次全过。
- 审查发现并已修：光标脚本第一次注入会清掉所有扩展浮层（改为被清掉就挂回，并加了检查）；和 Agent 断开后旧状态会让药丸一直亮（断开时收起）；收起时实际挡住的宽度与文档不符（收窄到约 12px 并改文档）。
- 实测发现：侧栏关着时 Agent 的点击会挪走浏览器鼠标位置，悬停卡片随之收起（见边界）。验收里悬停改为持续微动，与真人的手一致。
- 工程检查：`VITEST_MAX_WORKERS=1 npm run check` 退出码 0，253 个文件、2392 项测试通过，文档 0 错误。日志 `out/acceptance/edge-pill/final/check.log`。
- 未跑：真实网站、多窗口、真人观感与悬停手感。此次未重载日常扩展、未提交。
