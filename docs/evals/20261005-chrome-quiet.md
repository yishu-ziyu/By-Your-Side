# 任务：在侧栏打字或读回答时，顶栏和次要按钮安静地淡下去，鼠标一动就回来

[issue #46](https://github.com/yishu-ziyu/By-Your-Side/issues/46) · [使用说明](../guides/usage.md)

## 规则

- R1 在输入框连续打字约 1 秒，或在对话区用滚轮翻看时，顶栏按钮（会话切换、新会话、更多）和输入区的次要按钮（当前页标签、附件、···、边注）淡到几乎看不见；指针停在顶栏或这些控件上时不淡。
  - 正：打字 1.3 秒后这些按钮不透明度低于 0.2；对话区真的滚动后同样变淡。机器检查：`scripts/acceptance/real-path/chrome-quiet.mts`。
  - 反：打 0.3 秒就停下（比如打两个字就发送），1.5 秒后仍不淡；指针停在顶栏上打字不淡。机器检查：同上。
- R2 鼠标一动，或用 Tab 把焦点移到按钮上，200ms 内恢复到完全可见。
  - 正：变淡后移动鼠标，200ms 内回到 0.95 以上，并回到各自原来的样子（禁用的「新会话」仍是半透明）；Tab 到附件按钮，该按钮完全可见。机器检查：同上。
- R3 菜单开着时不淡出，避免「看不见却点到」。
  - 反：打开「更多」菜单后焦点回到输入框继续打字，按钮保持可见。机器检查：同上。
- R4 顶栏状态（未连接、正在…、重试）、输入框、发送/停止按钮始终不变淡；系统设了减少动态效果时照样变淡，但不播放过渡，直接切换。
  - 正：变淡时状态、输入框、发送按钮不透明度为 1。减少动态效果时淡出、恢复的过渡时长为 0。机器检查：同上。

## 还没答上的问题

无。issue 让实现时在「减少动态效果时不自动藏」和「即时显隐」二选一：选即时显隐，安静的效果对这类用户同样有用，只是去掉动画。

## 技术前提

- 前提：无头真侧栏里能用 CDP 发真实键盘、鼠标移动和滚轮事件，并读到元素实际不透明度。依据：已有侧栏验收用同一套输入方法（`scripts/acceptance/real-path/sidebar-interaction.mts`）；滚轮与不透明度由本验收实测。

## 边界与不做

- 不改页面上的浮层，不做全屏沉浸阅读。
- 顶栏状态、任务条、「我来/你继续」、发送/停止不淡出：用户要始终知道 Agent 在做什么。
- 变淡的按钮仍可点击：真人点之前鼠标一定会动，按钮先回来。
- 不改阅读字号与字体。

## 证据

- 做法：`extension/src/sidepanel/chrome-quiet.ts`。用 Web Animations 叠在原样式上：淡出 0.4 秒停在 0.08；恢复 0.12 秒回到元素自己的样式后撤掉动画，不覆盖禁用等状态。只在打字过程中判断「连续打了 1 秒」（两次按键间隔超过 0.6 秒算重新开始）。鼠标移动只认真实位移，滚动后浏览器补发的不动的移动不算。
- 端到端：`npx tsx scripts/acceptance/real-path/chrome-quiet.mts --headless --run=final`，12/12 通过。产物在 `out/acceptance/chrome-quiet/final/`：result.json、quiet.png、loud.png。
  - R1：打 0.3 秒停下不淡；连续打字后 7 个按钮都是 0.08；对话区滚动 120px 后变淡；指针在顶栏上不淡。
  - R2：移动鼠标约 0.09 秒恢复，禁用的「新会话」恢复为 0.45；Tab 到附件按钮约 0.1 秒完全可见。
  - R3：菜单开着、焦点回输入框继续打字，不淡。
  - R4：状态、输入框、发送按钮始终为 1；减少动态效果时过渡时长为 0，变淡和恢复都是直接切换。
- 反证：去掉「菜单开着不淡」，R3 失败；去掉「鼠标一动就恢复」，恢复、原样、顶栏悬停与减少动效恢复 4 项失败。
- 稳定性：final、stable-2、stable-3 全过。
- 回归：侧栏交互验收 32/32（run=after-chrome-quiet）；药丸验收 16/16（run=after-chrome-quiet）。
- 审查发现并已修：打两个字就发送也会在 1 秒后变淡；顶栏状态被一起淡掉；恢复时把禁用按钮的半透明改成了全亮；菜单检查被焦点条件掩盖、没真正测到；对话区为空、滚轮没真的滚动。另外自查发现恢复动画只写了起点时浏览器把它当终点，会先变暗再跳亮，已固定起点。
- 工程检查：`VITEST_MAX_WORKERS=1 npm run check` 退出码 0，2392 项测试通过，文档 0 错误。日志 `out/acceptance/chrome-quiet/final/check.log`。
- 未跑：真人观感、触控板惯性滚动、任务运行中的侧栏。此次未重载日常扩展、未提交。
