# 任务: 输入框空着只留字和发送，用的时候工具行才展开

用户每天看得到加号、话筒和思考开关，即使还没开始写。空着更干净，点进去或写出字以后这些才出现。发送键一直在。

## 规则

- R1 没字、没附件、焦点不在输入框时，工具行收起，发送键仍在。
  - 例子(正)：打开侧栏不点输入框，看不见加号，看得见发送键 — 谁检查：`composer-expand` / 人
  - 例子(反)：空着就露出加号 — 谁检查：`composer-expand`
- R2 点进输入框、写出字、加上附件或打开附件菜单，工具行展开。
  - 例子(正)：点输入框后加号出现；打完字或加上附件再点别处，加号还在 — 谁检查：`composer-expand`
  - 例子(反)：点进去加号不出现；有字时失焦就收回 — 谁检查：`composer-expand`
- R3 没连模型、出错、窄到约 320 时，上面两条仍成立。
  - 例子(正)：先连接模型的空侧栏、发出去后出现连模型卡片、侧栏宽 320，发送键都在，点进去加号都会出来；出错后失焦工具收回 — 谁检查：`composer-expand` / 人
  - 例子(反)：窄屏发送键不见，或出错后点不进输入框 — 谁检查：`composer-expand`

## 还没答上的问题

- 无

## 技术前提

- 前提：工具行收进 `#composer-bar-inner`，发送键留在行外，展开用已有动效 token。小实验：演示页方向 C。结果：通过。

## 边界与不做

- 不把模型选择从顶栏「更多」挪进输入框。
- 不改斜杠技能选中后写入正文的现有行为。
- 说话输入时整行工具栏本来就会换成声波，不受这条影响。
