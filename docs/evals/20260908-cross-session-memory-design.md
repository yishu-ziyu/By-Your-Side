# 跨会话记忆：原型判断依据

日期：2026-09-08。仅原型与开发标准，未授权产品实现。

## 要判断的两件事

1. 明确说“记住”后，简短回执是否足够，同时能找到具体内容和适用范围。
2. 管理记忆时，是保留聊天背景的抽屉更合适，还是独立管理视图更清楚。

## 对照

- A（推荐）：会话内回执，点开记忆抽屉；保持当前任务位置。
- B：顶部常设记忆入口，进入独立管理视图；更强调集中管理。
- 两案使用相同材料和功能，不以删掉某案功能制造偏向。第一版范围为候选：用户明确要求保存、相关会话使用、查看、纠正、删除。自动观察与习惯学习后置。
- “所有会话 / 当前站点”是待人评范围提案，不代表用户已经批准全局默记。例子直接由用户句子明确限定范围。

## 已阅读的设计依据

- [Will’s S：渐进式揭示](https://www.notion.so/20f886bc60ff816b86e1c9ce8dbfc3ea)：常用操作保持简单，细节按需展开；不能藏掉影响决定的适用范围。采用：回执短，内容与来源在详情中，范围始终可见。
- [Will’s S：指引与反馈](https://www.notion.so/20f886bc60ff81b980f7f60210dfebea)：位置、去向、返回路径和动作结果清楚。采用：抽屉/管理视图有标题和返回；保存、失败、更新、删除分别反馈。
- [Will’s S：用户控制与自由](https://www.notion.so/1f8886bc60ff81399125f75d27c0732c)：提供可见退出和取消。采用：编辑可取消，删除前说明影响，返回原会话。
