## 规则

- R1 用户能选择按量或套餐；保存后下次开启生效。套餐只连接套餐接口，不自动退回按量。
  - 正例：设置重开仍是套餐；下一次连接使用套餐地址。检查者：`voice-plan-settings.mts`，真实设置、存储与网络记录。
  - 反例：存储值损坏后开启，出现新按量连接。必须报错并保持未连接。检查者：同上。
- R2 套餐先核对转写的意图。明确闲聊由原生语音回答，不同时启动助手任务；网页请求只交给现有助手一次。
  - 正例：闲聊听到原生回复；点网页按钮时服务器收到一次点击。检查者：真实语音验收、服务器计数与侧栏录像。
- R3 转写迟到、分流失败或超过上限时，不放行未经核对的原生回答，不执行网页动作；界面说明失败。
  - 反例：说“已保存”，网页却没有请求。检查者：真实供应商消息与侧栏音频、文字事件。
- R4 新开口或关闭语音后，旧分流结果不能恢复旧回复或执行旧动作。原有按量、按住说话不改变。
  - 正例：旧分流尚未结束就关闭语音，晚到结果不点击。检查者：真实会话故障注入与已有按量路径。
