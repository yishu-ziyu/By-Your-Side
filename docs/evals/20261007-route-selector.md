# 任务: 第一次用页面选择器或按文字操作做成的事，也记下做法，下次照着走（YIS-103）

上一步见 [20261007-route-record](20261007-route-record.md)、[20261007-route-check](20261007-route-check.md)。

## 规则
- R1 模型用选择器（`#date`、`text=青松` 等，不是 @N 编号）点、填、选时，也读出那个元素在无障碍树里的描述记进做法。选择器指向不唯一时，动作本身就不执行；读不出描述时，照旧整份不存。
  - 例子(正)：第一次请模型用 `#date`、`#time`、`#topic`、`#submit` 操作订会议室，订对后记下做法；第二次照着走订对 — 谁检查：`scripts/acceptance/real-path/route-replay.mts --first=selector`
- R2 按文字点到的不是控件（卡片标题、段落、表格格子、标签文字、图片）时，有名字的也认得出；照走时和控件一样，页面上要恰好一个对得上。
  - 例子(正)：模型用 `text=青松` 点了卡片标题，做法照存 — 谁检查：同上
- R3 按文字点的正是用户这次说的那一项（标题「青松」），就当成选的值，下次换成那次说的（「白桦」）。
  - 例子(反)：下次订白桦，照走时还去点「青松」 — 谁检查：`agent/test/route-record.test.ts`、`agent/test/route-replay.test.ts`

## 还没答上的问题

## 技术前提
- 前提：选择器在页面里按动作同一套解析找到唯一元素后，能对上无障碍树里的同一个节点。做法：页面里临时给元素打个记号，用 CDP 文档树找回记号拿到节点编号，再擦掉记号。由真实路径直接检查，不另做小实验。

## 边界与不做
- 没有名字的元素（空白 div）照旧认不出，整份不存。
- 坐标点击照旧记不下。
