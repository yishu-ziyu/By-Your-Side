# 任务: 从侧栏「⋯」菜单点「在新窗口打开」，当前会话开在一个单独的小窗口里，用起来和侧栏一样

这是“把一个会话拿出来单独开一个窗口”的第二步（第一步见 [两个侧栏各看各的会话](20261015-per-panel-conversation.md)）。侧栏照旧。

## 规则
- R1 点「在新窗口打开」，开出一个小窗口，显示侧栏正在看的会话；侧栏不动。刷新小窗口，仍是这个会话。
  - 例子(正)：侧栏里问过一句，点菜单后小窗口里有这段问答，侧栏还在原来的会话；刷新小窗口，问答还在 — 谁检查：`npx tsx scripts/acceptance/real-path/conversation-popout.mts --headless`
  - 例子(反)：小窗口打开是空白新会话 — 谁检查：同上
- R2 在小窗口里问，助手读和操作的是打开它的那个浏览器窗口里正在看的网页，不是小窗口自己。输入框上方的页面标牌也显示那一页。
  - 例子(正)：用户点进小窗口问“点一下按钮”，源窗口网页上的按钮被点了 — 谁检查：同上
- R3 打开小窗口的那个浏览器窗口关了，小窗口改看最近用过的普通浏览器窗口。
  - 例子(正)：另开一个窗口再关掉源窗口，小窗口里再问，点的是另一个窗口里的网页 — 谁检查：同上
- R4 只有扩展自己的侧栏页能连上后台；网页地址的路径也叫 sidepanel.html 也不行。
  - 例子(反)：网页 `http://…/sidepanel.html?…` 里的内容脚本连侧栏端口，能收到会话清单 — 谁检查：同上

## 技术前提
- 前提：小窗口地址带 `conversation=` 和 `window=`（源窗口）；页面要找“当前标签页”时都问同一个函数，侧栏答自己的窗口，小窗口答源窗口。小实验：scripts/acceptance/real-path/conversation-popout.mts 结果：通过

## 边界与不做
- 小窗口里这一版没有语音对话和说话输入，也没有再开小窗口的菜单项。
- 网页上按住说话、右键提问，按第一步的规则交给源窗口里最近点进过的那个页面（侧栏或小窗口）。
- 无头 Chrome 不按给的大小开窗口；小窗口的大小和位置由人在有窗口的 Chrome 里检查。
