# 任务：用语音完成文字入口的任务调度，并支持带资料、指定会话和连续纠正

状态更新（2026-09-09）：P0/P1阶段自动验收通过；P2–P5已有实现和部分真实结果，P6已开始真人测试，整体未完成。下文“基线”和实施顺序保留2026-09-08制定方案时的历史，不代表当前仍未实现。逐项结果与失败见[验收台账](20260909-voice-dispatch-results.md)，项目状态见[进度入口](../STATUS.md)。

新增用户要求：语音查看当前浏览器页面，另立[只读观察标准](20260909-voice-page-observation.md)。不因此放宽原48句分类、三轮真实路径或时延门槛。

## 目标与完成边界

用户能说出任务、补充要求、查进度、暂停、继续、停止，看到与文字入口相同的任务记录和实际网页结果。再扩展到引用页面资料、指定已有会话、连续纠正与有序复合指令。

“对齐”指任务操作、上下文、归属和结果一致，不要求把设置页每个按钮都改成语音。执行模型、浏览器工具和团队调度继续复用现有能力。语音模型负责听说，不另建执行系统。

本方案冻结后，实现不得放宽下列标准以通过测试。新发现的产品歧义单独提请用户裁决。

## 已核对的基线

- 文字空闲输入进入 user_message，运行中进入 steer；可携带 PageContext 和附件。
- 当前语音只有 EDIT/NONE 分类；修改仅可送至正在运行的主任务，不携带页面资料或附件。
- 语音修改最终等待 Pi 接收后才播报回执；完整网页预算 1000→800 验收仍未通过。历史机器检查不能替代复测。
- 接管与交还经扩展的 control 流程执行，涉及页面归属、组代次、成员和页面快照。不能从语音后台绕过。
- 当前 TaskProgressSnapshot 的 successVerified 固定为 false，不能据 idle 或 agent_end 宣称任务成功。
- 语音切换会话即关闭；断开语音不停止网页任务。

## 操作语义与状态限制

- 空闲时明确任务请求→启动；运行中补充→当前任务修改；运行中新建无关任务→询问是否另开会话，不覆盖原任务。
- 查询进度与闲聊只回答；“能不能改”“他刚才说改800”“如果改800会怎样”不执行修改。
- “暂停任务／先停一下”→保留任务并接管；“终止任务／取消任务”→终止；“停止”单独出现且对象不明→询问停播报还是停任务。播放层插话立即停声，不等待语义判定。
- 暂停状态的条件补充保存为待续指令，并明确“继续后生效”；单独修改不能自动交还。恢复时携带新快照及待续原话。
- 查询、修改、暂停、继续、停止绑定明确目标。不存在或重名目标不执行；不得由语音模型编造会话ID。
- 任务完成后迟到的修改拒绝；明确新任务才可启动。重复传输不得重复执行。
- 已接受的旧指令不会因新一句开始而被假装撤回；新纠正作为后续指令。尚未接受的过期分类结果不得执行。
- 复合指令按顺序、逐项回执；中途失败停止后续项并保留已发生事实，不承诺回滚已完成的网页动作。

## 工程设计

### 一个操作通路，两个输入适配器

文字／按钮和语音都进入共享操作接口。采用渐进迁移：先把现有运行中修改接进去，再逐项迁移；每次迁移同时跑原文字路径回归。

共享请求包含 requestId、来源、目标conversationId、预期runId/controlEpoch、操作类型、原始用户文字、显式引用／附件引用。语音补充 voiceId、turn；网页内容不能成为用户指令。使用真正的运行标识替代仅用 startedAt 判断任务身份。

操作集合：start、steer、status、pause、resume、abort；chat／clarify 留在对话层。先让结构化路由输出严格校验的操作与目标引用，再由应用解析目标并校验状态。模型不直接调浏览器工具。

执行边界串行校验目标与预期状态。维护 requestId 回执，区分 rejected、accepted、applied、failed、unknown；accepted 只说明执行器已接收，applied 仅用于可确认的控制动作。任务完成另以实际结果证据记录，不从 agent_end 推断。

连接中断后查询原requestId结果，不盲重发。进程重启后如无法恢复接受与执行事实则返回unknown；不能承诺跨崩溃“恰好一次”。去重记录保留策略及重启行为在测试中固定。

### 浏览器控制复用现有协议

语音暂停／继续发出带关联ID的控制请求，由扩展运行与按钮相同的流程：冻结页面写入→确认成员和代次→后台保持任务；继续时采集当前快照→交还。失败时保持实际归属并明确原因。

成功暂停／终止回执必须晚于在途写入排空或取消。不可撤销的已发生动作如实报告；不能仅停止模型就播报“已停手”。

### 上下文、记录与播报

页面引用与已选附件由侧栏在语音提交时快照化，并绑定目标。跨会话不隐式携带当前页面；需明确“用当前页面”。不通过语音读取任意本地路径，不声称支持现有附件解析器未支持的类型。

原话、目标、回执进入现有会话记录并支持重载。语音先收到执行回执再确认成功；完成、失败、需要用户操作可主动播报一次。查询事实带观察时间；状态变更后更新事实，不复述上一轮缓存。

普通诊断日志记录时序、ID、错误码，不记录原录音、转写全文或凭据；原话只按现有会话历史规则保存。测试材料使用无私人数据的固定音频和页面。
