# 主执行光球状态标记落地

用户批准演示后应用到产品，沿用四个 Lucide 图标与已确认配色：等你操作 Hand、完成 Check、失败 CircleAlert、停止 Square。仅主执行球旁显示 18px 标记，运行三态隐藏标记；原库动画不变。

## 验收

- [x] 真实前端中四类标记图形、颜色和可访问标签正确；思考/执行/等待不显示结果图标。
- [x] 完成、停止历史重放保持各自标记；停止不冒充完成。
- [x] 原动效运行/暂停和减少动态行为保持。
- [x] 真实生产文本任务得到答案并显示完成勾号。
- [x] 类型、构建、模块边界、diff 与相关单测通过。

受控前端证据：[26 项检查](20260915-orb-markers/result.json)、同目录四种状态截图。使用隔离 headless Chrome 和生产构建，Port 事件为受控输入，不冒充完整业务路径。真实 native 文本入口发送“只回答 8 加 7 等于多少”，得到 15，见[完成截图](20260915-orb-markers/native-completed.png)。

全体普通单测首次为 1753 通过、1 失败，唯一失败是旧源码断言要求结束文案只能固定赋值“查看执行过程”；现已区分完成/失败/停止，按新文案修订断言。随后关联的71项测试通过，未为仅断言变化重复整套检查。

## 边界与实现

停止状态过去仅在当前面板内存中。后台在实际中止活动任务时，先记录 run_stopped 事件，再记录 idle；回放同一事件可恢复停止方块。没有用文案猜测停止结果。没有活动任务时不创建停止记录。其余标记由既有状态推导，未另增一套状态机。

失败和停止时标题相应显示“执行失败 / 已停止 · 查看过程”；图标有 aria-label，颜色不是唯一信号。构建和重载本地扩展已完成，未提交/发布。保留已有并发改动。
