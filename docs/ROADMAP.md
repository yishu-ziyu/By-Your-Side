## 人机协作（高交互性）
- [x] 插话 steer：运行中发消息自动转 steer（2026-09-03 已有，本轮补 UX 提示）
- [ ] 危险操作确认（2026-09-03 定调：纯对话形式，不做卡片/就地 UI）：
  - 形态：Agent 在对话里用自然语言说清"在哪个页面、要动什么、后果是什么"，用户回复明确肯定才执行（已在 prompt 强化：批量需逐项列明、页面变化后需重新征得同意、含糊回复不算同意）
  - 现状：prompt 层约定，非硬闸门；若以后要"保证不发生"，在执行层加不可跳过的闸门（tool_call 挂起等待下一条用户消息放行），UI 仍保持纯对话
- [ ] 接管/交接按钮：用户随时接管页面，Agent 旁观等待交接（overlay pointer-events:none 天然支持穿透点击）
- [ ] 选中即问：右键/划词调起 Agent，带页面上下文问答
- [ ] 多任务并行：多个 Agent session 各绑标签页并行执行，页面光标按实例着色区分（光标渲染层已支持 for(id)，agent 侧多 session 编排待做）
