# 字体字号

点击侧栏右上角「更多 → 字体字号」。你选择后，当前回答立即变化。

- 这些选项只影响助手的回答。按钮、状态栏和输入框保留系统字体，代码保持等宽字体。
- 系统缺少宋体时，侧栏使用后备字体，所以不同系统上看到的字体可能不同。
- 以前保存的宋体或黑体选择继续保留，不因默认外观调整而重置。
- 出现保存失败的提示时，本次的效果仍可查看，但关闭侧栏后可能不保留。

## 划词工具条

选中网页文字后，选区旁默认弹出划词工具条。用户可以在设置页关掉它，已打开的网页立即生效。

- 关闭只停掉“选中就弹出”。用户按快捷键或用右键菜单属于主动发起，仍然打开阅读卡。
- 已展开、正在问答的阅读卡不会因关闭开关而收起。
- 这项设置只存在本浏览器里。
