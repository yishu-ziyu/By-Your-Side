# 阅读外观

点击侧栏右上角的“设置”，打开“阅读外观”。

- **字体**：宋体、黑体、系统默认。默认宋体。
- **字号**：小、标准、大。默认标准。
- 选择后，当前回答立即变化；保存成功后，重新打开侧栏仍使用你的选择。
- 点击“恢复默认”，回到宋体、标准字号。

这些选项只影响助手的回答。按钮、状态栏和输入框保留系统字体；代码保持等宽字体。不同系统上可用的字体可能不同，缺少宋体时会使用后备字体。

如果出现保存失败提示，本次阅读效果仍可查看，但关闭后可能无法保留；可以重新选择后重试保存。

较长的回答会按内容组织，并在相关段落旁附上可点击的来源名称。来源名称不代表内容已经独立核实；回答中的转述、推断和未确认部分仍应分别看待。短回答无需固定标题。
