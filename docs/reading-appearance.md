# 阅读外观

点击侧栏右上角「更多 → 阅读外观」。

- **字体**：宋体、黑体、系统默认。默认是系统字体。
- **字号**：小、标准、大。默认是标准。
- 你选择后，当前回答立即变化。保存成功后，重新打开侧栏仍使用你的选择。
- 点击「恢复默认」，回到系统字体和标准字号。

以前保存的宋体或黑体选择继续保留，不因默认外观调整而重置。

这些选项只影响助手的回答。按钮、状态栏和输入框保留系统字体；代码保持等宽字体。不同系统上可用的字体可能不同；系统缺少宋体时，侧栏使用后备字体。

如果出现保存失败的提示，本次的阅读效果仍可查看，但关闭侧栏后可能不保留。你可以重新选择，再试一次保存。

较长的回答按内容组织，并在对应段落旁附上可点击的来源名称。来源名称不代表内容已经独立核实；回答中的转述、推断和未确认的部分仍应分别看待。短回答不用固定标题。

## 划词工具条

选中网页文字后，选区旁默认弹出「问 AI / 解释 / 转入侧栏」划词工具条。在设置页的「划词」一栏取消勾选，就能关闭划词工具条；已打开的网页立即生效，不用刷新。

- 关闭只停掉“选中就弹出”。选中后按 `⌘J` 或右键「问 By Your Side」属于主动发起，仍然打开阅读卡。
- 已展开、正在问答的阅读卡不会因关闭开关而收起。
- 这项设置只存在本浏览器里；从没保存过时，划词工具条视为开启（[`ask-selection.ts`](../extension/src/shared/ask-selection.ts)）。

「转入侧栏」和阅读卡的转入行为见[使用说明](guides/usage.md#任务卡与引用)。
