# 经验：扩大一道检查的范围时，要同时测它不该触发的那一边

## 现象（10-02）

9415c84 把「交付前目标核对」从「改过页面的任务」扩大到「用过网页工具的任务」，只测了它该拦的情况（答非所问 30/30 判「接着做」）。评测里网站连不上时，助手 57 s 已正确说明。核对仍判「接着做」，催它重试两次、思考档升到 max，用户收到 3 条相同说明，耗时 224 s。

## 方法

- 扩大检查/闸门范围前，列出新纳入的情形里「结果做不成但处理正确」的样本，例如网站挂了、数据不存在、用户该决定。再把它们与「该拦」的样本一起做真实模型探针。
- 判断结论要能表达「做不成」（`blocked`），不要只有「做完 / 没做完」两态。
