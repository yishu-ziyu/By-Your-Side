# 页面读数：截断文字与输入范围

[协议](protocol.md) · [验收记录](evals/20261002-tier1-product-gaps.md)

页面读数指快照、读元素和填写回执交给模型的内容。规则写在 [shared/page-readout.ts](../shared/page-readout.ts)，各读取入口共用这份规则。

## 截断文字给出完整值

- 页面把长文字截成省略号显示时，读数在显示的文字后附上完整值。所以模型能说出完整的商品名，不只说前半截。
- 完整值只取页面自己给出、而且和显示的文字对得上的写法。程序不猜：宁可缺完整值，也不给模型一个可能张冠李戴的名字。
- 用 CSS 省略号截断的文字不需要这条规则，因为页面里本来就是全文。

## 范围输入框带允许范围

- 时间、日期、数字和滑块输入框的读数带上页面允许的范围。所以模型填写前就知道哪些值页面不接受。
- 无障碍树不提供时间、日期框的范围和当前值，所以全页快照另外补读。补读失败时，快照照常输出，只缺范围。
- 填了越界的值时，程序照常写入，但回执写明页面不接受这个值，并给出允许范围，不报成单纯成功。越界是写入后的警告，不是拒绝写入。
- 是否越界只按浏览器自己的判定。程序不自己比较时间或数字，所以程序和页面不会给出两种结论。
- 时间框格式无效（如 `9:30pm`）时，程序不执行，保留原值。空值仍可清空。
- 网页刷新时间框的时、分子框以后，旧的元素编号失效，模型要重新快照。

验收入口见[验收入口](testing/acceptance.md)。加 `--live` 时，脚本另外读 webscraper 测试站的最后一页和 httpbin 表单；httpbin 表单只填写，不提交。
