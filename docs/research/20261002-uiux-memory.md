## 预期与真实衡量方法

以下是实施后的验收目标，尚未实测。

1. 360×765px：使用本轮同一请求和同一两份文件，恢复会话后两份文件名称与打开/下载都在消息区首屏；图片默认不超过48px高。记录截图和元素矩形；不以缩小字体达到目标。
2. 图片核对：从文件行到原图最多两次点击。下载内容的SHA256与真实持久化图片相同。展开/收起不调用模型，不修改会话选择、不重放工具。
3. 会话辨识：准备5个相似长标题、2个有文件的会话；列表可看到两行标题与更新时间。切换后草稿、历史和文件归属正确；菜单完整信息可用键盘操作。
4. 状态真实性：运行、用户接管、停止请求中、停止失败、部分完成、重启后中断、缺恢复依据逐态留证。用户能说出谁行动；后台无运行事实时不得显示正在执行。
5. 边界：长中文文件名、长图、3份以上文件、已删除和读取失败。文件名不与按钮重叠，已删除/读取失败不能打开或下载空文件。
6. 体验判断由人做：找回指定会话与下载指定文件各测5人，记录时间、误点、是否误认为重开即重新执行。目标是相同内容下比当前版本更快且误判更少；不能用静态像素节省量代替此结果。
