# 记忆、过往任务与任务跨轮

本页写记忆、过往任务和任务跨轮的边界与取舍。

- 消息和字段以代码为准（[`shared/protocol.ts`](../shared/protocol.ts)）。
- 记什么、记成哪种、用在哪里，见[记忆模型](memory-model.md)。用户看到的行为见[使用说明](guides/usage.md#会话页面和记忆)。
- 验收见 [20260927 记忆、主动、任务感](evals/20260927-memory-proactive-task.md)。

## 个人记忆

- 修改、忘记和撤销只作用于当前版本的记忆。操作失败时，侧栏不显示成功回执。
- 网站范围只限制助手在哪里使用记忆。记忆面板仍列出全部条目。
- 程序读不懂的数据，或比当前版本更新的格式，只读不写，不当作空记忆覆盖。旧格式升级时，程序只修状态和链接，不删条目。
- 网页、附件和工具输出都不能自行授予修改记忆的权限。
- 自动记哪些、不记哪些，见[记忆模型](memory-model.md#一句话记成哪种)。网站上的操作步骤，以及回复的语言、格式和语气，不自动记；这些留给纠正后的询问。
- 判断一句话要不要记的期间，如果新消息、中止或接管让这句话作废，判断结果不写入。
- 诊断记录只写编号、种类、规则和结论，不写用户原话和记忆原文。
- 判断请求的取档、重试与失败原因见[后台判断](model-effort.md#后台判断)。

**纠正后开口问「要我记住吗」。**

- 助手只看用户直接发的话，不看网页、附件和工具输出。用户在任务运行期间插话说的纠正，助手不问。
- 这一轮回答先显示，然后程序才问快速模型。
- 做法的文字应出自用户原话。如果做法里有原话中没有的邮箱、网址或长数字，助手这次不问。
- 做法所属的网站，取用户说这句话时所在的网页，不从原话里解析网址。没有网页时，取任务最近操作过的网页；两者都没有，助手就不问关于网站的做法。
- 询问期间，如果用户又发话、中止或接管，程序丢掉这次询问，不发过时的询问。询问判断失败时，程序只留记录，不补判。
- 做法的文字只取任务宿主保存的那一份。模型工具和网页都没有写入做法的途径。

**判断失败后补判。** 「要不要记」的判断失败时，原话进本机补判队列；补判完成或放弃后，程序删掉这条原话。补判前，如果用户已改动这次补判涉及的记忆，程序作废这次补判。代价是可能少记一条，但记忆不会被改回旧值，也不会新旧并存。

用户忘记一条记忆后，后续轮次不再读取这一条；原来的会话记录仍保留。记忆没有按 Chrome 配置分开存储，所以不应宣称已实现浏览器配置隔离。

## 过往任务

- 写入前，程序只隐去密码、验证码、卡号等具体值，不删整段。只提到这些关键词、没有具体值的文字照常保留。
- 程序读不懂的数据只读不写：本会话的写入都被拒绝，原文不动。只有「全部清空」连读不懂的条目一起清掉。
- 过了有效期的过往任务，助手仍能查到。

## 用户设的提交条件

用户设的提交条件作为用户要求继续保存，但网页操作不再逐次确认（见[网页操作不再逐次确认](browser-confirmation.md)）。安全边界见[协议](protocol.md#安全)。

## 任务跨轮

上一个任务部分完成时，程序按简单规则判断用户的下一句是否算接着做，不调用模型（10-04 起，为了回应更快，见[验收](evals/20261004-cut-unused.md)）。
规则是：目标核对的结论是在等用户，或者助手上一句在问用户，用户的下一句就算接着做。接着做时，任务和目标不变；恢复提示写明这是用户的补充，不是重启。

后续记忆范围与检索方案见[记忆研究](research/20261002-extension-memory.md)。

## 扩展会话恢复

- 会话恢复复用 Pi 原生的会话与存储规则，不另写一套。记录存在扩展的 IndexedDB 里，不访问本机文件系统。
- 发出动作前先等记录保存完成，这条规则见[协议](protocol.md#侧栏恢复与持久化)。
- 会话恢复不启用自动压缩。
- 恢复旧消息时，程序不自动执行旧的工具调用。中断的任务先读取当前页面；结果未知的写入仍受控制闸门约束。
- 个人记忆不替代当前会话记录。旧版本从未保存的消息，不能凭侧栏回放还原成完整的执行证据。

文件正文独立保存，见[文件卡片与截图](artifacts.md)。用户可见的恢复验收见[本轮记录](evals/20261002-session-durability.md)。
