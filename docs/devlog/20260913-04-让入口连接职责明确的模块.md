# 让入口连接职责明确的模块

用户要求仓库可维护、可扩展、不冗杂。已有缺陷显示维护压力集中在状态归属和入口装配；大量历史状态又使后续接手容易读到矛盾结论。

本次先分离完整的模型选择交互和无工具语音模型调用，Node授权账本回归Agent，补运行依赖方向检查。没有把语音确认和控制器共享状态机械拆成多个互相回调的文件。未解的大入口热点保留在架构文档中。

当前文档入口只保留现状与因果，完整旧记录归档。全量回归再次暴露规模测试与普通测试抢资源，改为顺序执行；保留原门槛和失败记录。
