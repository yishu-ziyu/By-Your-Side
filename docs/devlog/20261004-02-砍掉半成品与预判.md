# 砍掉半成品与预判

2026-10-04。[验收](../evals/20261004-cut-unused.md)

## 方向

产品负责人决定：只做好「侧栏一句话，助手在浏览器里快速做完」。没被用到、到不了、或花时间却没收益证据的功能，删代码，不留开关。

## 原因

17 次日常运行 + 112 次评测运行里：技能、经历、示范与观察、并行助手、Stagehand、上传、目标规划工具、指导模式、小伙伴 M、十几个模型从没调过的工具都没用上；翻译/定位/续接三个意图预判和技能快捷路径在主模型前多一轮等待（慢页面多读一次页、最多多等 8 秒）；回答要等目标核对（中位多 2.2 秒、最长 12 秒）。

## 结果

模型工具 45→30 个，工具定义字数 −35%；产品源码净删约 1.57 万行。新任务只预读一次页面；回答写完就交付、回到空闲，目标核对在后面跑，没做完才作为后续一轮接着做。圈画因语音在用而保留；页面光标头像用的 `grok-bot.ts` 保留。`eval:live` 失去 Node 套件，如实报 BLOCKED，需要一套在扩展里跑的真实模型评测。
