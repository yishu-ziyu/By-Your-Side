# 让会话复盘真正跑起来

## 1. 原来只有骨架

经验目录、复盘代理和会话结束钩子都在。目录没有实际经验，日志只有启动报错。脚本存在不能证明机制在运行。

本次修正了 Kimi 的提示词参数顺序，以及 Bash 中紧邻中文括号的变量展开。后台开始和结束现在都有会话编号与退出状态，失败不会继续占用冷却期。

## 2. 退出方式也影响结果

一次性 `-p` 模式结束后没有触发 SessionEnd。改为恢复验收会话，再从交互界面执行 `/exit`，才看到真实事件和后台进程。后台在终端退出后继续运行，最终完成。

## 3. 产出还需要核对

自动复盘写出了两条经验和一条提案。其中一条把模块找不到误归纳成语法不支持。

主代理回看完整错误，又跑了一个内联 import 反例，推翻了这个结论。随后修正经验和提案，保留初稿，并加强复盘的证据要求。自动生成不等于可以直接进入开发规范。

## 4. 结果与下一步

两条经验、一条待审提案，实际 skill 新增 0 个。专项 4 项检查、类型检查和构建通过；收尾全量测试 990 项通过、1 项点击测试失败，本任务未改动该产品实现。
