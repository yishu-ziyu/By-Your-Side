# 语音内容由一处生成

Pi 继续负责普通问答与浏览器任务。语音层对已交给 Pi 的输入等待正式交付，不再抢先生成另一份招呼，也不播额外任务确认。明确控制仍有回执；没有正式答案来源时保留实时语音回答。

首次修复的隔离检查通过，但日常扩展里一句问候仍引出了当前页面介绍。单靠回复次数不能验收内容：闲聊现在保留页面身份与工具，却按需读页。需要页面的问题仍可读取；不以过滤问候词或裁掉工具解决。

主答案等待期与输入候选分开处理。真的新话语取代旧回答，空白/噪音则接回已有回答。恢复不会再次派发，也不把路由等待、播放许可与已收音频混为一个状态。

结果、独立复核、失败样本和真实入口证据见[验收](../evals/20260913-voice-greeting-fix.md)。真人听感与等待时长仍分别验收。
