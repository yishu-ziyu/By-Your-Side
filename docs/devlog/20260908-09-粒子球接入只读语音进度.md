# 粒子球接入只读语音进度

## 1. 入口确定

用户选择 VoiceOrbs 的紫色粒子球。输入区保留小入口，开启后展开。用户看过动态对照，认可大小与位置。

## 2. 事实先到，回答后到

原生工具调用有漏触发记录。每次语音回答前，应用主动读取当前任务状态。模型可以补查，不能发起网页操作。

执行结束只代表这一轮停下，不代表任务成功。错误、暂停和中止保留各自状态。

## 3. 停声在本机完成

用户插话后先清空播放队列，再通知服务端取消。服务端晚到的旧音频不恢复播放。粒子跟随真实输入或输出的声量。

## 4. 当前证据

三种语音问进度的说法，在没有任务时均正确回答没有任务。计算反例回答17。四轮来自真实 Step 服务，输入是本机合成语音。

ChromeMain 中扩展当前被禁用。运行中网页任务和真人听感尚未验收。下一步是启用扩展，完成同一任务从运行到状态变化的实际语音问答。
