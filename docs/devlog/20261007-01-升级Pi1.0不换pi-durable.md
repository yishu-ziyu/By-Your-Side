# 升级 Pi 1.0，不换 pi-durable

- 日期：2026-10-07。验收见[底座升到 Pi 1.0](../evals/20261007-pi1-rebuild.md)。
- 原来的计划：pi-durable 两个实验（接管交还、两个任务同时跑）都通过，就把我们的循环换成 pi-durable，旧会话迁过去。
- 实测推翻：Pi 1.0.4 仍有 `Agent`，只升级时类型错误 51 处，集中在存储与循环；换 pi-durable 则要重做插话截断、首字超时、备用模型、每次调用的思考档、custom 消息和上下文钩子。L6「接管后交还」0/3 的原因在我们自己的结果记账和目标核对，换底座也修不好。
- 现在：用户裁决先升级、保留自己的循环，再修 L6。会话存储用 npm 别名沿用 0.84.4 的实现，格式不变，不迁移。阶梯 pi1-1a 各级不退步；L6 修复后 3/3。
- 留下的：pi-durable 等真要做「扩展后台重启后接着做」时再接，步 0 的三个实验（事件延迟、offscreen 恢复、服务商打包）仍有效。沿用的 0.84.4 会话存储是技术债。
