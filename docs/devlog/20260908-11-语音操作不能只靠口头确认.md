# 语音操作不能只靠口头确认

## 1. 一次没有成功的修改

真实测试中，语音说预算已改成800。网页仍是1000，还显示899元的候选商品。模型没有调用修改工具。

## 2. 应用负责送达

改为先拿到原话，由当前任务模型区分修改与查询。应用等待任务队列接收成功，再把回执交给语音模型。语音不能抢先回答成功。

修改只进入原任务。任务停了就拒绝，不另起一个任务。

## 3. 当前结果

五种意图的分类实测通过，耗时1.2至1.7秒。无任务时明确拒绝修改。查询、计算、引用他人的话和暂停请求不会误改条件。

新的完整网页复测遇到ChromeMain没有窗口。800预算的真实筛选结果仍待开窗验证。
