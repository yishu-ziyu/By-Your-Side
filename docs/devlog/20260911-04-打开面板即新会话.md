# 打开面板不再翻出上一段任务

方向：用户截图指出打开侧边栏会看到上一段任务的流水（"已接收新任务／原话：…"），要求"每次打开进入都是一个新的会话页面"。

做了什么。面板文档启动时不再自动继承上一段会话：先不选、也不回放它的记录；等会话清单到手再决定——
上一段还是空白（标题仍是「新会话」且空闲）就复用它，否则发一次新会话请求，落在空白的新会话页上。
连不上后台时不急着重开，连上后再决定，6s 兜底新建；新建请求迟迟没有回执就退回显示上一段，不把面板卡死。

为什么改在面板而不是后台。后台分不清"面板重新打开"和"托盘/网络抖动重连"——按连接事件建会话会反复新建；
面板文档启动才是用户眼里的"打开进入"，所以判断放在面板侧，沿用后台已经给的会话清单（标题/状态）。

结果。真构建面板 + 隔离 headless Chrome 13/13 PASS：上一段有内容时打开即空白新会话、旧记录不回放、
旧会话仍在切换列表并显示「后台运行中」入口；上一段还是空白时直接复用，不攒空会话；拿不到清单时兜底新建。
`run-status-ui` 10/10、153 文件 1335 项测试、typecheck、build 全过。

边界。没动「＋ 新会话」、会话切换、任务执行、控制权与台账；历史会话一个都没删。
