# 插话当场截断正在写的回答

- 日期：2026-10-05。验收：[直连按钮与改方向](../evals/20261005-ghost-hud-and-steering.md)。
- 原来：运行中插话进 Pi 的插话队列，Pi 只在一次模型调用结束后读。模型在写长回答时，用户要等整段写完才看到按新要求写的版本；实测 234 字长文要多等约 3.5 秒。
- 现在：侧栏文字插话（`source=text`）到达时，若模型正在写正文、还没开始写工具调用，扩展的会话循环把已写部分当成这次调用的完整回复收下，取消旧请求，Pi 在同一轮里读插话并重写；点完约 35 ms 开始写新回答。
- 为什么不另开协议：规范草案要新增 `STEER_INFLIGHT_TASK`，但它和现有 `task_action` 的 `steer` 是同一件事。快捷按钮只是预填好的插话。
- 不变的：语音插话、模型正在写工具调用或在执行工具时，照旧等这一步结束；插话的登记、销账和「补充而非替换」约定不变。
