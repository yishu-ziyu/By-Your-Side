# 快速复用与首次执行策略分开验收

用户授权把参数化技能、任务路由、成功路径学习和程序优先策略接入独立 worktree。

实际产品路径证明：成功任务经用户保存后，可以换材料、通过原工具和结果账本执行，并以零次主模型调用交付。保留这条路径，不另建浏览器执行器。

首次任务的额外program-first提示是另一项假设。早期两轮配对未过门槛且暴露了agent_end早于最终交付的测量问题；修正计时和请求计数后的第三组实际主模型调用45→34，减少24.4%，仍低于40%。因此额外提示只通过`SIDEAGENT_PROGRAM_FIRST=1`显式启用；普通任务保留原策略与既有browser_run工具。不能用复用技能的收益替这项假设宣称成功。

验收隔离也必须包含诊断日志。发现测试会话落到日常 trace 的轮转目录后，已为验收和 Vitest 增加独立目录；历史影响与未恢复限制保留在验收文件，不用“未改全局配置”掩盖它。

完整标准、真实失败与证据见 [本轮验收](../evals/20260919-skill-fast-loop.md)。
