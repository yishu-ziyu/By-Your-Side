# 独立验收发现执行事实没有接通

## 1. 已通过什么

原固定浏览器检查15项通过，定点测试82项通过。超时和断连两个既有场景已经阻止重复新增。原冻结文件没有变化。

## 2. 为什么仍然退回

RPC和模型工具事件使用不同的调用编号，执行事实没有沿编号映射传下来。任务进度改用错误文字判断。测试里的超时与断连文字被识别，另一种明确unknown的错误却被归成未执行。

独立Chrome反例在第一次写入后返回unknown。再次请求通过，页面和服务端都新增了两条。这个反例保留原来的计数要求，只改变故障回执类型。

晚到回执处理函数没有生产接线，页面核查恢复也没有生产入口。直接调用账本方法通过，不能证明这些入口已经接通。同id重复投递的执行去重仍缺失。

## 3. 下一步

退回实现者按[独立验收报告](../evals/20260909-write-receipt-loss-independent-review.md)的R1—R4修复。先连接事实、身份与恢复，再做真实模型和侧栏组合验收。

本轮没有改产品。新增模块检查5/10，新增浏览器反例3/6，失败证据完整保留。原因、适用边界与复跑方式已写入验收报告，不重复提炼wiki或提出规则升级。
