# 新读数不等于本次操作的证据

## 1. 旧断点已接通

第二轮独立复跑固定浏览器15项、旧反例6项、边界10项和定点96项均通过。之前的身份映射、晚到回接和去重检查已经转绿。

## 2. 恢复入口仍然误判

新工具会重新读页面，但允许模型选择任意target与expect。已有标题出现在新读数里，也会解除新增动作的未知状态。

隔离Chrome实测读了“隔离记录页”这个标题。产品称新增结果已经确认。换等价选择器再次调用，实际记录从一条变两条。

## 3. 继续的条件

要确认的是本次动作的结果。重新读取的时间不能代替结果关联。窄场景有充分证据才恢复，没有证据则保留未知。

本轮只验收，未改产品。新反例7项中4项通过、3项失败，证据与返工要求见[第二轮报告](../evals/20260909-write-receipt-loss-independent-review-r2.md)。机制未过，真实模型组合验收后移；不把未完成修复写成新经验。
