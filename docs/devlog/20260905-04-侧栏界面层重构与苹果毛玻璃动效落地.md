# 侧栏界面层重构与苹果毛玻璃动效落地

日期：2026-09-05

## 1. 为什么重构界面

此前侧栏的视觉设计存在几个明显问题。

第一，用户消息使用了高饱和度的蓝底渐变（`#2563eb` 到 `#4a86ff`）。在窄侧栏中大面积出现时，侵略性强，视觉杂乱，干扰长文本阅读。

第二，状态切换生硬。发送按钮与中止按钮是两个彼此独立、靠 `hidden` 属性粗暴切换的 DOM。切换瞬间发生重排与重心偏移。

第三，缺乏层级表达。整个界面扁平单调，没有利用玻璃材质来区分 Chrome 与内容的景深。

用户提出了明确要求：向苹果设计风格靠拢，引入透明毛玻璃效果与灵动物理交互。

## 2. 核心设计定力：材质与状态的分离

做玻璃质感最容易掉入的陷阱，是在整个页面无脑滥用 `backdrop-filter: blur()`，把消息正文也做成半透明。

这会导致文字对比度严重劣化，产生廉价感和视疲劳。

我们在动手前确立了一条不可动摇的设计原则：

> **Glass 用来表达层级，Motion 用来表达状态。**

1. **顶层 Chrome 使用 Liquid Glass**：顶栏 Topbar 与底部 Composer Dock 享有环境光折射、高光边缘（Specular Rim）与背景饱和度增强。
2. **正文主体使用坚实微晶卡片（Solid Surface）**：用户消息、执行步骤卡片、回复气泡均为纯白/深灰实体材质，确保 100% 的阅读清晰度。
3. **状态流转使用连续性动量物理**：状态发生改变时，依靠物体的连续质量与弹簧惯性，而非突兀的弹窗或瞬间替换。

## 3. 六个关键位置的落地

### 3.1 Send ↑ / Stop ■ 原位形变按钮

我们消灭了原本交替隐藏显示的两个独立按钮。

整个控制流由单个原位形变按钮承载：

- 点击按压时带有 `active: scale(0.86)` 的触感下陷。
- 当任务开始（出现 abort 需求）时，按钮不被销毁，圆角在 350ms 内从 50% 平滑收敛到 9px，背景色由黑/蓝渐变为 Apple Red。
- 箭头向上旋转 90 度并溶解，方块自中心弹性展开。
- 空间重心毫厘不移。

### 3.2 页面感知胶囊与 Morphing Sheet

输入区顶部内嵌当前活动标签页的感知胶囊（Page Context Pill）。

它显示当前标签页的 Favicon、网站域名与绿点连接状态。

当用户点击它时，它不是弹出一个突兀的系统级弹窗，而是在原地舒展膨胀为检查器面板（Morphing Sheet），显示完整的 URL、标题与 AX 树状态；点击关闭时平滑收敛回胶囊。

### 3.3 Model Picker 弹簧生长选择器

模型选择器从 Composer 工具栏左下角锚点（`origin: bottom left`）以物理弹簧曲线（`cubic-bezier(0.34, 1.56, 0.64, 1)`）弹性生长。

展开时带有 Liquid Glass 磨砂底与精致的供应商标识（MiniMax, Kimi, OpenAI 等），关闭时带阻尼收缩，不造成任何布局跳动。

### 3.4 Liquid Glass 顶栏 + Dynamic Island 灵动状态指示器

在 `sidepanel.html` 头部注入了 SVG 光学折射滤镜（`feTurbulence` + `feDisplacementMap`）。

顶栏拥有物理级透镜高光。右侧的状态胶囊升级为灵动岛（Dynamic Activity Island）：

- 常态下为深色微晶胶囊，内置常驻呼吸绿点。
- 运行中自适应伸展并呈启动蓝。
- 断连或重试时呈警告橙。
- 无论浅色还是深色模式，都保证严格的视觉对比度。

### 3.5 纯白实体气泡与平滑步骤抽屉

彻底剔除刺眼的蓝色大渐变。

用户消息改用纯净白/深灰微晶气泡，圆角按 Apple HIG 调整为 `18px 18px 4px 18px`，稳重优雅。

执行步骤聚合块（`details.run-steps`）采用实体微晶卡片，展开箭头带有弹簧旋转，工具 chips 采用语义化动作药丸，抽屉展开带有高度平滑阻尼，自然推挤下方兄弟节点。

### 3.6 危险操作 macOS Alert Sheet 拦截卡

当系统执行不可逆敏感操作需要用户确认时，卡片采用 macOS 系统级警示卡片设计：带有 Apple Red 微警示边框，按键带有 60ms 物理下沉回弹，视觉焦点清晰明确。

## 4. 技术克制：零 React 运行时依赖

市面上很多炫酷的 Agent UI 库都依赖 React、Framer Motion 或大型运行时。

By-Your-Side 保持了完全的架构克制：

- 界面层全部采用 **原生 TypeScript + 原生 DOM + 现代 CSS**。
- 不引入任何外部框架与打包膨胀。
- 构建产物仅 257KB，毫秒级冷启动。
