# 侧栏统一视觉语言：墨色写字，光球说话

## 方向

10-06 用真实模型核查 10-05 批量上线的 #43 #49 #53 #55：功能大多能用，但每个都自己发明了一套样子（深蓝小标签、药丸按钮、琥珀/青绿胶囊、灰色药丸加圆圈角标），拼在一起像硬加上去的。#49 的出处在真实路径上根本到不了界面。用户的要求：产品要美、要有艺术感，代理要有自己的审美。

## 决定

- 用 Claude Design（本地 `/design`）按同一份简报出画板，用户逐项选方向：出处 A、旁白 A 加 B 的气泡、续做清单 B、语音 A；动效采用滚动渐隐与带模糊的 300ms 淡入。
- 共同规则：侧栏只有墨、米白和一种墨蓝；墨蓝只用于焦点框和网页上被操作元素的描边。唯一带颜色、会动的是光球，听、想、说、动网页都由它表达，不再加彩色胶囊。默认只露摘要，细节收进折叠，按钮只在指着那一行时出现。
- 基调像 Claude（安静、可依赖），记号是我们自己的光球。
- 出处与完成情况拆开：读了哪些页面是事实，和任务做没做完无关，按「这一轮」清零。

## 放弃

- 设计稿的「你在操作 · 继续」不用，沿用产品已有的「现在归你 · 你继续」。
- Agent 光标不用黑箭头，保留墨蓝，和用户自己的鼠标分得开。
- 语音区不做成独占侧栏的视图，仍在输入框上方。

## 续：侧栏壳与过程灰字（#58）

- 一轮任务原来有五处在讲过程：琥珀提示、重复原话的厚任务卡、「执行失败」块、输入框上方任务条、改方向建议。改成一行灰字：进行中「正在 动词 对象」扫光，结束收成「做了 N 件事 ›」，做法取自 Whirl 的 `phase-activity.tsx`。
- 过程行不放光球：用户看了预览不喜欢紫色小球。光球只留在起始区和语音。
- 任务条不删，只让位：页面归你、控制回执、任务页不一致、未送入的附件仍要它说。
- 顶栏保留新会话按钮（用户选定，不按 issue 收进 ⋯）：最常用的动作不该藏两层。
