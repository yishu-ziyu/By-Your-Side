# 教学模式手绘圈点勾画与通透批注落地

Agent 教用户操作或在网页划重点时，机械的矩形框显得生硬疏离。

今天将 Drawably 风格的手绘笔触（圈选与引导弯箭头）落地到教学模式，并解决了荧光笔遮挡文字的问题。

## 1. 缘起与诉求

用户在探索了 Danilaa1/drawably 后提出：能否将这种手绘涂鸦感应用在 Agent 的教学模式或网页圈点勾画中。

我们首先制作了独立评估原型（`docs/evals/20260907-hand-drawn-teach-marks.html`），并排对比方案：
- 方案 A：420ms 笔触生长后定格（克制优雅，信息不打扰）；
- 方案 B：1200ms 3 帧微抖动（Boil，活泼手绘感，持续吸引注意力）；
- 荧光笔高亮与引导箭头等延伸场景。

用户在体验后给出两项关键决断：
1. **动效做成用户可选项**：A 与 B 都很喜欢，做成设置偏好，默认为 A（生长定格），用户可随时切 B（持续微抖）；
2. **荧光笔不能挡字**：原版粗折线太暗太密会把小字遮住发污，必须保证字迹清晰锐利。

## 2. 核心设计与算法落地

遵循 0 外部依赖与极简原则，自研轻量几何与伪随机数生成器。

1. **轻量几何模块（`extension/src/shared/rough/`）**：
   - `mulberry32`：32 位快速确定性 PRNG，相同 seed 产出完全一致的路径；
   - `roughEllipse`：双层重叠偏置椭圆笔触，产生自然下笔起承转合；
   - `roughArrow`：二次贝塞尔引导曲线配合手绘展开箭头端点；
   - `chiselWash`：平头马克笔单次扁平横刷，替代密集来回折线；
   - `variants`：生成 3 帧独立微扰动路径供 Boil 动画切换。
2. **文字通透无遮挡（Mix-Blend-Mode）**：
   - 荧光笔改用 `mix-blend-mode: multiply`（正片叠底）；
   - 背景色采用高明度低饱和柠檬黄（`#fef08a`，alpha 0.55）；
   - 无论页面上的黑色正文、灰色次要文字还是代码，均 100% 锐利透出，永不被油墨遮蔽。
3. **滚动与 Resize 零闪烁**：
   - 确定性固定 seed 生成 SVG 路径；
   - 页面滚动与窗口缩放仅更新外层容器文档绝对坐标，严禁在 scroll 事件中重新调用 PRNG，实现 0 布局重排抖动。

## 3. 运行模式感知与面板交互

1. **模式自动区分**：
   - `teach` 教学模式打出的 `mark` 自动采用手绘风格（`style: "sketch"`）；
   - 普通 `act` 执行模式保持简洁的精确实线矩形框，兼顾效率与严谨。
2. **动效偏好无缝切换**：
   - 后台通过 `chrome.storage.local` 持久化 `markMotion`（`grow` | `boil`）；
   - 侧边栏的「教学模式」切换按钮支持右键直接快捷切换动效档位（持续微抖 vs 生长定格），并在悬浮提示中展示当前档位；
   - 遵循 `prefers-reduced-motion` 媒体查询，开启减弱动效时一律自动定格。
