# 让一句失败留在一句里

## 1. 真人试用推翻了什么

用户说要改成打开YouTube并检查邮箱。语音被识别，操作判断却失败，随后整个语音入口断开。

固定句集通过没有覆盖这次体验。继续重复原句集不能代替找原因。

## 2. 错误被放大了

一次意图判断失败走进了关闭连接的路径。程序主动停掉了语音连接和麦克风。

现在失败只结束当前一句。确定未执行时说明未执行；结果不明时查询原回执。下一句可以继续。

## 3. 让应用承担确定的事情

过去要求模型分配每个分句编号，漏一个语气词就整句失败。真实模型在另一个网站与天气请求上重复犯了相同错误。

现在模型判断动作及分界，应用保留完整原话。判断也能读到当前任务目标，理解用户是在纠正哪个要求。否定、未来条件和控制顺序仍然检查。

## 4. 页面不必等到所有资源都加载完

打开网页过去等整个页面加载完成。图片和其他资源可以拖住反馈。

现在按当前文档可交互状态返回。超时明确表示尚未确认就绪。独立Chrome测试中，图片一直加载，页面输入框已经可用，工具正常返回。同一个网址重新导航时，也没有接受旧文档。

## 5. 结果与下一步

本地754项测试通过，真实模型原句集48项与新增自然说法8项通过，独立Chrome检查4项通过。

这些结果没有证明公网响应已经足够快。一次自然说法仍因重试用了6.388秒。

新版尚未加载到用户扩展。下一步是让用户接入，判断连续交谈和真实任务是否改善。
