# 学 Claude 的理念，不照搬外观

## 方向

侧栏对齐 Claude 的明暗：底色从偏黄的 `#f5f2eb` 换成近中性的 `#faf9f5`，文字从 `#292821` 加深到 `#141413`。强调色不用 Claude 的陶土橙，改为墨蓝 `#2d4a86`，并且只给「AI 正在做或做过的事」用：页面圈画、名牌、边缘光和侧栏里的强调色同色。紫色光球和小伙伴 M 保留，M 可以在「更多」里关掉。

## 原因

- 用户觉得底色太黄，希望往 Claude 的风格和对比度上靠。
- Anthropic 自己的 frontend-design 指南把「暖奶油底 + 衬线 + 陶土橙」列为 AI 生成界面最常见的默认样子，并说明陶土橙是 Claude 的交互色；照搬会让产品像仿品。
- 改前页面层是亮蓝 `#2f6fed`、侧栏是棕色 `#79523b`，两边不像同一个产品；侧栏同时有棕、紫、黑、绿多种强调色，没有「只在一处大胆」。
- 效果图对比墨蓝与朱砂后选墨蓝：朱砂圈画在中文语境里容易读成「这里错了」。
