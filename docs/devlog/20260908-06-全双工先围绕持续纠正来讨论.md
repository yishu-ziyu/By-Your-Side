# 全双工先围绕持续纠正来讨论

## 1. 本次学习

读完 Google Cloud Tech 的实时语音 Agent 总览字幕。视频把听、看、想、说和操作放在同一段持续交流里。它特别指出：工具要等几秒时，对话体验也必须被照顾。

画面下载失败。本次没有判断演示的听感和延迟。

## 2. 对产品的初步判断

我们已有文字插话、页面接管和交还。全双工讨论可以从一条现有工作路径展开：Agent 正在操作时，用户用声音纠正它。

停止播报、改变任务条件、拿回页面，会导致不同结果。后续要先把这些行为说清楚。直接把语音转写接到当前消息入口还不够：接管状态下，当前普通消息会要求用户先交还。

这仍是建议。用户还没有裁定首个语音场景，也没有选择模型和界面。
