# 主 Agent 看见整个浏览器

## 1. 原因

用户让助手列出 B 站页面，助手却只能列出当前会话拥有的页面。

防止并行操作冲突的规则，限制了主 Agent 的查找和读取能力。用户明确要求：主 Agent 负责全局协调，子 Agent 受分工范围约束。

## 2. 改动

主 Agent 可以列出全部标签页，按页面编号读取其他会话的页面。读取不会改变归属。

操作被占用的页面时，复用已有移交流程和会话运行时索引。停止相关成员，等旧操作结束，再移交。无关 worker 继续工作。用户接管仍然优先。

没有增加新的消息协议，也没有合并会话内容。

## 3. 验证

只跑相关权限、读取、协调测试，以及类型检查和构建。没有跑全量测试。

真实 Chrome 的 10 项检查通过，包含全局查看、跨会话读取、移交、关闭和无关成员继续工作。扩展已重载，用户可以直接重试列出 B 站标签页。
