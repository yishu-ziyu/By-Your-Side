# 浏览器智能先从减少执行歧义开始

## 1. 对照什么

读了当前路线图、观察和输入链路，并对照 ego lite、Playwright、Stagehand 的固定源码快照。

路线图当前要求先稳定现有能力。伙伴、记忆、语音和主动性有先后条件，不能用增加功能跳过可靠性。

## 2. 发现什么

本项目截图会返回 0x0，回退可能拍到其他前台页。DOM 点击回退有两处点击触发。坐标算出后还要等视觉反馈，缺少临近输入时的同等级命中检查。

这些是源码事实或条件风险，本轮没有制造真实业务事故来验证。

成熟执行器给模型的帮助很具体：目标带身份，短暂障碍由驱动处理，实际输入有证据，模型选择的对象由代码转换为合法动作。

## 3. 方向如何调整

保留现有 Pi、控制权协议和可选组合执行。下一轮先修观察与单次点击的可信度，再验证定位与动作分段。

稳定之后，从用户明确示范和接管纠正开始学习。先证明换材料后还会做，再扩大记忆范围。

## 4. 数字与下一步

对照了三个外部项目。没有新增模型基准，没有修改产品代码或正式路线图。
