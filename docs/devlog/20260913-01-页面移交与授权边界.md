# 页面移交与授权边界

用户批准修复页面移交、经验匹配、授权闭环。保留既有扩展与本地运行时分工。

原反例表明，按成员工作指针拦截会漏掉旧页面；把成员整体冻结又会影响另一页。改为状态层按页面围栏，等在途操作后再移交。停止成员继续由原 release 路径处理。

授权不是一句聊天回复。运行时保存原请求，侧栏提交允许或拒绝，确认后仍复核执行版本。生产装配必须把独立 fetch 和组合程序接到同一个授权入口；“需要确认”的报错不算闭环。

自动提取经验和用户明确编辑的偏好使用不同相关性规则，避免共同动词把无关流程带进当前任务。采用保守词项规则，仍有同义表达与未识别动作的边界。
