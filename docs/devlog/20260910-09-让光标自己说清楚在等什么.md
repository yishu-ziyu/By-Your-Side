# 让光标自己说清楚在等什么

## 方向

第一轮光标只在"点、填、悬停、危险确认"这四种时刻出现，其余时间（等模型、读页面、任务收尾、在别的标签页干活）用户看不到任何状态。第二轮把状态挂到光标名牌上：等待、读页面、完成、失败，另加一个右上角的跨页胶囊。

## 原因

- 用户的问题不是"缺动画"，而是"不知道它在干什么"。加持续动画只会更吵。
- 状态得跟人现在看的那一页对齐：它在别的标签页干活时，当前页需要的是一条能点过去的线索，而不是一个假装在本页的光标。
- 完成与失败的寿命要求相反：完成要立刻收（不占屏幕），失败要留着（等处理）。

## 做法与结果

- 文案、颜色、计时、胶囊渲染全在页面侧（`extension/src/content/cursor.ts`）；background（`extension/src/background/cursor-status.ts`）只决定状态、挂到哪一页、什么时候撤。状态不是执行证据，画不上不影响任务判定。
- 状态优先级：拿住双键 > 动作名牌 > 状态 > 成员名，所以危险确认期间状态更新不会覆盖确认键。
- 用户接管或主动停止立刻收状态，并抑制到下一次 `agent_start`，避免收尾的 `agent_end` 补一个假的"完成"。
- 跨页胶囊只在等待/读页面阶段出现，点击走 `cross_page_click` → 切到工作页；完成/失败阶段不挂（"正在另一个标签页工作"此时不成立）。
- 按用户选择把状态字号缩到主文案 11px、名字 9.5px。

机器证据见[本轮验收](../evals/20260910-cursor-status.md)；真实网页上的可辨认度与跳转手感仍待人验收。
