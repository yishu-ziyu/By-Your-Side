# 跨会话记忆先看使用路径

## 1. 功能拓展优先

用户明确将效率优化放到后续。当前先让产品能记住明确交代的做法，并在相关的新会话里使用。Pi 保留。

## 2. 先判断入口

独立校验先写标准。原型用同一套合成材料比较两个入口：聊天中的回执与抽屉，以及独立管理视图。用户先判断保存、使用和管理是否清楚。

## 3. 模拟也要守住事实

校验发现旧回复会展示新版记忆，失败重试会恢复已忘记条目。这些已修正。任意输入没有接模型，原型明确告知覆盖范围，不生成看似通用的成功结果。

## 4. 当前交付

两套可点击方案，20 项浏览器事件路径检查，7 项独立脚本反例复核。真实点击主路径和窄屏、深色显示已检查。产品代码改动为 0。下一步由用户选择入口和范围，再进入实现。
