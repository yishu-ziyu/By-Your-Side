# 规模、窄侧栏、交付可见、接管关闸

方向：执行包 PR-03 到 PR-05 里还能机器做的部分。不连日常 Chrome。正式版仍不能打。

播放排队和打断从 `StepVoiceSession` 迁到 `VoicePlayback`。开口只停声音，没有取消任务的入口。TTS 生成仍在会话里。侧栏任务条加结果卡：摘要是主信息，没有摘要整张卡不出现。

回执 `list` 热路径改走内存，不再同步读五千个文件。B01：2 万条 + 200 会话，事件循环 p95=1.43ms。B02：满 2 小时固定 list，堆增量 -0.56MiB，RSS 收在约 24MB。没有活跃语音，没有强制 GC，只能说回执这一层没越用越胖。

窄侧栏 12 档（320/400/520 × 600/900 × 100%/200%）：输入、发送、接管、新会话在视口里，不横溢。2000 条历史上打字 p95=34ms。Enter 发送，Escape 关会话菜单。

交付和接管原先会自己把自己卡死。打开面板还在决定新会话时，正式回答被当成旧历史丢掉。Agent 没连上时，点接管会关闸再因为发送失败把闸门撤掉。改完后：这一次的回答仍显示；本地提交接管，写入停住。隔离真 SW + 真面板：交付可见 p95=18ms，接管关闸 p95=15ms。不含模型往返，伴随进程未装进那次隔离实例。

结果。PR-04/PR-05 机器项有分母。人眼层级、声学打断、陌生人试用仍缺。

边界。没把隔离无 host 写成「整天开语音也没漏」。没打正式标签。
