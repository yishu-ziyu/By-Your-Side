# Stagehand 接入先停在独立探针

用户要求当前登录页可填、可停、可纠正且不串页。现场确认 ego 已有 Pi 与连续程序执行，因此本轮价值是验证替换执行层是否值得。

官方 SDK 的有限浏览器检查通过，但官方 Pi 集成未转发用户取消，默认 launch 新浏览器，直挂又绕开 ego 的任务与授权控制。连接句柄 close 还可能关闭用户 Chrome。本轮保留现有生产路径，不扩大迁移，不做速度承诺。
