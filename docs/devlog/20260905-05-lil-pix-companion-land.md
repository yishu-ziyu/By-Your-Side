# Lil Pix 伴侣落地

日期：2026-09-05

## 1. 选的是哪一个

并排页里方案 A 是 Rauno 原版微像素终端，不是后来笔记里写的小煤球。用户说「就按你推荐的那个来，就是第一个」。

生产按这个形象落地：24–34px 像素小人，打字时倚靠输入框顶沿，发送后护航到气泡外沿。

## 2. 明确不做的两件事

悬浮像素手套拿掉了。上一轮用户问「这个是手吗还是边框」，它在视网膜上像一块碎框。摸头改成系统光标 `grab` / `grabbing`，身体直接下压。

闲时不晃。周边视野对运动敏感，无目的的 bob 会抢正文。

## 3. 怎么接到现有侧栏

单独模块 `companion.ts`，不往 `main.ts` 堆动画定时器。侧栏仍是原生 TS + DOM。

生命周期只有五件事：打字、发送、步骤开始、步骤结束、run 结束。历史回放那一批消息不触发巡游。

落点锁在卡片外沿。用户气泡靠右，小人站在它左边；步骤卡全宽，小人站在左上角圆角上，不压「执行步骤」。顶栏不够高时往下夹，避免钻进状态胶囊。

- 测试：40 个文件，371 项，含 5 项外沿几何。

- 机器截图：idle / lean / send / step 与气泡内文不相交。
