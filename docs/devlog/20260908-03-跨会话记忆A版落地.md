# 跨会话记忆 A 版落地

2026-09-08

## 1. 先完成用户能走通的路径

用户选择会话内抽屉。说“请记住”后看到保存结果；新建会话时，相关任务可以使用这条偏好。点击“记忆”可以查看、修改和忘记。

第一版只保存明确要求留下的内容。保留 Pi，不做自动学习，效率优化留待以后。

## 2. 原型完成判断就停

HTML 的作用是让用户看到改后的样子。用户选定后进入产品实现，不继续打磨比较页。

后续开发由主代理独立完成。沟通围绕用户如何操作、看到什么展开。

## 3. 实际使用暴露的问题

带数字的中文会议名曾匹配不到偏好。分词修正后，新会话能使用原来保存的格式；“整理”等通用词不再单独触发使用。

重新连接时两个伴随进程会争用会话索引临时文件，侧栏因此显示未连接。改为各自独立文件后，真实重连和记忆使用通过。

## 4. 当前结果

真实侧栏与 M3 主路径 8 项通过，加入重连后 9 项通过。原有会话操作回归 17 项通过。全量检查为 68 个文件、586 项测试，类型和构建通过；另补两项晚到结果检查。

尚未完整退出用户的 Chrome 做重启验收。不同 Chrome 配置当前也未分开保存记忆。这两项不能算通过。下一步补齐剩余隔离与组合场景，用户判断实际入口和提示是否清楚。
