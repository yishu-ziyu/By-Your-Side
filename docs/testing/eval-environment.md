# 评测中的站点不可用

[验收入口](acceptance.md) · [测量规则](../../eval/README.md)

环境分类只认浏览器证据，判定条件见 [`environment.mjs`](../../eval/harness/environment.mjs)。网页普通正文提到断网、限流或验证码等字样，模型自称断网、任务超时、HTTP 404 和操作失败均不应单独作为排除依据；不通过识别助手的解释来判断。

初始已不可用时不调用模型，保存实际页面截图和证据；结束时仅按最新页面判定，早先断连后已恢复不作排除。最终任务先按原成功规则判分；已完成的结果不因后续页面不可用而被排除，普通答案错误也不因同页有环境问题而排除。只有失败确由浏览器证据支持的不可用造成才单列。重定向或子资源报错不应借用原状态。旧记录未采集证据不推定环境失败。

机器不把环境项判为成功或产品失败。报表、复核页、看板单独显示数量并排除通过率分母。产品任务的平均 token、调用次数、耗时与成本也排除环境项，避免零调用受阻题稀释平均数。普通失败和无法确定仍计入分母。共同题比较只采用所有配置都有正常判分的题。

同一主机名的任务串行，其他主机可以并发；这是评测调度，不改变产品的网络行为，也不写全局设置。

验收命令：`npx tsx scripts/acceptance/eval-environment.mts`。结果见[验收](../evals/20261002-eval-environment.md)。
