# 评测中的站点不可用

[验收入口](acceptance.md) · [测量规则](../../eval/README.md)

环境分类只认浏览器证据：任务页导航返回的连接错误、Chrome错误页、主文档HTTP429、明确人机验证页及HN的短Sorry限流页。网页普通正文提到这些词、模型自称断网、任务超时、HTTP404和操作失败均不能单独作为排除依据。验证码页同时要求可见挑战文本、挑战标题和挑战控件；不通过识别助手的解释来判断。

每题记录初始和结束时任务页的URL、标题、限长正文、挑战控件标记及匹配当前URL的主文档HTTP状态。初始已不可用时不调用模型，保存实际页面截图和证据；结束时仅按最新页面核对，早先断连后已恢复不作排除。最终任务先按原成功规则判分；已完成的结果不因后续页面不可用而被排除，普通答案错误也不因同页有环境问题而排除。只有失败确由浏览器证据支持的不可用造成才单列。重定向或子资源报错不能借用原状态。旧记录只有已有最终页面证据符合条件才重分类；未采集证据不推定环境失败。

判分结果新增`environment`、`pass:null`及环境证据；机器不把它判为成功或产品失败。报表、复核页、看板单独显示数量并排除通过率分母。普通失败和无法确定仍计入分母，判分程序出错与启动失败沿用原边界。共同题比较只采用所有配置都有正常判分的题；任一配置站点不可用，该题不进入双方共同题分母，单配置统计仍保留自身记录。

同一主机名的任务串行，其他主机可以并发；这是评测调度，不改变产品的网络行为，也不写全局设置。

验证命令：`npx tsx scripts/acceptance/eval-environment.mts`。它用真实无头Chrome与扩展访问断连、429和验证码页面，核对截图与无模型调用；另用独立手算例子验证1项通过、1项失败、1项环境的通过率为1/2。结果见[验收](../evals/20261002-eval-environment.md)。
