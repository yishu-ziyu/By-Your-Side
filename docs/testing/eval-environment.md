# 评测中的站点不可用

[验收入口](acceptance.md) · [测量规则](../../eval/README.md)

评测把站点不可用的题单独列出。判定条件见 [`environment.mjs`](../../eval/harness/environment.mjs)。

## 怎样算不可用

- 只有浏览器证据能把一题判为站点不可用。不按助手的解释判断。
- 网页正文提到断网或验证码、模型自称断网、任务超时、HTTP 404、操作失败，单独出现时都不能作为排除依据。
- 结束时只按最新页面判定。早先断连、后来已恢复的，不排除。
- 旧记录没有采集证据的，不推定为站点不可用。

## 怎样计分

- 已完成的结果不因后续页面不可用而排除。普通答案错误不因同页有站点问题而排除。
- 站点不可用的题既不算成功，也不算产品失败，单独显示数量，并排除出通过率分母。
- 平均 token、调用次数、耗时与成本也排除这些题，因为零调用的受阻题会稀释平均数。
- 普通失败和无法确定的题仍计入分母。

同一主机名的任务串行，只是评测调度，不改变产品的网络行为。
