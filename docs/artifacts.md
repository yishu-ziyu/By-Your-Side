# 文件、下载与页面阅读

[文档导航](README.md) · [协议](protocol.md) · [使用说明](guides/usage.md)

本页是会话文件卡片、截图、回答小程序、文件下载、整页翻译与阅读外观的唯一说明。

## 文本文件与截图

助手为用户生成的文本文件存在当前会话里，另一个会话读不到：

- **只有交给用户的文件才有文件卡片**：助手自己做事用的中间文件（如待上传文件）存在同一文件区，但侧栏不显示卡片；目标核对也只把有卡片的文件算作已交付。
- **沙箱查看与持久化**：「打开」在新标签页的沙箱页里显示文件，碰不到扩展权限和存储。侧栏历史只存文件引用，扩展重启后文件仍可打开、下载和重读。
- **截图何时给用户**：截图默认只进模型上下文，侧栏只在执行过程里记一步「截图」。只有用户明确索要截图时，模型才标为交给用户并存进会话文件区。图片文件不能当文本读取或修改，只能删除。

## 回答里的小程序（实验功能）

- 开关在「设置 → 实验功能 → 回答里的小程序」，默认关闭。关闭时助手不写小程序，历史回答里的小程序只显示开启提示。
- 打开后，需要动手试算或筛选的问题由助手在回答里生成沙箱小程序（卡片或一句话能说清的仍用卡片或文字）。小程序写完才挂载，高度随内容自适应；运行报错或空白时显示原因与「让助手修好」按钮，用户点击后才发回给助手，不自动重发。
- **沙箱边界**：小程序运行在独立 CSP 沙箱（侧栏 `frame-src 'self' blob:`）内，不能联网、不能加载外部资源、不能跳转外链，也碰不到网页和扩展；只能通过 `bys.save` / `bys.state` 持久化自身状态，或提议一句话等用户点「放进输入框」。

## 文件下载

- **页面下载**：是否下载完成只看 Chrome 的下载状态，中断算失败。不用调试通道的 `Page.setDownloadBehavior`（扩展调试通道拒绝该浏览器级命令）。
- **点击期间开始的下载**：助手未预先订阅就点击下载入口时，点击的工具结果也会附上点击期间开始的同网站下载，避免助手和目标核对误以为没导出而重复点击。因 Chrome 下载无标签页归属，工具结果只说明下载「在这期间开始」。
- **按链接下载**：用于链接直接打开 PDF 阅读器等场景，沿用页面控制闸门；危险下载留给用户在 Chrome 里决定。下载登记在扩展后台内存里按编号索引，扩展后台重启后旧编号失效。

## 整页翻译

- **由近及远逐批落页**：用户先看到当前一屏的译文，再看到其余段落；只写入原文未变的段落，翻译期间被网页改动的段落留给下一批。
- **待翻流光占位**：尚未译出的段落末尾挂独立占位元素，不改网站自身样式。批次可恢复时不立刻撤占位，避免页面跳动；用户中止任务或长时间无翻译动作时，页面自动撤除占位。
- **失败、限流与时限**：一批最终失败后不再开新批，但在途批次照常写入并如实报告已完成与剩余段数。服务商报并发超限时降低并发退避重试（额度与账单错误不算限流）；输出写满上限时拆小批次重译。整页翻译不设固定总时限，只在长时间无新批次落页或用户中止时停止。
- **可掀开的仅译文模式**：译文覆盖在原节点上而不改写原文；按住译文掀开露出原文，松开复位，普通点击仍交给原链接。核验翻译是否生效必须检查译文层，不能检查原文是否变成中文。

## 阅读外观与划词工具条

- **字体字号**：侧栏「更多 → 字体字号」只改变助手回答的正文字体与字号，按钮、状态栏、输入框保留系统字体，代码保持等宽字体。
- **划词工具条**：选中网页文字默认弹出划词工具条，可在设置页关闭（已打开的网页立即生效）。关闭后仅停掉“选中即弹出”，按快捷键 `⌘J` / `Ctrl+J` 或右键菜单仍可打开阅读卡；已展开的阅读卡不因关掉开关而收起。
