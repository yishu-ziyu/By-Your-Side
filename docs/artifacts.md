# 文件卡片与截图

## 文本文件

助手用文件工具为用户写文本文件，命令沿用 Pi web-ui 的约定。文件存在当前会话里；另一个会话读不到这些文件。

- 侧栏把文件显示成带「打开」「下载」按钮的文件卡片。回合结束时，文件卡片挪到回答下面。
- 「打开」在新标签页显示文件。网页文件在沙箱页里运行，碰不到扩展的权限和存储（[查看页](../extension/src/sidepanel/artifact-viewer-page.ts)）。
- 侧栏历史只存文件引用，不存全文。所以扩展重启后，文件仍可打开、下载，模型也能再读。
- 组合执行和页面脚本存的文件写进同一个文件区；文件正文不进模型上下文（[细节](browser-program.md#存文件)）。

## 截图：哪些给用户看

截图默认只给模型自己看，侧栏只在执行过程里记一步「截图」。组合执行里的截图同样不给用户。

只有用户要的就是这张图时（如「把这页截个图给我」），模型才把截图标为给用户，任务宿主再把这张 PNG 存进同一个文件区。

- 侧栏显示缩略图、文件名和操作按钮；用户可展开预览、打开原图、下载原始 PNG。
- 会话没有文件区时，工具结果明确写「没给到用户」。
- 图片文件不能当文本读取或修改，只能删除。
