# 文件、下载与页面阅读

[文档导航](README.md) · [使用说明](guides/usage.md)

## 文本文件与截图

- **只有交给用户的文件才有文件卡片**：助手自己做事用的中间文件（如待上传文件）存在同一文件区，但侧栏不显示卡片；目标核对也只把有卡片的文件算作已交付。
- **截图何时给用户**：截图默认只进模型上下文，侧栏只在执行过程里记一步「截图」。只有用户明确索要截图时，模型才标为交给用户并存进会话文件区。图片文件不能当文本读取或修改，只能删除。

## 回答里的小程序（实验功能）

- 默认关闭。

## 文件下载

- **点击期间开始的下载**：助手未预先订阅就点击下载入口时，点击的工具结果也会附上点击期间开始的同网站下载，避免助手和目标核对误以为没导出而重复点击。因 Chrome 下载无标签页归属，工具结果只说明下载「在这期间开始」。

## 整页翻译

- **失败、限流与时限**：一批最终失败后不再开新批，但在途批次照常写入并如实报告已完成与剩余段数。服务商报并发超限时降低并发退避重试（额度与账单错误不算限流）；输出写满上限时拆小批次重译。整页翻译不设固定总时限，只在长时间无新批次落页或用户中止时停止。
