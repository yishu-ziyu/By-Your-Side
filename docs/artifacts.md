# 文件卡片与截图

## 文本文件

助手为用户写的文本文件存在当前会话里；另一个会话读不到这些文件。

- 只有交给用户的文件才有文件卡片：助手存文件时标明这是用户要的文件。
- 助手自己做事用的中间文件（比如要上传到网页的文件）照样存在文件区，但侧栏不显示。因为用户没要文件时，侧栏曾出现一张中间文件的卡片。
  代价：助手忘了标，用户要的文件就没有卡片。目标核对也只看有卡片的文件，所以这个文件不会被当成已交付。
- 「打开」在新标签页显示文件。网页文件在沙箱页里运行，碰不到扩展的权限和存储。
- 侧栏历史只存文件引用，不存全文。所以扩展重启后，文件仍可打开、下载，模型也能再读。
- 组合执行存的文件写进同一个文件区（见[组合执行](browser-program.md#存文件的坑)）。

## 截图：哪些给用户看

截图默认只给模型自己看，侧栏只在执行过程里记一步「截图」。

只有用户要的就是这张图时（如「把这页截个图给我」），模型才把截图标为给用户，任务宿主再把这张图存进同一个文件区。会话没有文件区时，工具结果明确写「没给到用户」。

图片文件不能当文本读取或修改，只能删除。
