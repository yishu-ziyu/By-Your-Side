# 术语表

[文档导航](README.md) · [文档维护](development/documentation.md#写法)

本表是用词的权威位置。当前说明按本表用词：一个词只表示一件事，一件事只用一个词。

- 表中没有的新概念，先补本表，再写正文。
- “意思”一栏用普通话解释，不用代码名下定义。代码里的名字以代码为准。
- 历史记录不按本表改写。

## 界面与运行位置

| 词 | 意思 | 不用 |
|---|---|---|
| 扩展 | 本产品的 Chrome 扩展 | 插件、浏览器扩展 |
| 侧栏 | Chrome 侧边栏里的产品界面 | 面板、侧边栏（指本产品时） |
| 设置页 | 扩展的设置页面 | 选项页 |
| 边缘药丸 | 侧栏关闭、任务在做、暂停等你或出错时，用户正在看的标签页右边缘中间的小入口；平时是一道细光，鼠标停上去展开成小卡 | 胶囊、边缘小标、小标（指它时） |
| 胶囊 | 界面上的圆角小块。只带限定词使用：语音胶囊、听写胶囊、材料胶囊、数字胶囊，见[使用说明](guides/usage.md) | 不带限定词单说“胶囊” |
| 光球 | 语音开着时显示的动画球，样式在设置页选 | — |
| 任务卡 | 消息流里可折叠的卡片，列出多步任务的目标、网站、各项进度和材料 | — |
| 任务条 | 任务运行时，输入框正上方写当前状态和动作的一行 | — |
| 执行过程 | 回答上方可展开的逐步动作记录 | 运行块 |
| 动作卡 | 执行过程里写一步动作的一行卡片 | — |
| 阅读卡 | 在页面上打开的问答卡；按 `⌘J`、右键菜单或划词工具条打开 | — |
| 划词工具条 | 选中页面文字后，选区旁弹出的小工具条 | — |
| 引用条 | 输入框上方显示所引文字的一条 | — |
| 材料 | 送进任务、供模型参考的文字、截图或页面；材料不是已核实的来源 | 证据（指它时） |
| 文件卡片 | 侧栏里可打开、可下载的文件卡 | 文件卡、下载卡 |
| 扩展后台 | 扩展的后台服务进程（Chrome 的 service worker） | 单说“后台”、SW |
| 任务宿主 | 扩展的隐藏文档（Chrome 的 offscreen 文档）里运行的任务核心 | 单说“宿主”（指别的东西时） |
| 本机 | 用户的电脑 | 本地（指电脑时） |

“后台”不单用。写成“扩展后台”“后台判断”或“后台任务”之一。

## 会话与任务

| 词 | 意思 | 不用 |
|---|---|---|
| 会话 | 侧栏里的一条对话线，有自己的消息、目标、草稿和附件 | 对话、聊天（指这件事时） |
| 执行成员 | 会话里执行任务的成员。现在每个会话只有一个执行成员，名为 Lead | 会话（指执行成员时）、并行助手 |
| 任务 | 用户交给助手的一件事，从开始到交付 | 作业、工作（指这件事时） |
| 插话 | 任务运行时，用户再说一句来改变当前任务 | 打断 |
| 补充 | 给已有要求加条件的一句话；送进运行中的任务时，按插话处理 | 追加 |
| 中止 | 结束当前任务；侧栏按钮也叫“中止” | 停止、终止、取消（指这件事时） |
| 停声 | 只停播放的声音，不中止任务 | 停止播报 |
| 纠正 | 用户指出助手做错，并给出正确做法 | 纠错 |
| 交付 | 把最终回答或部分结果正式交给用户 | 用“交付”指开发任务收尾 |
| 收尾 | 开发流程里，验证之后、交给用户之前的最后一步 | 交付（指开发流程时） |

用户原话里的“终止任务”“别说了”照原样引用，不改成本表用词。

## 页面与控制

| 词 | 意思 | 不用 |
|---|---|---|
| 页面 | 标签页里加载的文档和内容 | 这页、网页（泛指时） |
| 标签页 | Chrome 的一个标签 | 单说“标签”、tab（正文） |
| 网站 | 一个域名下的站点 | 站点 |
| 网页操作 | 助手在页面上点击、填写、导航 | 页面操作、浏览器操作 |
| 读页 | 助手读取当前页面的可见文字 | 读取页面、读页面 |
| 划词 | 选中页面文字后追问或翻译的动作 | 划选 |
| 整页翻译 | 把整个页面翻成译文或双语 | 页面翻译、全文翻译、网页翻译 |
| 页面控制 | 页面现在归助手还是归用户 | 控制权、单说“控制” |
| 接管 | 用户从助手手里拿回页面控制（侧栏按钮叫「我来」） | 移交 |
| 交还 | 用户把页面控制还给助手（按钮叫「你继续」） | 移交、归还 |
| 接手 | 一个会话把另一个会话正在用的工作标签页拿过来；原会话先停下 | 移交、转交；也不用它指换模型 |
| 任务控制 | 对任务的暂停、继续、中止 | 单说“控制” |
| 控制闸门 | 执行层里拦截写操作的程序检查 | 控制门、权限门 |

## 模型与结果

| 词 | 意思 | 不用 |
|---|---|---|
| 助手 | 面向用户的 AI 角色 | AI 助手、Agent（指产品角色时） |
| Agent | 只作代码名，例如 `agent/` 包、Pi Agent | 用作“助手”的同义词 |
| Pi | 任务运行时所用的开源 Agent 框架，不是模型 | — |
| 主模型 | 设置里选的主任务模型 | 当前模型 |
| 快速模型 | 设置里的第二个模型。快速模型做后台判断；主模型出错时，快速模型代替主模型回答 | 备用模型、小模型 |
| 后台判断 | 用快速模型回答一个窄问题 | 侧判断、旁路判断 |
| 模型请求 | 一次模型调用 | 单说“请求”（指模型调用时） |
| 设置 | 用户在设置页或侧栏菜单里改的选项 | 配置（指用户选项时） |
| 配置 | 接入模型、语音和凭据所需的参数 | 设置（指接入参数时） |
| 工具结果 | 一次工具调用返回给模型的内容 | 执行结果（指返回内容时） |
| 回执 | 程序对请求、控制或动作的确认 | 把模型的回答叫回执 |
| 结果未知 | 写入后无法确认是否生效；程序不自动重做 | 结果不确定 |
| 核验 | 程序读取页面状态，检查动作是否生效 | 校验、核对（指这件事时） |
| 目标核对 | 交付后，用快速模型检查用户要的结果是否达成 | 目标检查、结果核对、单说“核对” |
| 账本 | 程序登记执行事实的记录 | 台账 |
| 诊断记录 | 本机保存、可从设置页导出的任务诊断数据 | 诊断日志、轨迹、trace（正文） |

## 记忆

| 词 | 意思 | 不用 |
|---|---|---|
| 记忆 | 助手跨任务记住的内容 | 偏好（泛指时） |
| 过往任务 | 动手做过事的任务结束时，记忆里留下的一条摘要 | 历史任务、旧任务 |
| 做法 | 从用户纠正里归纳、经用户确认后照做的规则；记忆面板里这一组叫「做事的方法」 | 经验（指记忆条目时） |

## 开发流程

| 词 | 意思 | 不用 |
|---|---|---|
| 主代理 | 开发流程里负责判断和验收的编程代理 | 本 agent、当前代理 |
| 代理工具 | 开发用的编程代理，例如 Claude Code、Codex | 宿主（指这件事时） |
| 检查命令 | 仓库里的一组机器检查，见[开发检查](development/checks.md) | 校验 |
| 构建 | 把源码打包成可加载的扩展 | 编译 |
| 验收 | 按事先写的标准检查并留下证据；记录放在 `docs/evals/` | 验证（指这件事时） |
| 评测 | 用题集测模型或产品的质量 | 评估、测评 |
| 复核 | 人对文档或结果的再次检查 | 核验（指人工检查时） |
| 经验 | `docs/knowledge/` 里经过核对的开发经验条目 | 教训、pattern（正文） |
| 提案 | 待用户裁决的经验或规则修改 | 建议（作名词时） |
| 验收输出 | 检查和验收写到 `out/` 的文件 | 产物（指测试输出时） |
