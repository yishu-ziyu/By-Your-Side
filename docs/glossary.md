# 术语表

[文档导航](README.md) · [文档维护](development/documentation.md#写法)

当前说明按本表用词。一个词只表示一件事；一件事只用一个词。表中没有的新概念，先补本表，再写正文。历史记录不按本表改写。

## 界面与运行位置

| 词 | 意思 | 不用 |
|---|---|---|
| 扩展 | 本产品的 Chrome 扩展 | 插件、浏览器扩展 |
| 侧栏 | Chrome 侧边栏里的产品界面 | 面板、侧边栏（指本产品时） |
| 设置页 | 扩展的设置页面 | 选项页 |
| 胶囊 | 侧栏关闭时，操作页面边上的小入口 | 边缘小标、小标 |
| 语音胶囊、数字胶囊等 | 带限定词的“胶囊”指界面上别的圆角小块，见[使用说明](guides/usage.md) | 单说“胶囊”指它们 |
| 文件卡片 | 侧栏里可打开、可下载的文件卡 | 文件卡、下载卡 |
| 扩展后台 | 扩展的 background service worker | 单说“后台”、SW |
| 任务宿主 | offscreen 文档里运行的任务核心 | 单说“宿主”（指别的东西时） |
| 本机 | 用户的电脑 | 本地（指电脑时） |

“后台”不单用。写成“扩展后台”“后台判断”或“后台任务”之一。

## 会话与任务

| 词 | 意思 | 不用 |
|---|---|---|
| 会话 | 一个用户会话，对应 `conversationId` | 对话、聊天（指这件事时） |
| 执行成员 | 会话里的执行者，对应 `sessionId`；现在只有 Lead | 会话（指 `sessionId` 时）、并行助手 |
| 任务 | 用户交给助手的一件事，从开始到交付 | 作业、工作（指这件事时） |
| 插话 | 任务运行时，用户再说一句来改变当前任务，协议是 `steer` | 打断 |
| 补充 | 语音输入的一类：给已有要求加条件；送进运行中的任务时走插话 | 追加 |
| 中止 | 结束当前任务，协议是 `abort`；侧栏按钮也叫“中止” | 停止、终止、取消（指这件事时） |
| 停声 | 只停播放的声音，不中止任务 | 停止播报 |
| 纠正 | 用户指出助手做错，并给出正确做法 | 纠错 |
| 交付 | 把最终回答或部分结果正式交给用户 | 用“交付”指开发任务收尾 |
| 收尾 | 开发流程里，验证后、交给用户前的最后一步 | 交付（指开发流程时） |

## 页面与控制

| 词 | 意思 | 不用 |
|---|---|---|
| 页面 | 标签页里加载的文档和内容 | 这页、网页（泛指时） |
| 标签页 | Chrome 的标签，对应 `tabId` | 单说“标签”、tab（正文） |
| 网站 | 一个域名下的站点 | 站点 |
| 网页操作 | 助手在页面上点击、填写、导航 | 页面操作、浏览器操作 |
| 读页 | 用 `read_page` 读当前页面的可见文字 | 读取页面、读页面 |
| 划词 | 选中页面文字后追问或翻译的动作 | 划选 |
| 整页翻译 | 把整个页面翻成译文或双语 | 页面翻译、全文翻译、网页翻译 |
| 页面控制 | 页面现在归助手还是归用户 | 控制权、单说“控制” |
| 接管 | 用户从助手手里拿回页面控制，协议是 `takeover` | 移交 |
| 交还 | 用户把页面控制还给助手，协议是 `handback` | 移交、归还 |
| 接手 | 一个会话把另一个会话的工作标签页拿过来，协议是 `take_tab` | 移交、转交 |
| 任务控制 | 对任务的暂停、继续、中止 | 单说“控制” |
| 控制闸门 | 执行层拦截写操作的闸门 | 控制门、权限门 |

## 模型与结果

| 词 | 意思 | 不用 |
|---|---|---|
| 助手 | 面向用户的 AI 角色 | AI 助手、Agent（指产品角色时） |
| Agent | 只作代码名，例如 `agent/` 包、Pi Agent | 用作“助手”的同义词 |
| Pi | 任务运行时 `pi-agent-core`，不是模型 | — |
| 主模型 | 设置里选的主任务模型 | 当前模型 |
| 快速模型 | 设置里的第二个模型；做后台判断，主模型出错时接手 | 备用模型、小模型 |
| 后台判断 | 用快速模型回答一个窄问题 | 侧判断、旁路判断 |
| 模型请求 | 一次模型调用 | 单说“请求”（指模型调用时） |
| 设置 | 用户在设置页或侧栏菜单里改的选项 | 配置（指用户选项时） |
| 配置 | 接入模型、语音和凭据所需的参数 | 设置（指接入参数时） |
| 工具结果 | 一次工具调用的返回，对应 `tool_result` | 执行结果（指返回内容时） |
| 回执 | 程序对请求、控制或动作的确认 | 把模型的回答叫回执 |
| 结果未知 | 写入后无法确认是否生效；不自动重做 | 结果不确定 |
| 核验 | 程序读取页面状态，检查动作是否生效 | 校验、核对（指这件事时） |
| 目标核对 | 交付后，用快速模型检查用户要的结果是否达成 | 目标检查、结果核对、单说“核对” |
| 账本 | 程序登记执行事实的记录 | 台账 |
| 诊断记录 | 本机保存、可从设置页导出的任务诊断数据 | 诊断日志、轨迹、trace（正文） |

## 记忆

| 词 | 意思 | 不用 |
|---|---|---|
| 记忆 | 助手跨任务记住的内容 | 偏好（泛指时） |
| 过往任务 | 记忆里的 past 类 | 历史任务、旧任务 |
| 做法 | 记忆里的 method 类 | 经验（指记忆条目时） |

## 开发流程

| 词 | 意思 | 不用 |
|---|---|---|
| 主代理 | 开发流程里负责判断和验收的编程代理 | 本 agent、当前代理 |
| 检查命令 | `npm run check*` 这组机器检查 | 校验 |
| 代理工具 | 开发用的编程代理，例如 Claude Code、Codex | 宿主（指这件事时） |
| 提案 | 待审的经验或规则修改，放在 `docs/knowledge/proposals/` | 建议（作名词时） |
| 构建 | `npm run build` 打包扩展 | 编译 |
| 验收 | 按事先写的标准检查并留证，对应 `docs/evals/` 和 `accept:*` | 验证（指这件事时） |
| 评测 | 用题集测模型或产品质量，脚本在 `eval/harness/` | 评估、测评 |
| 复核 | 人对文档或结果的再次检查 | 核验（指人工检查时） |
| 经验 | `docs/knowledge/` 里的开发经验条目 | 教训、pattern（正文） |
| 验收输出 | 检查和验收写到 `out/` 的文件 | 产物（指测试输出时） |
