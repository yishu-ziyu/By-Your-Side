## 现在能用什么、还差什么

| 能力 | 现在 | 还差 |
|---|---|---|
| 侧栏对话与卡片 | 回答逐字淡入，流式重绘保留首尾记忆引用与操作区；卡片的结论／依据选中背景连续滑动，过程记录只在还有隐藏内容的边缘渐隐；输入 `@` 带上其他标签页；比价、选择、步骤、清单画成卡片，卡片数值可在侧栏即时重算并跨重开保留，比价行点击切回原标签页并圈出对应数字；需要向用户追问多项时渲染小表单一键发回；问网页结构时画结构图、点方块看原文；回答写完可拖短成要点或一句；长会话顶部章节条支持鼠标拖动；进行中打另一件事会另开并带回回答；实验功能「回答里的小程序」默认关（见[文件、下载与页面阅读](artifacts.md#回答里的小程序实验功能)） | 部分刚刚进日常的卡片交互与结构图尚待真人日常试用 |
| 读页与阅读卡 | 大页面与屏幕上的 PDF（含文字、目录页码与 `#page=N` 翻页）能直接读出；表单包裹正文的页面（如对话网站）自动回退提取完整正文；划词解释写到一半可改口 | 阅读卡不查证、不用记忆；PDF 偶发未翻页就列作者或主要引用找不准 |
| 网页操作 | 点击、填写、回车直接执行（见[网页操作](web-actions.md)）；新开页与跳转直接带回内容，结果页留在后台并提供「切过去看」；同网站第二次自动带上成功用法笔记；富文本编辑器支持子块定向修改与 `ClipboardEvent('paste')` 粘贴回退，掩码输入框同值重填不再重复触发重试；跨页原样搬文字不经模型重打；发送前在网页与侧栏双重确认（覆盖点击、多行回车与脚本提交），拒绝后保留草稿并提供重试入口；付款按钮永远由用户自己点；填写结果按字段列出并支持一键还原未改动的标准控件 | 画板（Canvas）无 DOM/无障碍节点，感知与核验受限；跨域 iframe 内单栏圈选与脚本异步发送仍有边界；真实网站批准后实际发送待真人验 |
| 跑完后的核对与持久化 | 回答先显示，过程行写「核对中…」后更新为「已核对页面」或「有 N 步没做成」；常规核对只调 1 次模型，多目标补读并行执行，续做上限收敛为 3 轮，同一证据不重复续做（见[目标核对](goal-check.md)）；核心循环基于 `pi-durable` + OPFS Worker 原地追加，扩展重载或浏览器重启后从存储接着做，已执行的提交不重做 | 语音念结果不等核对；回答中文名字未读到原文的核对尚未覆盖 |
| 圈画与教学 | 能把每一处词单独圈出；教学一次一步指给用户看，等用户自己点 | 被标签断开的词圈不到；圈过后刷新再点旧名称仍会发操作指令；真人未试教学 |
| 记忆与浏览习惯 | 个人资料原话直记可撤销；明确的网站操作纠正自动记、可删除；默认从用户自己的浏览记录里发现连续 2 天重复的操作并询问是否记为做法（见[记忆模型](memory-model.md)）；教过「说 X 就开这些网址」后说 X 约 0.3 秒并行开好 | 真人长期试用待验；删除规则不清除对话、过往任务或站点笔记 |
| 整页翻译 | 一屏先译出第一段，再由近及远译完整屏；仅译文模式直接原地替换原节点文字并保留网页原有样式 | 离 2 秒首屏目标还差；翻译中途插话改网页会导致译文写不进 |

| 语音 | 插话即停声；按住右 `⌥` 说话，松开先应一句短确认，做完在胶囊上方显示精简卡片；GPT-Live 切页同步窗口标题与站点、带最近话题指代、长回答只读开头、后台忙时换连接不挂断通话（见[语音架构](voice-architecture.md)） | 阶跃实时语音傍晚常挂住；MiniMax 意图判断约一成调用 15 秒内不回；连续改口与外放回声未完整验收 |

## 速度与启动表现

| 情况 | 当前实测 | 目标 |
|---|---|---|
| 点进输入框预热后，按下回车到发出首个模型请求前的页面采集（`pre_observation`） | 约 24 ms（未预热日常中位 370 ms） | 越低越好 |
| 问当前网页一个简单问题，到第一个字 | `gpt-6-luna` 命中会话前缀缓存后中位 2.6 秒，超 4 秒占 6/50 | 3 秒 |
| 做一个单步网页动作，到做完 | 单次键盘填表含读回中位 115 ms；端到端受模型单轮耗时影响 | 10 秒 |

- 给模型的网页内容里带元素清单会让阶跃答错。

## 能用的模型

日常主模型 `MiniMax-M3.1-Flash-Preview`，快速模型 `openai-codex/gpt-6-luna`。设置页「模型」可点「测一下」。

- 不再用：OpenCode Go（订阅到期）、小米 MiMo 自家套餐、DeepSeek（密钥失效）、智谱 GLM（余额用完）。
- Kimi 编程套餐同一时间只收 1 个请求，扩展已排队；评测用的 Kimi 登录每次有效约 15 分钟，由 `npm run kimi:keep` 后台续期。

## 仍需解决

- 去掉批准卡后，网页里的恶意内容可能让助手在已登录的网站上动手（见[网页操作不再逐次确认](web-actions.md#网页操作不再逐次确认)）。近期仅自用，分发给他人前必须先做防护。
- 页面脚本仍能读到卡号、密码这类敏感栏的值。
