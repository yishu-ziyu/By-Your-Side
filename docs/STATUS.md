## 当前工作

已修复语音问候重复回应与文字先到时丢音：正式答案只播一次，闲聊不自动读页，空白候选不会吞掉等待中的答案。已重载日常扩展，合成问候经真实 native host 验证一次回答、有音频、无读页/任务确认/页面介绍；1,662 单测、类型与依赖检查通过。真人麦克风待用户验收，监控继续暂停。延迟及测试中出现的服务/工具失败见[修复验收](evals/20260913-voice-greeting-fix.md)。

已量清语音首声等待：说一句话到听见第一声实测 4.9–7.7 秒，其中**两段串行的模型往返占 5.2 秒**（意图分类 1.7–2.7s、主 Agent 首字 2.5s）。三条本地优化路径都用真实调用验过并被数据否决：分类耗时≈供应商下限（削提示词、加 reasoning 都无效）、池内更快的模型不是更慢就是判断出错、TTS 提前建连只值 270ms。唯一还能显著缩短的是让分类与回答并行（预期 -2 秒），但那会动刚确认的回答归属规则，未擅自改。见[首声验收](evals/20260913-voice-first-audio-latency.md)。

用户已认可宋体、回答层次及设置方案。已实现阅读外观并重载本地扩展，原生验证保存、重开、恢复默认及实际长短回答。普通单测通过，规模检查复跑仍超时，原因未定位；不宣称全套检查通过。见[阅读外观验收](evals/20260913-reading-settings.md)及[使用说明](reading-appearance.md)。

仓库可维护性整理已完成并重载验证：模型选择器、无工具语音模型调用独立成模块；Node授权账本归回Agent；生产依赖方向加入自动检查。统一check通过（1598普通+2规模）；最后绝对路径反例补充后13项边界与类型检查通过。模型菜单和正常消息原生通过。检查与原生验证见[本轮验收](evals/20260913-repository-maintainability.md)。开发入口见[架构与维护](architecture.md)。
