## 现在能用什么、还差什么

| 能力 | 现在 | 还差 |
|---|---|---|
| 侧栏对话与卡片 | 回答逐字淡入，流式重绘保留首尾记忆引用与操作区；卡片的结论／依据选中背景连续滑动，过程记录只在还有隐藏内容的边缘渐隐；输入 `@` 带上其他标签页；比价、选择、步骤、清单画成卡片，卡片数值可在侧栏即时重算并跨重开保留，比价行点击切回原标签页并圈出对应数字；需要向用户追问多项时渲染小表单一键发回；问网页结构时画结构图、点方块看原文；回答写完可拖短成要点或一句；长会话顶部章节条支持鼠标拖动；进行中打另一件事会另开并带回回答；实验功能「回答里的小程序」默认关（见[文件、下载与页面阅读](artifacts.md#回答里的小程序实验功能)） | 部分刚刚进日常的卡片交互与结构图尚待真人日常试用 |
| 读页与阅读卡 | 大页面与屏幕上的 PDF（含文字、目录页码与 `#page=N` 翻页）能直接读出；表单包裹正文的页面（如对话网站）自动回退提取完整正文；划词解释写到一半可改口；阅读卡可拖、可缩放，尺寸记住 | 阅读卡不查证、不用记忆；PDF 偶发未翻页就列作者或主要引用找不准 |
| 网页操作 | 点击、填写、回车直接执行（见[网页操作](web-actions.md)）；新开页与跳转直接带回内容，结果页留在后台并提供「切过去看」；自动站点笔记已暂停，旧记录可管理；富文本编辑器支持子块定向修改与 `ClipboardEvent('paste')` 粘贴回退，掩码输入框同值重填不再重复触发重试；跨页原样搬文字不经模型重打，可只搬指定的句或段；发送前在网页与侧栏双重确认（覆盖点击和多行回车；页面脚本只读），拒绝后保留草稿并提供重试入口；付款按钮永远由用户自己点；填写结果按字段列出并支持一键还原未改动的标准控件 | 画板（Canvas）无 DOM/无障碍节点，感知与核验受限；跨域 iframe 圈选、无发送语义的控件仍有边界；真实网站批准后实际发送待真人验 |
| 跑完后的核对与持久化 | 回答先显示，过程行写「核对中…」后更新为「已核对页面」或「有 N 步没做成」；常规核对只调 1 次模型，多目标补读并行执行，续做上限收敛为 3 轮，同一证据不重复续做（见[目标核对](goal-check.md)）；核心循环基于 `pi-durable` + OPFS Worker 原地追加，宿主重启后等用户手动继续，重新读原页后做剩余步骤 | 语音念结果不等核对；回答中文名字未读到原文的核对尚未覆盖 |
| 圈画与教学 | 能把每一处词单独圈出，被标签拆开的词也圈得到；教学一次一步指给用户看，等用户自己点 | 圈过后刷新再点旧名称仍会发操作指令；真人未试教学 |
| 记忆与浏览习惯 | 个人资料原话直记可撤销；明确的网站操作纠正自动记、可删除；默认从用户自己的浏览记录里发现连续 2 天重复的操作并询问是否记为做法（见[记忆模型](memory-model.md)）；教过「说 X 就开这些网址」后说 X 约 0.3 秒并行开好 | 真人长期试用待验；删除规则不清除对话、过往任务或站点笔记 |

| 下载 | 点击引起的同网站下载会写进工具结果，不再重复导出 | 助手读不到已下载文件的内容，需产品决定 |
| 模型与备用切换 | 模型菜单用离散滑块选档位并显示自动升档后的实际档位；设了备用模型时主模型首次出错换它接着做（日常还没设）；同一批 11 个真实网站任务上 `gpt-6-luna`、`MiniMax`、`Kimi` 均 11/11 通过 | 30 条日常错误分析中排第一的是模型服务卡住未触发备用切换（4 条中 2 条）；跨页搬运时 `gpt-6-luna` 仍偶发重打 |
| 语音 | 读文章时按住右 ⌥ 问选中的段落，光标停在这段末尾听，回答在同一处的阅读卡里边写边念，念到一半可改口，换段问时同一张卡里各轮保留各自的出处；语音发起的任务等核对完再念；语音模型没交给助手的话由宿主再判一次；长任务念过程；「记下来」写 flomo 和记忆；去别的网站查时原文留着；插话即停声；按住右 `⌥` 说话，松开先应一句短确认，做完在胶囊上方显示精简卡片；GPT-Live 切页同步窗口标题与站点、带最近话题指代、长回答只读开头、后台忙时换连接不挂断通话（见[语音架构](voice-architecture.md)） | 阅读卡语音：验收里松开到第一个回答字中位约 1.8 秒（分流和回答同时开始），念声首音偶尔 5 秒，真麦克风、扬声器外放下的停声未在日常验；语音层没交给助手时宿主约 1.7 秒判完接手（先等 0.5 秒、判意图约 1.2 秒）；按住说话：松开约 0.55 秒交给助手、约 1 秒念确认句；「去别的网站查」常只去英文维基；阶跃边生成边念的部分不等核对；阶跃实时语音傍晚常挂住；MiniMax 意图判断约一成调用 15 秒内不回；连续改口与外放回声未完整验收 |
