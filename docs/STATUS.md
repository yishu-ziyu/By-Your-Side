产品是 Chrome 扩展形态的开发预览版，用户目前只自用。日常 Chrome 已加载 10-16 合并版 `831233e7`：明确的网站操作纠正会自动保存，下次在同网站沿用；一次性要求不推广成长期规则。侧栏显示规则、范围、编辑和删除入口，重开时按当前保存状态显示。删除、停止、接管、新任务和另一窗口的修改都能挡住迟到学习；连续相反纠正只保留后一条生效。

新版本在隔离真实扩展中通过保存、实际导出、删除、重开与跨窗口检查；有窗口 Chrome + gpt-6-luna 在真实维基百科验证了教过后新会话只填搜索框不提交。另用两个无历史的隔离配置做一次配对：无规则时提交搜索，仅有规则时不提交。日常 Chrome（MiniMax）已验证实际填写搜索框和恢复原值。日常检查首次因侧栏连接断开中止，改用既有窗口中的独立测试页后通过，未隐藏首次失败；未跑全量测试。证据及上一版备份在主目录 `out/release-20261016-site-rules/`，备份为 `daily-before/`。保存和删除规则的测试只用隔离数据，未修改真实用户的长期规则。

上一项填写结果与恢复入口继续保留：实际字段计数、同名字段所在区域、实际恢复数量、用户后改未动和不能恢复部分。网站已保存内容、任意脚本修改和编辑器正文不承诺通用恢复；此前 QA 填错栏 2/6 的归因仍待单独配对调查，不算已修复。

原有页面圈选和发送前确认继续保留：回答里提到的控件可在页面上指出；发送确认覆盖点击、回车和脚本提交，用户拒绝后本轮不再发送。

## 现在能用什么、还差什么

| 能力 | 现在 | 还差 |
|---|---|---|
| 侧栏对话 | 回答逐字淡入；输入 @ 带上别的标签页；比价、选择、步骤、清单画成卡片，数由侧栏算，按钮能接着说或切页；回答先显示，目标核对在后面运行；核对判没做完时屏幕上仍只有一份回答；写完后能拖短成要点或一句，不再问模型 | 非填写任务中的任务栏、团队卡是否仍重复，待继续核查 |
| 读页与阅读卡 | 大页面能读完；划词解释，写到一半可以改口 | 阅读卡不能查证、不用记忆 |
| 网页操作 | 点击、填写、回车直接执行；新开页、跳转后直接带回页面内容，结果页留在后台，回答下给「切过去看」（见[真实网站对比](evals/20261013-real-sites-vs-ego.md)）；同一网站第二次带上上次做成的做法（[站点笔记](evals/20261013-site-notes.md)）；发送先问用户，付款由用户自己点；填写结果按字段身份列出，恢复入口在同一张过程卡；只恢复仍有效的记录，用户后来改过的值不动 | iframe 边界仍需核查；真实网站脚本发送路径未验收 |
| 跑完后的核对 | 回答先显示，过程行写「核对中…」，出结论后改成「已核对页面」或「有 N 步没做成」，判做完时不再出「继续原任务」；做错时说“核对发现：…正在改” | 语音念结果不等核对 |
| 圈画与教学 | 能把每一处词单独圈出；能一步一步指给用户看，等用户自己点 | 被标签断开的词圈不到；真人没试过教学 |
| 记忆 | 明确的网站做法自动记、可删除；下次同站带入，其他归纳仍先问；停止和删除后旧学习不再写回，重开和跨窗口显示当前状态 | 真人长期试用；规则删除不清除对话、过往任务或站点笔记 |
| 整页翻译 | 一屏先译出第一段，再译完整屏 | 离 2 秒目标还差 |
| 下载 | 点击引起的下载会告诉助手，所以不再重复导出 | 助手读不到已下载文件的内容；要产品决定 |
| 备用模型 | 主模型卡住或暂时出错时换备用模型接着做 | 换模型后的完整交付没测过 |
| 不同模型 | 同一批 11 个真实网站任务（训练集），修复前 gpt-6-luna 10/11、MiniMax 10/11、Kimi 9/11，修复后三个都 11/11；Kimi 不再被拒，MiniMax 不再卡住 | 每个任务只跑了 1 次，独立测试集没跑；跨页原样搬运时 gpt-6-luna 仍不用“指定来源”、照旧重打 |
| 语音 | 插话即停声；按住说话，松开后先应一句，做完把回答里的卡片显示在胶囊上方；免按键可选 GPT-Live | 阶跃实时语音傍晚常挂住；外放回声没验 |

## 能用的模型

日常主模型本轮读到为 MiniMax-M3.1-Flash-Preview，未改模型设置。快速模型与备用模型本轮未重新核对。设置页「模型」一栏点「测一下」就能重测。

- 不再用：OpenCode Go（订阅到期）、小米 MiMo、DeepSeek（账号的密钥失效）、智谱 GLM（余额用完）。OpenCode Go 和智谱还连在日常扩展里，建议删掉。
- Kimi 编程套餐同一时间只收 1 个请求（10-15 实测：同时 2 个必有 1 个被拒），扩展已排队；评测用的 Kimi 登录每次只有 15 分钟，跑前要先在 Pi 里调一次刷新。
- 同一个模型每次快慢差好几秒，所以单次数字只看大概。

## 仍需解决

- 去掉批准卡后，网页里的恶意内容可以让助手在已登录的网站上动手（[说明](browser-confirmation.md)）。用户决定近期只自用，给别人用之前必须先做防护。

## 下一步
