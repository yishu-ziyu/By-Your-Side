本轮另加入三个网站的六种内置用法（搜索、视频字幕和指定帖子读取），按当前网站加载；字幕绑定当前视频，错误网站不执行。同一参数明确失败两次后，再次原样执行会被拦下。六种用法已在日常 Chrome 真实网站上逐项验过，包括多语言轨、自动字幕、多分P、无字幕和未登录，以及执行中停止、改目标；未登录时如实说明要登录或要先开字幕。扩展重载、侧栏连上时不再给上百个旧会话同时重新起名：日常实测重载后从 129 次起名请求降到 0，之前这阵请求会让快速模型限流，答完后的核对随之失败。事实摘录不再先斟酌要不要画卡，同模型同档位交错对照首字中位约快 0.6–1.1 秒；卡片的标题和说明文字跟着可调值一起变。网页操作在页面里失败时，原因原样交给助手（以前只剩一句脚本报错，助手会绕开甚至改网页凑结果）；下拉框找不到选项时不再先清掉原选中项。在任何页面说「记进 flomo」都能直接记上，记完从笔记列表读回核对；页面上没有用户要的选项时，助手如实说明，不改网页凑结果。详见[本轮方法与验收范围](evals/20261023-site-methods.md)。
