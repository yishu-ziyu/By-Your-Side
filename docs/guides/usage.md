# 使用说明

[文档导航](../README.md) · [当前状态](../STATUS.md) · [源码安装](getting-started.md)

本页描述交互及边界，功能是否已加载、哪一轮验收通过只看当前状态。

## 可以做什么

| 场景 | 你可以这样说 | 能力 |
|---|---|---|
| 理解网页 | “读一下这篇文章，总结主要观点。” | 读取页面、整理回答，按需展开执行过程 |
| 阅读时追问 | 选中文字后按 `⌘J` | 在页面内解释、翻译和连续追问；可转入侧栏继续 |
| 整页翻译 | “把这页翻译成中文，只保留译文。” | 待翻的段落先出现占位，译文到了原地替换；双语或仅译文，切换显示、字体与恢复原文 |
| 操作浏览器 | “把这几条结果的标题和链接整理给我。” | 导航、搜索、点击、填写、截图及多步网页操作 |
| 在页面上圈给你看 | “在页面上圈出五小时用量。” | 手绘框圈住目标；名称和旁边的数值圈进同一个框，名牌放在不压字的空白处 |
| 修改执行中的要求 | “预算改成六百，其他条件不变。” | 将修改送到原任务，保留页面与任务归属 |
| 增加独立任务 | “同时在新标签页打开另一个网站。” | 登记独立要求，安排执行，并把结果送回当前语音 |
| 记住你的资料和偏好 | “我的邮箱是 …” 或 “请记住，我希望先看中文摘要。” | 自动记下你说过的个人资料（可撤销），修改和忘记，支持网站范围 |

选中文字后默认弹出「问 AI / 解释」小工具条，可在设置页“划词”一栏关掉，详见[划词工具条](../reading-appearance.md#划词工具条)。

页面内阅读问答有独立的上下文，不会把每一次阅读追问都当作对后台任务的修改。整页翻译目前面向可访问的网页 DOM，不覆盖图片 OCR、PDF 或跨域 iframe。

## 快速模型与即时动作

设置页「快速模型」里可以另选一个响应快的模型（只列已填 key 或已登录的服务商），不选就用主模型。选了以后：

- **划词「解释」**和**整页翻译的每一批**改用它，并且用它允许的最低思考档（能关掉思考的就关掉）。它一个字都没出就失败时，自动改用主模型再答一次；仍失败时提示里写明原因，如「模型拒绝了请求参数」「超时」。
- **“把这页翻译成中文”这类话**：消息里提到翻译或语言时，先让它判断是不是“现在翻译整页”，是就直接开始翻译并用一句话报告段数，不再等主模型；不是、拿不准或 8 秒内没回，都照常交给主模型。
- **“价格在哪”这类问题**：先读一次页面，让它挑出答案所在的那一行，页面滚过去圈出来，再回一句话；拿不准或超时照常交给主模型。

阶跃的文字模型每次回答前都会先思考、关不掉，用作快速模型会很慢，设置页会提示。实测数字和限制见[即时动作验收](../evals/20260926-instant-2s.md)。

## 语音交互

点击输入区的“语音”，首次使用时允许麦克风访问。文字输入仍然可用。点完就可以开口：显示“正在开启麦克风”的这几秒里说的话会先留着，连上后补给语音模型，不用等“正在听你说”。一句话中间停顿、被语音模型切成几段时，“你：”这一行会把几段拼在一起显示。语音服务偶尔会整段没反应，大约 12 秒后会自动重连，并提示“刚才语音服务没有响应，请再说一遍”。

- **补充原任务**：普通修改直接送达，任务保持原有身份。
- **提出独立要求**：共享来源页面的要求会等待；并发与等待名额满时给出反馈。具体准入约束见[任务调度](../voice-dispatch.md)。
- **停止播报**：“别说了”控制声音，不等于取消网页任务。
- **控制指定任务**：可以按明确任务名称查询、修改或取消；页面接管与任务控制另有执行回执。
- **接收多个结果**：关联任务的结果回到原语音，按各自任务身份校验、排队播报。
- **终止任务**：任务运行中说“终止任务”会直接终止，不再复述确认；停下后才说“已终止”。
- **人设与音色**：在设置页“实时语音”里分别选择。人设可选默认、罗宾式或自定义描述，只影响语气和措辞；下次开启语音时生效。

只装扩展时，模型在侧栏「更多 → 模型与语音」里配置：保存后，新建的对话马上用新模型，已有对话也会跟着切换。

日常语音使用 StepAudio 3 Realtime；不提供 2.5 切换或回退。“停声”按钮只在正在回答时出现，只停声音，不取消后台任务。实现和完整边界见[语音架构](../voice-architecture.md)，历史验证见[日常迁移](../evals/20260920-realtime3-daily.md)。旧语音测试不代表新版本真人体验通过。

## 生成文件

说“把这页的商品和价格导出成 CSV”“把刚才的调研整理成一份 Markdown”“做一个能换算份数的小网页”时，助手会把文件写好，在回答下方显示一张文件卡片，点「下载」保存。支持 CSV、Markdown、文本、JSON、网页（HTML）、SVG；CSV 用 Excel 打开中文不乱码。PDF、Word、Excel 这类二进制格式暂不支持。网页文件目前只能下载后自己打开，还不能在侧栏里直接预览运行。

## 下载网页上的文件

说“把这个页面上的季度报表下载下来”时，助手点页面提供的下载链接或按钮，文件由 Chrome 存进你的下载文件夹（和你自己点的一样）。只有 Chrome 报告下载完成，回答才会说已保存；下载中断时会用平常话说失败原因（如“服务器传来的文件不完整”，不念 Chrome 的错误码），没下完时会说还没下完。Chrome 判为可能有害的文件要你在 Chrome 的下载列表里自己点“保留”。助手自己生成的文件走上一节的文件卡片，不经过这里。

## 会话、页面和记忆

侧栏顶部只有一行：左边是当前会话名（点开切换会话），右边是「＋ 新会话」和「⋯ 更多」；品牌由 Chrome 自己的标题栏显示，顶部不再重复。连接正常时顶部不显示连接状态，只在连接中或断开时出现「重连中…/未连接」。「帮我操作 / 指导我操作」保留在输入框里；切换当前模型收在“更多 → 当前模型”，模型目录与切换回执不变。任务进行中，输入框正上方有一行任务条，写现在的状态和正在做的动作；点右侧的箭头展开目标和这次带上的材料；任务页不是你眼前这页时，这一行会写「任务在 某网站」。停止用输入框右下角的停止键。

模型菜单从「更多」按钮处轻微展开，关闭时短暂淡出；关闭即停止菜单交互，焦点原在菜单内时回到「更多」按钮，点击别处则保留那里的焦点。搜索、切换常用/全部和目录更新不会重播入场。Escape 先清搜索，再关闭；方向键和 Enter 选择模型，收到回执才更新当前模型。系统开启“减少动态效果”时即时开关。

回答按稳定节奏逐字淡入，不随模型输出忽快忽慢；历史记录和系统“减少动态效果”时整段显示。动过页面的回合在回答上方留一行“做了 N 步 · 耗时”（运行中它显示当前在做什么，如“正在复核目标证据”），展开是逐步的动作清单（✓ / ✕）。没做完时回答下方只留一行说明还缺什么（“没做成：…”，中断时是“还没做：…”）：助手在回答里列出了缺什么时，直接在输入框回复，不出现“继续”；中断、出错或还有记录在案的未完成步骤时，仍可点“继续”。发送、提交这类危险点击会被拦下，在页面上等你点“确认 / 取消”，也可以在侧栏回“确认 / 可以，提交吧”或“取消”，效果相同；这一轮结束后按钮仍留在页面上，侧栏那一行写“等你在页面上确认：…”。这时另开会话操作同一页，旧的确认会收起，新会话照常操作。你在授权卡上点“拒绝”是你的选择，侧栏不把它说成失败，也不给“继续”。模型服务出错时约 7 秒内重试完并用平常话说明，不贴状态码或原始报错。

成功恢复的回执归到同一任务的执行过程；过程尚未出现时先以中性历史记录显示。失败、结果未知和需要决定的回执仍直接可见。回答末尾的复制图标一直可用，不以透明工具栏撑开对话。默认回答使用系统字体 14px，宋体等已保存的阅读偏好仍保留。

侧栏里显示的都是人话：不出现工具名、元素编号或内部占位字；这些原文只留在诊断记录里。

多个会话分别保存聊天、目标、草稿与附件。切换侧栏会话不会取消后台任务；关闭语音也不会停止网页执行。中断后不会自动重放旧动作；“继续原任务”的当前可用范围以 STATUS 中的真实恢复记录为准，不能把保留上下文等同于恢复执行。与后台的连接断开时按发送，输入框里的正文、引用和附件都留着，并提示“这条没有发出去”，连上后再发一次；已经交出但后台没收到（例如扩展后台恰好被 Chrome 停掉）的一条，重连后也会放回输入框并给同样的提示。只装扩展时，扩展内的助手重启（崩溃、被 Chrome 回收或扩展重载）后会话列表和界面里的记录都还在，接着发就行；但助手不记得重启前聊过什么，需要时把要点再说一遍或重新划词。

网页操作携带会话、任务与控制版本。同页共享或移交通过已有协调机制处理，不能仅凭 `tabId` 绕过页面归属。你可以接管页面，再交还给助手。

你在对话里亲口说过的关于自己的资料（邮箱、姓名、电话、地址、常用偏好，如“坐飞机都要靠过道”）会自动记下，包括回答助手提问时只报的一个邮箱。说“我 10 月 3 日飞成都”这类带日子的安排也会记下，到那天结束前你在任何网站提“那天”“这趟行程”它都知道，过了那天不再主动提，但问“我上次去成都是什么时候”仍答得出；订过的票这类过往任务也按票面日期同样处理。“这次先订经济舱”这类只对眼前这件事的话不记。对话里出现“已记住：… 撤销 查看”，点“撤销”就删掉这条。网页上出现的邮箱、网页里要求“记住…”的文字、一次性的任务参数和任何密码、验证码、卡号都不记。记下的资料每轮都会带上，所以新对话里说“帮我订阅”会直接填你记住的邮箱，不再问。明确说“请记住……/忘掉……”照样有效。

你纠正助手后（如“不对，只导了当前页，我要全部”），若能归纳出以后照做的做法，它会在回答后问“以后在这个网站……，要我记住吗？”，下面是“记住 / 这次就行”；会换掉一条旧做法时多一行“这会替换：…”。点“记住”后变成“好，记住了。[这个网站] 撤销”：点范围在“这个网站 / 所有网站”间切换，点“撤销”就不再照做（替换过的旧做法换回来）。早就记着同样的做法时只回“已经记着了。”，不重复保存。点“这次就行”不保存，同一会话里这条纠正不再问。问过的询问有了结果后，重新打开侧栏也照样显示（如“好，记住了。可在「记忆」面板查看或撤销”），只是不再给按钮；作废的询问只留问句和“这条询问已结束”，还没回答的照常可点。记住的做法（和从纠正里总结的待验证做法）在“更多 → 记忆”的“做事的方法”一组，写明用在哪、哪天记的、用过几次，点“查看来源”看你当时的原话，也能修改或忘记。

动手做过事的任务结束时会留一条“过往任务”（目标、去过的网站、结果、还差什么），回到同一网站时助手知道之前做过什么，问“我之前订阅过哪些邮件列表”也能答。记忆和过往任务都在“更多 → 记忆”里查看、修改、删除或全部清空。每条记忆写明是哪种（关于你 / 做过的事 / 做事的方法）、用在哪（所有网站 / 仅某网站 / 到某月某日为止）、你当时的原话和用过几次。你说“我邮箱换成 b@…”后，旧邮箱不再带给助手，收在列表下方“历史”里标“已被替换”，点“撤销替换”就换回旧的、新的标为“已失效”；已失效的那条也可以点“恢复这条”重新生效。过往任务同样标“做过的事”和用过几次。这些只存在这台电脑上（只装扩展时存在扩展自己的本地存储里，卸载扩展即删除）。只装扩展时没有技能存储，菜单里只有“记忆”，不显示“示范给 AI”。网站范围内的记忆只用于相关站点；忘记会停止后续使用，不删除既有聊天记录。

任务不随一轮结束：没做完就结束时，输入框上方留一行“还差：…”；做完后以回答和执行过程交付结果，输入框上方不再重复留“已完成”（纯聊天也不留）。这时随口补一句（不用说“继续”，比如“邮件应该到了，你再看看”）就算同一任务的补充，助手从原任务接着做。任务的下一步在别的网站时（例如去邮箱点确认链接），助手自己打开那个网站去做；只有登录、验证码、付款和只有你能做的选择才交给你，发送、删除等危险点击照样等你确认。每个动手的任务一轮结束时，助手会先核对你要的结果达成没有（过程行显示“核对是否做完”）；没做完而它自己能做时会接着做，最多两次。你在任务里说了“提交前让我确认”，这个任务里的提交、订阅、注册这类按钮会像删除一样先停在页面上等你点“确认”，或在侧栏回“确认 / 可以，提交吧”。

EverOS 桥接已于 2026-10-01 移出主线（[历史](../history/20261001-everos-retired.md)）。

回答正文的字体与字号设置见[阅读外观](../reading-appearance.md)。侧栏里的小伙伴 M 可以在右上角「更多 → 显示小伙伴 M」关掉或打开，重新打开侧栏后保持你的选择。

## 数据和权限

扩展需要页面访问、标签页、脚本执行、调试、下载和 offscreen 文档等权限，以完成观察与操作。下载权限用于确认页面下载是否完成；它覆盖整个浏览器配置的下载记录，助手只认自己在当前页面触发的那一次下载，不删除你下载文件夹里的文件。使用 `chrome.debugger` 时，Chrome 可能显示正在调试的提示条。

任务所需的文字、页面内容或截图会发送给配置的模型服务；语音输入发送给阶跃服务。

会话、任务回执、记忆和日志主要保存在 `~/.sideagent/`；只装扩展时，任务的诊断记录和语音每一轮的识别文字留在浏览器本地（不存录音），可在设置页「诊断记录」导出或清空；模型凭据由对应配置管理。提交、发布、删除等行为受任务指令、授权与接管流程约束，具体边界见[协议](../protocol.md)和[人机协作约定](../human-ai-contract.md)。
