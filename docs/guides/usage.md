# 使用说明

[文档导航](../README.md) · [当前状态](../STATUS.md) · [源码安装](getting-started.md)

本页写用户能看到的交互和边界。某项功能是否已加载、哪一轮验收通过，只看[当前状态](../STATUS.md)。

## 可以做什么

| 场景 | 你可以这样说 | 助手做什么 |
|---|---|---|
| 理解页面 | “读一下这篇文章，总结主要观点。” | 读页面，整理回答；执行过程可展开 |
| 阅读时追问 | 选中文字后按 `⌘J` | 在页面内解释、翻译和连续追问；可转入侧栏继续 |
| 整页翻译 | “把这页翻译成中文，只保留译文。” | 待翻的段落先显示占位，译文到了就原地替换；可切换双语或仅译文、换字体、恢复原文 |
| 网页操作 | “把这几条结果的标题和链接整理给我。” | 导航、搜索、点击、填写、截图和多步网页操作 |
| 在页面上圈给你看 | “在页面上圈出五小时用量。” | 用手绘框圈住目标；名称和旁边的数值圈在同一个框里，名牌放在不压字的空白处 |
| 修改执行中的要求 | “预算改成六百，其他条件不变。” | 把修改送进原任务；页面和任务归属不变 |
| 增加独立任务 | “同时在新标签页打开另一个网站。” | 登记一个独立任务，安排执行，把结果送回当前语音 |
| 记住你的资料和偏好 | “我的邮箱是 …” 或 “请记住，我希望先看中文摘要。” | 自动记下你说过的个人资料（可撤销）；可修改、忘记，可限定网站 |

选中文字后，页面默认弹出「问 AI / 解释」划词工具条。你可以在设置页「划词」一栏关掉它，见[划词工具条](../reading-appearance.md#划词工具条)。

页面内的阅读问答有自己的上下文。所以助手不把每一次阅读追问都当成对后台任务的修改。整页翻译只翻可访问的网页文字，不翻图片里的文字、PDF 和跨域 iframe。

## 快速模型

你可以在设置页「快速模型」另选一个响应快的模型。列表只列出已填 key 或已登录的服务商。不选时，助手只用主模型。选了快速模型以后：

- **划词「解释」和整页翻译的每一批**改用快速模型。快速模型一个字都没出就失败时，助手改用主模型再答一次。主模型也失败时，提示写明原因，例如「模型拒绝了请求参数」「超时」。
- **主模型出错时改用快速模型**：主模型迟迟不出字、连不上、限流或服务出错时，助手第一次就换快速模型接着回答。侧栏写明从哪个模型换到哪个模型。规则见[模型出错](../model-effort.md#主任务的模型服务出错)。
- **[目标核对](../goal-check.md)**也用快速模型。目标核对在回答显示之后才运行，所以不拖慢回答。

阶跃的文字模型每次回答前都先思考，这一步关不掉。所以阶跃文字模型用作快速模型时很慢，设置页会提示。实测数字见[即时动作验收](../evals/20260926-instant-2s.md)。

## 语音交互

点输入区的「语音」开始。第一次使用时，Chrome 请你允许麦克风访问。语音开着时，文字输入照常可用。

- 点完「语音」就可以开口，不用等「正在听你说」出现。开麦那几秒说的话不会丢。
- 你一句话中间停顿、被切成几段时，「你：」这一行把几段拼在一起显示。
- 语音服务偶尔整段没有反应。这时扩展自动重连，并提示「刚才语音服务没有响应，请再说一遍」。

你说的话按下面几类处理：

- **补充原任务**：普通修改直接送进原任务，任务身份不变。
- **提出独立要求**：如果新要求和运行中的任务用同一个来源页面，新要求先等待。并发和等待名额满时，助手告诉你。准入规则见[任务调度](../voice-dispatch.md)。
- **停声**：说“别说了”只停声音，不中止网页任务。
- **控制指定任务**：你说出明确的任务名称，就能查询、修改或中止这个任务。
- **接收多个结果**：关联任务的结果回到原语音，排队播报。
- **中止任务**：任务运行中说“终止任务”，助手直接中止，不再复述确认。任务停下后，助手才说“已终止”。

语音的外观和声音：

- **语音风格与音色**：在设置页「语音对话」分别选。语音风格可选默认、罗宾式或自定义描述，只影响语气和措辞，下次语音对话生效。
- **光球**：在设置页「语音对话」可选暮色（默认）、晨光或粒子，点一下立即换。暮色和晨光是自己渲染的循环视频（[来历](../evals/20261007-voice-orb-styles.md)）。

**按住说话**让你不开侧栏也能交代一句话：

- 在网页上单独按住右 ⌥ 说话，松开后这句话交给助手。地址栏和 Chrome 自带页面上不能用（[验收](../evals/20261007-ptt-dictation.md)）。
- 听写走阶跃 Step Plan 套餐，填了阶跃的 key 就能用。第一次用时，扩展打开麦克风授权页。
- 按住时，网页底部出现听写胶囊，依次显示在听、听写中、在做（当前步骤）和结果。结果是回答的第一句和「留给你的」。任务在跑时，按 Esc 或点「停」停下（[验收](../evals/20261007-ptt-capsule.md)）。
- 在设置页「语音对话」填 MiniMax 订阅 Key（`sk-cp-` 开头，只扣套餐）后，助手做完会念出结果第一句和「留给你的」。念的时候按 Esc 只停声音。设置里可以关掉朗读（[验收](../evals/20261007-ptt-speak.md)）。

模型在侧栏「更多 → 模型与语音」里配置。保存后，新会话和已有会话都改用新模型。

「停声」按钮只在助手说话时出现，只停声音，不中止后台任务。完整边界见[语音架构](../voice-architecture.md)。

## 生成文件

你说“把这页的商品和价格导出成 CSV”“把刚才的调研整理成一份 Markdown”“做一个能换算份数的小网页”时，助手写好文件，在回答下方显示一张文件卡片。

- 点「下载」保存文件。点「打开」在新标签页看文件，标签页标题是文件名，右上角也有「下载」。
- 助手自己做事时存的中间文件不显示卡片，只有你要的文件才显示。
- 支持 CSV、Markdown、文本、JSON、网页（HTML）和 SVG。PDF、Word、Excel 这类二进制格式暂不支持。
- 打开后，网页照常显示，网页里的脚本能运行；Markdown 显示成排好版的正文；SVG 图片直接显示；CSV、JSON 和文本用等宽字体原样显示。CSV 用 Excel 打开时中文不乱码。
- 打开的网页在隔离区里运行。这个网页读不到扩展保存的密钥、记忆和设置，也改不了扩展页面。但是它能加载网上的脚本和图片，和你下载后自己打开一样。
- 你在会话里删掉文件后，已打开的标签页改为显示「文件已不在了」。浏览器重启后，旧标签页也这样提示。

## 要一张截图

你说“把这页截个图给我”时，截图显示在回答下面的卡片里。点图片或「打开」，在新标签页看大图；点「下载」，存成 PNG。助手为了看清页面自己截的图不进会话，只在执行过程里记一步「截图」。

## 下载文件

你说“把这个页面上的季度报表下载下来”时，助手点页面上的下载链接或按钮。Chrome 把文件存进你的下载文件夹，和你自己点的一样。PDF 在 Chrome 阅读器里打开后，助手仍能下载它。

- 只有 Chrome 报告下载完成，回答才说文件已保存。没下完时，回答说还没下完。
- 下载中断时，助手用平常话说失败原因，例如“服务器传来的文件不完整”，不念 Chrome 的错误码。
- Chrome 判为可能有害的文件，要你在 Chrome 的下载列表里自己点「保留」。

助手自己生成的文件走[生成文件](#生成文件)的文件卡片，不经过下载。

## 会话、页面和记忆

### 会话

- 侧栏顶部只有一行：左边是当前会话名，右边是「＋」（新会话）、「记忆」和「⋯」（更多）。
- 连接正常时，顶部不显示连接状态。只有在重连或断开时，顶部才显示「重连中…」或「未连接」。
- 主模型在「更多 → 当前模型」里切换。模型菜单的搜索框里有字时，按 Escape 先清空搜索；再按一次 Escape，菜单才关闭。
  你选了新模型以后，助手回执到了，侧栏显示的主模型才改变。
- 点侧栏顶部的会话名，打开会话列表。列表按最近更新排序，每条显示更新时间和任务状态。
- 每个会话分别保存消息、目标、草稿和附件。打开侧栏时回到上次的会话；点「＋」才新开会话。
- 切换会话不中止后台任务；关闭语音也不中止网页任务。
- 任务运行时，输入框上方有一行任务条，写着当前状态和正在做的动作。任务页面不是你眼前的页面时，任务条写「任务在 某网站」。中止键在输入框右下角。
- 点任务条右侧的箭头，任务条展开这次任务的目标和送进任务的材料。

### 回答和执行过程

- 回答按稳定节奏逐字显示，不随模型输出忽快忽慢。历史记录和系统开了「减少动态效果」时，回答整段显示。
- 模型先写了一段话、接着又去操作页面时，这段话收进执行过程。最后的回答只出现一次。
- 动过页面的回合，在回答上方留一行「做了 N 步 · 耗时」。运行中，这一行写当前动作，例如「正在打开页面」。展开这一行，可以看到逐步的动作清单（✓ / ✕）。
- 任务没做完时，回答下方只留一行，写还缺什么：「没做成：…」，中断时写「还没做：…」。
- 如果助手在回答里写明了还缺什么，你直接在输入框回复，界面不出现「继续」。中断、出错或还有记录在案的未完成步骤时，你可以点「继续」。
- 助手想把已经做成的一步再做一遍时，程序拦下这一步，标为「已做过，没再重复」。这一步不算没做成。
- 模型服务出错时，助手很快重试完，并用平常话说明，不贴状态码或原始报错。
- 侧栏只显示人话，不出现工具名、元素编号或内部占位字。这些原文只留在诊断记录里。
- 失败、结果未知和需要你决定的回执直接显示。回答末尾的复制图标一直可用。

### 断线和重启

- 中断后，助手不自动重放旧动作。「继续原任务」能恢复到什么程度，以 [STATUS](../STATUS.md) 里的真实恢复记录为准；保留上下文不等于恢复执行。
- 侧栏与扩展后台断开时，你按发送，输入框里的正文、引用和附件都留着，并提示「这条没有发出去」。连上后，你再发一次。
- 如果一条消息已经交出，但扩展后台没有收到（例如扩展后台恰好被 Chrome 停掉），重连后这条消息也放回输入框，提示相同。
- 扩展内的助手重启后（崩溃、被 Chrome 回收或扩展重载），会话列表和界面里的记录都还在，你接着发就行。会话消息和任务检查点会恢复，文件也能重新打开和读取。

### 你和助手交替操作页面

- 助手操作页面时，侧栏有「接管」按钮。你点「接管」，助手立刻停手，页面左上角出现「现在归你 · 交还」。
- 你在页面上改完，点页面条或侧栏同一位置的「交还」。助手先重读你改过的页面，再在同一个任务里接着做；你在暂停期间写的补充一起带上（[验收](../evals/20261005-takeover-handback.md)）。
- 关掉侧栏后，任务照常继续。任务在做、暂停等你或出错时，你正在看的标签页右边缘中间留一颗边缘药丸。这个标签页不一定是任务所在的标签页。
  边缘药丸平时是一道细光：蓝色呼吸表示正在做，琥珀色表示暂停等你，红色表示出错。
  鼠标停上去，边缘药丸展开成小卡，显示状态和你的原话；点「打开侧栏」回到侧栏。出错状态在侧栏看过一次后，边缘药丸不再显示（[验收](../evals/20261005-edge-pill.md)）。
- 你在侧栏连续打字或用滚轮翻看回答时，顶栏按钮和输入区的次要按钮淡下去；鼠标一动、按 Tab 或打开菜单，这些按钮立刻回来。
  顶栏的连接状态、输入框、发送键和中止键、「接管 / 交还」和任务条始终不淡。
  系统开了「减少动态效果」时，按钮直接隐去和出现，不播放过渡（[验收](../evals/20261005-chrome-quiet.md)）。

### 记忆

记忆怎么分类、为什么这样设计，见[记忆模型](../memory-model.md)。你能看到和操作的部分如下。

- **自动记下的资料**：你在会话里亲口说过的关于自己的资料，助手自动记下。资料包括邮箱、姓名、电话、地址和常用偏好（如“坐飞机都要靠过道”）。你回答助手提问时只报一个邮箱，这个邮箱也记下。
- **带日子的安排**：你说“我 10 月 3 日飞成都”，助手也记下。那天结束前，你在任何网站提“那天”“这趟行程”，助手都知道指什么。过了那天，助手不再主动提起，但你问“我上次去成都是什么时候”，助手仍答得出。
- **不记的内容**：只对眼前这件事的话（如“这次先订经济舱”）、网页上出现的邮箱、网页里要求“记住…”的文字、一次性的任务参数，以及任何密码、验证码和卡号。
- **回执和撤销**：助手记下一条时，会话里出现「已记住：… 撤销 查看」，点「撤销」删掉这一条。你说了新值（如“我搬到杭州了”），回执写「已更新：住在杭州（原来是住在北京）」，点「撤销」恢复旧值。
- **网页上按记忆填写**：助手按记忆填的输入框带淡蓝底和「记得的」小标签；你自己改了这一格，标签消失。点标签可以选「改一下」「这次不用」（清空这一格，记忆还在）或「忘掉」（清空这一格并删掉这条记忆，可撤销）。
- **每轮都带上**：「关于你」的资料每一轮都交给助手。所以在新会话里说“帮我订阅”，助手直接填你记住的邮箱，不再问。
- 你明确说“请记住……”“忘掉……”，助手照办。

**纠正后的询问**：你纠正助手后（如“不对，只导了当前页，我要全部”），如果助手能归纳出以后照做的做法，就在回答后问「以后在这个网站……，要我记住吗？」。

- 点「记住」，询问变成「好，记住了。[这个网站] 撤销」。点范围，在「这个网站 / 所有网站」之间切换；点「撤销」，助手不再照做这条做法。
- 新做法会替换一条旧做法时，询问多一行「这会替换：…」。撤销后，旧做法换回来。
- 点「这次就行」，助手不保存，同一会话里不再为这条纠正发问。
- 助手早就记着同样的做法时，只回「已经记着了。」，不重复保存。
- 重新打开侧栏后，已回答的询问照样显示结果，但不再给按钮；作废的询问只留问句和「这条询问已结束」；没回答的询问照常可点。

**过往任务**：动手做过事的任务结束时，助手留一条过往任务，写目标、去过的网站、结果和还差什么。你回到同一网站时，助手知道之前做过什么；你问“我之前订阅过哪些邮件列表”，助手也能答。

**「记忆」面板**（点侧栏顶部的「记忆」打开）：

- 面板里可以查看、修改、删除或全部清空记忆和过往任务。
- 每条写明种类（关于你 / 做过的事 / 做事的方法）、适用范围（所有网站 / 仅某网站 / 到某月某日为止）、你当时的原话和用过几次。
- 「做事的方法」一组放两种做法：你纠正后点「记住」的做法，和助手从纠正里总结的待验证做法。
  这一组每条写明用在哪、哪天记的、用过几次；点「查看来源」看你当时的原话。
- 你把邮箱换成新的以后，助手不再用旧邮箱。旧邮箱收在列表下方「历史」里，标「已被替换」。点「撤销替换」，旧邮箱恢复生效，新邮箱标「已失效」；已失效的一条可以点「恢复这条」重新生效。
- 限定网站的记忆只在这个网站上使用。忘记一条记忆后，助手不再使用它，但已有的会话记录不删。
- 记忆只存在这台电脑上，存在扩展自己的本地存储里。卸载扩展时，记忆一起删除。

### 任务跨轮

- 任务没做完就结束时，输入框上方留一行「还差：…」。任务做完时，结果在回答和执行过程里，输入框上方不再留「已完成」；纯聊天也不留。
- 这时你随口补一句（如“邮件应该到了，你再看看”），不用说“继续”，助手就把它当作同一任务的补充，从原任务接着做。
- 任务的下一步在别的网站时（例如去邮箱点确认链接），助手自己打开那个网站去做。只有登录、验证码、付款和只有你能做的选择，助手才交给你。
- 动手做过事的任务在回答显示后，助手再做[目标核对](../goal-check.md)。没做完、助手又能自己做时，助手接着做一轮，并避开这次已经失败的做法；你能看到这一轮。
- 如果原因在网站那边（网站连不上、页面不存在、网站拒绝访问），助手说明一次就停，输入框上方写「没做成：网站现在连不上，稍后可以让我再试」。你说“再试”，助手接着做。

### 网页操作不逐次确认

- 助手在网页上的操作直接执行，不逐次请你确认（见[网页操作不再逐次确认](../browser-confirmation.md)）。想先看一眼再提交，就在任务里说明，或随时点中止、接管页面。
- 某一步查不清是否生效时，助手重读页面，没生效就再做一次或换个办法，所以偶尔会把同一个按钮点两次（见[去掉重试锁](../evals/20261010-drop-retry-locks.md)）。付款按钮仍由你自己点。

回答正文的字体与字号设置见[字体字号](../reading-appearance.md)。

## 数据和权限

扩展申请的权限以 [`manifest.json`](../../extension/manifest.json) 为准。你可能注意到的两点：

- 助手使用调试接口操作页面时，Chrome 可能显示正在调试的提示条。
- 下载权限覆盖整个浏览器配置的下载记录。助手只读取它操作期间、同一网站开始的下载状态，不删除你下载文件夹里的文件。

数据去向：

- 任务需要的文字、页面内容或截图，发给你配置的模型服务。语音输入发给阶跃服务。
- 任务的诊断记录和语音每一轮的识别文字留在本机浏览器里，不存录音。你可以在设置页「诊断记录」导出或清空。
- 模型凭据由对应的配置管理。
- 提交、发布、删除等动作按你的任务要求执行，你可随时中止或接管。边界见[协议](../protocol.md)和[人机协作约定](../human-ai-contract.md)。

**警告：** 在不信任的页面上让助手动手之前，先看一眼页面内容。因为网页操作不再逐次确认，网页里藏的恶意指令可能让助手在已登录的网站上点击、发送或提交。

## 任务卡与引用

多步任务在消息流里显示可折叠的任务卡。任务卡列出目标、作用网站、已完成 / 待执行 / 受阻 / 结果未知的项目，以及送进任务的材料。

- 材料不是已核实的来源。步骤完成数也不保证整个目标达成。
- 执行中的活动单独显示。任务卡不编造步骤或进度。
- 只有原任务有恢复依据、当前状态也允许时，卡片底部才出现「继续原任务」。请求中、超时和失败照实显示；已中止的任务不能从这个入口复活。

转入侧栏：

- 划词工具条上可以直接点「转入侧栏」。按 `⌘J` 打开的阅读卡，即使还没有回答，也能点「在侧栏继续」。
- 转入后，选中的文字进入输入框上方的引用条，输入框获得焦点，消息不自动发送。去掉引用不清空你已输入的正文。

## 页面伴读交互

- **掀开原文**：用仅译文模式时，按住译文覆盖层可以看原文，松开或移出后复位。双语模式把原文和译文并列显示。详见[整页翻译](../page-translation.md#可掀开的仅译文)。
- **段落提示**：在 ＋ 菜单里选关闭、原文摘录或解释段落，默认关闭。
  - 启用后，侧栏进入伴读导轨，原会话保留；关闭段落提示或发送提问后，侧栏回到会话。
  - 选解释段落时，鼠标停在段落上才生成解释。解释发给设置里选的模型，可能出错；原文摘录模式不调用模型。
  - 关闭段落提示或关闭侧栏后，助手不再发新请求。选择只保留到侧栏关闭。
- **拖拽投喂**：网页正文不整块拖，划词照常。
  - 选中任意文字后，按住选区稍停，再拖到输入区，材料就是选中的那段。
  - 表格和代码块在悬停时左上角出现把手，按住把手可拖整块。
  - 松手后，输入区出现带 ✕ 的材料胶囊和提问草稿。已有正文保留；你点发送，材料才交给模型。来源变了或内容过长时，材料不添加。
- **直连按钮**：当前页有媒体、播放器的「下一个」或长代码块时，顶栏下方出现「暂停/播放」「下一个」「折叠/展开代码」。
  - 点按钮，助手直接在页面上做，不调用模型。页面正中浮起一枚提示，侧栏显示耗时和「没用模型」。
  - 浏览器不让直接播放时，助手照实提示，请你在页面上点一下。
- **写到一半改方向**：任务运行时，输入区上方出现「改成对比表格」「浓缩成 3 句话」。点按钮或直接打字回车，不用先停。模型正在写的回答当场停下，按新要求重写，新回答前标「已改方向」。如果模型正在操作页面，你的补充等这一步做完再生效。
- **数字反查**：本轮文字请求的回答里，如果一个完整数字能在请求页面上唯一匹配，回答为它生成数字胶囊。
  - 点数字胶囊，页面回到原位置并短暂高亮。
  - 来源页面已导航、文字变了或数字重复匹配时，助手拒绝定位。没有可靠来源的历史回答不生成数字胶囊。
  - 数字胶囊只证明原文位置，不证明模型解释正确，也不保证所有数字都能反查。

## 看着它做与顺手的小交互（10-05，未经真人试用）

- **光标旁白**：助手点击、填写时，助手的光标旁挂一句短话，如「我在点「提交」」「我在填「日期」」，做完随光标收起。状态仍在页面右上角。
- **侧栏动作卡**：任务运行时，执行过程自动展开，每步一张动作卡，如「点「提交」」「填这一栏」，用词和光标旁白相同；模型的过程旁白夹在动作卡之间。任务结束后，执行过程收成「做了 N 步」，可再展开。已知缺口：填写步骤在侧栏里暂时叫不出字段名。
- **Shift+悬停链接**：按住 Shift 在普通链接上稍停，链接下方出现预览卡，写网站、标题和几行要点。预览直接从网页取，不经过模型，也不带登录状态。松开或移开时预览卡收起，点击照常跳转。设置页「划词」一栏可以关掉。
- **回答出处**：如果回答有真实的已读页面记录，回答顶上显示「读了 N 个网站」，正文里指向已读页面的链接带数字角标。点角标，侧栏切到（或新开）那一页；能定位就高亮原段落，否则提示「已打开来源页」。这一页同时挂到输入框上方，你的下一句提问会带上它。
- **圈出来问**：从输入区 + 菜单选「圈出来问」（侧栏有焦点时按 ⌘/Ctrl+Shift+S），在页面上按住拖动画圈，可以连圈几处。
  - 每圈一处，输入框上方多一张带编号的截图。去掉一张截图，页面上对应的圈也去掉。
  - 圈里的网页文字随截图一起交给助手（输入框里填的值不带），所以助手能说准圈的是哪个商品。
  - 回答里的 ①② 能点：页面滚回那一圈，再用蓝色手绘圈指一下。那一圈已经不在（页面变了或你又圈了新的一组）时，写「原处已变化」。
  - 按 Esc 退出圈选，已圈的保留。圈完不自动发送。
- **/ 技能**：在输入框开头打 `/`，列出保存的提示词。选中后，正文放进输入框，你按发送才运行；带问题的技能先问清再开始。悬停你自己发过的消息，可以「存成技能」。列表末尾「管理技能」可以增删改，自带的几条也能删。
- **主动建议**（在设置页「划词」一栏打开，默认关）：
  - 你在一页停留一阵，并且滚动过或选过文字后，模型判断一次有没有值得做的下一步，例如对比两篇、记下观点、比价、翻译。
  - 模型有把握、又能引用原文时，出一张一句话的卡。卡的第一个词就是按钮，如「申请 | 晚退房到 14:00 · 全季酒店」，下面一行写出处。
  - 侧栏开着时，卡出现在对话流里。按第一个词，助手就做，卡原位变成这一轮的开头，步骤和回答接在下面；点句子其余部分，这件事放进输入框；悬停时出现 ×。
  - 侧栏关着时，卡出现在页面右下角。点卡，侧栏打开并把这件事填进输入框。
  - 同一页只判断一次，两张卡之间有间隔，点 × 后本次不再出现。每次判断（出没出卡、卡写了什么）都记进本机诊断记录，可在设置页导出回看。
- **继续上次的事**（在设置里打开，默认关）：新会话的起点出现几张卡。卡片来自本机记录里中断的任务、等你回话的会话、没做完的过往任务和出错的阅读追问。按钮带你回到原任务、会话或页面，不直接动手。点 × 后，一段时间内不再出现。
- **划词朗读**：划词工具条上的「朗读」用浏览器自带的声音读选中的文字，当前句高亮；底部小播放条可以暂停、调速、关闭。朗读不发起页面任务。
- **语音胶囊**：语音时，状态显示为「正在听」「正在想」「正在说」；说话时当前句高亮；有真实来源时显示「N 个来源」。
