# 使用说明

[文档导航](../README.md) · [当前状态](../STATUS.md) · [源码安装](getting-started.md)

本页描述交互及边界，功能是否已加载、哪一轮验收通过只看当前状态。

## 可以做什么

| 场景 | 你可以这样说 | 能力 |
|---|---|---|
| 理解页面 | “读一下这篇文章，总结主要观点。” | 读取页面、整理回答，按需展开执行过程 |
| 阅读时追问 | 选中文字后按 `⌘J` | 在页面内解释、翻译和连续追问；可转入侧栏继续 |
| 整页翻译 | “把这页翻译成中文，只保留译文。” | 待翻的段落先出现占位，译文到了原地替换；双语或仅译文，切换显示、字体与恢复原文 |
| 网页操作 | “把这几条结果的标题和链接整理给我。” | 导航、搜索、点击、填写、截图及多步网页操作 |
| 在页面上圈给你看 | “在页面上圈出五小时用量。” | 手绘框圈住目标；名称和旁边的数值圈进同一个框，名牌放在不压字的空白处 |
| 修改执行中的要求 | “预算改成六百，其他条件不变。” | 将修改送到原任务，保留页面与任务归属 |
| 增加独立任务 | “同时在新标签页打开另一个网站。” | 登记独立要求，安排执行，并把结果送回当前语音 |
| 记住你的资料和偏好 | “我的邮箱是 …” 或 “请记住，我希望先看中文摘要。” | 自动记下你说过的个人资料（可撤销），修改和忘记，支持网站范围 |

选中文字后默认弹出「问 AI / 解释」小工具条，可在设置页「划词」一栏关掉，详见[划词工具条](../reading-appearance.md#划词工具条)。

页面内阅读问答有独立的上下文，不会把每一次阅读追问都当作对后台任务的修改。整页翻译目前面向可访问的网页 DOM，不覆盖图片 OCR、PDF 或跨域 iframe。

## 快速模型

设置页「快速模型」里可以另选一个响应快的模型（只列已填 key 或已登录的服务商），不选就用主模型。选了以后：

- **划词「解释」**和**整页翻译的每一批**改用它。它一个字都没出就失败时，自动改用主模型再答一次；仍失败时提示里写明原因，如「模型拒绝了请求参数」「超时」。
- **主模型出错时接手**：主模型迟迟没出字、连不上、限流或服务出错，第一次就换快速模型接着回答，侧栏写明从哪个换到哪个；规则见[模型出错](../model-effort.md#主任务的模型服务出错)。
- **回答后的目标核对**也用它；目标核对在回答显示之后运行，不拖慢回答。

阶跃的文字模型每次回答前都会先思考、关不掉，用作快速模型会很慢，设置页会提示。实测数字和限制见[即时动作验收](../evals/20260926-instant-2s.md)。

## 语音交互

点击输入区的「语音」，首次使用时允许麦克风访问。文字输入仍然可用。点完就可以开口，不用等「正在听你说」；开麦那几秒说的话不会丢。一句话中间停顿、被切成几段时，「你：」这一行会把几段拼在一起显示。语音服务偶尔会整段没反应；这时扩展自动重连，并提示「刚才语音服务没有响应，请再说一遍」。

- **补充原任务**：普通修改直接送达，任务保持原有身份。
- **提出独立要求**：共享来源页面的要求会等待；并发与等待名额满时给出反馈。具体准入约束见[任务调度](../voice-dispatch.md)。
- **停止播报**：“别说了”控制声音，不等于中止网页任务。
- **控制指定任务**：可以按明确任务名称查询、修改或中止。
- **接收多个结果**：关联任务的结果回到原语音，排队播报。
- **终止任务**：任务运行中说“终止任务”会直接中止，不再复述确认；停下后才说“已终止”。
- **人设与音色**：在设置页「实时语音」里分别选择。人设可选默认、罗宾式或自定义描述，只影响语气和措辞；下次开启语音时生效。
- **光球**：设置页「实时语音」里可选暮色（默认）、晨光或粒子，点一下立即换。暮色和晨光是自己渲染的循环视频（[来历](../evals/20261007-voice-orb-styles.md)）。
- **按住说话**：在网页上单独按住右 ⌥ 说话，松开后这句话交给助手，侧栏不用开。听写走阶跃 Step Plan 套餐（填了阶跃的 key 即可）；第一次用会打开麦克风授权页。地址栏和 Chrome 自带页面上不可用（[验收](../evals/20261007-ptt-dictation.md)）。按住时网页底部出现胶囊，依次显示在听、听写中、在做（当前步骤）、结果（回答第一句和「留给你的」）；任务在跑时按 Esc 或点「停」停下（[验收](../evals/20261007-ptt-capsule.md)）。在设置页「实时语音」填 MiniMax 订阅 Key（sk-cp- 开头，只扣套餐）后，做完会念出结果第一句和「留给你的」；念的时候按 Esc 只停声音，设置里可关（[验收](../evals/20261007-ptt-speak.md)）。

只装扩展时，模型在侧栏「更多 → 模型与语音」里配置：保存后，新建的会话马上用新模型，已有会话也会跟着切换。

「停声」按钮只在回答时出现，只停声音，不中止后台任务。完整边界见[语音架构](../voice-architecture.md)。

## 生成文件

说“把这页的商品和价格导出成 CSV”“把刚才的调研整理成一份 Markdown”“做一个能换算份数的小网页”时，助手会把文件写好，在回答下方显示一张文件卡片。点「下载」保存；点「打开」在新标签页直接看。打开后，网页照常显示，里面的脚本能运行；Markdown 显示成排好版的正文；SVG 图片直接显示；CSV、JSON、文本原样用等宽字体显示。标签页标题是文件名，右上角也有「下载」。支持 CSV、Markdown、文本、JSON、网页（HTML）、SVG；CSV 用 Excel 打开中文不乱码。PDF、Word、Excel 这类二进制格式暂不支持。打开的网页放在隔离区里运行，读不到扩展保存的密钥、记忆和设置，也动不了扩展页面。打开的网页能加载网上的脚本和图片，和你下载后自己打开一样。会话里删掉的文件，已开的标签页会改成「文件已不在了」；浏览器重启后旧标签页也会这样提示。

## 要一张截图

说“把这页截个图给我”时，截图直接显示在回答下面的卡片里：点图片或「打开」在新标签页看大图，点「下载」存成 PNG。助手为了看清页面自己截的图不会出现在会话里，只在执行过程里记一步「截图」。

## 下载文件

说“把这个页面上的季度报表下载下来”时，助手点页面提供的下载链接或按钮。文件由 Chrome 存进你的下载文件夹（和你自己点的一样）。PDF 在 Chrome 阅读器打开后仍可下载。只有 Chrome 报告下载完成，回答才会说已保存；下载中断时会用平常话说失败原因（如“服务器传来的文件不完整”，不念 Chrome 的错误码），没下完时会说还没下完。Chrome 判为可能有害的文件要你在 Chrome 的下载列表里自己点「保留」。助手自己生成的文件走[生成文件](#生成文件)的文件卡片，不经过这里。

## 会话、页面和记忆

点顶部会话名打开列表。名称最多显示两行；超长名称可悬停查看全文。每条会话显示更新时间和现有任务状态，列表仍按最近更新排序。

侧栏顶部只有一行：左边是当前会话名（点开切换会话），右边是「＋ 新会话」和「⋯ 更多」。连接正常时顶部不显示连接状态，只在连接中或断开时出现「重连中…/未连接」。切换主模型收在「更多 → 当前模型」。任务运行时，输入框正上方有一行任务条，写现在的状态和正在做的动作；点右侧的箭头展开目标和这次带上的材料；任务页不是你眼前这页时，这一行会写「任务在 某网站」。中止用输入框右下角的中止键。

模型菜单里，Escape 先清搜索，再关闭；方向键和 Enter 选择模型，收到回执才更新主模型。

回答按稳定节奏逐字淡入，不随模型输出忽快忽慢；历史记录和系统「减少动态效果」时整段显示。模型直接写回答时也是边生成边显示；它写完这段又去操作网页，这段话就收进执行过程，最后的回答只出现一次，写完就显示。动过页面的回合在回答上方留一行「做了 N 步 · 耗时」。运行中，这一行显示当前在做什么，如「正在打开页面」；展开是逐步的动作清单（✓ / ✕）。没做完时，回答下方只留一行，说明还缺什么（「没做成：…」，中断时是「还没做：…」）。助手在回答里列出了缺什么时，你直接在输入框回复，不出现「继续」；中断、出错或还有记录在案的未完成步骤时，仍可点「继续」。助手想把已经做成的一步再做一遍时会被拦下，这一步标「已做过，没再重复」，也不算没做成。模型服务出错时会很快重试完并用平常话说明，不贴状态码或原始报错。

失败、结果未知和需要决定的回执直接可见。回答末尾的复制图标一直可用。

侧栏里显示的都是人话：不出现工具名、元素编号或内部占位字；这些原文只留在诊断记录里。

多个会话分别保存消息、目标、草稿与附件。打开侧栏回到上次会话；点「＋」才另开会话。切换侧栏会话不会中止后台任务；关闭语音也不会中止网页执行。中断后不会自动重放旧动作；「继续原任务」的当前可用范围以 STATUS 中的真实恢复记录为准，不应把保留上下文等同于恢复执行。与扩展后台的连接断开时按发送，输入框里的正文、引用和附件都留着，并提示「这条没有发出去」，连上后再发一次；已经交出但扩展后台没收到（例如扩展后台恰好被 Chrome 停掉）的一条，重连后也会放回输入框并给同样的提示。扩展内的助手重启（崩溃、被 Chrome 回收或扩展重载）后会话列表和界面里的记录都还在，接着发就行；会话消息和任务检查点会恢复，文件也能重新打开和读取。

助手在操作页面时，侧栏有「我来」：点了它立刻停手，页面左上角出现「现在归你 · 你继续」。你在页面上改完，点页面条或侧栏同一位置的「你继续」，助手先重读你改过的页面，再在同一个任务里接着做；暂停期间写的补充一并带上（[验收](../evals/20261005-takeover-handback.md)）。

关掉侧栏后任务照常继续。这时当前网页右边缘中间留一道细光：蓝色呼吸是正在做，琥珀色是暂停等你，红色是出错。鼠标停上去展开成小卡，显示状态和你的原话，点「打开侧栏」回到侧栏；侧栏开着或没有任务时不显示。出错在侧栏看过一次后不再显示（[验收](../evals/20261005-edge-pill.md)）。

在侧栏输入框连续打字，或用滚轮翻看回答时，顶栏按钮和输入区的次要按钮（当前页标签、附件、···、边注）会淡下去；鼠标一动、按 Tab 或打开菜单就立刻回来。顶栏状态、输入框、发送/停止、「我来/你继续」和任务条始终不变。系统设了减少动态效果时直接切换，不播放过渡（[验收](../evals/20261005-chrome-quiet.md)）。

你在会话里亲口说过的关于自己的资料会自动记下，包括回答助手提问时只报的一个邮箱。这类资料指邮箱、姓名、电话、地址、常用偏好，如“坐飞机都要靠过道”。说“我 10 月 3 日飞成都”这类带日子的安排也会记下。到那天结束前，你在任何网站提“那天”“这趟行程”，助手都知道；过了那天，助手不再主动提，但问“我上次去成都是什么时候”仍答得出；订过的票这类过往任务也按票面日期同样处理。“这次先订经济舱”这类只对眼前这件事的话不记。会话里出现「已记住：… 撤销 查看」，点「撤销」就删掉这条。说了新值，如“我搬到杭州了”，回执写「已更新：住在杭州（原来是住在北京）」，点「撤销」恢复旧值。网页上出现的邮箱、网页里要求“记住…”的文字、一次性的任务参数和任何密码、验证码、卡号都不记。记下的资料每轮都会带上，所以新会话里说“帮我订阅”会直接填你记住的邮箱，不再问。网页上按记忆填的那一格带淡蓝底和「记得的」小标签；你自己改了这一格，标签就消失。点标签可以「改一下」「这次不用」（清空这一格，记忆还在）或「忘掉」（清空并删掉这条，侧栏写明已忘掉，可撤销）。明确说“请记住……/忘掉……”照样有效。

你纠正助手后（如“不对，只导了当前页，我要全部”），若能归纳出以后照做的做法，助手会在回答后问「以后在这个网站……，要我记住吗？」，下面是「记住 / 这次就行」；会换掉一条旧做法时多一行「这会替换：…」。点「记住」后变成「好，记住了。[这个网站] 撤销」：点范围在「这个网站 / 所有网站」间切换，点「撤销」就不再照做（替换过的旧做法换回来）。早就记着同样的做法时只回「已经记着了。」，不重复保存。点「这次就行」不保存，同一会话里这条纠正不再问。问过的询问有了结果后，重新打开侧栏也照样显示（如「好，记住了。可在「记忆」面板查看或撤销」），只是不再给按钮；作废的询问只留问句和「这条询问已结束」，还没回答的照常可点。记住的做法，和从纠正里总结的待验证做法，都在「更多 → 记忆」的「做事的方法」一组。每条写明用在哪、哪天记的、用过几次；点「查看来源」看你当时的原话，也能修改或忘记。

动手做过事的任务结束时，会留一条「过往任务」（目标、去过的网站、结果、还差什么）。回到同一网站时，助手知道之前做过什么；问“我之前订阅过哪些邮件列表”也能答。记忆和过往任务都在「更多 → 记忆」里查看、修改、删除或全部清空。每条记忆写明是哪种（关于你 / 做过的事 / 做事的方法）、用在哪（所有网站 / 仅某网站 / 到某月某日为止）、你当时的原话和用过几次。你说“我邮箱换成 b@…”后，旧邮箱不再带给助手，收在列表下方「历史」里标「已被替换」，点「撤销替换」就换回旧的、新的标为「已失效」；已失效的那条也可以点「恢复这条」重新生效。过往任务同样标「做过的事」和用过几次。这些只存在这台电脑上（只装扩展时存在扩展自己的本地存储里，卸载扩展即删除）。网站范围内的记忆只用于范围内的网站；忘记会停止后续使用，不删除既有会话记录。

任务不随一轮结束：没做完就结束时，输入框上方留一行「还差：…」；做完后以回答和执行过程交付结果，输入框上方不再重复留「已完成」（纯聊天也不留）。这时随口补一句（不用说“继续”，比如“邮件应该到了，你再看看”）就算同一任务的补充，助手从原任务接着做。任务的下一步在别的网站时（例如去邮箱点确认链接），助手自己打开那个网站去做；只有登录、验证码、付款和只有你能做的选择才交给你。每个动手的任务回答显示、任务回到空闲之后，助手再用目标核对确认你要的结果达成没有；没做完而它自己能做时会作为看得见的后续一轮接着做，并避开这次已经失败的做法。如果原因在网站那边（网站连不上、页面不存在、网站拒绝访问），助手说明一次就停。输入框上方写「没做成：网站现在连不上，稍后可以让我再试」，你说“再试”就接着做。网页上的点击、填写、导航和请求直接执行，不逐次确认（见[网页操作不再逐次确认](../browser-confirmation.md)）；想先看一眼再提交，就在任务里说明，或随时点中止、接管页面。如果某一步做了却查不清生效没有（比如点上传或付款时超时），助手不会再点付款、提交、发送、删除这类会重复出事的按钮；看页面、开新页面、关弹窗照常。助手只在页面上核验一次；核验不了，就告诉你哪一步没确认、没有重做，请你看一眼。点了按钮页面弹出确认框时，助手马上就能看到，按你的要求确认或取消。

回答正文的字体与字号设置见[阅读外观](../reading-appearance.md)。

## 数据和权限

扩展需要页面访问、标签页、脚本执行、调试、下载和 offscreen 文档等权限，以完成观察与操作。下载权限用于确认页面下载是否完成；它覆盖整个浏览器配置的下载记录，助手只认自己在当前页面触发的那一次下载，不删除你下载文件夹里的文件。使用 `chrome.debugger` 时，Chrome 可能显示正在调试的提示条。

任务所需的文字、页面内容或截图会发送给配置的模型服务；语音输入发送给阶跃服务。

任务的诊断记录和语音每一轮的识别文字留在本机浏览器里（不存录音），可在设置页「诊断记录」导出或清空；模型凭据由对应配置管理。提交、发布、删除等行为按任务指令执行，你可随时中止或接管，具体边界见[协议](../protocol.md)和[人机协作约定](../human-ai-contract.md)。

**警告：** 在不信任的页面上让助手动手前，请先留意页面内容。不再逐步确认后，网页里藏的恶意指令可能让助手在已登录的网站上点击、发送或提交。

## 任务卡与引用

多步任务在消息流里显示可折叠任务卡。卡片列出目标、作用网站、已完成/待执行/受阻/结果未知项，以及送入任务的材料。材料不是已核实的来源；步骤完成数不是整个用户目标的成功保证。执行中的活动单独显示，不假造步骤或进度。

只有原任务有恢复依据且当前状态允许时，卡片底部才出现「继续原任务」。请求中、超时与失败仍如实显示；中止的任务不能通过此入口复活。

划词工具条可直接点「转入侧栏」。按 `⌘J` 打开的阅读卡即使还没有回答，也能点「在侧栏继续」。选区进入输入框上方的引用条，输入框获得焦点，不自动发送。去掉引用不清空已输入正文。

## 页面伴读交互

- **掀开原文**：使用仅译文模式后，按住译文覆盖层查看原文，松开或移出后复位。双语模式保留原译文并列显示。详见[整页翻译](../page-translation.md#可掀开的仅译文)。
- **边注模式**：输入区上方选择关闭、原文摘录或 AI 解释。启用时进入伴读导轨；原会话保留，关闭或发送提问后返回会话。默认关闭；选择 AI 后，停在段落上才生成解释。关闭或关闭侧栏停止后续请求。解释发送给设置里选的模型，仍可能出错；原文模式不调用模型。选择仅保留到侧栏关闭。
- **拖拽投喂**：网页正文不整块拖，划词照常。选中任意文字后按住选区稍停再拖到输入区，材料就是选中的那段；表格和代码块悬停时左上角出现把手，按住把手拖整块。松手生成带 ✕ 的材料胶囊和提问草稿。已有正文保留，点击发送才把材料交给模型。来源变化或内容过长时不添加。
- **直连按钮**：当前页有媒体、播放器的「下一个」或长代码块时，顶栏下方出现「暂停/播放」「下一个」「折叠/展开代码」。点了直接在页面上做，不调用模型；页面正中浮起一枚提示，侧栏显示耗时和「没用模型」。浏览器不让直接播放时如实提示，请在页面上点一下。
- **写到一半改方向**：任务运行时输入区上方出现「改成对比表格」「浓缩成 3 句话」。点它或直接打字回车，不用先停：模型正在写的回答当场停下，按新要求重写，新回答前标「已改方向」。模型正在操作页面时，补充等这一步做完再生效。
- **数字反查**：本轮文字请求的回答中，能在请求页面唯一匹配的完整数字生成定位胶囊。点击后回到原位置并短暂高亮。来源导航、文字变化或重复匹配时拒绝定位；没有可靠来源的历史回答不生成胶囊。它证明原文位置，不证明模型解释正确，也不承诺所有数字都能反查。

## 看着它做与顺手的小交互（10-05，未经真人试用）

- **光标旁白**：助手点击、填写时，助手的光标旁挂一句短话，如「我在点「提交」」「我在填「日期」」；做完随光标收起。状态仍在页面右上角。
- **侧栏动作卡**：任务运行时运行块自动展开，每步一行「点「提交」」「填这一栏」，用词与光标旁白相同；模型的过程旁白夹在卡片之间。结束后收成「做了 N 步」，可再展开。填写步骤在侧栏里暂时叫不出字段名。
- **Shift+悬停链接**：按住 Shift 在普通链接上稍停，链接下方出现预览卡（网站、标题、几行要点，直接从网页取，不经模型）；松开或移开即收起，点击照常跳转。不带登录状态取页。设置「划词」里可关。
- **回答出处**：带真实已读页面记录的回答顶上显示「读了 N 个网站」，正文里指向已读页面的链接带数字角标。点开会切到（或新开）那一页，能定位就高亮原段落，否则提示「已打开来源页」，并把这一页挂到输入框上方，下一句提问带上它。
- **圈出来问**：输入区 + 菜单「圈出来问」（侧栏有焦点时 ⌘/Ctrl+Shift+S），在页面上按住拖动画圈，可以连圈几处。每圈一处，输入框上方多一张带编号的截图；去掉一张，页面上那一圈也去掉。圈里的网页文字随图一起交给助手（输入框里的值不带），助手能说准圈的是哪个商品。回答里的 ①② 能点：页面滚回那一圈，再用蓝色手绘圈指一下；那一圈已经不在（页面变了或又圈了新的一组）就写「原处已变化」。Esc 退出，已圈的留着；不自动发送。
- **/ 技能**：输入框开头打 `/` 列出保存的提示词，选中后正文放进输入框，你按发送才跑；带问题的技能先问清再开始；悬停自己发过的消息可「存成技能」，列表末尾「管理技能」可增删改。自带的几条可删。
- **主动建议**（设置「划词」里打开，默认关）：在一页停留一阵且滚动或选过文字后，模型判断一次有没有值得做的下一步（对比两篇、记下观点、比价、翻译等，不限这些）；有把握且能引用原文时出一张一句话的卡，第一个词就是按钮（如「申请 | 晚退房到 14:00 · 全季酒店」），下面一行写出处。侧栏开着时卡出在对话流里：按第一个词就做，卡原位变成这一轮的开头，步骤和回答接在下面；点句子其余部分把这件事放进输入框；悬停出 ×。侧栏关着时卡出在页面右下角，点了打开侧栏并填进输入框。每次判断（出没出卡、卡写了什么）记进本机诊断记录，可在设置导出回看。同一页只判断一次，两张卡之间有间隔，× 后本次不再出现。
- **继续上次的事**（设置里打开，默认关）：新会话起点出现几张卡。卡片来自本机记录里中断的任务、等你回话的会话、没做完的过往任务和出错的阅读追问；按钮回到原任务、会话或页面，不直接动手。× 后一段时间不再出现。
- **划词朗读**：划词条「朗读」用浏览器自带声音读选中文字，当前句高亮，底部小播放条可暂停、调速、关闭。不发起页面任务。
- **语音胶囊**：语音时状态显示为「正在听」「正在想」「正在说」；说话时当前句高亮；有真实来源时显示「N 个来源」。
