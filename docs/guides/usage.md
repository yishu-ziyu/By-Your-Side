# 使用说明

[文档导航](../README.md) · [当前状态](../STATUS.md) · [源码安装](getting-started.md)

本页写用户能看到的交互和边界。某项功能现在做到哪，只看[当前状态](../STATUS.md)。

## 可以做什么

| 场景 | 你可以这样说 | 助手做什么 |
|---|---|---|
| 理解页面 | “读一下这篇文章，总结主要观点。” | 读页面，整理回答；执行过程可展开 |
| 阅读时追问 | 选中文字后按 `⌘J` | 在页面内解释、翻译和连续追问；可转入侧栏继续 |
| 整页翻译 | “把这页翻译成中文，只保留译文。” | 译文原地替换原文；可切换双语或仅译文、换字体、恢复原文 |
| 网页操作 | “把这几条结果的标题和链接整理给我。” | 导航、搜索、点击、填写、截图和多步网页操作 |
| 在页面上圈给你看 | “在页面上圈出五小时用量。” | 用手绘框圈住目标，名称和旁边的数值圈在同一个框里 |
| 修改执行中的要求 | “预算改成六百，其他条件不变。” | 把修改送进原任务；页面和任务归属不变 |
| 记住你的资料和偏好 | “我的邮箱是 …” | 自动记下你说过的个人资料（可撤销）；可修改、忘记，可限定网站 |

页面内的阅读问答有自己的上下文。所以助手不把每一次阅读追问都当成对后台任务的修改。整页翻译不翻图片里的文字、PDF 和跨域 iframe。

## 快速模型和备用模型

两项都在设置页选，都只列出已连接的服务商。不选时，助手只用主模型。

- **快速模型**用于划词「解释」、整页翻译和[目标核对](../goal-check.md)。快速模型一个字都没出就失败时，助手改用主模型再答一次。目标核对在回答显示之后才运行，所以不拖慢回答。
- **备用模型**只在主模型出错时接手。规则见[模型出错](../model-effort.md#主任务的模型服务出错)。

阶跃的文字模型每次回答前都先思考，这一步关不掉。所以阶跃文字模型用作快速模型时很慢。

## 语音交互

点输入区的「语音」开始。语音开着时，文字输入照常可用。

- 点完「语音」就可以开口，开麦那几秒说的话不会丢。
- 语音服务偶尔整段没有反应。这时扩展自动重连，并请你再说一遍。
- 补充原任务：普通修改直接送进原任务，任务身份不变。
- 停声：说“别说了”或点「停声」只停声音，不中止网页任务。完整边界见[语音架构](../voice-architecture.md)。
- 中止任务：任务运行中说“终止任务”，助手直接中止，不再复述确认。
- 独立要求的排队与准入见[任务调度](../voice-dispatch.md)。

**按住说话**让你不开侧栏也能交代一句话：在网页上单独按住右 ⌥ 说话，松开后这句话交给助手。地址栏和 Chrome 自带页面上不能用。按住时，网页底部的听写胶囊显示进度和结果；任务在跑时，按 Esc 停下。填了 MiniMax 订阅 Key 后，助手做完会念出结果，念的时候按 Esc 只停声音。

## 文件、截图和下载

- 你要 CSV、Markdown、网页这类文件时，助手写好文件，在回答下方显示文件卡片，可以打开或下载。PDF、Word、Excel 这类二进制格式暂不支持。规则见[文件卡片与截图](../artifacts.md)。
- 打开的网页文件在隔离区里运行，读不到扩展的密钥、记忆和设置。但是它能加载网上的脚本和图片，和你下载后自己打开一样。
- 你要截图时，截图进回答下面的卡片。助手为了看清页面自己截的图不进会话。
- 你让助手下载页面上的文件时，文件进你的下载文件夹。只有 Chrome 报告下载完成，回答才说文件已保存。Chrome 判为可能有害的文件，要你自己点「保留」。见[下载](../downloads.md)。

## 会话、页面和记忆

### 会话

- 每个会话分别保存消息、目标、草稿和附件。打开侧栏时回到上次的会话；点「＋」才新开会话。
- 切换会话不中止后台任务；关闭语音也不中止网页任务。
- 你选了新模型以后，助手确认收到了，侧栏显示的主模型才改变。

### 回答和执行过程

- 动过页面的回合，在回答上方留一行「做了 N 步 · 耗时」，可以展开看逐步动作。
- 任务没做完时，回答下方写还缺什么。中断、出错或还有未完成步骤时，你可以点「继续」。
- 助手想把已经做成的一步再做一遍时，程序拦下这一步。这一步不算没做成。
- 侧栏只显示人话，不出现工具名、元素编号或原始报错。这些原文只留在诊断记录里。

### 断线和重启

- 中断后，助手不自动重放旧动作。保留上下文不等于恢复执行。
- 侧栏与扩展后台断开时，你按发送，输入框里的正文、引用和附件都留着，并提示这条没有发出去。连上后，你再发一次。
- 扩展内的助手重启后（崩溃、被 Chrome 回收或扩展重载），会话、任务检查点和文件都还在。

### 你和助手交替操作页面

- 助手操作页面时，你点「接管」，助手立刻停手。你改完点「交还」，助手先重读你改过的页面，再在同一个任务里接着做；你在暂停期间写的补充一起带上。
- 关掉侧栏后，任务照常继续。任务在做、暂停等你或出错时，你正在看的标签页右边缘留一颗边缘药丸。这个标签页不一定是任务所在的标签页。

### 记忆

记忆怎么分类、为什么这样设计，见[记忆模型](../memory-model.md)。你能看到的部分：

- 你亲口说过的关于自己的资料，助手自动记下，并在会话里给「撤销」。网页上出现的内容、网页里要求“记住…”的文字、密码、验证码和卡号都不记。
- 助手按记忆填的输入框带「记得的」小标签，点标签可以改、这次不用或忘掉。
- 你纠正助手后，如果助手能归纳出以后照做的做法，就问你要不要记住。你点「记住」才生效，可改范围或撤销。
- 做成了事的任务结束时，助手留一条过往任务。你回到同一网站时，助手知道之前做过什么，但页面上的价格这类信息它会重新看。
- 「记忆」面板里可以查看、修改、删除或清空。卸载扩展时，记忆一起删除。

### 任务跨轮

- 任务没做完就结束时，你随口补一句，不用说“继续”，助手就从原任务接着做。
- 任务的下一步在别的网站时（例如去邮箱点确认链接），助手自己打开那个网站去做。只有登录、验证码、付款和只有你能做的选择，助手才交给你。
- 原因在网站那边（连不上、页面不存在、拒绝访问）时，助手说明一次就停。你说“再试”，助手接着做。

### 网页操作不逐次确认

- 助手在网页上的操作直接执行，不逐次请你确认，见[网页操作不再逐次确认](../browser-confirmation.md)。想先看一眼再提交，就在任务里说明，或随时中止、接管页面。
- 某一步查不清是否生效时，助手重读页面，没生效就再做一次。所以偶尔会把同一个按钮点两次。付款按钮仍由你自己点。

## 数据和权限

扩展申请的权限以 [`manifest.json`](../../extension/manifest.json) 为准。你可能注意到的两点：

- 助手使用调试接口操作页面时，Chrome 可能显示正在调试的提示条。
- 下载权限覆盖整个浏览器配置的下载记录。助手只读取它操作期间、同一网站开始的下载状态，不删除你下载文件夹里的文件。

数据去向：任务需要的文字、页面内容或截图，发给你连接的模型服务。诊断记录和语音的识别文字留在这个浏览器里，不存录音。本机的诊断记录保留原文（例如填写的内容、助手写的脚本），只遮住密码栏的值、密钥、令牌和 Cookie 这类凭据。你可以在设置页导出或清空；导出的文件再遮住填写的内容、读回的内容和脚本。

**警告：** 在不信任的页面上让助手动手之前，先看一眼页面内容。因为网页操作不再逐次确认，网页里藏的恶意指令可能让助手在已登录的网站上点击、发送或提交。

## 任务卡与引用

- 任务卡里的材料不是已核实的来源。步骤完成数也不保证整个目标达成。
- 已中止的任务不能从「继续原任务」复活。
- 从划词工具条或阅读卡转入侧栏后，选中的文字进入引用条，消息不自动发送。

## 页面伴读交互

- **掀开原文**：仅译文模式下，按住译文可以看原文，详见[整页翻译](../page-translation.md#可掀开的仅译文)。
- **拖拽投喂**：拖已选文字，或按住表格、代码块的把手，拖到输入区，就成为材料。你点发送，材料才交给模型。
- **直连按钮**：当前页有媒体、播放器或长代码块时，侧栏出现对应按钮。点按钮，助手直接在页面上做，不调用模型。
- **写到一半改方向**：任务运行时直接打字回车，不用先停。模型正在写的回答当场停下，按新要求重写。如果模型正在操作页面，你的补充等这一步做完再生效。
- **回答出处**：回答下面的「来源」只列这一轮真实读过的页面。点来源，主窗口切到那一页；能定位就高亮原段落。
- **数字反查**：回答里能在原页面找到唯一位置的数字带虚下划线，点它回原页定位。这只证明原文位置，不证明模型解释正确。
- **圈出来问**：从输入区 + 菜单选「圈出来问」，在页面上画圈，可以连圈几处。圈里的网页文字随截图一起交给助手，输入框里填的值不带。圈完不自动发送。
- **/ 技能**：在输入框开头打 `/`，列出保存的提示词。选中后，你按发送才运行。
- **@ 拉入标签页**：在输入框打 `@`，列出打开的标签页。选中后变成一枚页面胶囊。扩展后台读到正文才标已读；读不到会划线并写出原因。
- **三行计划**：任务要写页面或跨站时，发送前先出现会去、会做、不会做。「开始」才动手；「改一下」把计划放进输入框。只读、同一站的提问不出现这张卡。
- **结果主动作**：每条回答末尾有一个主动作（表格是「复制为表格」，改过页面是「在页面上查看」，否则是「复制」）。`Ctrl+Shift+K`（macOS 为 `⇧⌘K`）打开动作列表，和 `/` 技能分开。不用 `Ctrl+K`，以免和 Chrome 地址栏抢键。
- **主动建议**（默认关）：你在一页停留并滚动或选过文字后，模型判断一次有没有值得做的下一步。卡上的引文必须逐字出现在页面里，否则不出卡。
- **继续上次的事**（默认关）：新会话的起点出现中断或没做完的事。按钮带你回到原处，不直接动手。
- **光标旁白**：助手点击、填写时，光标旁挂一句短话说明在做什么。
- **Shift+悬停链接**：按住 Shift 在链接上稍停，出现预览卡。预览直接从网页取，不经过模型，也不带登录状态。设置页可以关掉。
- **划词朗读**：用浏览器自带的声音读选中的文字，不发起页面任务。
