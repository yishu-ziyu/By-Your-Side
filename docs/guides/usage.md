# 使用说明

[文档导航](../README.md) · [当前状态](../STATUS.md) · [源码安装](getting-started.md)

本页描述交互及边界，功能是否已加载、哪一轮验收通过只看当前状态。

## 可以做什么

| 场景 | 你可以这样说 | 能力 |
|---|---|---|
| 理解网页 | “读一下这篇文章，总结主要观点。” | 读取页面、整理回答，按需展开执行过程 |
| 阅读时追问 | 选中文字后按 `⌘J` | 在页面内解释、翻译和连续追问；可转入侧栏继续 |
| 整页翻译 | “把这页翻译成中文，只保留译文。” | 双语或仅译文，切换显示、字体与恢复原文 |
| 操作浏览器 | “把这几条结果的标题和链接整理给我。” | 导航、搜索、点击、填写、截图及多步网页操作 |
| 在页面上圈给你看 | “在页面上圈出五小时用量。” | 手绘框圈住目标；名称和旁边的数值圈进同一个框，名牌放在不压字的空白处 |
| 修改执行中的要求 | “预算改成六百，其他条件不变。” | 将修改送到原任务，保留页面与任务归属 |
| 增加独立任务 | “同时在新标签页打开另一个网站。” | 登记独立要求，安排执行，并把结果送回当前语音 |
| 记住明确偏好 | “请记住，我希望先看中文摘要。” | 保存、修改和忘记显式记忆，支持网站范围 |

页面内阅读问答有独立的上下文，不会把每一次阅读追问都当作对后台任务的修改。整页翻译目前面向可访问的网页 DOM，不覆盖图片 OCR、PDF 或跨域 iframe。

## 显示操作更快一步

在已经翻译的页面上，“改成宋体”“只显示译文”“切回双语”可以交给可选的 TypeSafe Jev 判断，直接调用原有浏览器工具，减少一次主模型规划。没有配置 Jev 时，仍使用原有任务模型。

小样本耗时数据与降级条件见[接入与验收](../evals/20260918-jev-display-integration.md)，不代表所有浏览器任务的性能。

## 语音交互

点击输入区的“语音”，首次使用时允许麦克风访问。文字输入仍然可用。

- **补充原任务**：普通修改直接送达，任务保持原有身份。
- **提出独立要求**：共享来源页面的要求会等待；并发与等待名额满时给出反馈。具体准入约束见[任务调度](../voice-dispatch.md)。
- **停止播报**：“别说了”控制声音，不等于取消网页任务。
- **控制指定任务**：可以按明确任务名称查询、修改或取消；页面接管与任务控制另有执行回执。
- **接收多个结果**：关联任务的结果回到原语音，按各自任务身份校验、排队播报。
- **终止任务**：任务运行中说“终止任务”会直接终止，不再复述确认；停下后才说“已终止”。
- **人设与音色**：在设置页“实时语音”里分别选择。人设可选默认、罗宾式或自定义描述，只影响语气和措辞；下次开启语音时生效。

只装扩展时，模型在侧栏「更多 → 模型与语音」里配置：保存后，新建的对话马上用新模型，已有对话也会跟着切换。

日常语音使用 StepAudio 3 Realtime；不提供 2.5 切换或回退。“停声”按钮只停声音，不取消后台任务。实现和完整边界见[语音架构](../voice-architecture.md)，历史验证见[日常迁移](../evals/20260920-realtime3-daily.md)。旧语音测试不代表新版本真人体验通过。

## 会话、页面和记忆

回答按稳定节奏逐字淡入，不随模型输出忽快忽慢；历史记录和系统“减少动态效果”时整段显示。动过页面的回合在回答上方留一行“做了 N 步 · 耗时”（运行中它显示当前在做什么，如“正在复核目标证据”），展开是逐步的动作清单（✓ / ✕）。没做完时回答下方只留一行说明还缺什么：助手在回答里列出了缺什么时，直接在输入框回复，不出现“继续”；中断、出错或还有记录在案的未完成步骤时，仍可点“继续”。

多个会话分别保存聊天、目标、草稿与附件。切换侧栏会话不会取消后台任务；关闭语音也不会停止网页执行。中断后不会自动重放旧动作；“继续原任务”的当前可用范围以 STATUS 中的真实恢复记录为准，不能把保留上下文等同于恢复执行。

网页操作携带会话、任务与控制版本。同页共享或移交通过已有协调机制处理，不能仅凭 `tabId` 绕过页面归属。你可以接管页面，再交还给助手。

明确说“请记住……”保存偏好，可在记忆管理中查看、修改或忘记。网站范围内的记忆只用于相关站点；忘记会停止后续检索和注入，不删除既有聊天记录。

可选的 [EverOS 桥接](../integrations/everos.md)需要单独部署，普通安装不会自动启用。它与显式记忆的职责、数据边界分别维护，不把生成经验视为执行授权。

回答正文的字体与字号设置见[阅读外观](../reading-appearance.md)。

## 数据和权限

扩展需要页面访问、标签页、脚本执行、调试和 Native Messaging 等权限，以完成观察与操作。使用 `chrome.debugger` 时，Chrome 可能显示正在调试的提示条。

任务所需的文字、页面内容或截图会发送给配置的模型服务；语音输入发送给阶跃服务；可选 Jev 判断使用 TypeSafe 服务。本地伴随进程不意味着模型推理离线。

会话、任务回执、记忆和日志主要保存在 `~/.sideagent/`；只装扩展时，任务的诊断记录和语音每一轮的识别文字留在浏览器本地（不存录音），可在设置页「诊断记录」导出或清空；模型凭据由对应配置管理。提交、发布、删除等行为受任务指令、授权与接管流程约束，具体边界见[协议](../protocol.md)和[人机协作约定](../human-ai-contract.md)。
