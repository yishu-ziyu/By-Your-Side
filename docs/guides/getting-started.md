# 源码安装

[文档导航](../README.md) · [使用说明](usage.md) · [开发检查](../development/checks.md)

本产品是开发预览版。本页写 macOS + Chrome 上的源码安装方式；三系统的成品分发尚未完成。

产品只有扩展一种形态：任务核心运行在扩展内，不用另装本机程序（见[路线图](../ROADMAP.md)第 9 条）。

## 1. 构建扩展

需要 Google Chrome，以及用于构建的 Node.js **22.19 或更高版本**、npm、Git。

```bash
git clone https://github.com/yishu-ziyu/By-Your-Side.git
cd By-Your-Side
npm ci
npm run build
```

构建结果在 `extension/dist/`。依赖版本由仓库锁定，不用修改全局 npm 配置。

## 2. 加载扩展

1. 打开 `chrome://extensions`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本仓库的 `extension/dist/`。
3. 点击工具栏的 **By Your Side** 图标，打开侧栏。扩展页显示的版本应与 `extension/manifest.json` 一致。
4. 更新源码后，重新运行 `npm run build`，再在扩展页点「重新加载」。

扩展申请的权限见[数据和权限](usage.md#数据和权限)。其中「不限存储」让记忆和过往任务不受浏览器默认的存储配额限制；Chrome 安装扩展时不为这项权限额外弹提示。如果你已加载旧版，在扩展页点「重新加载」后，扩展才拿到新增的权限。

## 3. 配置模型

打开侧栏「更多 → 模型与语音」，配置文字模型和凭据。模型用量由对应服务计费。凭据保存在 Chrome 的本地扩展存储里。
扩展不从 `~/.pi/agent/` 或 `~/.sideagent/` 读取凭据；所以用过 Pi CLI 的用户也要在设置页重新填写。恢复与持久化的边界见[当前状态](../STATUS.md)。

阶跃的文字模型走 Step Plan 通道，消耗套餐 Credit。按开放平台 API 计费的只有实时语音，因为实时语音不在 Step Plan 的模型列表里。同一个 Key 能调用两个通道；扣哪边的费用只由请求地址决定。

在设置页更换文字模型后，当前会话也改用新模型；运行中的任务，下一次模型请求可能就用新模型。

只有在设置页设了快速模型时，主模型出错后任务才改用快速模型接着做。这项切换的范围和限制见[主任务的模型服务出错](../model-effort.md#主任务的模型服务出错)。

## 4. 可选：语音

在同一设置页填写阶跃语音 Key，也可以沿用阶跃文字模型的 Key。实时语音由开放平台按账号规则计费。不配置语音，不影响文字功能。
